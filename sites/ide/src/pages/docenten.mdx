# Docentenhandleiding

Praktische informatie voor docenten die deze online editor in de les willen gebruiken.

## Wat is dit?

Een **online code-editor** waarin je leerlingen direct in de browser code schrijven en draaien — geen installatie, geen account. Anders dan de andere cursussen is dit geen lessenreeks, maar **gereedschap**: een snelle plek om iets te demonstreren of leerlingen vrij te laten experimenteren naast de cursussen [Python](https://python.coderius.nl), [Webontwikkeling](https://web.coderius.nl) en [Python Games](https://play.coderius.nl).

## Technische randvoorwaarden

| Wat | Antwoord |
|---|---|
| Operating system | Alles met een moderne browser — ook Chromebook |
| Installatie | Geen — alles draait in de browser |
| Account | Niet nodig |
| Internet | Vereist |

## Klassikaal gebruik

- **Demonstreren**: typ live een voorbeeld en draai het op de beamer, zonder setup.
- **Vrij experimenteren**: laat leerlingen een idee uitproberen voordat je het in een cursus formaliseert.
- **Snelle check**: een leerling kan hier even een stukje code testen zonder de eigen omgeving te verlaten.

Omdat er geen opdrachten of voortgang in zitten, beoordeel je hier niets — gebruik de editor als hulpmiddel bij de inhoudelijke cursussen.
