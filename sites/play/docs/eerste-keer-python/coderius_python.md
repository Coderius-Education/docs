# Python leren via coderius-python

Programmeer je voor de eerste keer? Dan is <SiteLink site="python" to="/">coderius-python</SiteLink> de kortste route naar coderius-play. Je hoeft niets te installeren: je typt je code in de browser en klikt op uitvoeren.

De cursus begint bij je naam op het scherm zetten en werkt in dertien lessen toe naar lijsten en dictionaries. Elke les heeft opdrachten met een tip en een uitgewerkte oplossing, zodat je verder kunt als je vastloopt.

## Wat je nodig hebt voor coderius-play

Je hoeft niet de hele cursus af te maken. Voor de eerste hoofdstukken van coderius-play is dit genoeg:

1. <SiteLink site="python" to="/docs/basis/jouw-naam-op-het-scherm">Jouw naam op het scherm</SiteLink> — je eerste regel code
2. <SiteLink site="python" to="/docs/basis/jij-als-variabele">Jij als variabele</SiteLink> — waarden bewaren onder een naam
3. <SiteLink site="python" to="/docs/functies/functies">Functies</SiteLink> — hoe `def` werkt, want zo reageert je spel straks op toetsen

De rest kom je vanzelf tegen. Elke les in coderius-play die iets uit de python-cursus gebruikt, heeft een blok "Hier bouw je op verder" met een link naar de juiste les.
