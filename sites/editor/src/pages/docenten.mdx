# Docentenhandleiding

Praktische informatie voor docenten die deze cursus klassikaal willen inzetten: wat de site is, welke randvoorwaarden er zijn, en hoe je de lessen indeelt.

## Wat is dit?

Een cursus voor leerlingen die voor het eerst met een **code-editor** werken. Je leerlingen installeren VS Code en leren ermee werken voor websites en Python, plus de basis van **Git & GitHub**. Doelgroep: leerlingen die de stap van online-editors naar een echte ontwikkelomgeving zetten.

## Technische randvoorwaarden

| Wat | Antwoord |
|---|---|
| Operating system | Windows, macOS of Linux |
| Software | VS Code en Git (gratis; installatie wordt in de cursus uitgelegd) |
| Account | Een GitHub-account voor het Git-deel |
| Internet | Vereist — voor de installatie en GitHub |

## Didactische aanpak

Dit is een **doe-cursus**: je leerlingen volgen stapsgewijze instructies en voeren ze meteen uit in hun eigen editor. Waar een handeling op meerdere knoppen kan, staat een kort "welke knop"-overzicht. Sneltoetsen worden voor zowel Windows/Linux (Ctrl) als Mac (Cmd) genoemd.

Laat je leerlingen elke stap zelf uitvoeren in plaats van mee te kijken op de beamer — de routine zit in de herhaling.

## Klassikaal gebruik & differentiatie

- **Plenair starten**: doe de installatie samen voor; daarna werken je leerlingen zelfstandig door de tracks.
- **Snelle leerlingen** gaan door naar Git & GitHub of een eigen project.
- **Langzamere leerlingen** blijven bij de installatie en het web- of Python-spoor.
- **Beoordelen**: laat leerlingen een klein project committen en pushen naar GitHub.
