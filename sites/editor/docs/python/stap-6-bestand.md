# Stap 6: een Python-bestand maken en uitvoeren

Je omgeving staat klaar. Tijd om te controleren of er ook echt Python in draait.

1. Klik met de rechtermuisknop in de Explorer, het linker paneel van VS Code
2. Kies **New File...**
3. Noem het bestand `main.py`
4. Typ deze regel in het bestand:

```python
print("Hallo wereld")
```

5. Sla het bestand op via **File** → **Save**
6. Klik op de **▶ Play-knop** rechtsboven in de editor

## Wat je nu ziet

Onderaan opent de terminal en daar staat `Hallo wereld`. Vóór de prompt staat `(.venv)`: VS Code heeft je virtual environment gebruikt.

Ontbreekt de Play-knop, dan mist de Python-extensie uit [stap 5](./stap-5-vscode).
