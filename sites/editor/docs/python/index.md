# Python in VS Code

In zeven stappen zet je Python klaar voor een eigen project: je maakt een map, installeert Python, geeft het project zijn eigen afgesloten omgeving en opent het in VS Code.

## Voorbereiding

VS Code moet al op je computer staan, en tijdens die installatie moet het vakje **Add to PATH** aangevinkt zijn geweest. Zonder dat vakje kent je terminal het commando `code` niet, en dat gebruik je in stap 5. Zie [Installatie VS Code](/installatie-vscode/).

## De route

1. [Een projectmap aanmaken](./stap-1-projectmap) in de Verkenner
2. [PowerShell openen](./stap-2-powershell) vanuit die map
3. [Python installeren](./stap-3-installeren) met `python`
4. [Een virtual environment aanmaken](./stap-4-venv) met `python -m venv .venv`
5. [Je project openen in VS Code](./stap-5-vscode) met `code .`
6. [Een Python-bestand maken en uitvoeren](./stap-6-bestand)
7. [Packages installeren](./stap-7-pip) met `python -m pip install`

De volgorde ligt vast: elke stap gebruikt wat de vorige heeft neergezet. Loopt er iets vast, kijk dan bij [Er gaat iets mis](./problemen).
