# Stap 2: kijken wat git ziet met `git status`

De map is al een repository — dat deed je in stap 1. `git status` is vanaf nu je meest gebruikte commando: het vertelt je welke bestanden veranderd zijn, welke al klaarliggen voor een commit, en welke git nog niet kent.

Een nieuw bestand dat git nog niet kent heet **untracked** (niet-gevolgd).

```bash
git status
```
