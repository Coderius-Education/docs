# Git basis

In deze tutorial leer je de basis van **git**: een programma waarmee je versies van je code bijhoudt. Je oefent eerst in een veilige simulator in je browser. Daarna zet je in [Git in VS Code](/git/vscode/) hetzelfde op je eigen computer.

## Wat is git?

**Git** is een **versiebeheer**-systeem. Stel: je hebt een werkende website en je gaat hem aanpassen. Wat als je nieuwe versie kapot gaat? Met git kun je elke werkende versie als "snapshot" opslaan. Een snapshot heet een **commit**. Je kunt altijd terug naar een vorige commit.

Git werkt met drie zones:

- **Werkmap** — de bestanden waar je op dit moment in zit te typen.
- **Staging** — een soort wachtkamer voor wijzigingen die je in de volgende commit wilt meenemen.
- **Repository** — alle opgeslagen commits (de geschiedenis).

In elke stap van deze tutorial zie je een simulator. Bovenaan staan de drie zones. Daaronder zit een terminal waarin je `git`-commando's typt.

Twee dingen die het typen makkelijker maken, precies zoals in een echte terminal:

- **Tab** vult aan. Typ `git st` en druk op Tab, en er staat `git status`. Passen er meerdere, dan laat de terminal ze zien.
- **Pijltje omhoog** haalt je vorige commando terug.

Vanaf stap 2 begin je niet meer met een lege map: wat je in de vorige stap deed staat al gedaan in de terminal, in lichtere letters. Je hoeft dus niet elke keer opnieuw `git init` te typen.

## Git antwoordt in het Engels

De simulator drukt precies af wat echte git afdrukt, en dat is Engels. Dat is expres: straks typ je dezelfde commando's in VS Code, en dan wil je die regels herkennen in plaats van ze voor het eerst te zien.

De belangrijkste woorden kom je overal tegen:

| Wat git zegt | Wat het betekent |
|:---|:---|
| `untracked` | git kent dit bestand nog niet |
| `Changes to be committed` | dit ligt klaar in staging |
| `Changes not staged for commit` | dit is veranderd, maar ligt nog niet klaar |
| `nothing to commit, working tree clean` | alles is opgeslagen |
| `fatal:` | dit ging mis, git heeft niets gedaan |
| `hint:` | een tip — in de simulator staan die in het Nederlands |
