# Stap 8: controleer met `git log`

Open de terminal in VS Code via **Terminal** → **New Terminal** en typ:

```bash
git log
```

Je ziet beide commits, nieuwste eerst. Dit is exact hetzelfde commando als in de simulator — alleen draait het nu op je echte computer met echte bestanden.

Druk op **q** om het log te sluiten. Git toont lange uitvoer in een venstertje waar je met de pijltjes doorheen scrolt; **q** staat voor *quit*.

## Wat je nu ziet

Twee blokken, met bovenaan je laatste commit. Bij elke commit staat je eigen naam en e-mailadres — die uit stap 1. Achter de bovenste staat `(HEAD -> main)`: dat is waar je nu bent.
