# 1.8 Het complete algoritme

**Leerdoel:** je herkent alle bouwstenen die je hebt geleerd en ziet ze
samen werken. Daarna onderzoek je het algoritme als geheel.

## Alles samen

Hier is het hele algoritme, in 5 regels:

<CodeUitleg>

```python showLineNumbers
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1
```

<Regel n={2}>
**Bouwsteen 1** — door de lijst lopen. `enumerate` geeft je elke ronde de index én de waarde tegelijk.
</Regel>

<Regel n={3}>
**Bouwsteen 2** — vergelijken met het doel.
</Regel>

<Regel n={4}>
**Bouwsteen 3** — de index teruggeven bij een match. `return` stopt meteen de functie én de lus: verder zoeken is niet meer nodig.
</Regel>

<Regel n={5}>
**Bouwsteen 4** — deze regel wordt alleen bereikt als de lus afloopt zonder match. Let op de inspringing: hij staat buiten de `for`, op functie-niveau.
</Regel>

</CodeUitleg>

## Onderzoek

Speel met de code. Probeer in elk geval:

1. Zoek een waarde die **meerdere keren** voorkomt. Welke index krijg je?
2. Vervang de lijst door strings: `["appel", "peer", "kers"]`, doel
   `"peer"`. Werkt het?
3. Wat gebeurt er als de lijst **leeg** is?

<PyRunner initialCode={`def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1

# Experimenteer hier:
print(zoek([7, 7, 7, 7], 7))
print(zoek(["appel", "peer", "kers"], "peer"))
print(zoek([], "iets"))`} />

<details>
<summary>Wat zie je?</summary>

```
0
1
-1
```

- Bij meerdere voorkomende waarden krijg je de **eerste** (index 0).
- Strings werken precies hetzelfde — `==` vergelijkt ook strings.
- Lege lijst → de `for`-lus draait 0 keer → meteen `return -1`.

Lineair zoeken is *type-onafhankelijk*: het werkt op alles waar `==`
betekenis heeft.

</details>

## Een korte reflectie

We hebben in 4 kleine stappen iets gebouwd dat:

- Werkt op **elke** lijst, gesorteerd of niet.
- Werkt op getallen, strings, en alles met `==`.
- Een heldere "niet gevonden"-conventie heeft (`-1`).
- In het ergste geval **alle** elementen bekijkt — O(n).

Tijd om er iets *anders* van te maken.
