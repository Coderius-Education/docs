# Bouwsteen 3 — de index teruggeven

<Voorkennis
  items={[
    {site: 'python', to: '/docs/functies/functies', label: 'Functies en return-waarden'},
  ]}
/>

**Leerdoel:** je verpakt je code in een **functie** en gebruikt `return` om
de **index** terug te geven waar je het doel vond.

<Voorkennis items={[{to: '/docs/lineair-zoeken/bouwen/04-doorlopen', label: 'enumerate (bouwsteen 1)'}]} />

## Wat we willen

Twee dingen tegelijk:

1. Niet alleen *melden* dat we het vonden, maar de **positie** (index)
   teruggeven.
2. Het geheel in een **functie** stoppen die we kunnen aanroepen — zo kun
   je hem op meerdere lijsten gebruiken.

Voor de index gebruik je `enumerate` uit [bouwsteen 1](./04-doorlopen):
`for i, waarde in enumerate(lijst)` geeft elke ronde de index én de waarde.

## Voorspel

Wat denk je dat dit print?

```python
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i

print(zoek([3, 1, 4, 1, 5], 4))
print(zoek([3, 1, 4, 1, 5], 1))
```

<details>
<summary>Antwoord</summary>

```
2
1
```

- `zoek([3, 1, 4, 1, 5], 4)` → 4 staat op index 2. De `return 2` stopt de
    functie direct.
- `zoek([3, 1, 4, 1, 5], 1)` → de **eerste** 1 staat op index 1. Daarna
    stopt de functie — de tweede 1 op index 3 zien we niet meer.

</details>

## Belangrijk: `return` stopt de functie

Zodra Python `return i` uitvoert, **springt de functie eruit**. De `for`-lus
gaat dus **niet** verder. Dat is precies wat we willen: stop bij de eerste
match.

## Wat als we het niet vinden?

Probeer dit:

<PyRunner initialCode={`def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i

print(zoek([3, 1, 4, 1, 5], 9))`} />

<details>
<summary>Wat zie je?</summary>

```
None
```

Als de functie **nooit** een `return` uitvoert, geeft Python automatisch
`None` terug. Dat is niet wat we willen — we beloofden eerder dat we `-1`
zouden teruggeven bij "niet gevonden". Dat lossen we in de volgende stap op.

</details>
