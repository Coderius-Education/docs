# Bouwsteen 8 — `max_value` en `min_value`

**Leerdoel:** je schrijft twee **recursieve** functies die voor elke
positie uitrekenen wat de beste haalbare utility is voor X (`max_value`)
of voor O (`min_value`). Het zijn de boom-doorlopers van de
pen-en-papier-pagina, maar dan in code.

## Wat doen deze functies?

Op de [pen-en-papier-pagina](../02-pen-en-papier) rekende je de waarde
van elke knoop van onderop terug naar boven. Die vraag — "wat is deze
positie waard?" — is precies wat `max_value` en `min_value`
beantwoorden.

- **`max_value(bord)`**: X is aan zet. Hoe goed kan het maximaal voor X
  uitpakken? Geeft `1`, `-1` of `0`.
- **`min_value(bord)`**: O is aan zet. Hoe laag kan O de uitkomst voor
  X drukken? Geeft `1`, `-1` of `0`.

> Let op: `max_value` geeft **niet de zet** terug — alleen het **getal**
> dat de positie waard is. De zet zelf bepaal je straks in `minimax`.

## Wat is recursie?

Een functie die zichzelf aanroept. Een klein voorbeeld dat **geen**
tic-tac-toe is:

```python
def aftellen(n):
    if n == 0:
        print("Klaar")
        return
    print(n)
    aftellen(n - 1)

aftellen(3)
```

```
3
2
1
Klaar
```

De functie roept zichzelf aan met een **kleinere** input, tot de
**stopconditie** `n == 0` geraakt wordt.

Drie ingrediënten van recursie:

1. **Base case** — een conditie waarbij het antwoord meteen bekend is,
   zonder nieuwe aanroep.
2. **Recursieve aanroep** — de functie roept zichzelf aan op een
   kleinere input.
3. **Zekerheid dat je er komt** — die kleinere input moet uiteindelijk
   bij de base case uitkomen.

## Het recept, in woorden

Zo beschrijft CS50 de twee functies, nog zonder Python:

```
max_value(bord):
    is het bord klaar?  →  geef utility(bord) terug
    v = min oneindig
    voor elke zet die kan:
        v = het hoogste van v en min_value(bord na die zet)
    geef v terug

min_value(bord):
    is het bord klaar?  →  geef utility(bord) terug
    v = plus oneindig
    voor elke zet die kan:
        v = het laagste van v en max_value(bord na die zet)
    geef v terug
```

Leg dat naast het recept van de pen-en-papier-pagina:

- **Base case** = een terminal bord. Daar is de utility al bekend, dus
  daar stopt de recursie: `terminal(bord)` en `utility(bord)` uit
  bouwsteen 6 en 7.
- **Recursieve aanroep** = "kijk wat de tegenstander daarna doet". Na een
  zet van X is O aan de beurt, dus `max_value` vraagt het aan
  `min_value`. En andersom. Dat is de afwisseling van MAX- en MIN-lagen
  in de boom.
- **Je komt er** omdat elke aanroep één cel meer gevuld heeft. Na
  hoogstens negen stappen is het bord vol.

De twee functies zijn elkaars spiegelbeeld: `max_value` begint op min
oneindig en houdt het hoogste bij, `min_value` begint op plus oneindig
en houdt het laagste bij. Voor "oneindig" heeft Python `math.inf`, na
`import math`. Je begint zo laag dat élke echte uitkomst hoger is.

## Kijk hoe de recursie de boom doorloopt

Dit is de positie van de pen-en-papier-pagina. De twee functies
hieronder zijn af, met één toevoeging: ze printen bij elke aanroep waar
ze zijn, ingesprongen per laag van de boom. De extra parameter `diepte`
dient alleen voor dat inspringen.

<GameTree bord="XXO/OOX/..." waardes />

Het is dezelfde wandeling als op de pen-en-papier-pagina, in dezelfde
volgorde: eerst de linkertak helemaal
naar beneden tot een `klaar`, dan de waarde weer omhoog, dan de
volgende tak. Elke regel `MAX` of `MIN` is één aanroep van `max_value`
of `min_value`; elke inspringing is een laag dieper in de boom. Pas
helemaal onderaan, als alle drie de takken terug zijn, kent de wortel
zijn waarde: `MAX geeft 0`.

## Specificatie

- **Input** voor beide: een `bord`.
- **Output** voor beide: een geheel getal `1`, `-1` of `0`.

## Voorspel

Wat geeft `min_value` terug op dit bord, waar X net gewonnen heeft?

```python
bord = [["X","X","X"], ["O","O",None], [None]*3]
```

<details>
<summary>Antwoord</summary>

**`1`** (de utility van X-wint).

Het bord is **terminal**, dus de functie gaat meteen de base case in:
`return utility(bord)` → `1`. Geen recursie, geen min of max. Op een
terminal bord is `min_value(bord) == max_value(bord) == utility(bord)`.

</details>

<details>
<summary>Tip</summary>

Begin **altijd** met de base case:

```python
if terminal(bord):
    return utility(bord)
```

Daarna een lus over `actions(bord)` die `v` bijwerkt. Twee dingen om
dubbel te checken:

1. In `max_value` roep je `min_value` aan, niet `max_value`. Zie ook
   [er gaat iets mis](../17-fouten).
2. De startwaarde moet zó zijn dat **élke** echte uitkomst beter is: voor
   `max` begin je op `-math.inf`, voor `min` op `math.inf`.

</details>

<summary>Antwoord</summary>

```python
def max_value(bord):
    if terminal(bord):
        return utility(bord)
    v = -math.inf
    for zet in actions(bord):
        v = max(v, min_value(result(bord, zet)))
    return v


def min_value(bord):
    if terminal(bord):
        return utility(bord)
    v = math.inf
    for zet in actions(bord):
        v = min(v, max_value(result(bord, zet)))
    return v
```

Precies het recept, regel voor regel. `max_value` roept `min_value`
aan en andersom: die afwisseling ís de boom.
