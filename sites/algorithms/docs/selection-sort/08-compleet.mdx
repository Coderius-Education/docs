# Het complete algoritme

**Leerdoel:** je ziet alle bouwstenen samen en onderzoekt het algoritme.

## Alles samen

<CodeUitleg>

```python showLineNumbers
def selection_sort(lijst):
    n = len(lijst)
    for i in range(n):
        min_index = i
        for j in range(i, n):
            if lijst[j] < lijst[min_index]:
                min_index = j
        lijst[i], lijst[min_index] = lijst[min_index], lijst[i]
    return lijst
```

<Regel n={3}>
**Bouwsteen 4** — de buitenste lus: plek `i` krijgt deze ronde zijn definitieve waarde.
</Regel>

<Regel n={4} tot={7}>
**Bouwstenen 1 + 3** — zoek de index van de kleinste, maar alleen vanaf positie `i`: alles daarvóór staat al goed.
</Regel>

<Regel n={8}>
**Bouwsteen 2** — de swap zet de gevonden kleinste vooraan het ongesorteerde deel. Staat hij daar al (`min_index == i`), dan ruilt de regel hem onschuldig met zichzelf.
</Regel>

</CodeUitleg>

## Onderzoek

Probeer in elk geval:

1. **Strings** sorteren — werkt dat?
2. Een lijst met **duplicaten** — wat gebeurt er met gelijke waardes?
3. **Stabiliteit**: sorteer leerlingen op hun cijfer. Twee leerlingen
   met hetzelfde cijfer: blijven die in de volgorde staan waarin ze in de
   lijst stonden?

# Stabiliteit-test: sorteer op cijfer, vergelijk alleen lijst[...][0]
def selection_sort_op_cijfer(lijst):
    n = len(lijst)
    for i in range(n):
        min_index = i
        for j in range(i, n):
            if lijst[j][0] < lijst[min_index][0]:
                min_index = j
        lijst[i], lijst[min_index] = lijst[min_index], lijst[i]
    return lijst

leerlingen = [(7, 'Sam'), (5, 'Noor'), (7, 'Ali'), (5, 'Bo')]
print(selection_sort_op_cijfer(leerlingen))`} />

<details>
<summary>Wat zie je?</summary>

- Strings → alfabetisch gesorteerd. Python kan strings met `<` vergelijken.
- Duplicaten → gewoon naast elkaar in het resultaat.
- Stabiliteit: `[(5, 'Noor'), (5, 'Bo'), (7, 'Ali'), (7, 'Sam')]`. Sam
  stond vóór Ali, en staat nu erachter. Selection sort is **niet stabiel**:
  de swap in ronde 1 gooide Sam naar achteren, over Ali heen. Daarom
  vergelijkt de test alleen het cijfer (`lijst[j][0]`); vergelijk je de
  hele tuple, dan sorteert Python ook op naam en zie je hier niets.

</details>

## Hoeveel werk doet dit?

| Lijstgrootte | Vergelijkingen | Swaps |
|---:|---:|---:|
| 5 | 10 | 4 |
| 10 | 45 | 9 |
| 100 | 4950 | 99 |
| 1.000 | ~500.000 | 999 |
| 10.000 | ~50.000.000 | 9.999 |

Vergelijkingen groeien **kwadratisch** (`n²/2`). Swaps groeien **lineair**
(`n − 1`, één per ronde; de laatste ronde ruilt met zichzelf). Voor grote
lijsten is dat te traag — gebruik dan een beter sorteeralgoritme (zoals
merge sort, O(n log n)).

Maar voor educatieve doeleinden en kleine lijsten is selection sort
prima.
