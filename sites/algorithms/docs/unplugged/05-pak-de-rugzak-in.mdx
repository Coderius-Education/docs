# Pak de rugzak in

<Handout compact>

<div className="handout-blad">

Vier items, een rugzak die 8 kilo draagt. Welke combinatie is het meeste
waard? Je probeert eerst twee manieren van sorteren, en rekent het
daarna exact uit met de tabel van het knapsack-algoritme. Een potlood
per tweetal, ongeveer 25 minuten.

## De items

<div className="handout-overzicht">

| Item | Waarde | Gewicht |
|:---:|:---:|:---:|
| 1 | 2 | 1 kg |
| 2 | 6 | 2 kg |
| 3 | 7 | 3 kg |
| 4 | 8 | 5 kg |

</div>

De rugzak draagt maximaal **8 kg**. Elk item is er maar één keer:
meenemen of laten liggen, vandaar "0/1".

**Sorteer eerst.** Pak de items van waardevol naar minder waardevol,
zolang ze passen: items ______, waarde ______. Dan in volgorde van
waarde per kilo: items ______, waarde ______. Straks zie je of sorteren
genoeg was.

## De regels

Elke cel van de tabel beantwoordt: *"wat is de beste waarde als ik
alleen de items t/m deze rij mag gebruiken en zóveel kilo draagkracht
heb?"* Drie regels bepalen elke cel:

1. **Geen items** (rij 0): altijd 0, al ingevuld.
2. **Past het item van deze rij niet** (zwaarder dan de kolom)? Kopieer
   de cel er recht boven.
3. **Past hij wel?** Vergelijk **overslaan** (de cel recht boven) met
   **meenemen** (de waarde van het item + de cel één rij hoger en het
   gewicht van het item aan kolommen naar links). Schrijf de hoogste op.

```
beste(rij, kg) =
  0                             rij 0
  beste(rij−1, kg)              past niet
  max( beste(rij−1, kg),
       waarde + beste(rij−1, kg−gewicht) )
                                past wel
```

</div>

## De tabel

Vul de tabel rij voor rij in, van links naar rechts.

| beste waarde | 0 kg | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **geen items** | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| **t/m item 1** (2, 1 kg) | 0 |  |  |  |  |  |  |  |  |
| **t/m item 2** (6, 2 kg) | 0 |  |  |  |  |  |  |  |  |
| **t/m item 3** (7, 3 kg) | 0 |  |  |  |  |  |  |  |  |
| **t/m item 4** (8, 5 kg) | 0 |  |  |  |  |  |  |  |  |

</div>

De cel rechtsonder is de beste totaalwaarde: ______. Beter dan je twee
sorteringen?

<div className="handout-blad">

## Teruglopen — welke items?

De tabel geeft het getal, niet de items. Loop terug vanaf rechtsonder,
rij voor rij omhoog:

- Is de cel **gelijk** aan de cel erboven? Item niet meegenomen; ga een
  rij omhoog, zelfde kolom.
- Is hij **hoger**? Item zit erin: omcirkel het, ga een rij omhoog én
  zijn gewicht aan kolommen naar links.

Beste rugzak: items ______, waarde ______, gewicht ______ kg.

De tabel weet meer dan de cel rechtsonder. Draagt de rugzak maar
**5 kg**? Lees af, zonder te rekenen: waarde ______, items ______.

## Bespreek na

- Sorteren op waarde en sorteren op waarde per kilo gaven allebei
  minder dan de tabel. Welk item lieten ze liggen, en waarom?
- Bij 5 kg pakte de tabel wél de items met de beste waarde per kilo.
  Wanneer werkt sorteren dus wel, en wanneer niet?

## Antwoorden

Deze pagina print als losse laatste pagina — houd hem achter de hand of
knip hem eraf.

| beste waarde | 0 kg | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **geen items** | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| **t/m item 1** | 0 | 2 | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| **t/m item 2** | 0 | 2 | 6 | 8 | 8 | 8 | 8 | 8 | 8 |
| **t/m item 3** | 0 | 2 | 6 | 8 | 9 | 13 | 15 | 15 | 15 |
| **t/m item 4** | 0 | 2 | 6 | 8 | 9 | 13 | 15 | 15 | 16 |

**Sorteren.** Op waarde: item 4 (5 kg), dan item 3 (3 kg), vol: waarde
15. Op waarde per kilo (3, 2,33, 2 en 1,6 per kilo): item 2, item 3,
item 1, samen 6 kg, en item 4 past er niet meer bij: ook 15.

**De tabel.** Beste rugzak: **items 1, 2 en 4**, waarde **16**, gewicht
**8 kg**. Allebei de sorteringen lieten item 4 liggen of pakten hem
zonder de kleine items erbij. Alleen de combinatie van het zware item
met de twee lichtste vult de rugzak precies, en die combinatie vind je
niet door items één voor één te beoordelen. Daarom rekent het
algoritme alle deelproblemen door.

**Bij 5 kg** staat in de kolom van 5 kg onderaan **13**: items 2 en 3.
Dat is precies wat sorteren per kilo koos. Sorteren gaat goed zolang de
beste items toevallig samen passen; het gaat mis zodra een goede
combinatie een minder "efficiënt" item nodig heeft om de ruimte vol te
maken. Welk van de twee je hebt, weet je pas als je het uitrekent.
