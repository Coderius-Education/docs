**Leerdoel:** je slaat het web op als een graph en beantwoordt de vraag
achter de formule: *wie linkt naar deze pagina?* De controle die je
daarvoor schrijft, `p in web[i]`, komt in bouwsteen 3 terug in de formule.

## Het web in Python

Een **dict** waarbij elke pagina wijst naar de **set** pagina's waar hij
naar linkt:

```python
WEB = {
    "A": {"B", "C"},
    "B": {"C"},
    "C": {"A"},
    "D": {"C"},
}
```

`WEB["A"]` is `{"B", "C"}` — de uitgaande links van A.

## Wat we nodig hebben

Voor de formule moet je straks weten **welke pagina's naar `p` linken**
(en hoeveel links die elk uitdelen). Schrijf de helper `wie_linkt_naar`.

<summary>Antwoord</summary>

```python
def wie_linkt_naar(web, p):
    resultaat = set()
    for i in web:
        if p in web[i]:
            resultaat.add(i)
    return resultaat
```

Voor elke pagina `i` kijk je of `p` in zijn linkset zit. `D` zit bij
niemand, dus `wie_linkt_naar(WEB, "D")` is leeg.
