# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent de drie klassieke valkuilen bij het bouwen van
PageRank.

## Het verschil is meteen nul

Symptoom: de test van [bouwsteen 4](./bouwen/06-itereren) faalt, en de
ranks zien eruit alsof er maar één ronde is gerekend:

{/* foutmelding-los: de fout zit in de pagerank van de leerling; src/docs-tests/pagerank.test.ts rekent deze melding na */}

```
AssertionError: {'A': 0.25, 'B': 0.1437, 'C': 0.4784, 'D': 0.0375}
```

**Oorzaak:** `nieuw` en `rank` zijn dezelfde dict. `nieuw = rank` maakt
geen kopie, maar geeft dezelfde dict een tweede naam. Alles wat je in
`nieuw` zet, staat dus meteen ook in `rank`. Het verschil tussen de twee is
daardoor altijd 0, en de lus stopt na de eerste ronde.

**Oplossing:** begin elke ronde met een lege dict.

```python
# FOUT
nieuw = rank          # geen nieuwe dict, maar een tweede naam
for p in web:
    nieuw[p] = nieuwe_rank(web, rank, p, d)

# GOED
nieuw = {}
for p in web:
    nieuw[p] = nieuwe_rank(web, rank, p, d)
```

Hetzelfde gebeurt als je `rank = nieuw` vóór het meten van het verschil
zet: dan vergelijk je `nieuw` met zichzelf. De test toont dan
`'C': 0.5687`.

## Het basisdeel `(1 − d)/N` vergeten

Symptoom: de som van de ranks zakt onder de 1 en pagina's lopen leeg.

**Oorzaak:** je rekent alleen `d · Σ ...` en laat de willekeurige sprong
weg. Dan "lekt" er belang weg en klopt de verdeling niet meer.

```python
# FOUT
nieuw[p] = d * som          # basisdeel ontbreekt

# GOED
nieuw[p] = (1 - d) / n + d * som
```

## Dangling nodes — pagina's zonder uitgaande links

Symptoom: zodra een pagina nergens naartoe linkt, telt de som niet meer op
tot 1.

**Oorzaak:** het belang van zo'n "doodlopende" pagina wordt nergens
heen verdeeld en verdwijnt. In onze voorbeelden linkt elke pagina ergens
naartoe, dus dit speelt niet — maar in een echt web wel.

**Oplossing:** behandel een pagina zónder uitgaande links alsof hij naar
**alle** pagina's linkt (de surfer springt dan willekeurig verder):

```python
def uitgaande_links(web, i, paginas):
    if web[i]:
        return web[i]
    return set(paginas)
```

Zo blijft het belang behouden en telt de som weer op tot 1.
