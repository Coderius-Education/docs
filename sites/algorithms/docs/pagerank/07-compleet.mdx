# De complete oplossing

**Leerdoel:** je ziet de volledige `pagerank`-functie werken en speelt met
je eigen web.

## De functie

<CodeUitleg>

```python showLineNumbers
def pagerank(web, d=0.85, epsilon=1e-9):
    n = len(web)
    rank = {}
    for p in web:
        rank[p] = 1 / n
    while True:
        nieuw = {}
        for p in web:
            som = 0.0
            for i in web:
                if p in web[i]:
                    som += rank[i] / len(web[i])
            nieuw[p] = (1 - d) / n + d * som
        verschil = 0.0
        for p in web:
            verschil = max(verschil, abs(nieuw[p] - rank[p]))
        rank = nieuw
        if verschil < epsilon:
            return rank
```

<Regel n={2} tot={5}>
De startverdeling: elke pagina begint met een gelijk deel, samen precies 1.
</Regel>

<Regel n={6} tot={7}>
Herhaal tot de waardes stil komen te staan; elke ronde bouwt een verse dictionary op uit de vórige ronde.
</Regel>

<Regel n={10} tot={12}>
Wie linkt er naar `p`? Elke linker `i` geeft zijn rank gelijk verdeeld door over zijn uitgaande links.
</Regel>

<Regel n={13}>
De formule: een klein vast deel voor de willekeurige springer (`1 - d`), plus `d` keer wat er via links binnenkomt.
</Regel>

<Regel n={14} tot={16}>
De grootste verandering van deze ronde — dat is de maat voor "zijn we er al?".
</Regel>

<Regel n={18} tot={19}>
Verandert er minder dan `epsilon`, dan is het stabiel en zijn de ranks klaar.
</Regel>

</CodeUitleg>

oplost. Het echte Google-web heeft miljarden pagina's, maar het principe
