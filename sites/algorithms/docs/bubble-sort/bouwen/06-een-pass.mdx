**Leerdoel:** je weet precies tot welke index de binnenste lus loopt, en
waarom er `- 1` bij hoort.

## Wat we willen

Eén pass = één keer door de lijst lopen, elk paar buren bekijken en
zo nodig swappen.

## De `- 1` is cruciaal

Elke vergelijking pakt `lijst[i]` en `lijst[i + 1]`. De laatste `i` die
nog kan is dus `len(lijst) - 2`, want dan wijst `i + 1` precies naar het
laatste element.

```python
for i in range(len(lijst) - 1):     # 0, 1, ..., len-2
    ...
```

Vergeten we de `- 1`?

```python
for i in range(len(lijst)):         # 0, 1, ..., len-1
    if lijst[i] > lijst[i + 1]:     # crash bij i = len-1
        ...
```

{/* foutmelding-van: lijst = [5, 2, 9]\nfor i in range(len(lijst)):\n    if lijst[i] > lijst[i + 1]:\n        pass */}

→ `IndexError: list index out of range` op de laatste iteratie. Klassieke
beginnersfout.

## Voorspel

Wat denk je dat dit print?

```python
def een_pass(lijst):
    for i in range(len(lijst) - 1):
        if lijst[i] > lijst[i + 1]:
            lijst[i], lijst[i + 1] = lijst[i + 1], lijst[i]
    return lijst

print(een_pass([3, 1, 4, 1, 5]))
print(een_pass([5, 4, 3, 2, 1]))
print(een_pass([1, 2, 3, 4, 5]))
```

<details>
<summary>Antwoord</summary>

```
[1, 3, 1, 4, 5]
[4, 3, 2, 1, 5]
[1, 2, 3, 4, 5]
```

- In `[3, 1, 4, 1, 5]` gebeuren twee swaps, de 3 met de 1 en de 4 met de
    1; de 5 stond al achteraan.
- In de omgekeerde lijst `[5, 4, 3, 2, 1]` borrelt de 5 in één pass
    helemaal naar achteren. De rest staat nog rommelig.
- In `[1, 2, 3, 4, 5]` verandert niets, want die staat al goed.

</details>
