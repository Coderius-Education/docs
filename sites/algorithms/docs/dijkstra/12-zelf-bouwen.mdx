# Bouw zelf — kortste reis tussen steden

**Leerdoel:** je past Dijkstra toe op een **groter** voorbeeld: zes
Nederlandse steden met benaderde reistijden.

## Opdracht

Hier een mini-routekaart:

```
Amsterdam ── 30 ── Utrecht ── 60 ── Arnhem
    │                │               │   ╲
   25               45              90     80
    │                │               │       ╲
Den Haag ── 25 ── Rotterdam ── 40 ── Eindhoven ── 50 ── Maastricht
```

(Gewichten zijn benaderingen in minuten — gebruik dit niet om je
navigatie te vervangen.)

In Python:

```python
steden = {
    'Amsterdam':  [('Utrecht', 30), ('Den Haag', 25)],
    'Utrecht':    [('Amsterdam', 30), ('Arnhem', 60), ('Rotterdam', 45)],
    'Arnhem':     [('Utrecht', 60), ('Maastricht', 80), ('Eindhoven', 90)],
    'Den Haag':   [('Amsterdam', 25), ('Rotterdam', 25)],
    'Rotterdam':  [('Utrecht', 45), ('Den Haag', 25), ('Eindhoven', 40)],
    'Eindhoven':  [('Rotterdam', 40), ('Arnhem', 90), ('Maastricht', 50)],
    'Maastricht': [('Arnhem', 80), ('Eindhoven', 50)],
}
```

Schrijf een functie `kortste_reis(graph, start, doel)` die de afstand
**én** het pad teruggeeft. Gebruik je code van vorige pagina's.

```python
def kies_volgende(afstanden, bezocht):
    beste_node = None
    kleinste = float('inf')
    for node, d in afstanden.items():
        if node in bezocht:
            continue
        if d < kleinste:
            kleinste = d
            beste_node = node
    return beste_node


def dijkstra(graph, start):
    afstanden = {}
    for node in graph:
        afstanden[node] = float('inf')
    afstanden[start] = 0
    bezocht = set()
    voorgangers = {}
    while True:
        huidige = kies_volgende(afstanden, bezocht)
        if huidige is None:
            break
        bezocht.add(huidige)
        for buur, gewicht in graph[huidige]:
            nieuwe = afstanden[huidige] + gewicht
            if nieuwe < afstanden[buur]:
                afstanden[buur] = nieuwe
                voorgangers[buur] = huidige
    return afstanden, voorgangers


def reconstrueer_pad(voorgangers, start, doel):
    pad = []
    huidige = doel
    while huidige is not None:
        pad.append(huidige)
        if huidige == start:
            break
        huidige = voorgangers.get(huidige)
    pad.reverse()
    if pad and pad[0] == start:
        return pad
    return []


def kortste_reis(graph, start, doel):
    afstanden, voorgangers = dijkstra(graph, start)
    pad = reconstrueer_pad(voorgangers, start, doel)
    return afstanden[doel], pad

    'Amsterdam':  [('Utrecht', 30), ('Den Haag', 25)],

    'Arnhem':     [('Utrecht', 60), ('Maastricht', 80), ('Eindhoven', 90)],
    'Den Haag':   [('Amsterdam', 25), ('Rotterdam', 25)],
    'Rotterdam':  [('Utrecht', 45), ('Den Haag', 25), ('Eindhoven', 40)],
    'Eindhoven':  [('Rotterdam', 40), ('Arnhem', 90), ('Maastricht', 50)],
    'Maastricht': [('Arnhem', 80), ('Eindhoven', 50)],
}

    ('Amsterdam', 'Maastricht'): (140, ['Amsterdam', 'Den Haag', 'Rotterdam', 'Eindhoven', 'Maastricht']),
    ('Den Haag', 'Arnhem'): (115, ['Den Haag', 'Amsterdam', 'Utrecht', 'Arnhem']),
    ('Rotterdam', 'Maastricht'): (90, ['Rotterdam', 'Eindhoven', 'Maastricht']),
```

## Uitdaging (optioneel)

Schrijf `kortste_reizen(graph, start, doelen)` die voor een **lijst
bestemmingen** tegelijk de afstand en het pad geeft, als dict van
bestemming naar `(afstand, pad)`. Je hoeft maar **één** Dijkstra-run te
doen vanaf `start` — de afstanden naar alle steden zijn dan al berekend.

<details>
<summary>Tip</summary>

`kortste_reis` roept `dijkstra` één keer aan en `reconstrueer_pad` één
keer. Voor meerdere bestemmingen blijft het één keer `dijkstra`, en
daarna één keer `reconstrueer_pad` per bestemming, in een lus over
`doelen`.

</details>

<details>
<summary>Antwoord</summary>

Met de functies uit het antwoord hierboven:

{/* draaien-met: blok-erboven */}
```python
def kortste_reizen(graph, start, doelen):
    afstanden, voorgangers = dijkstra(graph, start)
    uitkomst = {}
    for doel in doelen:
        pad = reconstrueer_pad(voorgangers, start, doel)
        uitkomst[doel] = (afstanden[doel], pad)
    return uitkomst


reizen_vanuit_amsterdam = kortste_reizen(steden, 'Amsterdam', ['Maastricht', 'Arnhem', 'Eindhoven'])
for doel, (afstand, pad) in reizen_vanuit_amsterdam.items():
    print(f"{doel}: {afstand} min via {' → '.join(pad)}")
```

```
Maastricht: 140 min via Amsterdam → Den Haag → Rotterdam → Eindhoven → Maastricht
Arnhem: 90 min via Amsterdam → Utrecht → Arnhem
Eindhoven: 90 min via Amsterdam → Den Haag → Rotterdam → Eindhoven
```

Eén run, drie antwoorden: `afstanden` en `voorgangers` bevatten na één
keer `dijkstra` alles wat je voor elke bestemming nodig hebt.
