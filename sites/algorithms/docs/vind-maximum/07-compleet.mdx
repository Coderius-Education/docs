## Alles samen

In de bouwstenen heette de variabele `max_tot_nu_toe`, want dat is precies
wat hij is: het maximum tot nu toe. Nu de functie af is, is `maximum`
korter en even duidelijk.

<CodeUitleg>

```python showLineNumbers
def vind_maximum(lijst):
    maximum = lijst[0]
    for waarde in lijst:
        if waarde > maximum:
            maximum = waarde
    return maximum
```

<Regel n={2}>
**Bouwsteen 3** — de startwaarde is `lijst[0]`: gegarandeerd een echte waarde uit de lijst, dus ook veilig bij louter negatieve getallen.
</Regel>

<Regel n={3}>
**Bouwsteen 2** — door de lijst lopen, elke waarde precies één keer.
</Regel>

<Regel n={4} tot={5}>
**Bouwsteen 1** — vergelijken met de kampioen tot nu toe, en bij een grotere waarde overschrijven.
</Regel>

<Regel n={6}>
Het resultaat teruggeven — ná de lus, dus pas als alles bekeken is.
</Regel>

</CodeUitleg>

## Onderzoek

Speel met de code. Probeer in elk geval:

1. Wat gebeurt er op een lege lijst `[]`?
2. En op een lijst met strings, `["banaan", "appel", "kers"]`?
3. En op een gemengde lijst, `[1, "twee", 3]`?

<PyRunner initialCode={`def vind_maximum(lijst):

# Experimenteer

# Verwijder de # om de crash-cases te zien:
# print(vind_maximum([]))
# print(vind_maximum([1, "twee", 3]))`} />

<details>
<summary>Wat zie je?</summary>

Strings → werkt. Alfabetisch vergelijken: `'k' > 'b' > 'a'`, dus
"kers" > "banaan" > "appel" → output `kers`. Python kan strings
vergelijken met `<` en `>` (alfabetisch).

{/* foutmelding-van: [][0] */}

Lege lijst → `IndexError` op `lijst[0]`. Ons algoritme heeft geen
bescherming.

{/* foutmelding-van: "twee" > 1 */}

Gemengd → `TypeError: '>' not supported between instances of 'str' and
'int'`. Je kunt 1 niet met "twee" vergelijken.

</details>

## Hoeveel werk doet dit?

Voor `n` elementen doet dit algoritme `n` vergelijkingen; `lijst[0]` wordt
ook één keer met zichzelf vergeleken. Dat is `O(n)`: lineair in de
lijstgrootte.

Wil je écht minimaal werk? Sla het eerste element over met `lijst[1:]`
(zie [bouwsteen 3](./bouwen/06-initialisatie)). Dan zijn het `n − 1`
vergelijkingen. Maar O(n) blijft
O(n) — die ene vergelijking maakt geen verschil voor de groeisnelheid.
