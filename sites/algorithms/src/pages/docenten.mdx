# Docentenhandleiding

Praktische informatie voor docenten die deze cursus klassikaal willen inzetten: wat de site is, welke randvoorwaarden er zijn, en hoe je de lessen indeelt.

## Wat is dit?

Een interactieve cursus **algoritmes** waarin je leerlingen elk algoritme zelf stap voor stap opbouwen en in de browser uitvoeren — van zoeken en sorteren tot grafen en speltheorie. Doelgroep: leerlingen die al wat Python kennen en willen begrijpen *hoe* en *waarom* een algoritme werkt.

## Technische randvoorwaarden

| Wat | Antwoord |
|---|---|
| Operating system | Alles met een moderne browser |
| Installatie | Geen — de code draait in de browser |
| Account | Niet nodig |
| Internet | Vereist — de site is online |

## Didactische aanpak

Elk algoritme volgt dezelfde vaste opbouw, zodat je leerlingen het patroon herkennen:

1. **Concept** — korte uitleg met een analogie en een visueel voorbeeld.
2. **Stellingen** — een Predict-fase: waar/niet-waar-vragen met het antwoord verborgen.
3. **Bouwen** — per pagina één klein stukje code (≤ 10 regels), uit te voeren met de runner.
4. **Compleet** — de volledige werkende implementatie.
5. **Aanpassen** — varianten op de basisoplossing.
6. **Zelf bouwen** — een uitdaging die je leerling vanaf nul oplost.
7. **Fouten** & **Cheatsheet** — veelgemaakte fouten en een naslag.

Laat je leerlingen bij "Stellingen" eerst zelf kiezen voordat ze het antwoord openklikken.

## Klassikaal gebruik & differentiatie

- **Plenair starten**: bespreek het concept en de stellingen samen, daarna bouwen je leerlingen zelf.
- **Snelle leerlingen** doen de "zelf bouwen"-uitdaging of een volgend algoritme.
- **Langzamere leerlingen** stoppen bij "Compleet" — de "aanpassen"- en "zelf bouwen"-stappen zijn optioneel.
- **Beoordelen**: laat leerlingen een algoritme uitleggen aan de hand van een eigen voorbeeld.

## Unplugged activiteiten

Onder [Unplugged](/docs/unplugged) staan werkvormen zonder computer, elk met een printknop op de pagina:

- [Zoeken en sorteren met kaarten](/docs/unplugged/01-zoeken-en-sorteren-met-kaarten) — vier algoritmes uitvoeren met een gewoon kaartspel. Geschikt als les-opener voordat je leerlingen hetzelfde algoritme in Python bouwen.
- [Van code naar klasse](/docs/unplugged/02-van-code-naar-klasse) — knipkaartjes met Python-snippets sorteren naar Big O-klasse. Sluit aan op hoofdstuk 7.
- [De kortste route — Dijkstra op papier](/docs/unplugged/03-dijkstra-op-papier) — in tweetallen Dijkstra uitvoeren op een kaart met zeven plekken, met een gok-vooraf als opener. Sluit aan op hoofdstuk 8.

## Leerlijn

Kies op de [startpagina](/) een algoritme; elk is zelfstandig te doen. De cursus behandelt onder meer:

| Thema | Algoritmes |
|---|---|
| Zoeken | Lineair zoeken, binair zoeken, vind-maximum, max & min |
| Sorteren | Bubble sort, selection sort |
| Complexiteit | Big-O |
| Grafen | Dijkstra, PageRank |
| Recursie & optimalisatie | Torens van Hanoi, knapsack, minimax |
