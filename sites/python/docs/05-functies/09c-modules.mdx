# 9c Modules importeren

```python

```

## Waarom je hem eerst moet ophalen

`print()` en `len()` liggen altijd klaar. De meeste andere functies niet: die zitten in een **module**, een verzameling functies die bij elkaar hoort. `time` is de module voor alles met tijd.

Laat je de eerste regel weg, dan kent Python de naam niet:

```
NameError: name 'time' is not defined
```

**`import time`** zegt: haal die module erbij. Vanaf dat moment kun je alles wat erin zit gebruiken.

## Twee manieren om te importeren

Je kunt de hele module halen, of alleen het stuk dat je nodig hebt.

```python
import time

time.sleep(1)
```

```python
from time import sleep

sleep(1)
```

Allebei pauzeren ze een seconde. Het verschil zit in wat je daarna typt:

| | `import time` | `from time import sleep` |
|:---:|:---:|:---:|
| **Aanroepen met** | `time.sleep(1)` | `sleep(1)` |
| **Wat krijg je** | de hele module | alleen `sleep` |
| **Waar hij vandaan komt** | zie je aan de naam | zie je alleen bovenaan |

De eerste vorm is duidelijker: `time.sleep` vertelt meteen waar die functie vandaan komt. De tweede is korter, en handig als je één functie heel vaak gebruikt.

**Let op:** kies je `from time import sleep`, dan werkt `time.sleep(1)` níét meer — je hebt de module zelf immers niet gehaald.

## Import staat bovenaan

Zet je imports op de eerste regels van je bestand, vóór de rest van je code. Python leest je bestand van boven naar beneden: staat de import onder de plek waar je hem gebruikt, dan is hij daar nog niet bekend.

```python
# FOUT
time.sleep(1)
import time

# GOED
import time
time.sleep(1)
```

## Er gaat iets mis

```
NameError: name 'sleep' is not defined
```

**Oorzaak:** je gebruikt `sleep(1)` maar je hebt `import time` geschreven. Dan heet hij `time.sleep`.

**Oplossing:** kies één van de twee vormen en houd hem vol.

```python
# FOUT
import time
sleep(1)

# GOED
from time import sleep
sleep(1)
```

## Opdracht 9c.1: Aftellen

Tel af van 3 naar 1 met een halve seconde pauze ertussen, en print daarna `Start!`.

Verwachte uitvoer:

```
3
2
1
Start!
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Je hebt `time` nodig en een for-loop. Met `range(3, 0, -1)` tel je terug van 3 naar 1. Pauzeer met `time.sleep(0.5)`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
import time

for getal in range(3, 0, -1):
    print(getal)
    time.sleep(0.5)

print("Start!")
```

De pauze staat ín de loop, dus tussen elk getal zit een halve seconde. Samen duurt het aftellen anderhalve seconde.

## Opdracht 9c.3: Wachten in een eigen functie

Schrijf een functie `zeg_langzaam(tekst, seconden)` die eerst wacht en daarna de tekst print. Roep hem twee keer aan met verschillende waarden.

Verwachte uitvoer:

```
Eerst dit
En dan dit
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

De import staat bovenaan je bestand, niet in de functie. In de functie zelf staan twee regels: pauzeren en printen.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
import time

def zeg_langzaam(tekst, seconden):
    time.sleep(seconden)
    print(tekst)

zeg_langzaam("Eerst dit", 0.5)
zeg_langzaam("En dan dit", 1)
```

De pauze verschilt per aanroep, want `seconden` is gewoon een parameter. Zo bouw je met een kant-en-klare functie je eigen functie.
