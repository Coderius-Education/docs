# 15c De melding bewaren

Soms wil je wel laten zien wat Python van de fout vond, maar zonder dat je
programma stopt. Met `as` bewaar je de fout in een variabele:

```python
tekst = "twaalf"

try:
    getal = int(tekst)
except ValueError as fout:
    print(f"Dat lukte niet: {fout}")
```

Uitvoer:

```
Dat lukte niet: invalid literal for int() with base 10: 'twaalf'
```

{/* foutmelding-van: int("twaalf") */}

`fout` is de fout zelf. Print je hem, dan zie je de melding die Python
anders onderaan de foutmelding had gezet, zonder de naam `ValueError`
ervoor. De naam van de variabele kies je zelf; `fout` is gebruikelijk.

## Welke fout was het?

Met `type(fout).__name__` krijg je ook de naam van de fout. Dat is handig
als één `except` meer soorten fouten afvangt, tussen haakjes:

```python
getallen = [10, 0]

try:
    print(getallen[0] / getallen[1])
except (ZeroDivisionError, IndexError) as fout:
    print(f"Het ging mis met een {type(fout).__name__}: {fout}")
```

Uitvoer:

```
Het ging mis met een ZeroDivisionError: division by zero
```

## Opdracht 15c.1: Een logboek

Zet elk getal uit de lijst om met `int()`. Lukt het niet, print dan de
melding van Python achter `Overgeslagen:`.

Verwachte uitvoer:

```
3
Overgeslagen: invalid literal for int() with base 10: 'vier'
5
```

{/* niet-draaien: de startcode valt expres om, met de fout die de opdracht afvangt */}

<CodeExercise>{`teksten = ["3", "vier", "5"]

for tekst in teksten:
    print(int(tekst))`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Het `try`-blok staat binnen de for-loop, zodat de loop na een fout
doorgaat met de volgende tekst.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teksten = ["3", "vier", "5"]

for tekst in teksten:
    try:
        print(int(tekst))
    except ValueError as fout:
        print(f"Overgeslagen: {fout}")
```

Uitvoer:

```
3
Overgeslagen: invalid literal for int() with base 10: 'vier'
5
```

</details>

## Opdracht 15c.2: Wat ging er mis?

{/* foutmelding-los: de namen staan hier als wat je achter except schrijft, geen melding van Python */}

Vang in één `except` zowel een `KeyError` als een `ZeroDivisionError` af, en
print de naam van de fout.

Verwachte uitvoer:

```
Fout: KeyError
```

{/* niet-draaien: de startcode valt expres om, met de fout die de opdracht afvangt */}

<CodeExercise>{`punten = {"Sara": 30, "Noor": 45}
naam = "Alex"
rondes = 3

print(punten[naam] / rondes)`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

{/* foutmelding-los: de namen staan hier als wat je achter except schrijft, geen melding van Python */}

Zet de twee fouten tussen haakjes achter `except`, met `as fout` erachter.
De naam krijg je met `type(fout).__name__`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
punten = {"Sara": 30, "Noor": 45}
naam = "Alex"
rondes = 3

try:
    print(punten[naam] / rondes)
except (KeyError, ZeroDivisionError) as fout:
    print(f"Fout: {type(fout).__name__}")
```

Uitvoer:

```
Fout: KeyError
```

</details>
