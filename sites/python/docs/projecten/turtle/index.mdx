# Tekenen met turtle

Met **turtle** laat je een schildpad met een pen over het scherm lopen. Waar
hij langskomt, trekt hij een lijn. De speeltuin tekent wat hij doet onder je
code, en met Stap voor stap zie je de tekening regel voor regel groeien.

De projecten vormen een lijn: doe ze van boven naar beneden. Elk project
voegt precies één ding toe. De eerste zeven gebruiken alleen losse commando's:
eerst lijnen en hoeken, dan vormen, kleur, `penup`, `goto` en cirkels. Daarna komt er
per project één Python-concept bij, in de volgorde van de cursus: een
variabele, `if`, een for-loop, de loopvariabele, een while-loop, functies en
lijsten. Kies je hieronder een concept, dan zie je welke projecten het
oefenen.

<ProjectKiezer soorten={['turtle']} />

Elke opdracht laat zien wat er moet komen. De code die je hier schrijft,
werkt ook met de echte turtle op je eigen computer. Zet daar wel
`turtle.done()` als laatste regel onder je programma. Zonder die regel sluit
het tekenvenster zodra de tekening klaar is, behalve in Thonny. In de
speeltuin doet `turtle.done()` niets, dus je kunt hem ook hier laten staan.
