# Projecten

In de lessen leer je steeds één ding tegelijk. Hieronder staat waar je ze
samen gebruikt: eerst in een project in deze cursus, daarna in een
dagelijkse puzzel, in spelletjes en in de algoritmes. Per rij zie je welke
concepten erin zitten, en welke lessen je na Tien groene flessen nog nodig
hebt. Het hele plaatje van de algoritmes staat op de
<SiteLink site="algorithms" to="/conceptenkaart">conceptenkaart</SiteLink>.
