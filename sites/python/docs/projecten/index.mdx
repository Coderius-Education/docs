# Projecten

In de lessen leer je steeds één ding tegelijk. In een project gebruik je ze
samen, aan één programma dat stap voor stap groeit. Je begint met code die
werkt maar onhandig is, en elke stap maakt hem korter en slimmer.

## Tien groene flessen

Je bouwt een aftelliedje na, tien coupletten lang. Eerst typ je het uit met
alleen `print`, aan het eind schrijf je `lied(10)` en zingt Python het hele
lied voor je. Onderweg gebruik je:

- `print` en f-strings, uit [Jouw naam op het scherm](/docs/basis/jouw-naam-op-het-scherm) en [f-strings](/docs/tekst/04a-f-strings)
- een for-loop die aftelt, uit [Range met stappen](/docs/herhalen/06b-range-stappen)
- `if`, `elif` en `else`, uit [And, or en elif](/docs/beslissen/05c-and-or-elif)
- functies met parameters en `return`, uit [Parameters](/docs/functies/09a-parameters) en [Return](/docs/functies/09b-return)

Ken je een van die lessen nog niet? Geen probleem: elke stap zegt bovenaan
welke les hij gebruikt.

Begin bij [stap 1: alleen print](/docs/projecten/tien-groene-flessen/stap-1-print).
