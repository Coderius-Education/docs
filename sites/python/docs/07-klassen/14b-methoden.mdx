# 14b Methoden

In 14a legde je vast wat een hond ís: een naam, een leeftijd, trucjes. Een
**methode** legt vast wat een hond kan. Het is een functie die je binnen de
klasse schrijft:

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def blaf(self):
        print(f"{self.naam} zegt: Woef!")


rex = Hond("Rex", 3)
bello = Hond("Bello", 7)

rex.blaf()
bello.blaf()
```

Uitvoer:

```
Rex zegt: Woef!
Bello zegt: Woef!
```

Een methode roep je aan met een punt, net als een attribuut, maar met
haakjes erachter: `rex.blaf()`.

## Wat is `self`?

Bij `rex.blaf()` vult Python `self` zelf in met het object vóór de punt:
`rex`. Daarom print dezelfde methode één keer "Rex" en één keer "Bello".
Elke methode heeft `self` als eerste parameter; bij het aanroepen schrijf
je hem nooit zelf.

## Een methode die een attribuut verandert

Via `self` kan een methode de attributen van zijn eigen object aanpassen:

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def verjaar(self):
        self.leeftijd += 1
        print(f"Hoera, {self.naam} is nu {self.leeftijd}!")


rex = Hond("Rex", 3)
rex.verjaar()
rex.verjaar()
```

Uitvoer:

```
Hoera, Rex is nu 4!
Hoera, Rex is nu 5!
```

## Parameters en `return`

Een methode kan meer parameters hebben dan `self`, en een waarde teruggeven
met `return`, net als een gewone functie uit les 9b:

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd
        self.trucjes = []

    def leer(self, trucje):
        self.trucjes.append(trucje)

    def hondenjaren(self):
        return self.leeftijd * 7


rex = Hond("Rex", 3)
rex.leer("zitten")
rex.leer("rollen")

print(rex.trucjes)
print(f"In hondenjaren is {rex.naam} {rex.hondenjaren()}.")
```

Uitvoer:

```
['zitten', 'rollen']
In hondenjaren is Rex 21.
```

## Er gaat iets mis

**`self` vergeten**

```python
class Hond:
    def blaf():
        print("Woef!")


rex = Hond()
rex.blaf()
```

Uitvoer:

```
TypeError: Hond.blaf() takes 0 positional arguments but 1 was given
```

Jij geeft geen argument mee, en toch zegt Python dat er één binnenkomt. Dat
is `rex`: Python geeft het object altijd mee als eerste argument. Zet
`self` bovenaan de parameters: `def blaf(self):`.

**De haakjes vergeten**

{/* uitvoer-varieert: het adres van het object verschilt per keer */}

```python
class Hond:
    def blaf(self):
        print("Woef!")


rex = Hond()
print(rex.blaf)
```

Uitvoer:

```
<bound method Hond.blaf of <__main__.Hond object at 0x7f3a2c1b8d10>>
```

Zonder haakjes roep je de methode niet aan, maar vraag je de methode zelf
op. Python print dan wat het is, met een geheugenadres dat bij jou anders
zal zijn. Schrijf `rex.blaf()`.

## Opdracht 14b.1: Bankrekening

Maak een klasse `Rekening` met een `eigenaar` en een `saldo` dat op 0
begint. Geef hem een methode `stort(bedrag)` die het saldo verhoogt, en een
methode `toon()` die het saldo print.

Verwachte uitvoer:

```
Saldo van Sara: 35 euro
```

<CodeExercise>{`class Rekening:
    def __init__(self, eigenaar):
        self.eigenaar = eigenaar
        self.saldo = 0

    def stort(self, bedrag):
        print(f"Nog te doen: {bedrag} euro storten")

    def toon(self):
        print("Nog te doen: het saldo printen")


rekening = Rekening("Sara")
rekening.stort(20)
rekening.stort(15)
rekening.toon()`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`stort` krijgt twee parameters, `self` en `bedrag`, en doet
`self.saldo += bedrag`. `toon` heeft alleen `self` nodig.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
class Rekening:
    def __init__(self, eigenaar):
        self.eigenaar = eigenaar
        self.saldo = 0

    def stort(self, bedrag):
        self.saldo += bedrag

    def toon(self):
        print(f"Saldo van {self.eigenaar}: {self.saldo} euro")


rekening = Rekening("Sara")
rekening.stort(20)
rekening.stort(15)
rekening.toon()
```

Uitvoer:

```
Saldo van Sara: 35 euro
```

</details>

## Opdracht 14b.2: Niet rood staan

Geef `Rekening` een methode `neem_op(bedrag)`. Is er genoeg saldo, dan gaat
het bedrag eraf en geeft de methode `True` terug. Is er te weinig, dan
blijft het saldo gelijk en geeft hij `False` terug.

Verwachte uitvoer:

```
True
False
Saldo van Sara: 5 euro
```

<CodeExercise>{`class Rekening:
    def __init__(self, eigenaar):
        self.eigenaar = eigenaar
        self.saldo = 0

    def stort(self, bedrag):
        self.saldo += bedrag

    def toon(self):
        print(f"Saldo van {self.eigenaar}: {self.saldo} euro")

    def neem_op(self, bedrag):
        return "nog te doen"


rekening = Rekening("Sara")
rekening.stort(35)
print(rekening.neem_op(30))
print(rekening.neem_op(10))
rekening.toon()`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Vergelijk `bedrag` met `self.saldo` in een `if`. In het ene geval
verlaag je het saldo en `return True`, anders `return False`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
class Rekening:
    def __init__(self, eigenaar):
        self.eigenaar = eigenaar
        self.saldo = 0

    def stort(self, bedrag):
        self.saldo += bedrag

    def toon(self):
        print(f"Saldo van {self.eigenaar}: {self.saldo} euro")

    def neem_op(self, bedrag):
        if bedrag <= self.saldo:
            self.saldo -= bedrag
            return True
        else:
            return False


rekening = Rekening("Sara")
rekening.stort(35)
print(rekening.neem_op(30))
print(rekening.neem_op(10))
rekening.toon()
```

Uitvoer:

```
True
False
Saldo van Sara: 5 euro
```

De tweede keer staat er nog 5 euro op de rekening, dus 10 opnemen lukt
niet en het saldo blijft staan.

</details>

## Opdracht 14b.3: Een stappenteller

Maak een klasse `Stappenteller` met een attribuut `stappen` dat op 0
begint, en drie methoden:

1. `stap()` telt er één stap bij.
2. `loop(aantal)` telt er `aantal` stappen bij.
3. `kilometers()` geeft terug hoeveel kilometer dat is, bij 1300 stappen
   per kilometer, afgerond op één decimaal.

Verwachte uitvoer:

```
2601 stappen is 2.0 km
```

<CodeExercise>{`class Stappenteller:
    def __init__(self):
        self.stappen = 0

    def stap(self):
        print("Nog te doen: één stap tellen")

    def loop(self, aantal):
        print(f"Nog te doen: {aantal} stappen tellen")

    def kilometers(self):
        return 0


teller = Stappenteller()
teller.stap()
teller.loop(2600)
print(f"{teller.stappen} stappen is {teller.kilometers()} km")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`__init__` heeft hier alleen `self` nodig. Voor het afronden gebruik je
`round(getal, 1)`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
class Stappenteller:
    def __init__(self):
        self.stappen = 0

    def stap(self):
        self.stappen += 1

    def loop(self, aantal):
        self.stappen += aantal

    def kilometers(self):
        return round(self.stappen / 1300, 1)


teller = Stappenteller()
teller.stap()
teller.loop(2600)
print(f"{teller.stappen} stappen is {teller.kilometers()} km")
```

Uitvoer:

```
2601 stappen is 2.0 km
```

</details>
