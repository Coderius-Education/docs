# 14c Objecten in een lijst

Eén hond is leuk, maar een asiel heeft er tientallen. Objecten kun je net
als getallen en teksten in een lijst stoppen, en er met een for-loop
doorheen lopen.

## Een lijst met objecten

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def blaf(self):
        print(f"{self.naam} zegt: Woef!")


honden = [Hond("Rex", 3), Hond("Bello", 7), Hond("Max", 1)]

for hond in honden:
    hond.blaf()
```

Uitvoer:

```
Rex zegt: Woef!
Bello zegt: Woef!
Max zegt: Woef!
```

Elke ronde is `hond` één object uit de lijst, met zijn eigen attributen en
methoden.

## Zoeken in een lijst objecten

Zoeken gaat zoals je in les 11c zocht naar het hoogste gemiddelde: houd de
beste tot nu toe bij, en vergelijk via de attributen.

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd


honden = [Hond("Rex", 3), Hond("Bello", 7), Hond("Max", 1)]

oudste = honden[0]
for hond in honden:
    if hond.leeftijd > oudste.leeftijd:
        oudste = hond

print(f"De oudste hond is {oudste.naam}.")
```

Uitvoer:

```
De oudste hond is Bello.
```

`oudste` is geen kopie, maar hetzelfde object als in de lijst. Verander je
`oudste.naam`, dan verandert de hond in de lijst mee.

## Een klasse die andere objecten bewaart

Het asiel zelf kan ook een klasse zijn. Het heeft een lijst honden als
attribuut, en methoden die met die lijst werken:

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd


class Asiel:
    def __init__(self, naam):
        self.naam = naam
        self.honden = []

    def neem_op(self, hond):
        self.honden.append(hond)

    def aantal(self):
        return len(self.honden)

    def jonger_dan(self, jaar):
        namen = []
        for hond in self.honden:
            if hond.leeftijd < jaar:
                namen.append(hond.naam)
        return namen


asiel = Asiel("De Blije Staart")
asiel.neem_op(Hond("Rex", 3))
asiel.neem_op(Hond("Bello", 7))
asiel.neem_op(Hond("Max", 1))

print(f"{asiel.naam} heeft {asiel.aantal()} honden.")
print(asiel.jonger_dan(5))
```

Uitvoer:

```
De Blije Staart heeft 3 honden.
['Rex', 'Max']
```

Wie `asiel` gebruikt, hoeft niet te weten hoe de honden bewaard worden. Hij
roept `neem_op` en `jonger_dan` aan, en het asiel regelt de rest.

## Er gaat iets mis

**Een attribuut van de lijst vragen in plaats van van een object**

```python
class Hond:
    def __init__(self, naam):
        self.naam = naam


honden = [Hond("Rex"), Hond("Bello")]
print(honden.naam)
```

Uitvoer:

```
AttributeError: 'list' object has no attribute 'naam'
```

`honden` is een lijst, en een lijst heeft geen naam. Neem eerst één hond,
`honden[0].naam`, of loop erdoorheen.

## Opdracht 14c.2: Een afspeellijst

Maak een klasse `Afspeellijst` met een `naam` en een lege lijst `nummers`.
Geef hem een methode `voeg_toe(nummer)` en een methode `totale_duur()` die
teruggeeft hoeveel seconden alle nummers samen duren.

Verwachte uitvoer:

```
Onderweg duurt 612 seconden
```

<CodeExercise>{`class Nummer:
    def __init__(self, titel, seconden):
        self.titel = titel
        self.seconden = seconden


class Afspeellijst:
    def __init__(self, naam):
        self.naam = naam
        self.nummers = []

    def voeg_toe(self, nummer):
        print(f"Nog te doen: {nummer.titel} toevoegen")

    def totale_duur(self):
        return 0

lijst.voeg_toe(Nummer("Zonnig", 201))

lijst.voeg_toe(Nummer("Thuis", 224))

<details>
<summary>Klik hier voor een tip.</summary>

`voeg_toe` doet `self.nummers.append(nummer)`. In `totale_duur` tel je in
een loop `nummer.seconden` op bij een totaal dat op 0 begint.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
class Nummer:
    def __init__(self, titel, seconden):
        self.titel = titel
        self.seconden = seconden


class Afspeellijst:
    def __init__(self, naam):
        self.naam = naam
        self.nummers = []

    def voeg_toe(self, nummer):
        self.nummers.append(nummer)

    def totale_duur(self):
        totaal = 0
        for nummer in self.nummers:
            totaal += nummer.seconden
        return totaal


lijst = Afspeellijst("Onderweg")
lijst.voeg_toe(Nummer("Zonnig", 201))
lijst.voeg_toe(Nummer("Snelweg", 187))
lijst.voeg_toe(Nummer("Thuis", 224))
print(f"{lijst.naam} duurt {lijst.totale_duur()} seconden")
```

Uitvoer:

```
Onderweg duurt 612 seconden
```

</details>

## Opdracht 14c.3: Minuten en seconden

Geef `Afspeellijst` nog een methode `langste()` die het `Nummer`-object
teruggeeft dat het langst duurt. Print daarna de titel en de duur in
minuten en seconden.

Daarvoor heb je twee rekentekens nodig die je nog niet kent. `//` deelt en
gooit de rest weg: `224 // 60` is `3`. `%` geeft juist die rest: `224 % 60`
is `44`.

Verwachte uitvoer:

```
Langste nummer: Thuis (3:44)
```

<CodeExercise>{`class Nummer:
    def __init__(self, titel, seconden):
        self.titel = titel
        self.seconden = seconden


class Afspeellijst:
    def __init__(self, naam):
        self.naam = naam
        self.nummers = []

    def voeg_toe(self, nummer):
        self.nummers.append(nummer)

    def langste(self):
        return self.nummers[0]


lijst = Afspeellijst("Onderweg")
lijst.voeg_toe(Nummer("Zonnig", 201))
lijst.voeg_toe(Nummer("Snelweg", 187))
lijst.voeg_toe(Nummer("Thuis", 224))

nummer = lijst.langste()
print(f"Langste nummer: {nummer.titel} ({nummer.seconden} s)")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Zoek het langste nummer zoals je in 14c.1 het dikste boek zocht. Voor
de seconden gebruik je `:02` in de f-string, zodat je altijd twee cijfers
krijgt: `f"{4:02}"` wordt `04`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
class Nummer:
    def __init__(self, titel, seconden):
        self.titel = titel
        self.seconden = seconden


class Afspeellijst:
    def __init__(self, naam):
        self.naam = naam
        self.nummers = []

    def voeg_toe(self, nummer):
        self.nummers.append(nummer)

    def langste(self):
        langste = self.nummers[0]
        for nummer in self.nummers:
            if nummer.seconden > langste.seconden:
                langste = nummer
        return langste


lijst = Afspeellijst("Onderweg")
lijst.voeg_toe(Nummer("Zonnig", 201))
lijst.voeg_toe(Nummer("Snelweg", 187))
lijst.voeg_toe(Nummer("Thuis", 224))

nummer = lijst.langste()
minuten = nummer.seconden // 60
seconden = nummer.seconden % 60
print(f"Langste nummer: {nummer.titel} ({minuten}:{seconden:02})")
```

Uitvoer:

```
Langste nummer: Thuis (3:44)
```

</details>
