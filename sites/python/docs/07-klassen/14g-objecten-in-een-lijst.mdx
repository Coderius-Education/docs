# 14g Objecten in een lijst

Eén hond is leuk, maar een asiel heeft er tientallen. Objecten kun je net
als getallen en teksten in een lijst stoppen, en er met een for-loop
doorheen lopen.

## Een lijst met objecten

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def blaf(self):
        print(f"{self.naam} zegt: Woef!")


honden = [Hond("Rex", 3), Hond("Bello", 7), Hond("Max", 1)]

for hond in honden:
    hond.blaf()
```

Uitvoer:

```
Rex zegt: Woef!
Bello zegt: Woef!
Max zegt: Woef!
```

Elke ronde is `hond` één object uit de lijst, met zijn eigen attributen en
methoden.

## Zoeken in een lijst objecten

Zoeken gaat zoals je in les 11c zocht naar het hoogste gemiddelde: houd de
beste tot nu toe bij, en vergelijk via de attributen.

```python
class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd


honden = [Hond("Rex", 3), Hond("Bello", 7), Hond("Max", 1)]

oudste = honden[0]
for hond in honden:
    if hond.leeftijd > oudste.leeftijd:
        oudste = hond

print(f"De oudste hond is {oudste.naam}.")
```

Uitvoer:

```
De oudste hond is Bello.
```

`oudste` is geen kopie, maar hetzelfde object als in de lijst. Verander je
`oudste.naam`, dan verandert de hond in de lijst mee.

## Er gaat iets mis

**Een attribuut van de lijst vragen in plaats van van een object**

```python
class Hond:
    def __init__(self, naam):
        self.naam = naam


honden = [Hond("Rex"), Hond("Bello")]
print(honden.naam)
```

Uitvoer:

```
AttributeError: 'list' object has no attribute 'naam'
```

`honden` is een lijst, en een lijst heeft geen naam. Neem eerst één hond,
`honden[0].naam`, of loop erdoorheen.

class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd
