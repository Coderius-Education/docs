# 14j Objecten opslaan als JSON

<Voorkennis items={[
  {to: '/docs/data/11c-geneste-dictionaries', label: '11c Geneste dictionaries'},

In [11d](/docs/data/11d-json) schreef je dictionaries en lijsten naar een
bestand. Een object van je eigen klasse lukt zo niet:

```python
import json


class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd


rex = Hond("Rex", 3)
print(json.dumps(rex))
```

Uitvoer:

```
TypeError: Object of type Hond is not JSON serializable
```

JSON kent tekst, getallen, `true`/`false`, `null`, lijsten en
dictionaries. Een `Hond` kent hij niet. Je zet het object dus eerst zelf om
naar een dictionary.

## Van object naar dictionary

Geef de klasse een methode `naar_dict()` die een dictionary teruggeeft met
één sleutel per attribuut:

```python
import json


class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def naar_dict(self):
        return {"naam": self.naam, "leeftijd": self.leeftijd}


rex = Hond("Rex", 3)
print(json.dumps(rex.naar_dict()))
```

Uitvoer:

```
{"naam": "Rex", "leeftijd": 3}
```

Dat is de hele truc: de klasse zet zichzelf om naar iets wat JSON wél kent.

## Een lijst objecten opslaan

Heb je meer objecten, dan maak je in een loop een lijst dictionaries, en
schrijf je die naar een bestand zoals in 11d:

```python
import json


class Hond:
    def __init__(self, naam, leeftijd):
        self.naam = naam
        self.leeftijd = leeftijd

    def naar_dict(self):
        return {"naam": self.naam, "leeftijd": self.leeftijd}


honden = [Hond("Rex", 3), Hond("Bello", 7)]

lijst = []
for hond in honden:
    lijst.append(hond.naar_dict())

with open("honden.json", "w") as bestand:
    json.dump(lijst, bestand, indent=2)

print(json.dumps(lijst))
```

Uitvoer:

```
[{"naam": "Rex", "leeftijd": 3}, {"naam": "Bello", "leeftijd": 7}]
```

In het bestand staat een gewone JSON-lijst met twee dictionaries. Wie het
opent, ziet niets van je klasse; die bestaat alleen in je programma.
