# 6c Een ronde overslaan met continue

Soms wil je in een loop bepaalde rondes overslaan. Kijk wat dit doet:

```python
for i in range(6):
    if i == 3:
        continue
    print(i)
```

Uitvoer:

```
0
1
2
4
5
```

De 3 ontbreekt. **`continue`** zegt: stop met déze ronde en ga meteen
door met de volgende. Alles wat in de loop ná `continue` staat (hier de
`print`) wordt die ronde overgeslagen — de loop zelf draait gewoon door.

## Waarom is dit handig?

Zonder `continue` moet je de rest van de loop in een `else` stoppen:

```python
for i in range(6):
    if i == 3:
        print("overslaan")
    else:
        print(i)
```

Bij één regel maakt dat weinig uit. Maar hoe meer code er in de loop
staat, hoe fijner het is om bovenaan te zeggen "deze ronde niet" en
daarna gewoon verder te schrijven zonder extra inspringen.

**Let op:** verwar `continue` niet met het verwante `break`, dat de
**hele loop** stopt in plaats van één ronde over te slaan. Dat is de
[volgende les](06d-break.mdx).

## Opdracht 6c.3: Tellen wat overblijft (uitdaging)

Loop door de getallen 0 t/m 20. Sla alles over dat kleiner is dan 5 of
groter dan 15. Print de getallen die overblijven, en print aan het eind
hoeveel het er waren.

Verwachte uitvoer (laatste regel):

```
Aantal geprint: 11
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Maak vóór de loop een teller die op 0 begint. Na de `continue`-check
print je het getal en doe je `teller = teller + 1`. De eindprint staat
buiten de loop.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teller = 0
for i in range(21):
    if i < 5 or i > 15:
        continue
    print(i)
    teller = teller + 1

print(f"Aantal geprint: {teller}")
```

De `continue` bewaakt de poort: alleen getallen van 5 t/m 15 komen bij
de `print` en de teller.
