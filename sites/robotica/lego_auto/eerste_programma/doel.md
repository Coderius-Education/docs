# Wat is de bedoeling?

Je editor werkt en de library staat op je bord. Voordat de sensoren en motoren erbij komen, schrijf je eerst een piepklein programma — helemaal zelf. Zo weet je zeker dat jouw code echt op het bord draait, en leer je de twee bouwstenen waar elk robotprogramma op rust: iets aanzetten, en iets blijven herhalen.

Vanaf hier bouw je in dit traject aan **één script** dat elke les een stukje groeit. Aan het eind van de rit is dat script je lijnvolger. Elke les eindigt met iets dat je op de robot kunt zien — een lampje, een waarde, een beweging — zodat je altijd weet of je stap gelukt is.

## Wanneer heb je deze stap gehaald?

- Het ingebouwde lampje van je bord knippert, met code die je zelf hebt getypt.
- Je kunt uitleggen wat de regel `while True:` doet.
