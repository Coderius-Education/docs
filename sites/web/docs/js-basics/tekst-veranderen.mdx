In de vorige les zag je dit recept al. Nu zoomen we in op het laatste stuk:

```html
<button onclick="document.getElementById('zin').textContent = 'De zon schijnt.'">Zin 1</button>
```

**`textContent`** is een eigenschap van een element: de zichtbare tekst die erin staat. Met het `=`-teken geef je die eigenschap een nieuwe waarde, en de pagina verandert meteen mee. De nieuwe tekst zet je tussen aanhalingstekens: `'De zon schijnt.'` — zo weet de browser dat het om letterlijke tekst gaat en niet om code.

Lees de regel van links naar rechts als een zin: *pak het document → zoek het element met id "zin" → zet de tekst ervan op "De zon schijnt."*.

Meerdere knoppen mogen naar hetzelfde element wijzen. Elke knop zet dan zijn eigen tekst in dezelfde `<p>` — de laatste klik wint.

## Predict

Bekijk de startcode: twee knoppen, allebei met `getElementById('zin')`.

<details>
<summary>Wat staat er in de `<p>` als je eerst op "Zin 1" en daarna op "Zin 2" klikt?</summary>

"Het regent." — elke klik vervangt de hele tekst. De tekst van "Zin 1" wordt niet aangevuld maar overschreven, want `=` geeft de eigenschap een nieuwe waarde.

</details>

## Er gaat iets mis

**Aanhalingstekens vergeten**

```html
<button onclick="document.getElementById('zin').textContent = Hallo">Klik</button>
```

```
Uncaught ReferenceError: Hallo is not defined
```

Zonder aanhalingstekens denkt de browser dat `Hallo` een stukje code is (een naam die ergens gedefinieerd moet zijn), niet een tekst. De foutmelding zie je in de browser-console (F12). Zet letterlijke tekst altijd tussen aanhalingstekens: `'Hallo'`.
