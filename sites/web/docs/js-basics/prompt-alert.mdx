Tot nu toe stond alle tekst vast in je code. Met twee ingebouwde functies praat je pagina met de gebruiker: **`alert()`** toont een bericht, **`prompt()`** stelt een vraag.

## `alert()`: toon een berichtvenster

```js
alert('Hallo wereld.');
```

Er verschijnt een pop-upvenster met je tekst en een OK-knop. De code wacht tot de gebruiker op OK klikt.

## `prompt()`: vraag om invoer

```js
const naam = prompt('Hoe heet je?');
```

Een pop-upvenster vraagt om tekst. Wat de gebruiker typt, komt in de variabele `naam` te staan. Daarna kun je die waarde gebruiken, bijvoorbeeld door hem met `+` aan een andere tekst te plakken:

```js
const naam = prompt('Hoe heet je?');
alert('Welkom, ' + naam + '.');
```

:::tip[Wanneer wel/niet?]
- **Wel**: snelle demo, mini-oefening, één losse vraag.
- **Niet**: een echte website. Pop-ups zijn storend, blokkeren de pagina en zijn niet te stylen. Daarvoor leer je later [formulieren uitlezen](/docs/js-basics/formulier-data).
:::

## Predict

Wat verschijnt er in de console als de gebruiker `16` typt?

```js
const leeftijd = prompt('Hoe oud ben je?');
console.log(leeftijd + 4);
```

<details>
<summary>Wat denk je: 20, of iets anders?</summary>

`164`. Alles wat uit `prompt()` komt is **tekst**, ook als de gebruiker een getal typt. `+` plakt teksten aan elkaar: `'16' + 4` wordt `'164'`. Waarom dat zo werkt en hoe je er wél mee rekent, leer je in [Waarden en operatoren](/docs/js-basics/operatoren-types).

</details>

Bouw een verhaaltjesmachine: vraag met drie prompts om een naam, een dier en een plaats, en zet daarna een gek verhaaltje met die drie woorden op de pagina. Sluit af met een `alert` dat het verhaal klaarstaat.

<details>
<summary>Antwoord</summary>

```js
function maakVerhaal() {
  const naam = prompt('Een naam:');
  const dier = prompt('Een dier:');
  const plaats = prompt('Een plaats:');
  document.getElementById('verhaal').textContent =
    naam + ' fietste naar ' + plaats + ' en kwam daar een pratende ' + dier + ' tegen.';
  alert('Je verhaal staat klaar.');
}

document.getElementById('knop').addEventListener('click', maakVerhaal);
```

</details>

## Er gaat iets mis

**De plus vergeten bij het plakken**

```js
alert('Hallo ' naam);
```

```
Uncaught SyntaxError: missing ) after argument list
```

Tussen elk stuk tekst en elke variabele hoort een `+`. Zonder die plus begrijpt JavaScript de regel niet meer en stopt het script meteen — er verschijnt dan helemaal geen pop-up. Controleer bij deze foutmelding of elke overgang tekst-variabele een `+` heeft: `alert('Hallo ' + naam);`.
