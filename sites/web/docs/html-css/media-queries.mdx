## Wat ga je leren?

Je leert hoe je je CSS laat reageren op de **schermbreedte** met een **media query** — zo ziet je pagina er goed uit op zowel een mobiel als een laptop.

## Theorie

Een **media query** is een CSS-blok dat alleen wordt toegepast onder bepaalde voorwaarden — meestal: als het scherm smaller of breder is dan een bepaalde breedte.

```css
.kaart {
  width: 600px;
}

@media (max-width: 700px) {
  .kaart {
    width: 100%;
  }
}
```

Lees dit als: "als de schermbreedte 700px of minder is, gebruik dan deze regels". Op een laptop is de kaart 600px breed; op een telefoon vult hij de hele breedte.

### De twee meest-gebruikte voorwaarden

| Voorwaarde | Wanneer geldig |
|---|---|
| `(max-width: 700px)` | Schermen **smaller** dan 700px (mobiel) |
| `(min-width: 800px)` | Schermen **breder** dan 800px (desktop) |

Je kunt ze ook combineren: `@media (min-width: 600px) and (max-width: 900px)` → alleen tablets.

### Aanpak: "mobile-first"

Veel ontwikkelaars schrijven hun CSS eerst voor **kleine schermen** (geen media query nodig) en voegen daarna regels toe voor grotere schermen via `min-width`. Je opent dan voor de smalle weergave geen apart blok — die is de basis.

```css
/* Basis: mobiel */
.menu { flex-direction: column; }

/* Aanvulling: desktop */
@media (min-width: 700px) {
  .menu { flex-direction: row; }
}
```

## Predict

Wat denk je dat er gebeurt met dit blok als je het voorbeeld op een breedte onder 600px bekijkt?

```css
.titel { font-size: 3rem; }
@media (max-width: 600px) {
  .titel { font-size: 1.5rem; }
}
```

<details>
<summary>Klik hier voor het antwoord</summary>

Op brede schermen is `.titel` 3rem groot (zo'n 48px). Zodra de breedte onder 600px komt, schakelt de browser over naar de media-query-regel en wordt `.titel` 1,5rem (24px) — half zo groot. Kies je weer een bredere stand, dan keert het terug.

</details>

## Er gaat iets mis

**De viewport-meta-tag vergeten**

```html
<!-- Deze regel ontbreekt in de <head> -->
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Zonder die regel doet een telefoon alsof zijn scherm 980px breed is en krimpt hij de hele pagina. Je `max-width: 600px`-regel wordt dan nooit gebruikt, hoe smal het toestel ook is. Op je laptop zie je daar niets van: daar klopt de breedte wel. Zet hem altijd in de `<head>`.

**Een breekpunt kiezen dat je nooit haalt**

```css
/* Deze regel gaat nooit aan op een telefoon */
@media (min-width: 1200px) {
  .kaart { background-color: lightgreen; }
}
```

Een `min-width` die hoger ligt dan het scherm waarop je test, doet niets — en dat lijkt op een fout in je CSS. Controleer met de knoppen boven het voorbeeld op welke breedte je kijkt voordat je je regel gaat aanpassen.
