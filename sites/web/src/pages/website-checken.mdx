# Website checken

Heb je [je eigen website](/jouw-website) af, of ben je een eind op weg? Upload je projectbestanden en zie meteen hoeveel bestanden je hebt. Wil je verder werken? Open je project met de knop **Bekijk in Online Editor**.

**Let op:** je bestanden gaan nooit naar een server. Alles gebeurt in je eigen browser — de website-checker werkt zelfs zonder internetverbinding, zodra de pagina geladen is.

## Wat kun je uploaden?

- Een **.zip-bestand** van je project
- **Losse bestanden** (je `index.html`, `style.css`, `script.js`, …)
- Een **hele map** met je project
