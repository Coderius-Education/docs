# Website checken

Heb je [je eigen website](/jouw-website) af, of ben je een eind op weg? Upload je projectbestanden en krijg een overzicht: hoeveel bestanden je hebt, welke HTML-elementen je gebruikt, en welke CSS- en JavaScript-technieken uit de [cheatsheet](/cheatsheet) je hebt toegepast.

**Let op:** je bestanden gaan nooit naar een server. Alles gebeurt in je eigen browser — de website-checker werkt zelfs zonder internetverbinding, zodra de pagina geladen is.

## Wat kun je uploaden?

- Een **.zip-bestand** van je project
- **Losse bestanden** (je `index.html`, `style.css`, `script.js`, …)
- Een **hele map** met je project

## Hoe lees ik het rapport?

Groene, aangevinkte items zijn technieken die je hebt gebruikt. Grijze items staan nog op "niet gebruikt" — dat is geen fout, sommige technieken passen gewoon niet bij elk project. Gebruik het als checklist: kun je een grijs item alsnog ergens toepassen, of past het niet bij jouw idee?
