# Je eerste website

Wij zijn groot fan van de cursus Web Lab op de site van de non-profit code.org.

Je leert in deze cursus de basis van web development: HTML & CSS.

## Hoe te beginnen?
Je gaat naar [deze link](https://studio.code.org/courses/web-development-2026/units/1/lessons/2/levels/1?login_required=true). 

- Volg je Informatica? Dan krijg je een inlogcode van je docent
- Volg je dit buiten een les? Vergeet dan niet een account aan te maken.

## Welke lessen zijn interessant?

De volgende lessen zijn erg nuttig. De volgorde is expres zo gekozen om je zo
prettig mogelijk te laten leren. Klik op een lesnummer om de les op Code.org te
openen, of op de oefenpagina voor onze uitleg in het Nederlands.

<CodeOrgTabel />

Hierna kun je in één van de laatste levels je eigen website maken.
