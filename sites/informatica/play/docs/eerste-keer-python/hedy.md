# Python leren via Hedy

[Hedy](https://hedy.org/) is een programmeertaal die stap voor stap meer op Python gaat lijken. Je begint met commando's in het Nederlands en bij elk niveau verdwijnt er een stukje hulp, tot je aan het eind gewoon Python schrijft.

Dat maakt het een zachte instap als code je nog helemaal niets zegt. Je werkt in de browser, in het Nederlands, en je hoeft niets te installeren.

## Wanneer stap je over

Rond niveau 12 schrijf je code die op Python lijkt: variabelen, `if` en herhalingen. Dat is het moment om over te stappen naar coderius-play, of eerst naar <SiteLink site="python" to="/">coderius-python</SiteLink> als je de Python-schrijfwijze nog wilt oefenen.

Hedy is er niet alleen in het Nederlands: je kunt de taal van de commando's zelf kiezen.
