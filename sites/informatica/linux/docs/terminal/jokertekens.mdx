# 2.4 Jokertekens

## Het sterretje

<Voorkennis items={[{to: '/docs/terminal/kopieren', label: 'Kopiëren, verplaatsen en weggooien'}]} />

Tien foto's verplaatsen met tien keer `mv`? Dat hoeft niet. Maak in de oefenterminal een paar bestanden:

```bash
mkdir fotos
cd fotos
touch strand.jpg zee.jpg kat.png verslag.txt
ls *.jpg
```

```
strand.jpg  zee.jpg
```

Het sterretje `*` is een **jokerteken**: het past op elk stuk tekst, ook op niets. `*.jpg` betekent "alles wat op `.jpg` eindigt".

<LinuxTerminal title="Oefenterminal" />

## De shell vult het in

De **shell** is het programma dat leest wat je typt en daarna het commando start. Op Ubuntu heet hij `bash`: daarom begint een melding als `bash: cd: www: No such file or directory` met zijn naam. Niet `ls` zoekt de bestanden, maar de shell: die vervangt `*.jpg` door de namen die passen, voordat het commando start. Met `echo` zie je wat het commando dan krijgt:

```bash
echo *.jpg
```

```
strand.jpg zee.jpg
```

Daarom werkt een jokerteken bij elk commando, niet alleen bij `ls`: ook `cat`, `cp`, `mv` en `rm` krijgen de namen die passen.

### Het vraagteken

Het vraagteken `?` past op precies één teken:

```bash
ls ?at.png
```

```
kat.png
```

### Tussen aanhalingstekens

Tussen aanhalingstekens vult de shell niets in. Dan krijgt het commando het sterretje zelf:

```bash
echo '*.jpg'
```

```
*.jpg
```

## Veel tegelijk verplaatsen \{#veel-bestanden-tegelijk-verplaatsen}

Met een jokerteken en een map aan het eind verplaats je alles in één keer:

```bash
mkdir vakantie
mv *.jpg vakantie/
ls
```

```
kat.png  vakantie  verslag.txt
```

`mv *.jpg vakantie/` wordt `mv strand.jpg zee.jpg vakantie/`: twee bestanden, en het laatste woord is de map waar ze heen gaan.

## Voorspel

Je staat in `fotos`, met `kat.png`, `verslag.txt` en de map `vakantie`. Je typt `rm *`. Wat gebeurt er?

<details>
<summary>Klik hier als je het hebt geprobeerd</summary>

`kat.png` en `verslag.txt` zijn weg, zonder vraag en zonder prullenbak. Alleen de map blijft staan, omdat `rm` zonder `-r` geen map weggooit:

```
rm: cannot remove 'vakantie': Is a directory
```

`rm *` is een van de gevaarlijkste regels die je kunt typen. Kijk daarom eerst met `echo *` wat er past: dat zijn precies de namen die `rm` krijgt. `ls *` laat van een map ook de inhoud zien, hier `strand.jpg` en `zee.jpg`, terwijl `rm *` die laat staan.

</details>

## Opdracht 2.4.a: foto's sorteren

In de map `downloads` in je thuismap staan foto's, een liedje en een paar documenten door elkaar.

1. Maak in `downloads` een map `fotos`.
2. Verplaats alle `.jpg`- en `.png`-bestanden daarheen, met één `mv` en jokertekens.
3. Laat zien wat er nu in `fotos` staat.

</details>

De shell maakt van de derde regel `mv vakantie1.jpg vakantie2.jpg kat.png fotos/`.

## Opdracht 2.4.b: opruimen met een vangnet

In de map `project` staan bestanden die op `.tmp` eindigen: rommel die een programma achterliet. Gooi ze weg, en alleen die.

1. Kijk eerst met `ls` en een jokerteken welke bestanden je gaat weggooien.
2. Gooi ze dan weg met één `rm`.

## Er gaat iets mis

### cannot access met een sterretje erin

```
ls: cannot access '*.jpeg': No such file or directory
```

**Oorzaak:** er past geen enkel bestand. Dan laat de shell het sterretje staan, en zoekt `ls` naar een bestand dat letterlijk `*.jpeg` heet. Vaak is het een andere extensie: `.jpg` in plaats van `.jpeg`.

**Oplossing:** kijk met `ls` hoe de bestanden echt heten.

### Een bestand is weg na mv

**Oorzaak:** je vergat de map aan het eind. Met twee foto's wordt `mv *.jpg` dan `mv strand.jpg zee.jpg`: dat hernoemt `strand.jpg` naar `zee.jpg`, en de oude `zee.jpg` is weg.

**Oplossing:** zet altijd een map als laatste woord, met een `/` erachter. Bestaat die map niet, dan weigert `mv` in plaats van stil iets te overschrijven.

```bash
# FOUT
mv *.jpg

# GOED
mv *.jpg vakantie/
```

### Not a directory

```
mv: target 'zee.jpg': Not a directory
```

**Oorzaak:** ook hier vergat je de map aan het eind, nu met drie foto's of meer. `mv` neemt het laatste woord als doel, en `zee.jpg` is geen map.

**Oplossing:** zet de map erachter: `mv *.jpg vakantie/`.

### missing destination file operand

```
mv: missing destination file operand after 'strand.jpg'
Try 'mv --help' for more information.
```

**Oorzaak:** de map aan het eind ontbreekt, en er past maar één foto op `*.jpg`. Dan krijgt `mv` één naam, en mist hij het doel.

**Oplossing:** zet de map erachter: `mv *.jpg vakantie/`.

### subdirectory of itself

```
mv: cannot move 'fotos' to a subdirectory of itself, 'fotos/fotos'
```

**Oorzaak:** je typte `mv * fotos/`. Het sterretje past op alles, ook op de map `fotos` zelf, en een map kan niet in zichzelf. De rest is wel verplaatst, ook wat geen foto is.

**Oplossing:** noem alleen wat je wilt verplaatsen, zoals `mv *.jpg *.png fotos/`. Kijk eerst met `echo` en dezelfde jokertekens wat er past.
