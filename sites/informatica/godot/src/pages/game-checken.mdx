# Game checken

Heb je je Godot-game af, of ben je een eind op weg? Upload je projectbestanden (of een zip van je hele project) en zie meteen hoeveel bestanden je hebt.

**Let op:** je bestanden gaan nooit naar een server. Alles gebeurt in je eigen browser.

## Wat kun je uploaden?

- Een **.zip-bestand** van je project
- **Losse bestanden** (je `.gd`-scripts, `.tscn`-scenes, `project.godot`)
- Een **hele map** met je project
