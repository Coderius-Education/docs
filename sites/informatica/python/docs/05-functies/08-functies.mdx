# 8 Functies

Wil je hetzelfde stuk code op meer plekken in je programma gebruiken, dan schrijf je het één keer als **functie**: je geeft een blok code een naam, en daarna roep je het aan zo vaak als je wilt.

## Van losse regels naar een functie

### Schrijf het uit

Een lied voor de schoolreis heeft twee coupletten, en na elk couplet komt het refrein. Zonder functie staat elke regel van het lied er los:

```python
print("De bus staat voor de school")
print("Hé ho, we gaan op reis")
print("En niemand wil naar huis")
print("De bus staat in de file")
print("Hé ho, we gaan op reis")
print("En niemand wil naar huis")
```

Uitvoer:

```
De bus staat voor de school
Hé ho, we gaan op reis
En niemand wil naar huis
De bus staat in de file
Hé ho, we gaan op reis
En niemand wil naar huis
```

Het refrein staat er twee keer, op twee plekken. Een loop lost dat niet op: tussen de refreinen staat steeds een ander couplet. Voor een derde couplet typ je het refrein nog een keer.

### Maak de functie

Met `def` geef je de twee regels van het refrein een naam: `refrein`. De gemarkeerde regels zijn nieuw: de regel met `def`, en daaronder het refrein, dat vier spaties inspringt. Zo weet Python welke regels bij de functie horen. Onder de functie staan alleen nog de coupletten.

```python {1-3}
def refrein():
    print("Hé ho, we gaan op reis")
    print("En niemand wil naar huis")

print("De bus staat voor de school")
print("De bus staat in de file")
```

Uitvoer:

```
De bus staat voor de school
De bus staat in de file
```

Het refrein is van het scherm verdwenen. `def` maakt de functie alleen: Python onthoudt hem, maar voert de regels erin nog niet uit.

### Roep hem aan

Een functie **aanroepen** doe je met zijn naam en haakjes: `refrein()`. Pas dan voert Python de regels in de functie uit. De gemarkeerde regels zijn nieuw: een aanroep na elk couplet.

```python {6,8}
def refrein():
    print("Hé ho, we gaan op reis")
    print("En niemand wil naar huis")

print("De bus staat voor de school")
refrein()
print("De bus staat in de file")
refrein()
```

Uitvoer:

```
De bus staat voor de school
Hé ho, we gaan op reis
En niemand wil naar huis
De bus staat in de file
Hé ho, we gaan op reis
En niemand wil naar huis
```

Dat is dezelfde uitvoer als van de zes losse regels. Een derde couplet kost nu twee regels: het couplet en `refrein()`. En een ander refrein verander je op één plek, in de functie.

### Voorspel

```python
def trommel():
    print("Boem")

def fanfare():
    trommel()
    print("Toet")
    trommel()

fanfare()
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="De regels trommel() in fanfare zijn ook aanroepen. Python voert ze uit.">`Toet`</Keuze>
  <Keuze goed uitleg="fanfare roept trommel aan, print zelf een regel en roept trommel weer aan.">`Boem`, `Toet` en `Boem`</Keuze>
  <Keuze uitleg="Een aanroep mag ook in een functie staan. Python kent trommel dan al.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `Boem`, `Toet` en `Boem`. Een functie mag een andere functie aanroepen. `fanfare()` voert zijn drie regels van boven naar beneden uit, en bij elke `trommel()` doet Python eerst wat in `trommel` staat. Zo bouw je een grote functie uit kleine.

  </Uitleg>
</Voorspel>

## Maak het af

Dit programma loopt een schooldag van drie uur af. Na het eerste en het tweede uur gaat de bel; na het derde uur ga je naar huis. De functie `bel` staat er al, maar niemand roept hem aan: op het scherm staan alleen de uren. Eén stap is nog open: de aanroepen van `bel` op de goede plek. Doe die zelf, en typ er geen `print` bij: de functie staat er al.

```

Naar het volgende lokaal
Uur 2: Engels
Tring
Boeken in je tas
Naar het volgende lokaal
Uur 3: gym
Naar huis
```

## Puzzel

Na een voorstelling klapt het publiek, maar de regels van het programma staan door elkaar. De functie `applaus` print drie keer `Klap` en daarna één keer `Bravo`. Het programma roept de functie één keer aan, en pas daarna valt het doek.

<Puzzel taal="python" code={`def applaus():
    for i in range(3):
        print("Klap")
    print("Bravo")
applaus()
print("Het doek valt.")`}>

De `def` staat bovenaan, want Python leest van boven naar beneden en moet de functie kennen voordat je hem aanroept. `print("Klap")` springt twee keer in en hoort dus bij de `for`. `print("Bravo")` staat onder de loop en komt één keer. `applaus()` springt niet in: pas op die regel voert Python de functie uit, en daarna gaat hij verder met het doek.

</Puzzel>

## Er gaat iets mis

### De haakjes vergeten

```python
def groet():
    print("Hallo!")

groet
```

Er gebeurt niets, en je krijgt ook geen foutmelding. Zonder `()` noem je de functie alleen; je roept hem niet aan. Schrijf `groet()`.

### De aanroep springt in

```python
def groet():
    print("Hallo!")
    groet()

print("Klaar")
```

Uitvoer:

```
Klaar
```

Geen foutmelding, maar `Hallo!` komt niet op het scherm. `groet()` springt in en hoort dus bij de functie zelf: buiten de functie roept niemand hem aan. De aanroep die je programma doet, staat tegen de kantlijn, zonder spaties ervoor. Een aanroep in een andere functie springt wel in, mee met die functie, zoals `trommel()` in `fanfare` uit de voorspelvraag.

### Aanroepen voordat de functie bestaat

{/* foutmelding-van: blok-erboven */}

```python
groet()

def groet():
    print("Hallo!")
```

Uitvoer:

```
NameError: name 'groet' is not defined
```

Python leest van boven naar beneden. Op de eerste regel bestaat `groet` nog niet. Zet de `def` boven de plek waar je de functie aanroept.

Maak een tekening van een huis door **kleine functies te combineren**: `dak()`, `muur()` en `deur()`. Roep ze allemaal aan binnen één `huis()`-functie, met twee muren tussen het dak en de deur.

Een backslash (`\`) schrijf je in een tekst dubbel: `print("   /\\")` zet `   /\` op het scherm.

Verwachte uitvoer:

```
   /\
  /  \
 /____\
|      |
|      |
|  []  |
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Elke functie print een of meer regels. In `huis()` roep je `dak()`, `muur()`, `muur()` en `deur()` aan.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python

def huis():
    dak()
    muur()
    muur()
    deur()

huis()
```
