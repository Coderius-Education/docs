# 8 Functies

Wil je hetzelfde stuk code op meer plekken in je programma gebruiken, dan schrijf je het één keer als **functie**: je geeft een blok code een naam, en daarna roep je het aan zo vaak als je wilt.

## Een functie maken en aanroepen

Met `def` definieer je een functie. Roepen doe je met de naam en haakjes:

```python
def groet():
    print("Hallo!")

groet()
groet()
```

Uitvoer:

```
Hallo!
Hallo!
```

- `def groet():` definieert de functie. Python onthoudt hem, maar voert nog niets uit.
- `groet()` roept de functie aan. Pas dan voert Python de code binnenin uit.
- De code binnen de functie springt **4 spaties** in.

```python
def groet():
    print("Hallo!")

print("Klaar")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="def maakt de functie alleen. Zonder aanroep draait de code erin nooit.">`Hallo!` en `Klaar`</Keuze>
  <Keuze goed uitleg="De functie bestaat, maar niemand roept hem aan. Alleen de laatste regel draait.">`Klaar`</Keuze>
  <Keuze uitleg="Een functie die je niet aanroept is geen fout. Python onthoudt hem en gaat door.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet alleen `Klaar`. `def` is een recept opschrijven, `groet()` is het recept uitvoeren. Zonder die aanroep komt `Hallo!` nooit op het scherm.

## Functies mogen functies aanroepen

```python
def lijn():
    print("=" * 20)

def welkom():
    lijn()
    print("  Welkom bij Python!")
    lijn()

welkom()
```

Uitvoer:

```
====================
  Welkom bij Python!
====================
```

Eén kleine functie (`lijn`) gebruik je twee keer binnen een grotere functie (`welkom`). Je schrijft de lijn één keer en gebruikt hem zo vaak als je wilt.

## Er gaat iets mis

**De haakjes vergeten**

```python
def groet():
    print("Hallo!")

groet
```

Er gebeurt niets, en je krijgt ook geen foutmelding. Zonder `()` noem je de functie alleen; je roept hem niet aan. Schrijf `groet()`.

**Aanroepen voordat de functie bestaat**

{/* foutmelding-van: blok-erboven */}

```python
groet()

def groet():
    print("Hallo!")
```

Uitvoer:

```
NameError: name 'groet' is not defined
```

Python leest van boven naar beneden. Op de eerste regel bestaat `groet` nog niet. Zet de `def` boven de plek waar je de functie aanroept.

## Opdracht 8.3: Een huisje bouwen

Maak een tekening van een huis door **kleine functies te combineren**: `dak()`, `muur()` en `deur()`. Roep ze allemaal aan binnen één `huis()`-functie, met twee muren tussen het dak en de deur.

In het dak staat een backslash (`\`). Die heeft in een tekst een speciale betekenis, dus schrijf je hem dubbel: `print("   /\\")` zet `   /\` op het scherm.

Verwachte uitvoer:

```
   /\
  /  \
 /____\
|      |
|      |
|  []  |
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Elke functie print een of meer regels. In `huis()` roep je `dak()`, `muur()`, `muur()` en `deur()` aan.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def dak():
    print("   /\\")
    print("  /  \\")
    print(" /____\\")

def muur():
    print("|      |")

def deur():
    print("|  []  |")

def huis():
    dak()
    muur()
    muur()
    deur()

huis()
```
