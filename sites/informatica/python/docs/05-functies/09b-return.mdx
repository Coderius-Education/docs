# 9b Return

Je functies met parameters tonen iets op het scherm. Wil je met de uitkomst **verder rekenen**, dan laat je de functie hem teruggeven met `return`. Die waarde kun je bewaren of in een berekening gebruiken.

## Van printen naar teruggeven

### Schrijf de functie

Een quiz heeft twee rondes, en elk goed antwoord is tien punten waard. Je wilt per ronde de punten zien, en daarna het totaal. Eerst een functie die de punten van één ronde uitrekent en print:

```python
def punten(goed):
    print(goed * 10)

punten(4)
punten(3)
```

Uitvoer:

```
40
30
```

De punten van elke ronde staan op het scherm, maar welk getal bij welke ronde hoort, zie je niet. Het totaal ontbreekt ook nog.

### Bewaar de uitkomst

Een uitkomst die je later nodig hebt, bewaar je in een variabele. De gemarkeerde regels zijn nieuw of veranderd: `ronde1` en `ronde2` vangen op wat de functie oplevert, en twee `print`-regels zetten ze in een zin.

```python {4-7}
def punten(goed):
    print(goed * 10)

ronde1 = punten(4)
ronde2 = punten(3)
print(f"Ronde 1: {ronde1} punten")
print(f"Ronde 2: {ronde2} punten")
```

Uitvoer:

```
40
30
Ronde 1: None punten
Ronde 2: None punten
```

In `ronde1` en `ronde2` zit `None`: letterlijk "geen waarde". De functie zet de 40 en de 30 op het scherm, maar geeft ze niet door aan de regel die hem aanroept.

### Geef hem terug

**`return`** geeft een waarde terug aan de plek van de aanroep. De gemarkeerde regel is veranderd: in de functie staat `return` waar `print` stond.

```python {2}
def punten(goed):
    return goed * 10

ronde1 = punten(4)
ronde2 = punten(3)
print(f"Ronde 1: {ronde1} punten")
print(f"Ronde 2: {ronde2} punten")
```

Uitvoer:

```
Ronde 1: 40 punten
Ronde 2: 30 punten
```

`ronde1 = punten(4)` vangt de 40 op. De losse `40` en `30` zijn weg: de functie zet zelf niets meer op het scherm. Het totaal ontbreekt nog.

### Reken ermee verder

Met een waarde die terugkomt, kun je rekenen, net als met elk ander getal. De gemarkeerde regel is nieuw: een `print` die de twee rondes optelt.

```python {8}
def punten(goed):
    return goed * 10

ronde1 = punten(4)
ronde2 = punten(3)
print(f"Ronde 1: {ronde1} punten")
print(f"Ronde 2: {ronde2} punten")
print(f"Totaal: {ronde1 + ronde2} punten")
```

Uitvoer:

```
Ronde 1: 40 punten
Ronde 2: 30 punten
Totaal: 70 punten
```

Met de `print` in de functie kon dit niet: `None` plus `None` geeft een foutmelding. Maak je een functie om een waarde te berekenen, dan hoort er een `return` in. Toont de functie alleen iets, dan is `print` genoeg.

### Voorspel

```python
def verdubbel(getal):
    return getal * 2

print(verdubbel(verdubbel(3)))
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Dat geeft de binnenste aanroep terug. De buitenste doet er nog iets mee.">`6`</Keuze>
  <Keuze goed uitleg="Eerst de binnenste aanroep, daarna de buitenste met die uitkomst.">`12`</Keuze>
  <Keuze uitleg="Een aanroep levert een waarde op, en een waarde mag je meegeven.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `12`. Python rekent eerst de binnenste aanroep uit: `verdubbel(3)` geeft 6 terug. Die 6 is het argument van de buitenste aanroep, en `verdubbel(6)` geeft 12. Een aanroep van een functie met `return` mag dus overal staan waar een waarde past: in een berekening, in een f-string of tussen de haakjes van een andere aanroep.

  </Uitleg>
</Voorspel>

## Maak het af

Je fietst 4 minuten over een kilometer. De functie `fietstijd` rekent uit hoe lang een rit duurt, maar geeft die uitkomst niet terug: op het scherm staat twee keer `None`. Twee stappen zijn nog open: de uitkomst teruggeven, en onderaan een regel die de twee ritten optelt. Doe die zelf, en laat de regels onder de functie staan.

Verwachte uitvoer:

```
Naar school: 12 minuten
Naar de club: 20 minuten
Samen: 32 minuten
```

<CodeExercise>{`def fietstijd(km):
    minuten = km * 4

school = fietstijd(3)
club = fietstijd(5)
print(f"Naar school: {school} minuten")
print(f"Naar de club: {club} minuten")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

De functie rekent `minuten` uit en doet er daarna niets mee. Welke regel geeft een waarde terug, en hoort die regel in de functie of eronder? Voor het totaal tel je twee variabelen op die je al hebt.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def fietstijd(km):
    minuten = km * 4
    return minuten

school = fietstijd(3)
club = fietstijd(5)
print(f"Naar school: {school} minuten")
print(f"Naar de club: {club} minuten")
print(f"Samen: {school + club} minuten")
```

Met `print(minuten)` in de functie staan de getallen wel op het scherm, maar blijven `school` en `club` `None`, en dan loopt de laatste regel vast.

</details>

## Puzzel

De functie `groepsprijs` rekent uit wat een groep betaalt in de bioscoop, maar de regels staan door elkaar. Een kaartje kost 12 euro en de groep krijgt samen 10 euro korting. Het programma bewaart de uitkomst in `bedrag` en print een zin met dat bedrag.

<Puzzel taal="python" code={`def groepsprijs(aantal):
    totaal = aantal * 12
    met_korting = totaal - 10
    return met_korting
bedrag = groepsprijs(4)
print(f"Jullie betalen {bedrag} euro.")`}>

In de functie staat `return` onderaan. Daar stopt de functie, dus alles wat hij moet uitrekenen staat erboven: eerst `totaal`, dan `met_korting`, dat `totaal` nodig heeft. Onder de functie vangt `bedrag = groepsprijs(4)` de waarde op die terugkomt. Pas daarna kan de `print` hem gebruiken.

</Puzzel>

## Er gaat iets mis

### Rekenen met een functie zonder return

{/* foutmelding-van: blok-erboven */}

```python
def verdubbel(getal):
    print(getal * 2)

print(verdubbel(5) + 1)
```

Uitvoer:

```
10
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

De functie print `10` en geeft `None` terug, en bij `None` kun je geen 1 optellen. Vervang de `print` in de functie door `return`.

### Code na return

```python
def verdubbel(getal):
    return getal * 2
    print("Klaar met verdubbelen")

print(verdubbel(5))   # 10
```

`Klaar met verdubbelen` komt nooit op het scherm. Bij `return` stopt de functie meteen, dus wat eronder staat draait niet. Zet zo'n regel boven de `return`.

### return buiten de functie

{/* niet-compileren: bewuste syntaxfout, return staat buiten de functie */}

```python
def verdubbel(getal):
    uitkomst = getal * 2
return uitkomst
```

Uitvoer:

{/* foutmelding-van: def verdubbel(getal):\n    uitkomst = getal * 2\nreturn uitkomst */}

```
SyntaxError: 'return' outside function
```

`return` hoort bij de functie en springt dus in, net als de regel erboven. Zonder die vier spaties staat hij buiten de functie, en daar valt niets terug te geven.

## Opdracht 9b.2: Max van twee

Schrijf een functie `max_van_twee(a, b)` die het grootste van twee getallen teruggeeft. Gebruik `if`/`else` in de functie.

Verwachte uitvoer:

```
20
7
5
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Als `a > b`, `return a`. Anders `return b`. Bij gelijke getallen maakt het niet uit welke je teruggeeft.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def max_van_twee(a, b):
    if a > b:
        return a
    else:
        return b

print(max_van_twee(10, 20))
print(max_van_twee(7, 3))
print(max_van_twee(5, 5))
```

## Opdracht 9b.3: Rekenmachine met functies

Bouw vier functies die elk een resultaat teruggeven: `optellen`, `aftrekken`, `vermenigvuldigen`, `delen`. Bij `delen` moet je eerst checken of `b` niet `0` is — als dat zo is, geef de tekst `"Fout: delen door 0!"` terug.

Verwachte uitvoer (bij `a = 20`, `b = 4`):

```
20 + 4 = 24
20 - 4 = 16
20 x 4 = 80
20 / 4 = 5.0
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`aftrekken` en `vermenigvuldigen` zijn één regel (`return a - b`, `return a * b`). Bij `delen`: `if b == 0:` → return de foutmelding, anders `return a / b`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def optellen(a, b):
    return a + b

def aftrekken(a, b):
    return a - b

def vermenigvuldigen(a, b):
    return a * b

def delen(a, b):
    if b == 0:
        return "Fout: delen door 0!"
    else:
        return a / b

a = 20
b = 4

print(f"{a} + {b} = {optellen(a, b)}")
print(f"{a} - {b} = {aftrekken(a, b)}")
print(f"{a} x {b} = {vermenigvuldigen(a, b)}")
print(f"{a} / {b} = {delen(a, b)}")
```

Je kunt nu zelf functies schrijven. In het hoofdstuk Modules haal je functies binnen die anderen al voor je schreven, met **`import`**.
