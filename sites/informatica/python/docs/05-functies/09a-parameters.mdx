# 9a Parameters

Je functies uit de vorige les deden altijd precies hetzelfde. Met een **parameter** geef je een functie informatie mee, en dan kan dezelfde functie verschillende dingen doen.

## Een parameter meegeven

### Schrijf de functie

Je nodigt Noor en Daan uit voor je feest. Op elke kaart staat de naam van de gast, en wat die gast meeneemt. Eerst een functie zoals je die kent, met de kaart voor Noor erin:

```python
def kaart():
    print("Hoi Noor,")
    print("Kom je naar mijn feest?")
    print("Groetjes, Sam")

kaart()
kaart()
```

Uitvoer:

```
Hoi Noor,
Kom je naar mijn feest?
Groetjes, Sam
Hoi Noor,
Kom je naar mijn feest?
Groetjes, Sam
```

Twee aanroepen geven twee kaarten voor Noor. De tweede was voor Daan bedoeld, maar de functie doet elke keer hetzelfde.

### Geef iets mee

Een **parameter** is een naam tussen de haakjes van `def`: een variabele die zijn waarde krijgt bij de aanroep. De gemarkeerde regels zijn veranderd: de `def` heeft de parameter `naam`, de eerste `print` gebruikt hem in een f-string, en elke aanroep geeft een naam mee.

```python {1-2,6-7}
def kaart(naam):
    print(f"Hoi {naam},")
    print("Kom je naar mijn feest?")
    print("Groetjes, Sam")

kaart("Noor")
kaart("Daan")
```

Uitvoer:

```
Hoi Noor,
Kom je naar mijn feest?
Groetjes, Sam
Hoi Daan,
Kom je naar mijn feest?
Groetjes, Sam
```

`"Noor"` en `"Daan"` zijn de **argumenten**: de waardes die je meegeeft bij de aanroep. Elke gast heeft een eigen kaart, maar wat die gast meeneemt, staat er nog niet op.

### Geef meer mee

Een functie mag meer parameters hebben, met een komma ertussen. De gemarkeerde regels zijn nieuw of veranderd: de `def` heeft er `hapje` bij, een nieuwe `print` gebruikt hem, en elke aanroep geeft twee argumenten mee.

```python {1,4,7-8}
def kaart(naam, hapje):
    print(f"Hoi {naam},")
    print("Kom je naar mijn feest?")
    print(f"Neem jij de {hapje} mee?")
    print("Groetjes, Sam")

kaart("Noor", "chips")
kaart("Daan", "cola")
```

Uitvoer:

```
Hoi Noor,
Kom je naar mijn feest?
Neem jij de chips mee?
Groetjes, Sam
Hoi Daan,
Kom je naar mijn feest?
Neem jij de cola mee?
Groetjes, Sam
```

Noor neemt de chips mee en Daan de cola. Binnen de functie zijn `naam` en `hapje` gewone variabelen: je gebruikt ze waar je een waarde nodig hebt.

### Voorspel

```python
def adres(straat, nummer):
    print(f"{straat} {nummer}")

adres(12, "Hoofdstraat")
```

## Maak het af

In de kantine kost alles 3 euro. De functie `bon` krijgt een product en een aantal, en print wat dat samen kost. De zin klopt al, maar de prijs is bij elke aanroep 6 euro: in de berekening staat nog een vast getal. Eén stap is nog open: de parameter in de berekening. Doe die zelf.

Verwachte uitvoer:

```
2 keer tosti: 6 euro
5 keer soep: 15 euro
```

<CodeExercise>{`def bon(product, aantal):
    prijs = 2 * 3
    print(f"{aantal} keer {product}: {prijs} euro")

bon("tosti", 2)
bon("soep", 5)`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Draai het programma eerst: vijf keer soep kost ook 6 euro. In de berekening staan twee getallen. Welk van de twee is de prijs van één product, en welk hoort bij elke aanroep anders te zijn?

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def bon(product, aantal):
    prijs = aantal * 3
    print(f"{aantal} keer {product}: {prijs} euro")

bon("tosti", 2)
bon("soep", 5)
```

Een parameter is binnen de functie een gewone variabele, dus je mag ermee rekenen.

</details>

## Er gaat iets mis

### Een argument vergeten

{/* foutmelding-van: blok-erboven */}

```python
def adres(straat, nummer):
    print(f"{straat} {nummer}")

adres("Hoofdstraat")
```

Uitvoer:

```
TypeError: adres() missing 1 required positional argument: 'nummer'
```

Python noemt de functie en de parameter die hij mist. Raden welk nummer je bedoelt kan hij niet.

### Een argument te veel

{/* foutmelding-van: blok-erboven */}

```python
def begroet(naam):
    print(f"Hallo, {naam}!")

begroet("Sara", "Alex")
```

Uitvoer:

```
TypeError: begroet() takes 1 positional argument but 2 were given
```

`begroet` heeft één parameter, dus hij neemt één argument. Wil je twee mensen begroeten, roep hem dan twee keer aan.

### De parameter niet gebruiken

```python
def begroet(naam):
    print("Hallo, Sara!")

begroet("Sara")
begroet("Alex")
```

Uitvoer:

```
Hallo, Sara!
Hallo, Sara!
```

Geen foutmelding, maar Alex krijgt de groet van Sara. De functie heeft een parameter en doet er niets mee: in de `print` staat nog een vaste naam. Zet de parameter op de plek van die vaste waarde: `f"Hallo, {naam}!"`.

## Opdracht 9a.2: Gepersonaliseerde groet

Schrijf een functie `groet(naam, taal)` die op basis van de taal een begroeting print. Roep hem drie keer aan.

Verwachte uitvoer:

```
Hallo, Sara!
Hello, Alex!
Hola, Maria!
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Binnen de functie: `if taal == "nl":` → Nederlandse groet, `elif taal == "en":` → Engelse groet, `elif taal == "es":` → Spaanse groet. Telkens met `{naam}` in een f-string.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def groet(naam, taal):
    if taal == "nl":
        print(f"Hallo, {naam}!")
    elif taal == "en":
        print(f"Hello, {naam}!")
    elif taal == "es":
        print(f"Hola, {naam}!")

groet("Sara", "nl")
groet("Alex", "en")
groet("Maria", "es")
```

## Opdracht 9a.3: Vormen tekenen

Maak twee functies: `driehoek(hoogte)` en `vierkant(grootte)`. De driehoek groeit per regel; het vierkant is altijd even breed als hoog. Roep ze beide aan.

Verwachte uitvoer (bij `driehoek(4)` en `vierkant(4)`):

```
*
**
***
****

****
****
****
****
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`"*" * i` voor de driehoek (groeit per ronde). `"*" * grootte` voor het vierkant (vaste breedte).

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def driehoek(hoogte):
    for i in range(1, hoogte + 1):
        print("*" * i)

def vierkant(grootte):
    for i in range(grootte):
        print("*" * grootte)

driehoek(4)
print()
vierkant(4)
```

In de [volgende les](site:python/docs/functies/09b-return) leer je hoe een functie een **resultaat teruggeeft** met `return`, zodat je het in de rest van je programma kunt gebruiken.
