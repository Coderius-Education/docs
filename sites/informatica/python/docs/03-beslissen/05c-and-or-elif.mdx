# 5c And, or en elif

Met `if`/`else` kies je tussen twee paden. Met `and` en `or` combineer je voorwaarden, en met `elif` maak je meer dan twee takken.

## Twee voorwaarden combineren: and en or

| Operator | Wanneer `True`? |
|:--------:|-----------------|
| `and`    | Als **beide** voorwaarden `True` zijn |
| `or`     | Als **minstens één** voorwaarde `True` is |
| `not`    | Als de voorwaarde **niet** `True` is: `not True` is `False` |

```python
leeftijd = 16
heeft_kaartje = True

if leeftijd >= 14 and heeft_kaartje:
    print("Je mag naar binnen!")
else:
    print("Sorry, je mag er niet in.")
```

Twijfel je tussen `and` en `or`? Vraag je dan af: moet het allebei, of is één genoeg?

## Meer dan twee takken: elif

`if`/`else` geeft je twee opties. Met `elif` (een afkorting van *else if*) voeg je extra takken toe:

```python
score = 65

if score >= 80:
    print("Uitstekend!")
elif score >= 55:
    print("Voldoende.")
else:
    print("Helaas, onvoldoende.")
```

Python kijkt de voorwaarden **van boven naar beneden** na en stopt zodra er één `True` is. De andere takken worden dan niet meer gecheckt. Je kunt zoveel `elif`-takken plaatsen als je wilt.

```python
score = 90

if score >= 55:
    print("Voldoende")
elif score >= 80:
    print("Uitstekend")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze goed uitleg="90 is 55 of meer, dus de eerste tak klopt al. Daarna kijkt Python niet verder.">`Voldoende`</Keuze>
  <Keuze uitleg="90 is wel 80 of meer, maar Python komt nooit bij die tak: de eerste klopte al.">`Uitstekend`</Keuze>
  <Keuze uitleg="Van een if met elif voert Python hoogstens één tak uit.">`Voldoende` en `Uitstekend`</Keuze>
  <Uitleg>

  Je ziet `Voldoende`, ook al is 90 uitstekend. Zet daarom de strengste voorwaarde bovenaan: eerst `>= 80`, dan `>= 55`.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**De variabele maar één keer genoemd**

{/* niet-compileren: bewuste syntaxfout, na and ontbreekt de variabele */}

```python
leeftijd = 15
if leeftijd >= 12 and <= 19:
    print("Tiener")
```

Uitvoer:

{/* foutmelding-van: leeftijd = 15\nif leeftijd >= 12 and <= 19:\n    print("Tiener") */}

```
SyntaxError: invalid syntax
```

Aan elke kant van `and` staat een hele vergelijking. Schrijf `leeftijd >= 12 and leeftijd <= 19`.

**or met maar één vergelijking**

```python
kleur = "groen"

if kleur == "rood" or "blauw":
    print("Mooie kleur")
```

Uitvoer:

```
Mooie kleur
```

Geen foutmelding, en toch klopt het niet: groen is geen rood of blauw. Python leest dit als `kleur == "rood"` of `"blauw"`, en een tekst die niet leeg is telt als `True`. Vergelijk aan beide kanten: `kleur == "rood" or kleur == "blauw"`.

## Opdracht 5c.3: Strenge toegangscontrole

Bouw een toegangscontrole die per reden uitlegt waarom iemand niet binnen mag. Gebruik `op_lijst` en `leeftijd` (drempel: 14).

Verwachte uitvoer (bij `op_lijst = False`, `leeftijd = 12`):

```
Sorry Alex, je staat niet op de lijst én je bent te jong.
```

Verwachte uitvoer (bij `op_lijst = False`, `leeftijd = 18`):

```
Sorry Alex, je staat niet op de gastenlijst.
```

Verwachte uitvoer (bij `op_lijst = True`, `leeftijd = 12`):

```
Sorry Alex, je bent te jong (minimum: 14).
```

Verwachte uitvoer (bij `op_lijst = True`, `leeftijd = 18`):

```
Welkom Alex!
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`not op_lijst` is `True` als de gast **niet** op de lijst staat. Vier takken op volgorde:

1. `not op_lijst and leeftijd < 14` → beide problemen
2. `not op_lijst` → alleen lijst-probleem
3. `leeftijd < 14` → alleen leeftijd-probleem
4. `else` → welkom

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
naam = "Alex"
leeftijd = 12
op_lijst = False

if not op_lijst and leeftijd < 14:
    print(f"Sorry {naam}, je staat niet op de lijst én je bent te jong.")
elif not op_lijst:
    print(f"Sorry {naam}, je staat niet op de gastenlijst.")
elif leeftijd < 14:
    print(f"Sorry {naam}, je bent te jong (minimum: 14).")
else:
    print(f"Welkom {naam}!")
```
