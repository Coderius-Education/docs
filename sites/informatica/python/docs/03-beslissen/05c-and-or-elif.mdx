# 5c And, or en elif

Met `if`/`else` kies je tussen twee paden. Met `and` en `or` combineer je voorwaarden, en met `elif` maak je meer dan twee takken.

## And en or: twee voorwaarden combineren

Soms hangt een beslissing van twee dingen af. Bij dit feest kom je alleen binnen als je 14 of ouder bent én een kaartje hebt:

```python
leeftijd = 16
heeft_kaartje = True

if leeftijd >= 14 and heeft_kaartje:
    print("Je mag naar binnen!")
else:
    print("Sorry, je mag er niet in.")
```

`and` is een van de drie woorden waarmee je voorwaarden combineert:

| Operator | Wanneer `True`? |
|:--------:|-----------------|
| `and`    | Als **beide** voorwaarden `True` zijn |
| `or`     | Als **minstens één** voorwaarde `True` is |
| `not`    | Als de voorwaarde **niet** `True` is: `not True` is `False` |

Twijfel je tussen `and` en `or`? Vraag je dan af: moet het allebei, of is één genoeg?

## Meer dan twee takken: elif

### Schrijf if en else

Een programma begroet je bij het uur van de dag. Eerst een `if` met `else`, voor de ochtend en de avond:

```python
uur = 9

if uur < 12:
    print("Goedemorgen")
else:
    print("Goedenavond")
```

Uitvoer:

```
Goedemorgen
```

Om 9 uur klopt dat. Maar om 14 uur zegt dit programma `Goedenavond`: de middag ontbreekt, want `if` en `else` geven samen twee takken.

### Voeg een tak toe

Een derde begroeting, voor de middag tot 18 uur, krijgt een eigen `if`. De gemarkeerde regels zijn nieuw: de tweede `if` met de voorwaarde `uur < 18`, en de `print` die erbij hoort.

```python {5-6}
uur = 9

if uur < 12:
    print("Goedemorgen")
if uur < 18:
    print("Goedemiddag")
else:
    print("Goedenavond")
```

Uitvoer:

```
Goedemorgen
Goedemiddag
```

Om 9 uur krijg je twee begroetingen. Het zijn twee losse beslissingen geworden: de tweede `if` weet niets van de eerste, en 9 is ook kleiner dan 18. De `else` hoort alleen nog bij de tweede `if`.

### Koppel de takken

`elif` (een afkorting van *else if*) maakt van twee beslissingen één: Python kijkt alleen naar een `elif` als de voorwaarde erboven `False` was. In de gemarkeerde regel is `if` nu `elif`:

```python {5}
uur = 9

if uur < 12:
    print("Goedemorgen")
elif uur < 18:
    print("Goedemiddag")
else:
    print("Goedenavond")
```

Uitvoer:

```
Goedemorgen
```

Python loopt de voorwaarden **van boven naar beneden** af en stopt bij de eerste die `True` is. `uur < 18` is om 9 uur ook `True`, maar daar komt Python niet meer. Je mag zoveel `elif`-takken toevoegen als je wilt; `else` vangt onderaan de rest op.

### Voorspel

```python
score = 90

if score >= 55:
    print("Voldoende")
elif score >= 80:
    print("Uitstekend")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze goed uitleg="90 is 55 of meer, dus de eerste tak klopt al. Daarna kijkt Python niet verder.">`Voldoende`</Keuze>
  <Keuze uitleg="90 is wel 80 of meer, maar Python komt nooit bij die tak: de eerste klopte al.">`Uitstekend`</Keuze>
  <Keuze uitleg="Van een if met elif voert Python hoogstens één tak uit.">`Voldoende` en `Uitstekend`</Keuze>
  <Uitleg>

  Je ziet `Voldoende`, ook al is 90 uitstekend. Zet daarom de strengste voorwaarde bovenaan: eerst `>= 80`, dan `>= 55`.

  </Uitleg>
</Voorspel>

## Maak het af

Een webwinkel rekent bezorgkosten: vanaf 50 euro is bezorgen gratis, vanaf 20 euro kost het 2 euro, en daaronder 5 euro. De drie prijzen staan er al, en twee hebben een `if`. Maar bij een bestelling van 60 euro noemt het programma ze alle drie. Twee stappen zijn nog open: de tweede `if` aan de eerste koppelen, en de laagste prijs alleen noemen als de andere twee niet gelden. Doe die zelf, en laat de drie prijzen staan.

Verwachte uitvoer:

```
Bezorgen is gratis.
```

## Puzzel

Dit programma geeft advies bij het percentage van je batterij, maar de regels staan door elkaar. Bij 80 of meer is hij vol genoeg voor de hele dag en bij 30 of meer genoeg voor de middag. Bij 10 of meer zet je de spaarstand aan, en daaronder zoek je een oplader.

<Puzzel taal="python" code={`batterij = 45
if batterij >= 80:
    print("Vol genoeg voor de hele dag.")
elif batterij >= 30:
    print("Genoeg voor de middag.")
elif batterij >= 10:
    print("Zet de spaarstand aan.")
else:
    print("Zoek nu een oplader.")`}>

Python loopt de voorwaarden van boven naar beneden af en stopt bij de eerste die `True` is. Daarom staat de strengste bovenaan: eerst `>= 80`, dan `>= 30`, dan `>= 10`. Stond `>= 10` boven `>= 30`, dan kreeg een batterij van 45 het advies over de spaarstand, want 45 is ook 10 of meer. De `else` staat onderaan en vangt wat overblijft.

</Puzzel>

## Er gaat iets mis

### De variabele maar één keer genoemd

{/* niet-compileren: bewuste syntaxfout, na and ontbreekt de variabele */}

```python
leeftijd = 15
if leeftijd >= 12 and <= 19:
    print("Tiener")
```

Uitvoer:

{/* foutmelding-van: leeftijd = 15\nif leeftijd >= 12 and <= 19:\n    print("Tiener") */}

```
SyntaxError: invalid syntax
```

Aan elke kant van `and` staat een hele vergelijking. Schrijf `leeftijd >= 12 and leeftijd <= 19`.

### or met maar één vergelijking

```python
kleur = "groen"

if kleur == "rood" or "blauw":
    print("Mooie kleur")
```

Uitvoer:

```
Mooie kleur
```

Geen foutmelding, en toch klopt het niet: groen is geen rood of blauw. Python leest dit als `kleur == "rood"` of `"blauw"`, en een tekst die niet leeg is telt als `True`. Vergelijk aan beide kanten: `kleur == "rood" or kleur == "blauw"`.

### if in plaats van elif

```python
getal = 150

if getal >= 100:
    print("Groot")
if getal >= 10:
    print("Middel")
else:
    print("Klein")
```

Uitvoer:

```
Groot
Middel
```

Geen foutmelding, maar je krijgt twee antwoorden. De tweede `if` begint een nieuwe beslissing, los van de eerste, en 150 is ook 10 of meer. Maak er `elif` van: dan kijkt Python er alleen naar als de eerste voorwaarde `False` was.

## Opdracht 5c.3: Strenge toegangscontrole

Bouw een toegangscontrole die per reden uitlegt waarom iemand niet binnen mag. Gebruik `op_lijst` en `leeftijd` (drempel: 14).


Verwachte uitvoer (bij `op_lijst = True`, `leeftijd = 12`):

```
Sorry Alex, je bent te jong (minimum: 14).
```

Verwachte uitvoer (bij `op_lijst = True`, `leeftijd = 18`):

```
Welkom Alex!
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`not op_lijst` is `True` als de gast **niet** op de lijst staat. Vier takken op volgorde:

1. `not op_lijst and leeftijd < 14` → beide problemen
2. `not op_lijst` → alleen lijst-probleem
3. `leeftijd < 14` → alleen leeftijd-probleem
4. `else` → welkom

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
naam = "Alex"
leeftijd = 12
op_lijst = False

if not op_lijst and leeftijd < 14:
    print(f"Sorry {naam}, je staat niet op de lijst én je bent te jong.")
elif not op_lijst:
    print(f"Sorry {naam}, je staat niet op de gastenlijst.")
elif leeftijd < 14:
    print(f"Sorry {naam}, je bent te jong (minimum: 14).")
else:
    print(f"Welkom {naam}!")
```
