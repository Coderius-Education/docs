# 5a Booleans en vergelijken

Je kunt nu variabelen maken, rekenen en tekst opmaken. Er bestaat nog een soort waarde: de **boolean**, `True` of `False`. Elke vergelijking levert er een op, en in de [volgende les](site:python/docs/beslissen/05b-if-else) beslist je programma ermee met `if` en `else`.

## Booleans

Een boolean heeft maar twee mogelijkheden: `True` (waar) of `False` (niet waar).

```python
is_student = True
heeft_kaartje = False

print(is_student)     # True
print(heeft_kaartje)  # False
```

Booleans gebruik je om "ja of nee"-feiten op te slaan.

## Vergelijkingsoperatoren

Met vergelijkingsoperatoren krijg je altijd een boolean terug:

| Operator | Betekenis | Voorbeeld | Resultaat |
|:--------:|-----------|-----------|-----------|
| `==` | gelijk aan | `5 == 5` | `True` |
| `!=` | niet gelijk aan | `5 != 3` | `True` |
| `<` | kleiner dan | `3 < 10` | `True` |
| `>` | groter dan | `3 > 10` | `False` |
| `<=` | kleiner of gelijk | `5 <= 5` | `True` |
| `>=` | groter of gelijk | `3 >= 10` | `False` |

```python
leeftijd = 16

print(leeftijd >= 18)  # False
print(leeftijd < 18)   # True
```

**Let op:** `=` slaat een waarde op, `==` vergelijkt twee waardes. Dat verschil is een van de meest gemaakte fouten in Python.

## Een vergelijking opslaan

Een vergelijking levert een boolean op, en die kun je in een variabele bewaren:

```python
leeftijd = 20

mag_stemmen = leeftijd >= 18
print(mag_stemmen)   # True
```

```python
leeftijd = 18
print(leeftijd > 18)
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="18 is niet groter dan 18. Het is gelijk, en > telt gelijk niet mee.">`True`</Keuze>
  <Keuze goed uitleg="> betekent echt groter dan. Bij gelijk is het antwoord False.">`False`</Keuze>
  <Keuze uitleg="Een vergelijking geeft een boolean, nooit een getal.">`18`</Keuze>
  <Uitleg>

  Je ziet `False`. Wil je weten of iemand 18 **of ouder** is, dan gebruik je `>=`: `leeftijd >= 18` is wel `True`.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**true met een kleine letter**

{/* foutmelding-van: blok-erboven */}

```python
is_student = true
```

Uitvoer:

```
NameError: name 'true' is not defined. Did you mean: 'True'?
```

`True` en `False` beginnen met een hoofdletter. Zonder hoofdletter denkt Python dat je een variabele bedoelt die niet bestaat.

**De tekens omgedraaid**

{/* niet-compileren: bewuste syntaxfout, de tekens staan omgedraaid */}

```python
leeftijd = 16
print(leeftijd =< 18)
```

Uitvoer:

{/* foutmelding-van: leeftijd = 16\nprint(leeftijd =< 18) */}

```
SyntaxError: invalid syntax
```

Het `=`-teken komt altijd als laatste: `<=` en `>=`. Je zegt het ook zo: kleiner of gelijk.

**Tekst vergelijken met een getal**

```python
print("10" == 10)   # False
```

Python geeft geen foutmelding, maar `"10"` is tekst en `10` is een getal, en die zijn nooit gelijk. Dit gebeurt met wat je met `input()` binnenkrijgt. Maak er eerst een getal van met `int()`, zoals in [Tekst naar getal](site:python/docs/basis/03b-tekst-naar-getal).

```

Tiener: True
Volwassen: False
```

- `is_tiener = leeftijd >= 12`
