# 5a Booleans en vergelijken

Je kunt nu variabelen maken, rekenen en tekst opmaken. Er bestaat nog een soort waarde: de **boolean**, `True` of `False`. Elke vergelijking levert er een op, en in de [volgende les](site:python/docs/beslissen/05b-if-else) beslist je programma ermee met `if` en `else`.

## Mag je in de achtbaan?

### Bewaar ja of nee

Bij een achtbaan hangt een bordje: je moet minstens 140 cm lang zijn. Of je erin mag, is een feit met twee mogelijkheden: ja of nee. Een boolean bewaart zo'n feit, als `True` (waar) of `False` (niet waar):

```python
mag_erin = True

print(mag_erin)
```

Uitvoer:

```
True
```

`True` heeft een hoofdletter en geen aanhalingstekens: het is geen tekst. Het antwoord is hier met de hand ingevuld. Voor iemand van 120 cm zegt dit programma ook `True`, want het weet niet hoe lang je bent.

### Vergelijk getallen

Of je in de achtbaan mag, kan Python zelf uitrekenen met een **vergelijking**. `lengte > 140` vraagt: is `lengte` groter dan 140? Het antwoord is een boolean. De gemarkeerde regels zijn nieuw of veranderd: je lengte, 140 cm, en de vergelijking die `mag_erin` zijn waarde geeft.

```python {1-2}
lengte = 140
mag_erin = lengte > 140

print(mag_erin)
```

Uitvoer:

```
False
```

`mag_erin` is `False`, want 140 is niet groter dan 140. Maar op het bordje staat minstens 140 cm: met precies 140 cm mag je erin.

### Kies het teken

`>` betekent echt groter dan: gelijk telt niet mee. Voor "minstens 140" is er `>=`, groter of gelijk. In de gemarkeerde regel is `>` nu `>=`:

```python {2}
lengte = 140
mag_erin = lengte >= 140

print(mag_erin)
```

Uitvoer:

```
True
```

Met 140 cm mag je erin. Maak je van de eerste regel `lengte = 139` en draai je het programma opnieuw, dan staat er `False`.

### De zes tekens

`>` en `>=` zijn twee van de zes **vergelijkingsoperatoren**. Elk geeft een boolean terug:

| Operator | Betekenis | Voorbeeld | Resultaat |
|:--------:|-----------|-----------|-----------|
| `==` | gelijk aan | `5 == 5` | `True` |
| `!=` | niet gelijk aan | `5 != 3` | `True` |
| `<` | kleiner dan | `3 < 10` | `True` |
| `>` | groter dan | `3 > 10` | `False` |
| `<=` | kleiner of gelijk | `5 <= 5` | `True` |
| `>=` | groter of gelijk | `3 >= 10` | `False` |

**Let op:** `=` slaat een waarde op, `==` vergelijkt twee waardes.

### Voorspel

```python
leeftijd = 20
mag_stemmen = leeftijd >= 18
leeftijd = 10

print(mag_stemmen)
```

## Maak het af

Bij het inchecken op het vliegveld mag een koffer hoogstens 23 kilo wegen. Op de band staan drie koffers: van 18, 23 en 27 kilo. Het programma print al per koffer of hij mee mag, maar het antwoord is met de hand ingevuld en klopt niet. Eén stap is nog open: de vergelijking die `mag_mee` bij elke koffer zijn waarde geeft. Doe die zelf, en typ niet zelf `True` of `False`: het programma rekent het uit.

Verwachte uitvoer:

```
Koffer van 18 kilo mag mee: True
Koffer van 23 kilo mag mee: True
Koffer van 27 kilo mag mee: False
```

<CodeExercise>{`maximum = 23

koffer = 18
mag_mee = False
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")

koffer = 23
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")

koffer = 27
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Welke twee variabelen vergelijk je met elkaar? "Hoogstens 23 kilo" betekent dat precies 23 kilo ook goed is: zoek bij De zes tekens het teken dat daarbij past. Denk ook aan de voorspelvraag: Python rekent een vergelijking uit op de regel waar hij staat.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
maximum = 23

koffer = 18
mag_mee = koffer <= maximum
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")

koffer = 23
mag_mee = koffer <= maximum
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")

koffer = 27
mag_mee = koffer <= maximum
print(f"Koffer van {koffer} kilo mag mee: {mag_mee}")
```

Met `<` mag de koffer van 23 kilo niet mee. En staat de vergelijking alleen bij de eerste koffer, dan houdt `mag_mee` de uitkomst van 18 kilo: dan mag ook de koffer van 27 kilo mee.

</details>

## Er gaat iets mis

### true met een kleine letter

{/* foutmelding-van: blok-erboven */}

```python
mag_erin = true
```

Uitvoer:

```
NameError: name 'true' is not defined. Did you mean: 'True'?
```

`True` en `False` beginnen met een hoofdletter. Zonder hoofdletter denkt Python dat je een variabele bedoelt die niet bestaat.

### De tekens omgedraaid

{/* niet-compileren: bewuste syntaxfout, de tekens staan omgedraaid */}

```python
leeftijd = 16
print(leeftijd =< 18)
```

Uitvoer:

{/* foutmelding-van: leeftijd = 16\nprint(leeftijd =< 18) */}

```
SyntaxError: invalid syntax
```

Het `=`-teken komt altijd als laatste: `<=` en `>=`. Je zegt het ook zo: kleiner of gelijk.

### Het teken de verkeerde kant op

```python
koffer = 18
maximum = 23
print(koffer >= maximum)
```

Uitvoer:

```
False
```

Geen foutmelding, maar een koffer van 18 kilo mag niet mee. `koffer >= maximum` vraagt of de koffer minstens 23 kilo weegt. Lees de vergelijking van links naar rechts: "hoogstens 23 kilo" is de koffer kleiner dan of gelijk aan het maximum, `koffer <= maximum`.

### Tekst vergelijken met een getal

```python
print("10" == 10)   # False
```

Python geeft geen foutmelding, maar `"10"` is tekst en `10` is een getal, en die zijn nooit gelijk. Dit gebeurt met wat je met `input()` binnenkrijgt. Maak er eerst een getal van met `int()`, zoals in [Tekst naar getal](site:python/docs/basis/03b-tekst-naar-getal).
