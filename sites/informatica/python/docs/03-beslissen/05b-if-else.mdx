# 5b If en else

Een vergelijking geeft `True` of `False`. Met `if` en `else` laat je je programma daar **iets mee doen**.

## Een record in je spel

### Print het bericht

Na elk potje laat een spel je punten zien, en het meldt een nieuw record. Eerst de twee regels die dat op het scherm zetten:

```python
punten = 120
record = 150

print(f"Je punten: {punten}")
print("Nieuw record.")
```

Uitvoer:

```
Je punten: 120
Nieuw record.
```

Dat klopt niet: het record staat op 150, en 120 is minder. Het programma meldt bij elk aantal punten een record.

### Stel de voorwaarde

Een `if` voert code alleen uit als een voorwaarde `True` is. De gemarkeerde regels zijn nieuw of veranderd: de `if` met de voorwaarde `punten > record` en een dubbele punt, en de `print` eronder, die nu vier spaties inspringt.

```python {5-6}
punten = 120
record = 150

print(f"Je punten: {punten}")
if punten > record:
    print("Nieuw record.")
```

Uitvoer:

```
Je punten: 120
```

{/* foutmelding-van: if True:\nprint("hoi") */}

Die inspringing is geen opmaak: Python ziet eraan welke regels bij de `if` horen, het **blok**. Laat je hem weg, dan krijg je een `IndentationError`. 120 is niet groter dan 150, dus Python slaat het blok over. Wie geen record haalt, hoort nu niets.

### Vang de rest op

`else` zegt wat er gebeurt als de voorwaarde van de `if` `False` is. De gemarkeerde regels zijn nieuw: `else` met een dubbele punt, recht onder de `if`, en een `print` die vier spaties inspringt.

```python {7-8}
punten = 120
record = 150

print(f"Je punten: {punten}")
if punten > record:
    print("Nieuw record.")
else:
    print("Het record blijft staan.")
```

Uitvoer:

```
Je punten: 120
Het record blijft staan.
```

Van de twee blokken voert Python er altijd precies één uit. Met `punten = 180` staat er `Nieuw record.` Een `else` is niet verplicht: zonder `else` doet een `if` niets als de voorwaarde `False` is.

### Voorspel

```python
score = 40

if score >= 50:
    print("Geslaagd")
print("Klaar")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="40 is niet 50 of meer, dus de ingesprongen regel slaat Python over.">`Geslaagd` en `Klaar`</Keuze>
  <Keuze goed uitleg="Alleen de ingesprongen regel hoort bij de if. De regel met Klaar staat erbuiten en draait altijd.">`Klaar`</Keuze>
  <Keuze uitleg="De laatste regel springt niet in, dus de if heeft er geen invloed op.">Niets</Keuze>
  <Uitleg>

  Je ziet alleen `Klaar`. De voorwaarde is `False`, dus Python slaat het ingesprongen blok over en gaat verder met de eerste regel die niet inspringt.

  </Uitleg>
</Voorspel>

## Maak het af

Bij het poortje van het station kijkt dit programma of er genoeg saldo op je kaart staat voor een rit van 4 euro. De drie `print`-regels staan er al, maar het programma zegt ze alle drie: eerst `Goede reis.` en meteen daarna dat je moet opladen. Twee stappen zijn nog open: de `if` met de voorwaarde, en `else` voor wie te weinig saldo heeft. Doe die zelf, en gooi geen regel weg: met `saldo = 3` moet hetzelfde programma zeggen dat je moet opladen.

Verwachte uitvoer:

```
Saldo: 10 euro
Goede reis.
```

<CodeExercise>{`saldo = 10
ritprijs = 4

print(f"Saldo: {saldo} euro")
print("Goede reis.")
print("Laad eerst je kaart op.")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Welke regel hoort bij genoeg saldo, en welke bij te weinig? Die twee springen in, elk onder een eigen regel met een dubbele punt. De regel met je saldo komt altijd op het scherm en springt niet in.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
saldo = 10
ritprijs = 4

print(f"Saldo: {saldo} euro")
if saldo >= ritprijs:
    print("Goede reis.")
else:
    print("Laad eerst je kaart op.")
```

Staat de laatste `print` nog zonder `else` onder de `if`, dan zegt het programma na `Goede reis.` nog steeds dat je moet opladen.

</details>

## Puzzel

Dit programma zegt of je een paraplu nodig hebt, maar de regels staan door elkaar. Is de kans op regen 50 procent of meer, dan neem je een paraplu mee. Anders laat je hem thuis. `Fijne dag.` komt altijd op het scherm, als laatste.

<Puzzel taal="python" code={`regenkans = 70
if regenkans >= 50:
    print("Neem een paraplu mee.")
else:
    print("Laat de paraplu thuis.")
print("Fijne dag.")`}>

De `if` kan pas vergelijken als `regenkans` een waarde heeft, dus `regenkans = 70` staat bovenaan. Onder `if` springt de regel in voor als de voorwaarde `True` is, onder `else` die voor alle andere gevallen. `print("Fijne dag.")` springt niet in: hij hoort bij geen van de twee blokken, dus Python voert hem altijd uit, na de `if` en de `else`.

</Puzzel>

## Er gaat iets mis

### De dubbele punt vergeten

{/* niet-compileren: bewuste syntaxfout, de dubbele punt ontbreekt */}

```python
leeftijd = 15
if leeftijd >= 18
    print("Volwassen")
```

Uitvoer:

{/* foutmelding-van: leeftijd = 15\nif leeftijd >= 18\n    print("Volwassen") */}

```
SyntaxError: expected ':'
```

Achter de voorwaarde van een `if`, en achter `else`, staat altijd een dubbele punt.

### Niet ingesprongen

{/* niet-compileren: bewuste inspringfout */}

```python
leeftijd = 15
if leeftijd >= 18:
print("Volwassen")
```

Uitvoer:

{/* foutmelding-van: leeftijd = 15\nif leeftijd >= 18:\nprint("Volwassen") */}

```
IndentationError: expected an indented block after 'if' statement on line 2
```

Na de dubbele punt verwacht Python een regel die 4 spaties inspringt.

### = in plaats van ==

{/* niet-compileren: bewuste syntaxfout, = in plaats van == */}

```python
leeftijd = 18
if leeftijd = 18:
    print("Gefeliciteerd")
```

Uitvoer:

{/* foutmelding-van: leeftijd = 18\nif leeftijd = 18:\n    print("Gefeliciteerd") */}

```
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

Met één `=` geef je een variabele een waarde. Vergelijken doe je met `==`. Python raadt het in de melding zelf al.

### else vergeten

```python
leeftijd = 20

if leeftijd >= 18:
    print("Volwassen")
print("Minderjarig")
```

Uitvoer:

```
Volwassen
Minderjarig
```

Geen foutmelding, maar het programma zegt twee dingen die elkaar tegenspreken. De laatste `print` springt niet in en hoort dus niet bij de `if`: Python voert hem altijd uit. Zet er `else:` boven en laat de `print` inspringen.

## Opdracht 5b.1: Geslaagd?

Maak een variabele `cijfer` met de waarde `5.5`. Schrijf een `if`/`else` die `Gefeliciteerd, je bent geslaagd!` print als `cijfer` minstens `5.5` is, en anders `Helaas, gezakt.`

Verwachte uitvoer (bij `cijfer = 5.5`):

```
Gefeliciteerd, je bent geslaagd!
```

Verwachte uitvoer (bij `cijfer = 5.4`):

```
Helaas, gezakt.
```

## Opdracht 5b.2: Toegangscontrole

Een feestje heeft een minimumleeftijd van 14. Print of de gast welkom is. Is hij te jong, zeg dan op een tweede regel over hoeveel jaar hij terug kan komen. Dat getal rekent je programma uit.

Verwachte uitvoer (bij `leeftijd = 15`):

```
Welkom op het feestje!
```

Verwachte uitvoer (bij `leeftijd = 11`):

```
Sorry, je bent te jong.
Kom over 3 jaar terug.
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Wie precies 14 is, mag erin: kies het teken daarbij. Onder `else` mogen twee regels inspringen. Het aantal jaren is het verschil tussen 14 en `leeftijd`, en dat kun je in een f-string uitrekenen.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
leeftijd = 11

if leeftijd >= 14:
    print("Welkom op het feestje!")
else:
    print("Sorry, je bent te jong.")
    print(f"Kom over {14 - leeftijd} jaar terug.")
```

## Opdracht 5b.3: Gepersonaliseerd resultaat

Schrijf een programma dat met `naam` en `cijfer` een persoonlijk bericht print. Gebruik een f-string in beide takken.

Verwachte uitvoer (bij `naam = "Alex"`, `cijfer = 6.5`):

```
Gefeliciteerd Alex, je hebt een 6.5 — geslaagd!
```

Verwachte uitvoer (bij `cijfer = 4.0`):

```
Helaas Alex, een 4.0 is niet genoeg.
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

</details>

<details>

