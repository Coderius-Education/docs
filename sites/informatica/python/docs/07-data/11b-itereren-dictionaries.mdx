# 11b Door een dictionary lopen

Je kunt nu dictionaries maken en waardes opzoeken met een sleutel. Je kunt ook **door** een dictionary lopen, en vooraf controleren of een sleutel bestaat.

## De uitslag van een verkiezing

### Schrijf de loop

De klas kiest een voorzitter. In een dictionary staat bij elke kandidaat het aantal stemmen. Eerst een `for`-loop over de dictionary, zoals over een lijst:

```python
stemmen = {"Noor": 12, "Daan": 8, "Yara": 15}

for naam in stemmen:
    print(naam)
```

Uitvoer:

```
Noor
Daan
Yara
```

Een loop over een dictionary geeft elke ronde een sleutel. Je ziet wie er meedeed, maar niet hoeveel stemmen iemand kreeg.

### Neem de waarde mee

**`.items()`** levert elke ronde een paar: eerst de sleutel, dan de waarde. De gemarkeerde regels zijn veranderd: de loop heeft twee namen, `naam` en `aantal`, en de `print` gebruikt ze allebei.

```python {3-4}
stemmen = {"Noor": 12, "Daan": 8, "Yara": 15}

for naam, aantal in stemmen.items():
    print(f"{naam}: {aantal} stemmen")
```

Uitvoer:

```
Noor: 12 stemmen
Daan: 8 stemmen
Yara: 15 stemmen
```

De volgorde van de twee namen ligt vast: de eerste krijgt de sleutel, de tweede de waarde. Ook Sem wil zijn aantal weten, maar zijn naam staat niet in de uitslag.

### Controleer eerst

{/* foutmelding-van: {"Noor": 12}["Sem"] */}

Sem vraagt hoeveel stemmen hij kreeg, maar hij was geen kandidaat: `stemmen["Sem"]` geeft een `KeyError`. Met **`in`** kijk je eerst of een sleutel in de dictionary zit. De gemarkeerde regels zijn nieuw: de `if` met `in`, en wat het programma in elk van de twee gevallen print.

```python {6-9}
stemmen = {"Noor": 12, "Daan": 8, "Yara": 15}

for naam, aantal in stemmen.items():
    print(f"{naam}: {aantal} stemmen")

if "Sem" in stemmen:
    print(stemmen["Sem"])
else:
    print("Sem deed niet mee.")
```

Uitvoer:

```
Noor: 12 stemmen
Daan: 8 stemmen
Yara: 15 stemmen
Sem deed niet mee.
```

`"Sem" in stemmen` is `False`, dus Python komt niet bij de regel met `stemmen["Sem"]`. Met `"Daan"` in plaats van `"Sem"` was de `if` waar geweest en stond er `8`.

### Voorspel

```python
leerling = {"naam": "Sara", "klas": "3B"}

print("Sara" in leerling)
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Sara staat wel in de dictionary, maar als waarde. Kijk waar in naar kijkt.">`True`</Keuze>
  <Keuze goed uitleg="in kijkt alleen naar de sleutels, en de sleutels zijn naam en klas.">`False`</Keuze>
  <Keuze uitleg="in op een dictionary mag; je krijgt een boolean terug.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `False`. `in` controleert **sleutels**, niet waardes. `"naam" in leerling` is wel `True`.

  </Uitleg>
</Voorspel>

## Maak het af

Je fietst naar school, naar de sporthal en naar het station. De afstanden staan in een dictionary, maar het programma print hem in één keer, met accolades en al. Eén stap is nog open: een loop die van elk paar een eigen regel maakt. Doe die zelf, en typ de plaatsen niet over: de loop haalt ze uit de dictionary.

Verwachte uitvoer:

```
Hoe ver is het fietsen?
school: 3 km
sporthal: 5 km
station: 2 km
```

<CodeExercise>{`afstanden = {"school": 3, "sporthal": 5, "station": 2}

print("Hoe ver is het fietsen?")
print(afstanden)`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Een loop over alleen `afstanden` geeft de sleutels. Welke methode levert elke ronde een paar? De loop heeft dan twee namen nodig, met een komma ertussen.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
afstanden = {"school": 3, "sporthal": 5, "station": 2}

print("Hoe ver is het fietsen?")
for plaats, km in afstanden.items():
    print(f"{plaats}: {km} km")
```

Zonder `.items()` kan het ook: een loop met `for plaats in afstanden:` en `afstanden[plaats]` in de `print`.

</details>

## Er gaat iets mis

### Twee namen zonder .items()

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara", "klas": "3B"}

for sleutel, waarde in leerling:
    print(sleutel, waarde)
```

Uitvoer:

```
ValueError: too many values to unpack (expected 2)
```

Zonder `.items()` krijg je per ronde alleen een sleutel, zoals `"naam"`. Die probeert Python over twee namen te verdelen, en dat lukt niet. Schrijf `for sleutel, waarde in leerling.items():`.

### De haakjes achter items vergeten

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara", "klas": "3B"}

for sleutel, waarde in leerling.items:
    print(sleutel, waarde)
```

Uitvoer:

```
TypeError: 'builtin_function_or_method' object is not iterable
```

`.items` zonder haakjes is de methode zelf, niet de paren die hij geeft. Zet de haakjes erachter: `leerling.items()`.

## Opdracht 11b.3: Digitaal winkelmandje

Bouw een winkelmandje met twee dictionaries: een `winkel` (product → prijs) en een `mandje` (product → aantal). Schrijf een functie `bereken_totaal(winkel, mandje)` die met `.items()` door het mandje loopt en de totaalprijs **teruggeeft** met `return`. Print daarnaast een kassabon.

Verwachte uitvoer:

```
=== Kassabon ===
  Brood x2  ->  5.0 euro
  Melk x1  ->  1.2 euro
  Chocola x3  ->  10.5 euro
================
Totaal: 16.7 euro
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Drie stappen binnen de loop van `bereken_totaal`:

1. `prijs = winkel[product]`: zoek de prijs op.
2. `regel = prijs * aantal`: bereken de regelprijs.
3. `totaal += regel`: tel op.

Daarna `return totaal`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
winkel = {
    "Brood": 2.50,
    "Kaas": 4.00,
    "Melk": 1.20,
    "Appel": 0.80,
    "Chocola": 3.50
}

mandje = {
    "Brood": 2,
    "Melk": 1,
    "Chocola": 3
}

def bereken_totaal(winkel, mandje):
    totaal = 0
    for product, aantal in mandje.items():
        prijs = winkel[product]
        totaal += prijs * aantal
    return totaal

print("=== Kassabon ===")
for product, aantal in mandje.items():
    prijs = winkel[product]
    print(f"  {product} x{aantal}  ->  {prijs * aantal} euro")
print("================")
print(f"Totaal: {bereken_totaal(winkel, mandje)} euro")
```
