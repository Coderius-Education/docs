# 11b Door een dictionary lopen

Je kunt nu dictionaries maken en waardes opzoeken met een sleutel. Je kunt ook **door** een dictionary lopen, en vooraf controleren of een sleutel bestaat.

## Loopen over de sleutels

Een simpele `for`-loop op een dictionary geeft je de **sleutels**:

```python
leerling = {"naam": "Sara", "leeftijd": 15, "klas": "3B"}

for sleutel in leerling:
    print(sleutel)
```

Uitvoer:

```
naam
leeftijd
klas
```

## Loopen over sleutels én waardes met .items()

Wil je beide tegelijk? Gebruik `.items()`:

{/* niet-draaien: fragment; leerling komt uit het blok erboven */}
```python
for sleutel, waarde in leerling.items():
    print(f"{sleutel}: {waarde}")
```

Uitvoer:

```
naam: Sara
leeftijd: 15
klas: 3B
```

`.items()` levert elke ronde een **paar**: eerst de sleutel, dan de waarde.

## Bestaat de sleutel? — de in-operator

{/* foutmelding-van: {"naam": "Sam"}["leeftijd"] */}

Met `in` check je of een sleutel in de dictionary zit. Daarmee voorkom je een `KeyError`:

{/* niet-draaien: fragment; leerling komt uit het blok erboven */}
```python
if "naam" in leerling:
    print(leerling["naam"])
else:
    print("Geen naam bekend.")
```

```python
leerling = {"naam": "Sara", "klas": "3B"}

print("Sara" in leerling)
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Sara staat wel in de dictionary, maar als waarde. Kijk waar in naar kijkt.">`True`</Keuze>
  <Keuze goed uitleg="in kijkt alleen naar de sleutels, en de sleutels zijn naam en klas.">`False`</Keuze>
  <Keuze uitleg="in op een dictionary mag; je krijgt een boolean terug.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `False`. `in` controleert **sleutels**, niet waardes. `"naam" in leerling` is wel `True`.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**Twee namen zonder .items()**

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara", "klas": "3B"}

for sleutel, waarde in leerling:
    print(sleutel, waarde)
```

Uitvoer:

```
ValueError: too many values to unpack (expected 2)
```

Zonder `.items()` krijg je per ronde alleen een sleutel, zoals `"naam"`. Die probeert Python over twee namen te verdelen, en dat lukt niet. Schrijf `for sleutel, waarde in leerling.items():`.

**De haakjes achter items vergeten**

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara", "klas": "3B"}

for sleutel, waarde in leerling.items:
    print(sleutel, waarde)
```

Uitvoer:

```
TypeError: 'builtin_function_or_method' object is not iterable
```

`.items` zonder haakjes is de methode zelf, niet de paren die hij geeft. Zet de haakjes erachter: `leerling.items()`.

## Opdracht 11b.3: Digitaal winkelmandje

Bouw een winkelmandje met twee dictionaries: een `winkel` (product → prijs) en een `mandje` (product → aantal). Schrijf een functie `bereken_totaal(winkel, mandje)` die met `.items()` door het mandje loopt en de totaalprijs **teruggeeft** met `return`. Print daarnaast een kassabon.

Verwachte uitvoer:

```
=== Kassabon ===
  Brood x2  ->  5.0 euro
  Melk x1  ->  1.2 euro
  Chocola x3  ->  10.5 euro
================
Totaal: 16.7 euro
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Drie stappen binnen de loop van `bereken_totaal`:

1. `prijs = winkel[product]`: zoek de prijs op.
2. `regel = prijs * aantal`: bereken de regelprijs.
3. `totaal += regel`: tel op.

Daarna `return totaal`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
winkel = {
    "Brood": 2.50,
    "Kaas": 4.00,
    "Melk": 1.20,
    "Appel": 0.80,
    "Chocola": 3.50
}

mandje = {
    "Brood": 2,
    "Melk": 1,
    "Chocola": 3
}

def bereken_totaal(winkel, mandje):
    totaal = 0
    for product, aantal in mandje.items():
        prijs = winkel[product]
        totaal += prijs * aantal
    return totaal

print("=== Kassabon ===")
for product, aantal in mandje.items():
    prijs = winkel[product]
    print(f"  {product} x{aantal}  ->  {prijs * aantal} euro")
print("================")
print(f"Totaal: {bereken_totaal(winkel, mandje)} euro")
```
