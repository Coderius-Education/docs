# 11a Dictionaries

Een lijst slaat waardes op een **positie** op (0, 1, 2, ...). Wil je een waarde opzoeken met een **naam**, zoals in een telefoonboek waar je een naam opzoekt en een nummer vindt, dan gebruik je een **dictionary**.

## Een dictionary maken

Tussen accolades, met sleutel-waarde-paren gescheiden door komma's:

```python
leerling = {
    "naam": "Sara",
    "leeftijd": 15,
    "klas": "3B"
}

print(leerling["naam"])      # Sara
print(leerling["leeftijd"])  # 15
```

- De **sleutel** staat links van de dubbele punt (`"naam"`).
- De **waarde** staat rechts (`"Sara"`).
- Met `dictionary[sleutel]` haal je de waarde op.

Opzoeken met een naam leest makkelijker dan met een nummer: bij `leerling["naam"]` zie je meteen wat je krijgt.

{/* niet-draaien: valt expres om; de voorspelvraag eronder vraagt waarom */}
```python
leerling = {"naam": "Sara", "leeftijd": 15}

print(leerling[0])
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Een dictionary heeft geen plekken die bij 0 beginnen. Hij kent alleen zijn sleutels.">`Sara`</Keuze>
  <Keuze uitleg="Met blokhaken vraag je een waarde op, nooit een sleutel. En 0 is geen sleutel van deze dictionary.">`naam`</Keuze>
  <Keuze goed uitleg="0 is geen sleutel van leerling, dus Python vindt niets en stopt.">Een foutmelding</Keuze>
  <Uitleg>

  Je krijgt een foutmelding. Een dictionary zoekt op sleutel, niet op plek. De sleutels hier zijn `"naam"` en `"leeftijd"`, dus `leerling["naam"]` werkt en `leerling[0]` niet.

  </Uitleg>
</Voorspel>

## Toevoegen en wijzigen

Een waarde aanpassen of een nieuwe sleutel toevoegen werkt hetzelfde:

{/* niet-draaien: fragment; leerling komt uit het blok erboven */}
```python
leerling["leeftijd"] = 16        # wijzigt bestaande sleutel
leerling["hobby"] = "muziek"     # voegt nieuwe sleutel toe
```

Bestaat de sleutel al, dan wordt de waarde overschreven. Bestaat hij nog niet, dan wordt hij toegevoegd.

## Er gaat iets mis

**Een sleutel die niet bestaat**

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara"}
print(leerling["leeftijd"])
```

Uitvoer:

```
KeyError: 'leeftijd'
```

De melding noemt de sleutel die Python zocht. Controleer de spelling, of voeg de sleutel eerst toe. Hoe je vooraf kijkt of een sleutel bestaat, leer je in de [volgende les](site:python/docs/data/11b-itereren-dictionaries).

**De aanhalingstekens om de sleutel vergeten**

{/* foutmelding-van: blok-erboven */}

```python
leerling = {"naam": "Sara"}
print(leerling[naam])
```

Uitvoer:

```
NameError: name 'naam' is not defined
```

Zonder aanhalingstekens zoekt Python een variabele `naam`, en die is er niet. De sleutel is de tekst `"naam"`: `leerling["naam"]`.

## Opdracht 11a.2: Favoriete film

Maak een dictionary voor je favoriete film met de sleutels `"titel"`, `"jaar"` en `"score"`. Print elke waarde apart met een f-string.

Verwachte uitvoer (voorbeeld):

```
Titel: The Matrix
Jaar: 1999
Score: 9.0
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

In een f-string gebruik je `{film['titel']}`. Let op het verschil tussen de **enkele** aanhalingstekens binnen de f-string en de dubbele aanhalingstekens van de sleutel in de dictionary zelf.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
film = {
    "titel": "The Matrix",
    "jaar": 1999,
    "score": 9.0
}

print(f"Titel: {film['titel']}")
print(f"Jaar: {film['jaar']}")
print(f"Score: {film['score']}")
```

## Opdracht 11a.3: Klasprofiel

Maak drie dictionaries voor drie leerlingen (elk met `"naam"` en `"klas"`). Stop ze in een lijst en print voor elk een nette regel.

Verwachte uitvoer:

```
Sara zit in klas 3B
Alex zit in klas 3A
Maria zit in klas 4C
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

In de loop is `leerling` elke ronde een dictionary. Gebruik `leerling['naam']` en `leerling['klas']` in een f-string.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
leerling1 = {"naam": "Sara", "klas": "3B"}
leerling2 = {"naam": "Alex", "klas": "3A"}
leerling3 = {"naam": "Maria", "klas": "4C"}

klas = [leerling1, leerling2, leerling3]

for leerling in klas:
    print(f"{leerling['naam']} zit in klas {leerling['klas']}")
```
