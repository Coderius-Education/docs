# 10a Lijsten

Een variabele houdt één waarde vast. Wil je tien waardes bewaren, zoals een boodschappenlijstje, een klassenlijst of een rij cijfers, dan gebruik je een **lijst** (Engels: *list*).

## Een estafetteteam

### Maak de lijst

Vier lopers vormen een estafetteteam. Een lijst bewaart hun namen in de volgorde waarin ze lopen. De elementen staan tussen blokhaken, met komma's ertussen:

```python
team = ["Noor", "Daan", "Yara", "Sem"]

print(team)
print(f"{len(team)} lopers")
```

Uitvoer:

```
['Noor', 'Daan', 'Yara', 'Sem']
4 lopers
```

`len()` geeft het aantal elementen in de lijst. Het hele team staat op één regel, met blokhaken en al. Wie er start, staat er niet los bij.

### Pak een element

De startloper is het eerste element. Eén element haal je op met blokhaken achter de naam van de lijst, met daartussen de plek van het element. De gemarkeerde regel is nieuw: het eerste element, dus plek `1`.

```python {5}
team = ["Noor", "Daan", "Yara", "Sem"]

print(team)
print(f"{len(team)} lopers")
print(f"Start: {team[1]}")
```

Uitvoer:

```
['Noor', 'Daan', 'Yara', 'Sem']
4 lopers
Start: Daan
```

Dat klopt niet: Daan loopt als tweede. Op plek `1` staat dus niet het eerste element.

### Tel vanaf nul

Python telt de plekken van een lijst vanaf 0: Noor staat op plek `0`, Daan op `1`, Yara op `2` en Sem op `3`. In de eerste gemarkeerde regel is `1` nu `0`. De tweede gemarkeerde regel is nieuw: `team[-1]` is het laatste element, want een min telt vanaf het eind.

```python {5-6}
team = ["Noor", "Daan", "Yara", "Sem"]

print(team)
print(f"{len(team)} lopers")
print(f"Start: {team[0]}")
print(f"Slot: {team[-1]}")
```

Uitvoer:

```
['Noor', 'Daan', 'Yara', 'Sem']
4 lopers
Start: Noor
Slot: Sem
```

De plek van een element heet de **index**. `team[3]` geeft ook Sem, maar `team[-1]` blijft kloppen als het team groeit. De opstelling zelf staat nog op één regel, tussen blokhaken.

### Loop de lijst af

Een `for`-loop kan een lijst aflopen: elke ronde komt het volgende element in de loop-variabele. De gemarkeerde regels zijn veranderd: in plaats van de hele lijst in één keer print de loop elke loper op een eigen regel.

```python {3-4}
team = ["Noor", "Daan", "Yara", "Sem"]

for loper in team:
    print(loper)
print(f"{len(team)} lopers")
print(f"Start: {team[0]}")
print(f"Slot: {team[-1]}")
```

Uitvoer:

```
Noor
Daan
Yara
Sem
4 lopers
Start: Noor
Slot: Sem
```

In de loop staat geen `range` en geen index: de lijst bepaalt zelf hoeveel rondes er zijn. Komt er een vijfde loper bij, dan print de loop die ook, telt `len()` hem mee en wijst `team[-1]` naar hem. Vlak voor de start verstuikt Daan zijn enkel, maar de lijst noemt hem nog.

### Vervang een loper

Joris loopt in de plaats van Daan. Een element vervangen is een toekenning, met de index tussen blokhaken. De gemarkeerde regel is nieuw: `team[1] = "Joris"` zet Joris op plek 1, waar Daan stond.

```python {2}
team = ["Noor", "Daan", "Yara", "Sem"]
team[1] = "Joris"

for loper in team:
    print(loper)
print(f"{len(team)} lopers")
print(f"Start: {team[0]}")
print(f"Slot: {team[-1]}")
```

Uitvoer:

```
Noor
Joris
Yara
Sem
4 lopers
Start: Noor
Slot: Sem
```

Daan is weg, en het team telt nog steeds vier lopers: de toekenning vervangt een element, er komt er geen bij.

print(dagen[len(dagen) - 1])

## Maak het af

Dit programma print je rooster van vandaag: bovenaan het eerste en het laatste uur, daaronder elk vak op een eigen regel en het aantal lessen. Achter `Eerste uur:` staat nog de hele lijst in plaats van één vak. Twee stappen zijn nog open: het eerste uur en het laatste uur. Doe die zelf, boven de loop, en haal de vakken uit de lijst: typ ze niet over.

Verwachte uitvoer:

```
Eerste uur: wiskunde
Laatste uur: Frans
wiskunde
gym
Engels
muziek
Frans
5 lessen
```

<CodeExercise>{`rooster = ["wiskunde", "gym", "Engels", "muziek", "Frans"]

print(f"Eerste uur: {rooster}")
for vak in rooster:
    print(vak)
print(f"{len(rooster)} lessen")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Draai het programma eerst: achter `Eerste uur:` staat de hele lijst. Op welke plek staat het eerste element? Het laatste uur is een nieuwe regel van dezelfde vorm, direct eronder. Tel daarvoor de plekken na, of tel vanaf het eind.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
rooster = ["wiskunde", "gym", "Engels", "muziek", "Frans"]

print(f"Eerste uur: {rooster[0]}")
print(f"Laatste uur: {rooster[-1]}")
for vak in rooster:
    print(vak)
print(f"{len(rooster)} lessen")
```

`rooster[4]` geeft ook `Frans`. `rooster[5]` bestaat niet: vijf elementen staan op plek 0 tot en met 4. Boven de loop bestaat `vak` nog niet, dus daar kun je het laatste vak alleen met een index uit de lijst halen.

</details>

## Er gaat iets mis

### Een plek die niet bestaat

{/* foutmelding-van: blok-erboven */}

```python
kleuren = ["rood", "groen", "blauw"]
print(kleuren[3])
```

Uitvoer:

```
IndexError: list index out of range
```

Drie elementen staan op plek 0, 1 en 2. Plek 3 bestaat niet. Het laatste element is `kleuren[2]`, of `kleuren[-1]`.

### Ronde haakjes in plaats van blokhaken

{/* foutmelding-van: blok-erboven */}

```python
kleuren = ["rood", "groen", "blauw"]
print(kleuren(0))
```

Uitvoer:

```
TypeError: 'list' object is not callable
```

Met ronde haakjes roep je een functie aan, en een lijst is geen functie. Een element opzoeken doe je met blokhaken: `kleuren[0]`.

### Tellen vanaf 1

```python
kleuren = ["rood", "groen", "blauw"]
print(kleuren[1])
```

Uitvoer:

```
groen
```

Geen foutmelding, maar je wilde het eerste element en krijgt het tweede. Het eerste element staat op plek 0: `kleuren[0]`.

## Opdracht 10a.3: Hoogste cijfer vinden

Gegeven een lijst cijfers, vind het **hoogste** cijfer zónder een ingebouwde functie te gebruiken. Loop door de lijst en vergelijk elk cijfer met de hoogste-tot-nu-toe.

Verwachte uitvoer (bij `cijfers = [7, 4, 8, 5, 9, 3, 6]`):

```
Het hoogste cijfer is: 9
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Begin met `hoogste = cijfers[0]`. In de loop: als `cijfer > hoogste`, sla dan `cijfer` op in `hoogste`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
cijfers = [7, 4, 8, 5, 9, 3, 6]

hoogste = cijfers[0]

for cijfer in cijfers:
    if cijfer > hoogste:
        hoogste = cijfer

print(f"Het hoogste cijfer is: {hoogste}")
```
