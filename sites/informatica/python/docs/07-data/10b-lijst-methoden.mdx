# 10b Lijst-methoden

Je kunt nu een lijst maken, opvragen en doorlopen. Met methoden **verander** je een lijst: elementen toevoegen, verwijderen of invoegen.

## Lootjes trekken

### Pak de laatste

Drie vrienden trekken lootjes voor een surprise. De lootjes zitten in een hoed: een lijst, met het bovenste lootje achteraan. Emma pakt het bovenste. Net als een tekst heeft een lijst methoden, die je met een punt aanroept:

```python
hoed = ["Daan", "Yara", "Emma"]

lot = hoed.pop()
print(f"Emma trekt {lot}")
print(hoed)
```

Uitvoer:

```
Emma trekt Emma
['Daan', 'Yara']
```

**`pop()`** haalt het laatste element uit de lijst en geeft het terug: het komt in `lot`. De lijst is daarna een element korter. Met een plek tussen de haakjes pakt `pop` een ander element: `hoed.pop(0)` is het eerste. Alleen trekt Emma zo haar eigen naam.

### Haal er één uit

Om niet haar eigen naam te trekken, haalt Emma eerst haar eigen lootje uit de hoed. De gemarkeerde regel is nieuw: **`remove`** zoekt `"Emma"` op in de lijst en haalt dat element weg.

```python {3}
hoed = ["Daan", "Yara", "Emma"]

hoed.remove("Emma")
lot = hoed.pop()
print(f"Emma trekt {lot}")
print(hoed)
```

Uitvoer:

```
Emma trekt Yara
['Daan']
```

`remove` geeft niets terug, dus er staat geen variabele voor. Emma trekt nu Yara. Haar eigen lootje ligt alleen nog naast de hoed: zo trekt niemand Emma.

### Voeg toe

Na het trekken gaat het lootje van Emma terug in de hoed. De gemarkeerde regel is nieuw: **`append`** voegt `"Emma"` toe aan het eind van de lijst.

```python {6}
hoed = ["Daan", "Yara", "Emma"]

hoed.remove("Emma")
lot = hoed.pop()
print(f"Emma trekt {lot}")
hoed.append("Emma")
print(hoed)
```

Uitvoer:

```
Emma trekt Yara
['Daan', 'Emma']
```

Moet een element ergens anders komen, dan gebruik je `insert`: `hoed.insert(0, "Emma")` voegt Emma toe op plek 0. Anders dan bij een tekst veranderen deze methoden de lijst zelf. `"hallo".upper()` liet de tekst zoals hij was, `hoed.append("Emma")` verandert `hoed`.

## Maak het af

Bij zaalvoetbal staan Finn, Lotte en Mila in het veld. Lotte wordt gewisseld voor Jip. Het programma meldt de wissel al, maar de lijst is nog niet veranderd. Twee stappen zijn nog open: Lotte uit de lijst halen en Jip toevoegen. Doe die zelf, en laat de eerste regel staan: verander de lijst met methoden.

Verwachte uitvoer:

```
Lotte gaat eruit, Jip komt erin
['Finn', 'Mila', 'Jip']
```

## Handige ingebouwde functies

Voor lijsten van getallen heb je vaak geen loop nodig:

```python
getallen = [3, 1, 4, 1, 5]

print(len(getallen))      # 5
print(sum(getallen))      # 14
print(min(getallen))      # 1
print(max(getallen))      # 5
print(sorted(getallen))   # [1, 1, 3, 4, 5]
```

### Voorspel

```python
getallen = [3, 1, 2]

sorted(getallen)
print(getallen)
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="sorted() maakt wel een gesorteerde lijst, maar die bewaart niemand.">`[1, 2, 3]`</Keuze>
  <Keuze goed uitleg="sorted() geeft een nieuwe lijst terug en laat getallen zoals hij was.">`[3, 1, 2]`</Keuze>
  <Keuze uitleg="De regel sorted(getallen) is in orde; Python gooit het resultaat alleen weg.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `[3, 1, 2]`. `sorted()` is geen methode van de lijst maar een functie, en die geeft een gesorteerde **kopie** terug. Wil je die bewaren, zet hem dan in een variabele: `gesorteerd = sorted(getallen)`.

  </Uitleg>
</Voorspel>

## Puzzel

Bij de kassa staan Sam en Noor in de rij, maar de regels van het programma staan door elkaar. Ali sluit achteraan, bedenkt zich en gaat weer weg. Het programma print eerst `Ali gaat naar huis.` en daarna de rij die overblijft: `['Sam', 'Noor']`.

<Puzzel taal="python" code={`rij = ["Sam", "Noor"]
rij.append("Ali")
weg = rij.pop()
print(f"{weg} gaat naar huis.")
print(rij)`}>

`append` zet Ali achteraan, en `pop()` haalt daarna de laatste uit de rij en geeft hem terug: dat is Ali. Wissel je die twee om, dan gaat Noor naar huis en blijft Ali staan. Beide methoden veranderen de lijst zelf, dus `print(rij)` staat onderaan: daar zie je de rij zoals hij na het veranderen is.

</Puzzel>

## Er gaat iets mis

### Iets weghalen dat er niet in zit

{/* foutmelding-van: blok-erboven */}

```python
dieren = ["kat", "vis"]
dieren.remove("hond")
```

Uitvoer:

```
ValueError: list.remove(x): x not in list
```

Er zit geen hond in de lijst. Controleer het eerst: `if "hond" in dieren:`.

### Het resultaat van append bewaren

```python
dieren = ["kat", "vis"]
dieren = dieren.append("hond")
print(dieren)   # None
```

Geen foutmelding, maar je lijst is weg. `append` verandert de lijst zelf en geeft niets terug, dus `dieren` wordt `None`. Schrijf alleen `dieren.append("hond")`, zonder `dieren =` ervoor.

### De lijst veranderen na de print

```python
dieren = ["kat", "hond", "vis"]
print(dieren)
dieren.remove("hond")
```

Uitvoer:

```
['kat', 'hond', 'vis']
```

Geen foutmelding, maar de hond staat er nog. Python voert de regels van boven naar beneden uit: bij de `print` was de lijst nog niet veranderd. Zet `print(dieren)` onder de regel met `remove`.

## Opdracht 10b.2: Cijfergemiddelde

Gegeven een lijst cijfers, bereken het gemiddelde en tel hoeveel cijfers een voldoende (`>= 5.5`) zijn.

Verwachte uitvoer:

```
Gemiddelde: 6.2
Aantal voldoendes: 6
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`sum(cijfers) / len(cijfers)` voor het gemiddelde. In een loop: `if cijfer >= 5.5:` → `aantal_voldoende += 1`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
cijfers = [7, 4, 8, 5, 9, 3, 6, 8, 5, 7]

gemiddelde = sum(cijfers) / len(cijfers)

aantal_voldoende = 0
for cijfer in cijfers:
    if cijfer >= 5.5:
        aantal_voldoende += 1

print(f"Gemiddelde: {gemiddelde}")
print(f"Aantal voldoendes: {aantal_voldoende}")
```

## Opdracht 10b.3: To-do lijst manager

Bouw een to-do lijst met drie functies:

- `toon_taken(taken)` print alle taken genummerd, en `voeg_toe(taken, taak)` voegt een taak toe.
- `verwijder(taken, nummer)` verwijdert de taak op die plek. De gebruiker telt vanaf 1.

Verwachte uitvoer:

```
Toegevoegd: Python oefenen
Toegevoegd: Boodschappen doen
Toegevoegd: Kamer opruimen
=== Mijn To-Do Lijst ===
  1. Python oefenen
  2. Boodschappen doen
  3. Kamer opruimen

=== Mijn To-Do Lijst ===
  1. Python oefenen
  2. Kamer opruimen

```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

De functies krijgen de lijst als parameter en veranderen hem met `append` en `pop`. Dat werkt zonder `global` en zonder `return`: je maakt geen nieuwe variabele, je past de lijst aan die je meekreeg.

- `voeg_toe`: één regel, `taken.append(taak)`.
- `verwijder`: `taken.pop(nummer - 1)`. De `-1` is nodig omdat de gebruiker bij `1` begint te tellen, maar Python bij `0`.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def toon_taken(taken):
    print("=== Mijn To-Do Lijst ===")
    for i in range(len(taken)):
        print(f"  {i + 1}. {taken[i]}")
    print()

def voeg_toe(taken, taak):
    taken.append(taak)
    print(f"Toegevoegd: {taak}")

def verwijder(taken, nummer):
    taken.pop(nummer - 1)

mijn_taken = []

voeg_toe(mijn_taken, "Python oefenen")
voeg_toe(mijn_taken, "Boodschappen doen")
voeg_toe(mijn_taken, "Kamer opruimen")
toon_taken(mijn_taken)

verwijder(mijn_taken, 2)
toon_taken(mijn_taken)
```

Een lijst werkt met posities (`[0]`, `[1]`, ...). In de [volgende les](site:python/docs/data/11a-dictionaries-basis) leer je **dictionaries**: waardes opzoeken via een **naam** in plaats van een nummer.
