# 11c Geneste dictionaries

Een dictionary koppelt een sleutel aan een waarde. Tot nu toe was die
waarde een getal of een tekst. Maar een waarde mag alles zijn: ook een
lijst, of weer een dictionary.

## Een klas in één variabele

### Maak de dictionary

Van elke leerling in een klas bewaar je de leeftijd en de cijfers. De sleutel is de naam. De waarde is zelf een dictionary, met daarin een lijst:

```python
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
}

print(klas["Sara"])
```

Uitvoer:

```
{'leeftijd': 15, 'cijfers': [7, 8, 6]}
```

`klas["Sara"]` is zelf een dictionary. Zo'n dictionary in een dictionary heet **genest**. Je krijgt alle gegevens van Sara tegelijk: haar cijfers staan er niet los bij.

### Zoek dieper

Een tweede sleutel staat direct achter de eerste: `klas["Sara"]["cijfers"]` haalt uit de dictionary van Sara de lijst met cijfers. De gemarkeerde regels zijn nieuw of veranderd: ze bewaren die lijst in `cijfers`, rekenen het gemiddelde uit met `sum()` en `len()`, en printen het.

```python {6-8}
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
}

cijfers = klas["Sara"]["cijfers"]
gemiddelde = sum(cijfers) / len(cijfers)
print(f"Sara: gemiddeld {gemiddelde}")
```

Uitvoer:

```
Sara: gemiddeld 7.0
```

Lees `klas["Sara"]["cijfers"]` van links naar rechts: eerst `"Sara"` in `klas`, dan `"cijfers"` in wat daaruit komt. Met een plek erachter, `klas["Sara"]["cijfers"][0]`, krijg je `7`. Voor Alex zijn dezelfde drie regels nog een keer nodig.

### Loop door de klas

Met `.items()` krijgt de loop elke ronde een naam en de dictionary die erbij hoort. De gemarkeerde regels zijn veranderd: de drie regels over Sara staan in de loop, met `naam` in plaats van `"Sara"` en `gegevens` in plaats van `klas["Sara"]`.

```python {6-9}
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
}

for naam, gegevens in klas.items():
    cijfers = gegevens["cijfers"]
    gemiddelde = sum(cijfers) / len(cijfers)
    print(f"{naam}: gemiddeld {gemiddelde}")
```

Uitvoer:

```
Sara: gemiddeld 7.0
Alex: gemiddeld 7.333333333333333
```

In de loop is één sleutel genoeg: `gegevens` is al de dictionary van één leerling. Alleen is 22 gedeeld door 3 geen mooi getal: achter het gemiddelde van Alex staan vijftien cijfers.

### Rond af

Eén cijfer achter de punt is genoeg voor een gemiddelde. Wat in een f-string tussen de accolades staat, kan achter een dubbele punt zeggen hoe Python het schrijft. De gemarkeerde regel is veranderd: `:.1f` betekent een kommagetal (`f`, van *float*) met één cijfer achter de punt.

```python {9}
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
}

for naam, gegevens in klas.items():
    cijfers = gegevens["cijfers"]
    gemiddelde = sum(cijfers) / len(cijfers)
    print(f"{naam}: gemiddeld {gemiddelde:.1f}")
```

Uitvoer:

```
Sara: gemiddeld 7.0
Alex: gemiddeld 7.3
```

Python rondt daarbij af: 7.333 wordt 7.3. `gemiddelde` zelf verandert niet, alleen hoe de `print` hem schrijft. De klas verandert nog: Sara haalt een 9 voor een toets en Noor komt erbij. Dat staat niet in `klas`.

### Pas de klas aan

Sara heeft een 9 gehaald en Noor is nieuw in de klas. Aanpassen gaat met dezelfde sleutels als opzoeken. De gemarkeerde regels zijn nieuw: `.append(9)` voegt een cijfer toe aan de lijst van Sara, en `"Noor"` is een nieuwe sleutel met een eigen dictionary als waarde.

```python {6-7}
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
}

klas["Sara"]["cijfers"].append(9)
klas["Noor"] = {"leeftijd": 15, "cijfers": [8, 8]}

for naam, gegevens in klas.items():
    cijfers = gegevens["cijfers"]
    gemiddelde = sum(cijfers) / len(cijfers)
    print(f"{naam}: gemiddeld {gemiddelde:.1f}")
```

Uitvoer:

```
Sara: gemiddeld 7.5
Alex: gemiddeld 7.3
Noor: gemiddeld 8.0
```

De loop is niet veranderd en print toch drie regels: hij loopt af wat er in `klas` staat. Een waarde wijzigen gaat net zo: `klas["Sara"]["leeftijd"] = 16`.

### Voorspel

```python
scores = [
    {"naam": "Sara", "punten": 120},
    {"naam": "Alex", "punten": 95},
]

print(scores[1]["punten"])
```

  <Keuze uitleg="Dat zijn de punten op plek 0. Een lijst telt zijn plekken vanaf 0.">`120`</Keuze>
  <Keuze goed uitleg="scores[1] is de tweede dictionary, en daarin hoort 95 bij punten.">`95`</Keuze>
  <Keuze uitleg="Een plek en dan een sleutel mag: wat scores[1] geeft, heeft sleutels.">Een foutmelding</Keuze>
  <Uitleg>

  Je ziet `95`. Nesten kan ook andersom: `scores` is een lijst waarin elk element een dictionary is. Een dictionary gebruik je als je iets opzoekt met een naam, een lijst als de volgorde telt of je alles langsloopt.

  </Uitleg>
</Voorspel>

## Maak het af

Op de sportdag heeft elk team een coach en een lijst met spelers. De loop loopt de teams al af en print hun kleur, maar niet hoe groot ze zijn. Eén stap is nog open: het aantal spelers van elk team in de zin. Doe die zelf.

Verwachte uitvoer:

```
Team Rood: 3 spelers
Team Blauw: 2 spelers
```

<CodeExercise>{`teams = {
    "Rood": {"coach": "Kim", "spelers": ["Sem", "Jip", "Bo"]},
    "Blauw": {"coach": "Omar", "spelers": ["Mila", "Finn"]},
}

for kleur, team in teams.items():
    print(f"Team {kleur}")`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

`team` is elke ronde de dictionary van één team. Welke sleutel geeft de lijst met spelers? En welke functie telt de elementen van een lijst?

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teams = {
    "Rood": {"coach": "Kim", "spelers": ["Sem", "Jip", "Bo"]},
    "Blauw": {"coach": "Omar", "spelers": ["Mila", "Finn"]},
}

for kleur, team in teams.items():
    spelers = team["spelers"]
    print(f"Team {kleur}: {len(spelers)} spelers")
```

In één regel kan het ook, met `{len(team['spelers'])}` in de f-string. De sleutel staat dan tussen enkele aanhalingstekens: dat leest makkelijker, en in oudere versies van Python moet het zo.

</details>

## Er gaat iets mis

### Een sleutel op de verkeerde laag

```python
klas = {"Sara": {"leeftijd": 15}}
print(klas["leeftijd"])
```

Uitvoer:

```
KeyError: 'leeftijd'
```

`"leeftijd"` is geen sleutel van `klas`, maar van de dictionary in
`klas["Sara"]`. Schrijf eerst de naam, dan de leeftijd:
`klas["Sara"]["leeftijd"]`.

### Een lijst opzoeken met een tekst

```python
scores = [{"naam": "Sara", "punten": 120}]
print(scores["naam"])
```

Uitvoer:

```
TypeError: list indices must be integers or slices, not str
```

`scores` is een lijst, en een lijst heeft plekken (0, 1, 2), geen
sleutels. Neem eerst een element met `scores[0]` en zoek daarin
`["naam"]` op.

### De naam in plaats van de gegevens

```python
klas = {"Sara": {"leeftijd": 15}}

for naam, gegevens in klas.items():
    print(naam["leeftijd"])
```

Uitvoer:

```
TypeError: string indices must be integers, not 'str'
```

`naam` is de sleutel, de tekst `"Sara"`, en in een tekst zoek je niets op
met een sleutel. De dictionary met de leeftijd zit in de tweede naam van
de loop: `gegevens["leeftijd"]`.

### De dictionary tellen in plaats van de lijst

```python
team = {"coach": "Lars", "spelers": ["Ali", "Mo", "Lin", "Tess"]}
print(len(team))
```

Uitvoer:

```
2
```

Geen foutmelding, maar het team heeft vier spelers. `len()` van een
dictionary telt zijn sleutels, hier `"coach"` en `"spelers"`. Tel de
lijst: `len(team["spelers"])`.

## Opdracht 11c.3: Wie heeft het hoogste gemiddelde?

Loop door `klas` en print wie het hoogste gemiddelde cijfer heeft,
en welk gemiddelde dat is.

Verwachte uitvoer:

```
Noor heeft het hoogste gemiddelde: 8.0
```

<CodeExercise>{`klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
    "Noor": {"leeftijd": 15, "cijfers": [8, 8, 8]},
}

# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Houd twee variabelen bij: de beste naam tot nu toe en het beste
gemiddelde tot nu toe. Begin met het gemiddelde op `0` en vervang beide
als je een hoger gemiddelde tegenkomt.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
klas = {
    "Sara": {"leeftijd": 15, "cijfers": [7, 8, 6]},
    "Alex": {"leeftijd": 14, "cijfers": [9, 5, 8]},
    "Noor": {"leeftijd": 15, "cijfers": [8, 8, 8]},
}

beste_naam = ""
beste_gemiddelde = 0
for naam, gegevens in klas.items():
    gemiddelde = sum(gegevens["cijfers"]) / len(gegevens["cijfers"])
    if gemiddelde > beste_gemiddelde:
        beste_naam = naam
        beste_gemiddelde = gemiddelde

print(f"{beste_naam} heeft het hoogste gemiddelde: {beste_gemiddelde:.1f}")
```

Uitvoer:

```
Noor heeft het hoogste gemiddelde: 8.0
```

</details>
