# 4a Slimme berichten met f-strings

Je rekenmachine uit [les 3](site:python/docs/basis/rekenmachine) werkte, maar al die spaties in `"Som:     "` tellen was gepruts. Met een **f-string** zet je tekst en variabelen in één zin.

## Een f-string maken

Een f-string is een gewone string met een `f` ervoor. Variabelen zet je tussen `{}`:

```python
naam = "Alex"
leeftijd = 15

print(f"Hallo, ik ben {naam} en ik ben {leeftijd} jaar oud.")
```

Uitvoer:

```
Hallo, ik ben Alex en ik ben 15 jaar oud.
```

Je kunt ook **berekeningen** doen binnen de accolades:

```python
leeftijd = 15

print(f"Volgend jaar ben ik {leeftijd + 1} jaar.")
```

Uitvoer:

```
Volgend jaar ben ik 16 jaar.
```

Tussen de accolades mag elke Python-uitdrukking staan: een variabele, een berekening, of een functie zoals `len()` uit de [volgende les](site:python/docs/tekst/04b-string-methoden).

```python
naam = "Alex"

print("Hallo, {naam}")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Python vult alleen iets in als er een f voor de aanhalingstekens staat.">`Hallo, Alex`</Keuze>
  <Keuze goed uitleg="Zonder f is het een gewone tekst, en de accolades zijn dan gewone tekens.">`Hallo, {naam}`</Keuze>

  Je ziet `Hallo, {naam}`, accolades en al. Pas met de `f` ervoor, `f"Hallo, {naam}"`, zet Python de waarde van `naam` op die plek.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**De f vergeten**

Zie je in je uitvoer `{naam}` staan in plaats van de naam, dan mist de `f` voor de aanhalingstekens. Python geeft geen foutmelding, dus deze fout zie je alleen aan de uitvoer.

**Tekst en een getal met + aan elkaar plakken**

{/* foutmelding-van: blok-erboven */}

```python
leeftijd = 15
print("Ik ben " + leeftijd + " jaar oud.")
```

Uitvoer:

```
TypeError: can only concatenate str (not "int") to str
```

Met `+` plak je alleen tekst aan tekst, en `leeftijd` is een getal. Een f-string heeft daar geen last van: `print(f"Ik ben {leeftijd} jaar oud.")`.

```
10 + 4 = 14

```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Eén f-string per berekening: `f"{a} + {b} = {a + b}"`. Voor de andere drie operatoren werkt het hetzelfde.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python

b = 4

print(f"{a} - {b} = {a - b}")
print(f"{a} x {b} = {a * b}")
print(f"{a} / {b} = {a / b}")
```
