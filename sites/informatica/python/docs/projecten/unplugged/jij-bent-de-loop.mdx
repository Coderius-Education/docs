# Jij bent de loop

<Handout>

Een loop doet steeds hetzelfde, maar de variabelen veranderen elke ronde.
Wat er tussen twee `print`-regels gebeurt, zie je niet op het scherm. Op
papier wel: in een tracetabel schrijf je per ronde op wat elke variabele
is.

## Wat je nodig hebt

- Een geprinte hand-out en een potlood per leerling. Werk eerst alleen,
  vergelijk dan met je buur.
- Ongeveer 25 minuten.

## Zo werkt het

1. Gok eerst wat het programma print, en schrijf je gok op.
2. Voer het programma uit alsof jij Python bent. Na elke ronde vul je één
   rij van de tabel in.
3. Klopt je gok? Zo niet: in welke ronde ging het anders dan je dacht?

## Programma 1

```python
punten = 0
for ronde in range(1, 5):
    punten = punten + ronde * 2
    if punten > 10:
        print("Over de 10 in ronde", ronde)
print("Eindstand:", punten)
```

<Antwoordblad titel="Antwoorden">

Zo kijk je je tabel na: het programma met een `print` op elke plek waar jij
een rij invulde. Dat is ook een manier om zelf een fout te zoeken.

**Programma 1.** De `print` staat in de loop, dus hij komt in elke ronde
waarin `punten > 10` waar is: in ronde 3 en 4.

```python
punten = 0
for ronde in range(1, 5):
    punten = punten + ronde * 2
    print("ronde", ronde, "punten", punten, punten > 10)
    if punten > 10:
        print("Over de 10 in ronde", ronde)
print("Eindstand:", punten)
```

Uitvoer:

```
ronde 1 punten 2 False
ronde 2 punten 6 False
ronde 3 punten 12 True
Over de 10 in ronde 3
ronde 4 punten 20 True
Over de 10 in ronde 4
Eindstand: 20
```

**Programma 2.** De voorwaarde kijkt Python alleen aan het begin van een
ronde. In ronde 4 is `getal` 27, dus de ronde begint, en daarin wordt het
81. Pas aan het begin van ronde 5 is `getal < 50` niet meer waar.

```python
getal = 1
stappen = 0
while getal < 50:
    print("begin van de ronde:", getal, getal < 50)
    getal = getal * 3
    stappen = stappen + 1
print(getal, stappen)
```

Uitvoer:

```
begin van de ronde: 1 True
begin van de ronde: 3 True
begin van de ronde: 9 True
begin van de ronde: 27 True
81 4
```

**Programma 3.** Het print `1`: elke ronde zet `teller = 0` de teller terug.
Een teller begint vóór de loop:

```python
teller = 0
for ronde in range(3):
    teller = teller + 1
print(teller)   # 3
```
