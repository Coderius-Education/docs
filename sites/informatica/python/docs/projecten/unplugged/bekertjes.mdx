# Een rij bekertjes

<Handout>

Een lijst is een rij bekertjes op tafel. Elk bekertje heeft een plek, en
de plekken tellen vanaf 0. In elk bekertje zit één briefje met een waarde.
Jij bent Python, en schuift met bekertjes.

## Wat je nodig hebt

- Per tweetal zes bekertjes (of zes vakjes op een vel papier), briefjes en
  een pen.
- Ongeveer 20 minuten.

## De spelregels

1. De plek van een bekertje is hoeveel bekertjes er links van staan.
   Het eerste heeft er geen links van zich: plek 0.
2. `snoep[1]`: kijk in het bekertje op plek 1. `snoep[-1]`: kijk in
   het laatste bekertje.
3. `append`: zet een nieuw bekertje achteraan de rij.
4. `pop()`: haal het laatste bekertje weg, en geef het briefje eruit
   terug.
5. `insert(0, …)`: zet een nieuw bekertje op plek 0. Alle andere
   schuiven één plek op.
6. `len`: tel de bekertjes.

## Deel 1

Zet eerst drie bekertjes neer, met `drop`, `chips` en `koek`.

```python
snoep = ["drop", "chips", "koek"]
snoep.append("ijs")
print(snoep[1])
print(snoep[-1])
eruit = snoep.pop()
snoep.insert(0, "fruit")
print(snoep)
print(len(snoep))
```

<Antwoordblad titel="Antwoorden">

**Deel 1.** `chips` heeft één bekertje links van zich, dus plek 1. Na
`pop()` zit het laatste bekertje met `ijs` in `eruit`, en `insert` schuift
de rest op.

```python
snoep = ["drop", "chips", "koek"]
snoep.append("ijs")
print(snoep[1])
print(snoep[-1])
eruit = snoep.pop()
snoep.insert(0, "fruit")
print(snoep)
print(len(snoep))
```

Uitvoer:

```
chips
ijs
['fruit', 'drop', 'chips', 'koek']
4
```

**Deel 2.** Vier bekertjes hebben de plekken 0, 1, 2 en 3. Plek 4 is er
niet, en dan stopt Python met een fout:

```python
snoep = ["fruit", "drop", "chips", "koek"]
print(snoep[4])
```

Uitvoer:

```
IndexError: list index out of range
```

**Deel 3.** `b = a` maakt geen nieuwe rij: etiket `b` komt op dezelfde
rij als `a`. Wat je via `b` toevoegt, staat dus ook in `a`.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4]
```
