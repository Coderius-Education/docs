# Stap 1: Een gekleurde pen (pencolor en pensize)

Tot nu toe tekende de schildpad dunne zwarte lijnen. Met twee nieuwe
commando's kies je een andere pen:

```python
import turtle

turtle.pencolor("red")
turtle.pensize(5)
turtle.forward(100)
```

- `turtle.pencolor("red")` maakt de lijn rood. De kleur is een Engels woord
  tussen aanhalingstekens, zoals `"red"`, `"blue"`, `"green"`, `"orange"`
  of `"purple"`.
- `turtle.pensize(5)` maakt de lijn 5 breed. Zonder dit commando is hij 1
  breed.

Beide gelden vanaf de regel waar ze staan, tot je een andere kleur of dikte
kiest.

## Opdracht: een blauw vierkant

elke `forward`.

## Er gaat iets mis

{/* foutmelding-van: blok-erboven */}

```python
import turtle

turtle.pencolor(red)
```

```
NameError: name 'red' is not defined
```

**Oorzaak:** zonder aanhalingstekens denkt Python dat `red` de naam van iets
is dat je zelf hebt gemaakt. Dat is niet zo, dus kent hij die naam niet.

**Oplossing:** zet de kleur tussen aanhalingstekens: `turtle.pencolor("red")`.
