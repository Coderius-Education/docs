# Tekenen met turtle

Een lijn van kleine tekenprojecten: doe ze van boven naar beneden. Elk
project voegt één ding toe, een turtle-commando of een Python-concept.

<ProjectKiezer soorten={['turtle']} />

Op je eigen computer zet je `turtle.done()` als laatste regel, anders sluit
het tekenvenster zodra de tekening klaar is (behalve in Thonny). In de
speeltuin doet die regel niets.

Ben je klaar met de lijn, dan volgen de grote turtle-projecten, zoals
[Bloemenveld](site:python/docs/projecten/bloemenveld/stap-1-for-loop) en
[Schildpaddenrace](site:python/docs/projecten/schildpaddenrace/stap-1-random).
Je vindt ze bij [Projecten](site:python/docs/projecten).
