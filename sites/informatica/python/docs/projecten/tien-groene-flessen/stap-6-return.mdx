# Stap 6: Een functie die tekst teruggeeft (return)

:::info
Deze stap gebruikt `return`, uit [Return](site:python/docs/functies/09b-return).
:::

In je couplet staan nu twee variabelen, met daaronder drie regels `if` en
`elif`. Kijk
wat die regels doen: ze zoeken de goede woorden bij een aantal
flessen. "3 groene flessen", "1 groene fles", "geen groene flessen meer".
Dat kan een functie doen die de tekst teruggeeft in plaats van hem te
printen:

```python
def staan(flessen):
    if flessen == 1:
        return "staat"
    else:
        return "staan"

print(staan(1))   # staat
print(staan(4))   # staan
```

Een functie met `return` kun je gebruiken waar je anders een stukje tekst
zou schrijven, ook tussen de accolades van een f-string.

## Opdracht: `aantal(flessen)`

Plak je programma uit stap 5 in het veld. Ben je het kwijt, neem dan de
oplossing van [stap 5](site:python/docs/projecten/tien-groene-flessen/stap-5-functie).

Vervang `nu` en `straks` door twee functies die tekst teruggeven:

1. `staan(flessen)`, zoals hierboven: `"staat"` bij één fles, anders
   `"staan"`.
2. `aantal(flessen)`, die voor elk aantal flessen de goede woorden
   teruggeeft:

| `aantal(3)` | `aantal(1)` | `aantal(0)` |
|:---:|:---:|:---:|
| `"3 groene flessen"` | `"1 groene fles"` | `"geen groene flessen meer"` |

Het couplet gebruikt daarna alleen nog die twee functies, en de `if`-regels
in `couplet` verdwijnen. De uitvoer blijft hetzelfde als in stap 5.

<details>
<summary>Klik hier voor een tip.</summary>

Begin met `aantal`. Er zijn drie gevallen: nul, één en al het andere, en
elk geval krijgt een eigen `return`. Test hem los voordat je verdergaat,
door een paar keer te printen wat hij teruggeeft. Daarna het couplet: de
eerste regel noemt `aantal` en `staan` van het aantal flessen nu, de
laatste regel die van één fles minder.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
def aantal(flessen):
    if flessen == 0:
        return "geen groene flessen meer"
    elif flessen == 1:
        return "1 groene fles"
    else:
        return f"{flessen} groene flessen"


def staan(flessen):
    if flessen == 1:
        return "staat"
    else:
        return "staan"


def couplet(flessen):
    print(f"{aantal(flessen)} {staan(flessen)} aan de muur,")
    print(f"{aantal(flessen)} {staan(flessen)} aan de muur,")
    print("en als er één groene fles valt,")
    print(f"dan {staan(flessen - 1)} er {aantal(flessen - 1)} aan de muur.")


for flessen in range(3, 0, -1):
    couplet(flessen)
    print()
```

Uitvoer:

```
3 groene flessen staan aan de muur,
3 groene flessen staan aan de muur,
en als er één groene fles valt,
dan staan er 2 groene flessen aan de muur.

2 groene flessen staan aan de muur,
2 groene flessen staan aan de muur,
en als er één groene fles valt,
dan staat er 1 groene fles aan de muur.

1 groene fles staat aan de muur,
1 groene fles staat aan de muur,
en als er één groene fles valt,
dan staan er geen groene flessen meer aan de muur.
```

Het couplet is nu vier regels zonder één `if`. Alles wat met enkelvoud en
meervoud te maken heeft, zit in `aantal` en `staan`.

</details>
