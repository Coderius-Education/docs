# Stap 6: Kleur naar het aantal (elif)

:::info
Deze stap gebruikt `elif`, uit [And, or en elif](site:python/docs/beslissen/05c-and-or-elif).
:::

Alle staven zijn lichtblauw. Een kleur kan meer vertellen: groen is
weinig, oranje is veel, rood is te veel. Er zijn drie kleuren, dus drie
takken. Met `elif` komt er tussen `if` en `else` een tak bij:

```python
waarde = 80
if waarde > 90:
    print("rood")
elif waarde > 60:
    print("oranje")
else:
    print("groen")
```

Uitvoer:

```
oranje
```

Python kijkt van boven naar beneden, en neemt de eerste tak die klopt. 80
is niet meer dan 90, wel meer dan 60: oranje.

## Opdracht: rood, oranje of groen

Plak je programma uit stap 5 in het veld. Ben je het kwijt, neem dan de
oplossing van [stap 5](site:python/docs/projecten/staafdiagram/stap-5-schalen).

Geef `staaf` een derde parameter `kleur`, en kies voor elke staaf een
kleur:

- meer dan 90 minuten: `"tomato"` (rood);
- meer dan 60 minuten: `"orange"`;
- de rest: `"limegreen"`.

```python
import turtle

minuten = {
    "chatten": 65,
    "video's": 110,
    "gamen": 80,
    "muziek": 45,
    "foto's": 30,
}

def staaf(x, hoogte, kleur):
    turtle.penup()
    turtle.goto(x, -100)
    turtle.pendown()
    turtle.fillcolor(kleur)
    turtle.begin_fill()
    for zijde in range(2):
        turtle.forward(60)
        turtle.left(90)
        turtle.forward(hoogte)
        turtle.left(90)
    turtle.end_fill()

def schrijf(x, y, tekst):
    turtle.penup()
    turtle.goto(x, y)
    turtle.write(tekst, align="center")

hoogste = 0
for naam, waarde in minuten.items():
    if waarde > hoogste:
        hoogste = waarde

x = -200
for naam, waarde in minuten.items():
    hoogte = waarde / hoogste * 200
    if waarde > 90:
        kleur = "tomato"
    elif waarde > 60:
        kleur = "orange"
    else:
        kleur = "limegreen"
    staaf(x, hoogte, kleur)
    schrijf(x + 30, -100 + hoogte + 5, f"{waarde} min")
    schrijf(x + 30, -118, naam)
    x += 80
turtle.hideturtle()
```

Met de minuten vergelijken is nodig: de hoogte van een staaf hangt af van
de hoogste, de minuten niet.

</details>

## Er gaat iets mis

**De staaf van video's is oranje, en er is geen enkele rode staaf.**

**Oorzaak:** je zette `waarde > 60` bovenaan, en `waarde > 90` bij de
`elif`. Python neemt de eerste tak die klopt. 110 is meer dan 60, dus
video's wordt oranje, en de tak voor rood komt nooit aan de beurt.

**Oplossing:** zet de strengste voorwaarde bovenaan: eerst meer dan 90,
dan meer dan 60.

## Jouw eigen gegevens

Je programma tekent elke dictionary met getallen, hoeveel paren er ook in
staan. Verzamel nu je eigen gegevens. Een paar ideeën:

- Hoeveel minuten zat jij deze week per dag op je telefoon? De meeste
  telefoons houden het bij, bij de instellingen voor schermtijd.
- Wat is de lievelingssnack van je klas? Turf het, en tel per snack.
- Hoeveel stappen zette je deze week per dag?

Zet ze in de dictionary in plaats van de minuten. Passen de grenzen voor
rood en oranje niet bij je getallen, kies dan andere, of laat de kleuren
weg.
