# Stap 4: Namen erbij (door een dictionary lopen)

:::info
Deze stap gebruikt een dictionary en `.items()`, uit [Dictionaries](site:python/docs/data/11a-dictionaries-basis) en [Door een dictionary lopen](site:python/docs/data/11b-itereren-dictionaries).
:::

Bij welke app hoort de hoogste staaf? Dat staat nergens. Bij elk getal
hoort een naam, en een naam met een getal is een paar in een dictionary.
Met `.items()` krijg je in elke ronde allebei:

```python
minuten = {"chatten": 65, "video's": 110}

for naam, waarde in minuten.items():
    print(f"{naam}: {waarde}")
```

Uitvoer:

```
chatten: 65
video's: 110
```

## Opdracht: de naam onder elke staaf

Plak je programma uit stap 3 in het veld. Ben je het kwijt, neem dan de
oplossing van [stap 3](site:python/docs/projecten/staafdiagram/stap-3-f-string).

Vervang de lijst door deze dictionary:

```python
minuten = {
    "chatten": 65,
    "video's": 110,
    "gamen": 80,
    "muziek": 45,
    "foto's": 30,
}
```

Teken weer een staaf per app, met het aantal minuten erboven, en schrijf nu
ook de naam onder elke staaf, in het midden, op hoogte -118.

Je functies `staaf` en `schrijf` blijven precies hetzelfde. Alleen de loop
verandert: die loopt nu over de paren van de dictionary, en krijgt in elke
ronde een naam en een getal. De naam schrijf je met dezelfde functie als
het getal.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

{/* turtle-plaatje: img/stap-4-namen.svg */}

```python
import turtle

minuten = {
    "chatten": 65,
    "video's": 110,
    "gamen": 80,
    "muziek": 45,
    "foto's": 30,
}

def staaf(x, hoogte):
    turtle.penup()
    turtle.goto(x, -100)
    turtle.pendown()
    turtle.fillcolor("skyblue")
    turtle.begin_fill()
    for zijde in range(2):
        turtle.forward(60)
        turtle.left(90)
        turtle.forward(hoogte)
        turtle.left(90)
    turtle.end_fill()

def schrijf(x, y, tekst):
    turtle.penup()
    turtle.goto(x, y)
    turtle.write(tekst, align="center")

x = -200
for naam, waarde in minuten.items():
    staaf(x, waarde)
    schrijf(x + 30, -100 + waarde + 5, f"{waarde} min")
    schrijf(x + 30, -118, naam)
    x += 80
turtle.hideturtle()
```

De staven staan in de volgorde van de dictionary.

</details>

## Er gaat iets mis

{/* foutmelding-van: minuten = {"chatten": 65}\nfor naam, waarde in minuten:\n    pass */}

```
ValueError: too many values to unpack (expected 2)
```

**Oorzaak:** je schreef `for naam, waarde in minuten:` zonder `.items()`.
Een loop over een dictionary geeft alleen de sleutels, zoals `"chatten"`.
Python probeert die ene tekst over twee variabelen te verdelen, en
`"chatten"` heeft zeven letters: te veel voor twee.

**Oplossing:** loop over `minuten.items()`. Dan krijg je per ronde een paar:
de naam en het getal.
