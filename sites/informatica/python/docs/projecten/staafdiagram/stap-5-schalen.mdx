# Stap 5: Op schaal (de hoogste zoeken met if)

:::info
Deze stap gebruikt `if`, uit [If en else](site:python/docs/beslissen/05b-if-else). Het hoogste getal zoeken met een loop deed je ook in [Lijsten](site:python/docs/data/10a-lijsten-basis), bij het hoogste cijfer.
:::

Elke minuut is nu één stap hoog. Bij jouw klas gaat dat goed, maar zit
iemand 300 minuten per dag op video's, dan steekt die staaf ver boven het
venster uit. En tel je in uren, dan zijn alle staven 1 of 2 stappen hoog:
platte streepjes.

Een diagram op schaal lost dat op. De hoogste staaf is altijd 200 hoog, en
de rest naar verhouding:

```python
hoogste = 110
waarde = 55
hoogte = waarde / hoogste * 200
print(hoogte)   # 100.0
```

55 is de helft van 110, dus die staaf wordt de helft van 200. Daarvoor moet
het programma eerst weten wat het hoogste getal is. Dat zoek je met een
loop: begin bij 0, en kom je een groter getal tegen, onthoud dan dat getal.

```python
cijfers = [6, 9, 7]

hoogste = 0
for cijfer in cijfers:
    if cijfer > hoogste:
        hoogste = cijfer
print(hoogste)   # 9
```

## Opdracht: de hoogste staaf 200 hoog

{/* turtle-plaatje: img/stap-5-schaal.svg */}

```python
import turtle

minuten = {
    "chatten": 65,
    "video's": 110,
    "gamen": 80,
    "muziek": 45,
    "foto's": 30,
}

def staaf(x, hoogte):
    turtle.penup()
    turtle.goto(x, -100)
    turtle.pendown()
    turtle.fillcolor("skyblue")
    turtle.begin_fill()
    for zijde in range(2):
        turtle.forward(60)
        turtle.left(90)
        turtle.forward(hoogte)
        turtle.left(90)
    turtle.end_fill()

def schrijf(x, y, tekst):
    turtle.penup()
    turtle.goto(x, y)
    turtle.write(tekst, align="center")

hoogste = 0
for naam, waarde in minuten.items():
    if waarde > hoogste:
        hoogste = waarde

x = -200
for naam, waarde in minuten.items():
    hoogte = waarde / hoogste * 200
    staaf(x, hoogte)
    schrijf(x + 30, -100 + hoogte + 5, f"{waarde} min")
    schrijf(x + 30, -118, naam)
    x += 80
turtle.hideturtle()
```

Verander een getal in de dictionary, bijvoorbeeld video's in 300. De
staaf van video's blijft 200 hoog, en de andere worden lager.

</details>

## Er gaat iets mis

{/* foutmelding-van: hoogste = 0\nwaarde = 65\nhoogte = waarde / hoogste * 200 */}

```
ZeroDivisionError: division by zero
```

**Oorzaak:** in de loop die het hoogste getal zoekt, schreef je
`waarde = hoogste` in plaats van andersom. Bij `=` krijgt de variabele
links de waarde van rechts. Nu verandert `waarde`, en blijft `hoogste` 0.
Delen door 0 kan niet.

**Oplossing:** zet `hoogste` links: `hoogste = waarde`.

Kopieer je programma voordat je verdergaat: de editor bewaart het niet.
