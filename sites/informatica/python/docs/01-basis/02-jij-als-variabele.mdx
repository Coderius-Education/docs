# 2 Jij als variabele

In de vorige les heb je tekst getoond met `print()`. In je visitekaartje stond je naam steeds opnieuw in de tekst — als je iets wil aanpassen, moet je elke regel langs. Dat kan makkelijker met een **variabele**: je geeft een waarde een naam en gebruikt die overal.

## Een waarde een naam geven

Een variabele maak je met een `=`-teken. Links de naam, rechts de waarde:

```python
naam = "Alex Jansen"

print(naam)
print(naam)
```

Uitvoer:

```
Alex Jansen
Alex Jansen
```

- `naam` is de **naam** van de variabele.
- `"Alex Jansen"` is de **waarde**.
- `print(naam)` toont de waarde — niet het woord "naam".

Verander je later `naam = "Sara"`, dan veranderen beide regels mee. Dat is de kracht van variabelen: één plek aanpassen, overal effect.

## Tekst of getal?

Tekst (een **string**) krijgt aanhalingstekens. Getallen niet. Een heel getal heet een **integer**, een getal met een punt een **float**:

```python
naam = "Alex"
leeftijd = 15
lengte = 1.72

print(type(naam))      # <class 'str'>
print(type(leeftijd))  # <class 'int'>
print(type(lengte))    # <class 'float'>
```

`type()` vertelt je welk soort waarde een variabele bevat. Onthoud: tekst met aanhalingstekens, getallen zonder. Een kommagetal schrijf je in Python met een punt: `1.72`, niet `1,72`.

## Variabelen veranderen

Je kunt op elk moment een nieuwe waarde in een variabele zetten:

```python
score = 0
print(score)   # 0

score = 10
print(score)   # 10
```

De variabele onthoudt alleen de **laatst** toegewezen waarde.

```python
a = 5
b = a
a = 8
print(b)
```

<Voorspel vraag="Wat print dit programma?">
  <Keuze goed uitleg="b kreeg de waarde die a op dat moment had, en dat was 5. Een nieuwe waarde in a verandert b niet.">`5`</Keuze>
  <Keuze uitleg="b = a maakt geen blijvende koppeling: b krijgt alleen de waarde die a op dat moment heeft.">`8`</Keuze>
  <Keuze uitleg="print(b) zet de waarde van b op het scherm, niet de naam.">`b`</Keuze>
  <Uitleg>

  Je ziet `5`. Op regel 2 krijgt `b` de waarde van `a`, en dat is dan 5. Op regel 3 krijgt `a` een nieuwe waarde, maar `b` houdt de zijne.

  </Uitleg>
</Voorspel>

## Tekst en variabele samen

Zet je in `print()` een komma tussen twee dingen, dan zet Python ze achter elkaar met een spatie ertussen:

```python
naam = "Alex"
print("Hallo", naam)
```

Uitvoer:

```
Hallo Alex
```

## Er gaat iets mis

**Een tikfout in de naam**

{/* foutmelding-van: blok-erboven */}

```python
naam = "Sara"
print(Naam)
```

Uitvoer:

```
NameError: name 'Naam' is not defined. Did you mean: 'naam'?
```

Voor Python zijn `naam` en `Naam` twee verschillende namen. Gebruik precies dezelfde naam als bij het `=`-teken.

**Een variabele gebruiken voordat hij bestaat**

{/* foutmelding-van: blok-erboven */}

```python
print(leeftijd)
leeftijd = 15
```

Uitvoer:

```
NameError: name 'leeftijd' is not defined
```

Python voert je code van boven naar beneden uit. Op regel 1 bestaat `leeftijd` nog niet. Zet de regel met het `=`-teken bovenaan.

**Aanhalingstekens om de naam**

```python
naam = "Sara"
print("naam")
```

Uitvoer:

```
naam
```

Geen foutmelding, maar wel het verkeerde woord. Met aanhalingstekens is `"naam"` tekst, en die zet `print()` letterlijk neer. Wil je de waarde zien, schrijf dan `print(naam)`.
