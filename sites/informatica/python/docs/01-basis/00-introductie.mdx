# 0 Welkom bij Python

Leuk dat je begint met Python. Je vindt Python terug in websites, games, data-analyse en kunstmatige intelligentie, en het is een goede taal om mee te beginnen.

## Wat ga je leren?

Elke les behandelt één nieuw ding. Dit zijn de hoofdstukken:

- Basis: je eerste programma, variabelen, rekenen en `input()`
- Tekst: f-strings en string-methoden
- Beslissen: booleans, `if`/`else`, `and`/`or` en `elif`
- Herhalen: `for`, `range`, `continue`, `break` en `while`
- Functies: `def`, parameters, `return` en scope
- Modules: code uit een andere module gebruiken, en je eigen module
- Data: lijsten, dictionaries, tuples en sets
- Bestanden: tekst en JSON opslaan en inlezen
- Klassen: je eigen objecten met attributen en methoden
- Fouten afvangen: `try`, `except` en `raise`

Naast de lessen zijn er [projecten](site:python/docs/projecten), van tekenen met turtle tot woordjes overhoren, en werkvormen zonder computer onder [Unplugged](site:python/docs/projecten/unplugged).

## Hoe werkt elke les?

Elke les heeft dezelfde opbouw:

1. Een korte intro die aansluit op wat je al kent.
2. Een minimaal werkend codevoorbeeld.
3. Een paar zinnen uitleg over wat er gebeurt.
4. Twee tot vier opdrachten om het zelf te doen, met een tip en de oplossing in een uitklap-blok.

Je hoeft niets te installeren: je draait de code direct in de browser. Alleen bij [Je eigen module](site:python/docs/modules/09e-eigen-module) werk je met twee bestanden, en dan heb je een editor op je computer nodig.

Loop je vast? Op [Er gaat iets mis](site:python/hulp) staan de fouten die het vaakst voorkomen, en de [cheatsheet](site:python/cheatsheet) zet alle code op een rij.

## En daarna?

Zodra je deze lessen door hebt, kun je verder met [Coderius Play](site:play/). Daar maak je met `play` animaties, kleine games en interactieve programma's.
