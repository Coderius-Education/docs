# 16c De melding bewaren

Soms wil je wel laten zien wat Python van de fout vond, maar zonder dat je
programma stopt. Met `as` bewaar je de fout in een variabele:

```python
tekst = "twaalf"

try:
    getal = int(tekst)
except ValueError as fout:
    print(f"Dat lukte niet: {fout}")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="De naam van de fout staat er niet bij. Je krijgt alleen de uitleg die Python erachter zet.">`Dat lukte niet: ValueError: invalid literal for int() with base 10: 'twaalf'`</Keuze>
  <Keuze goed uitleg="Tussen de accolades komt de tekst die bij deze fout hoort.">`Dat lukte niet: invalid literal for int() with base 10: 'twaalf'`</Keuze>
  <Keuze uitleg="Tussen de accolades staat de variabele fout, en Python zet de waarde ervan in de tekst, niet de naam.">`Dat lukte niet: fout`</Keuze>
  <Uitleg>

  {/* foutmelding-van: int("twaalf") */}

  `fout` is de fout zelf. Print je hem, dan zie je de melding die Python
  anders onderaan de foutmelding had gezet, zonder de naam `ValueError`
  ervoor. De naam van de variabele kies je zelf; `fout` is gebruikelijk.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**De fout aan tekst plakken met +**

{/* foutmelding-van: blok-erboven */}

```python
try:
    getal = int("twaalf")
except ValueError as fout:
    print("Dat lukte niet: " + fout)
```

Uitvoer:

```
TypeError: can only concatenate str (not "ValueError") to str
```

`fout` is geen tekst maar een fout. Met `+` plak je alleen tekst aan tekst. Zet hem in een f-string: `f"Dat lukte niet: {fout}"`.

**as vergeten**

{/* niet-compileren: bewuste syntaxfout, het woord as ontbreekt */}

```python
try:
    getal = int("twaalf")
except ValueError fout:
    print(fout)
```

Uitvoer:

{/* foutmelding-van: try:\n    getal = int("twaalf")\nexcept ValueError fout:\n    print(fout) */}

```
SyntaxError: invalid syntax
```

Tussen de naam van de fout en je variabele staat het woord `as`: `except ValueError as fout:`.

## Opdracht 16c.1: Een logboek

Zet elk getal uit de lijst om met `int()`. Lukt het niet, print dan de
melding van Python achter `Overgeslagen:`.

Verwachte uitvoer:

```
3
Overgeslagen: invalid literal for int() with base 10: 'vier'
5
```

{/* niet-draaien: de startcode valt expres om, met de fout die de opdracht afvangt */}

<CodeExercise>{`teksten = ["3", "vier", "5"]

for tekst in teksten:
    print(int(tekst))`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Het `try`-blok staat binnen de for-loop, zodat de loop na een fout
doorgaat met de volgende tekst.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teksten = ["3", "vier", "5"]

for tekst in teksten:
    try:
        print(int(tekst))
    except ValueError as fout:
        print(f"Overgeslagen: {fout}")
```

Uitvoer:

```
3
Overgeslagen: invalid literal for int() with base 10: 'vier'
5
```

</details>

## Opdracht 16c.2: Een prijs die niet klopt

Zet de prijs om met `float()`. Lukt dat niet, print dan welke tekst er stond
én wat Python ervan vond.

Verwachte uitvoer:

```
Kon '12,50' niet lezen: could not convert string to float: '12,50'
```

{/* niet-draaien: de startcode valt expres om, met de fout die de opdracht afvangt */}

<CodeExercise>{`prijs = "12,50"

bedrag = float(prijs)
print(bedrag)`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Na `except ValueError as fout:` heb je in de f-string zowel `prijs` als
`fout` tot je beschikking. Zet `prijs` tussen enkele aanhalingstekens in de
tekst.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
prijs = "12,50"

try:
    bedrag = float(prijs)
    print(bedrag)
except ValueError as fout:
    print(f"Kon '{prijs}' niet lezen: {fout}")
```

Uitvoer:

```
Kon '12,50' niet lezen: could not convert string to float: '12,50'
```

</details>
