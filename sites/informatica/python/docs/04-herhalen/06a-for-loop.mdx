# 6a For-loop

Wil je tien keer hetzelfde doen, bijvoorbeeld de getallen 0 tot en met 9 printen, dan hoef je geen tien regels te typen. Met een `for`-loop herhaalt Python het werk voor je.

## Van losse regels naar een loop

### Schrijf het uit

Een lift meldt elke verdieping waar hij langskomt. Zonder loop staat elke melding op een eigen regel:

```python
print("Verdieping 0")
print("Verdieping 1")
print("Verdieping 2")
```

Uitvoer:

```
Verdieping 0
Verdieping 1
Verdieping 2
```

Voor drie verdiepingen gaat dat nog. Kijk wat er per regel verandert: alleen het getal. De rest staat er drie keer.

### Herhaal de regel

Wat drie keer hetzelfde is, hoeft er maar één keer te staan. Een `for`-loop herhaalt de `print`, en `range(3)` zegt hoe vaak: drie rondes.

```python
for i in range(3):
    print("Verdieping")
```

Uitvoer:

```
Verdieping
Verdieping
Verdieping
```

De `print` springt vier spaties in, net als onder een `if`. Zo weet Python welke regel bij de loop hoort. Er staan drie regels, maar het nummer van de verdieping ontbreekt nog.

### Gebruik het getal

`range(3)` geeft de getallen `0`, `1` en `2`: de 3 zelf doet niet mee. Elke ronde zet Python het volgende getal in `i`, de **loop-variabele**. Met een f-string komt `i` in de zin. De gemarkeerde regel, de `print`, is veranderd:

```python {2}
for i in range(3):
    print(f"Verdieping {i}")
```

Uitvoer:

```
Verdieping 0
Verdieping 1
Verdieping 2
```

Dat is dezelfde uitvoer als van de drie losse regels. Voor honderd verdiepingen verander je alleen `3` in `100`. De naam `i` is geen wet: je mag de loop-variabele ook `teller` of `verdieping` noemen. `i` is traditie (van *index*).

### Voorspel

```python
for i in range(4):
    print(i + 1)
```

<Voorspel vraag="Welke getallen zet dit programma op het scherm?">
  <Keuze uitleg="Dat zijn de getallen die in i staan. De print doet er nog iets mee.">`0`, `1`, `2` en `3`</Keuze>
  <Keuze goed uitleg="range(4) geeft 0, 1, 2 en 3, en de print telt er steeds 1 bij op.">`1`, `2`, `3` en `4`</Keuze>
  <Keuze uitleg="range(4) geeft vier getallen, geen vijf: de 4 zelf doet niet mee.">`1`, `2`, `3`, `4` en `5`</Keuze>
  <Uitleg>

  Je ziet `1` tot en met `4`. `range(4)` geeft vier getallen en begint bij 0: `0`, `1`, `2` en `3`. Het laatste is dus **3**, niet 4. Wil je dat `i` zelf tot en met 4 loopt, gebruik dan `range(5)`.

  </Uitleg>
</Voorspel>

## Maak het af

Dit programma meldt welke kluisjes open zijn. De loop staat er al en draait vier rondes, maar het nummer van het kluisje ontbreekt. Eén stap is nog open: het nummer in de zin. Doe die zelf.

Verwachte uitvoer:

```
Kluisje 0 is open
Kluisje 1 is open
Kluisje 2 is open
Kluisje 3 is open
```

<CodeExercise>{`for kluisje in range(4):
    print("Kluisje is open")`}</CodeExercise>

## Er gaat iets mis

### De dubbele punt vergeten

{/* niet-compileren: bewuste syntaxfout, de dubbele punt ontbreekt */}

```python
for i in range(5)
    print(i)
```

Uitvoer:

{/* foutmelding-van: for i in range(5)\n    print(i) */}

```
SyntaxError: expected ':'
```

Net als bij `if` staat achter de `for`-regel een dubbele punt.

### range vergeten

{/* foutmelding-van: blok-erboven */}

```python
for i in 5:
    print(i)
```

Uitvoer:

```
TypeError: 'int' object is not iterable
```

Een `for`-loop loopt iets af, en een los getal valt niet af te lopen. Met `range(5)` maak je er vijf getallen van.

### Een regel te veel ingesprongen

```python
for i in range(3):
    print(i)
    print("Klaar")
```

Uitvoer:

```
0
Klaar
1
Klaar
2
Klaar
```

Geen foutmelding, maar `Klaar` staat drie keer op het scherm. Alles wat inspringt hoort bij de loop. Moet een regel één keer na de loop, laat hem dan niet inspringen.
