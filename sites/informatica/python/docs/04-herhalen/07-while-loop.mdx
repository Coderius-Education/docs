# 7 While-loop

Met een `for`-loop weet je van tevoren hoe vaak je herhaalt, bijvoorbeeld 5 keer met `range(5)`. Soms weet je dat niet, alleen wanneer je klaar bent. Dan gebruik je een `while`-loop: die herhaalt **zolang een voorwaarde `True` is**.

## Een simpele while-loop

```python
getal = 5

while getal > 0:
    print(getal)
    getal -= 1

print("Start!")
```

Uitvoer:

```
5
4
3
2
1
Start!
```

`getal -= 1` is een korte schrijfwijze voor `getal = getal - 1`. Hetzelfde geldt voor `+=`, `*=` en `/=`.

Drie ingrediënten die je altijd nodig hebt:

1. Een variabele met een startwaarde (`getal = 5`).
2. Een voorwaarde achter `while` (`getal > 0`).
3. Een **update**-stap binnen de loop (`getal -= 1`).

Vergeet je die update? Dan blijft `getal` voor altijd `5`, blijft `getal > 0` voor altijd `True`, en stopt de loop nooit. Dat heet een **oneindige loop**. De speeltuin heeft geen stopknop, dus het tabblad loopt vast: herlaad de pagina, en je code is weg. Twijfel je of een loop stopt, druk dan eerst op Stap voor stap. Die neemt hoogstens 1000 stappen op, en dan zie je in de opname waar je loop blijft rondgaan.

```python
getal = 1

while getal < 50:
    getal = getal * 3

print(getal)
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Bij 27 is getal < 50 nog True, dus de loop draait nog een ronde.">`27`</Keuze>
  <Keuze goed uitleg="De loop kijkt pas aan het begin van een ronde of hij doorgaat. 27 is kleiner dan 50, dus komt er nog een ronde: 81.">`81`</Keuze>
  <Keuze uitleg="De loop stopt niet precies op 50: getal springt er in één keer overheen.">`50`</Keuze>
  <Uitleg>

  Je ziet `81`. Het getal wordt 3, 9, 27 en 81. Pas bij 81 is `getal < 50` `False`, en dan stopt de loop. Een `while`-loop schiet dus vaak over zijn grens heen.

  </Uitleg>
</Voorspel>

## Er gaat iets mis

**De update vergeten**

{/* niet-draaien: deze loop stopt nooit */}

```python
getal = 5

while getal > 0:
    print(getal)
    getal - 1
```

`getal - 1` rekent wel iets uit, maar bewaart het nergens. `getal` blijft 5 en de loop stopt nooit: het tabblad loopt vast. Schrijf `getal -= 1`, of `getal = getal - 1`.

**De voorwaarde andersom**

```python
getal = 5

while getal < 0:
    print(getal)
    getal -= 1

print("Start!")
```

Uitvoer:

```
Start!
```

Er komt geen enkel getal op het scherm. 5 is niet kleiner dan 0, dus de voorwaarde is meteen `False` en de loop draait geen ronde. Lees je voorwaarde hardop: "zolang getal groter is dan 0".

## Opdracht 7.4: Virus dat verdubbelt

Een virus begint met `1` geïnfecteerd bestand en verdubbelt elke seconde. Print elke seconde het huidige aantal, totdat het boven **1 000 000** uitkomt. Print daarna na hoeveel seconden het systeem gekaapt is.

Verwachte uitvoer (de laatste regels):

```
262144
524288
Na 20 seconden is het systeem gekaapt.
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Drie stappen binnen de loop:

1. Print `infecties`.
2. Verdubbel: `infecties *= 2`.
3. Hoog `secondes` met 1 op.

Voorwaarde: `infecties <= 1_000_000`. Python negeert de liggende streepjes in een getal: `1_000_000` is hetzelfde als `1000000`, maar leest makkelijker.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
infecties = 1
secondes = 0

while infecties <= 1_000_000:
    print(infecties)
    infecties *= 2
    secondes += 1

print(f"Na {secondes} seconden is het systeem gekaapt.")
```

In de [volgende les](site:python/docs/functies/functies) ga je code **een naam geven** zodat je hem makkelijk kunt hergebruiken — dat doe je met **functies**.
