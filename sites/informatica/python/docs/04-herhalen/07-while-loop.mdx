# 7 While-loop

Met een `for`-loop weet je van tevoren hoe vaak je herhaalt, bijvoorbeeld 5 keer met `range(5)`. Soms weet je dat niet, alleen wanneer je klaar bent. Dan gebruik je een `while`-loop: die herhaalt **zolang een voorwaarde `True` is**.

### Schrijf één ronde

Je leest een boek van 120 bladzijden, elke dag 35. Hoeveel dagen dat duurt, weet je niet uit je hoofd. Eén dag is: print hoeveel bladzijden je nog moet, en haal er 35 af.

```python
bladzijden = 120

print(f"Nog {bladzijden} bladzijden")
bladzijden -= 35
```

Uitvoer:

```
Nog 120 bladzijden
```

`bladzijden -= 35` is een korte schrijfwijze voor `bladzijden = bladzijden - 35`. Hetzelfde geldt voor `+=`, `*=` en `/=`. Na deze ronde is `bladzijden` 85, maar dat zie je nog niet.

### Herhaal de ronde

De ronde moet terugkomen zolang er iets te lezen valt: zolang `bladzijden` groter is dan 0. De gemarkeerde regels zijn veranderd: de voorwaarde staat achter `while`, en de twee regels van de ronde springen in.

```python {3-5}
bladzijden = 120

while bladzijden > 0:
    print(f"Nog {bladzijden} bladzijden")
    bladzijden -= 35
```

Uitvoer:

```
Nog 120 bladzijden
Nog 85 bladzijden
Nog 50 bladzijden
Nog 15 bladzijden
```

Vóór elke ronde kijkt Python of `bladzijden > 0` nog `True` is. Na de vierde ronde is `bladzijden` -20, en dan stopt de loop. Vier dagen dus, en dat aantal staat nergens in de code.

### Sluit af

Wat ná het lezen komt, hoort niet bij de loop. De gemarkeerde regel is nieuw: een `print` die niet inspringt en dus één keer komt, als de loop klaar is.

```python {7}
bladzijden = 120

while bladzijden > 0:
    print(f"Nog {bladzijden} bladzijden")
    bladzijden -= 35

print("Boek uit.")
```

Uitvoer:

```
Nog 120 bladzijden
Nog 85 bladzijden
Nog 50 bladzijden
Nog 15 bladzijden
Boek uit.
```

### Drie ingrediënten

Een `while`-loop heeft altijd drie ingrediënten, en het programma over het boek heeft ze alle drie:

1. Een variabele met een startwaarde (`bladzijden = 120`).
2. Een voorwaarde achter `while` (`bladzijden > 0`).
3. Een **update**-stap binnen de loop (`bladzijden -= 35`).

Vergeet je die update? Dan blijft `bladzijden` voor altijd `120`, blijft `bladzijden > 0` voor altijd `True`, en stopt de loop nooit. Dat heet een **oneindige loop**. De speeltuin heeft geen stopknop, dus het tabblad loopt vast. Herlaad dan de pagina: je code staat er daarna weer, behalve wat je vlak voor het uitvoeren typte. Twijfel je of een loop stopt, druk dan eerst op Stap voor stap. Die neemt hoogstens 1000 stappen op, en dan zie je in de opname waar je loop blijft rondgaan.

### Maak het af

Een auto heeft 48 liter in de tank, en elke rit kost 8 liter. Eén rit staat er al uitgeschreven. Twee stappen zijn nog open: herhaal de rit zolang er genoeg in de tank zit voor nog een rit, en print daarna één keer `Tanken.` Doe die zelf.

Druk eerst op Stap voor stap, niet op Uitvoeren: springt de update niet in, dan stopt je loop nooit en loopt het tabblad vast.

Verwachte uitvoer:

```
Nog 48 liter
Nog 40 liter
Nog 32 liter
Nog 24 liter
Nog 16 liter
Nog 8 liter
Tanken.
```

<CodeExercise>{`tank = 48

print(f"Nog {tank} liter")
tank -= 8`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Welke regels horen bij één rit? Die springen allebei in onder `while`. Voor nog een rit heb je minstens 8 liter nodig.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
tank = 48

while tank >= 8:
    print(f"Nog {tank} liter")
    tank -= 8

print("Tanken.")
```

Bij 8 liter kan er nog precies één rit bij: `>=` en niet `>`. Na die rit is de tank leeg, en de loop stopt.

</details>

### Voorspel

```python
getal = 1

while getal < 50:
    getal = getal * 3

print(getal)
```

  <Keuze goed uitleg="De loop kijkt pas aan het begin van een ronde of hij doorgaat. 27 is kleiner dan 50, dus komt er nog een ronde: 81.">`81`</Keuze>
  <Keuze uitleg="De loop stopt niet precies op 50: getal springt er in één keer overheen.">`50`</Keuze>
  <Uitleg>

  Je ziet `81`. Het getal wordt 3, 9, 27 en 81. Pas bij 81 is `getal < 50` `False`, en dan stopt de loop. Een `while`-loop schiet dus vaak over zijn grens heen.

  </Uitleg>
</Voorspel>

## Puzzel

Een plant van 4 cm groeit elke week 5 cm, maar de regels van het programma staan door elkaar. Zolang de plant lager is dan 20 cm, print het programma eerst de hoogte en groeit de plant daarna. De eerste regel op het scherm is dus `De plant is 4 cm.` Na de loop print het programma één keer `Tijd voor een grotere pot.`

<Puzzel taal="python" code={`hoogte = 4
while hoogte < 20:
    print(f"De plant is {hoogte} cm.")
    hoogte += 5
print("Tijd voor een grotere pot.")`}>

Dit zijn de drie ingrediënten uit de uitleg: de startwaarde vóór de loop, de voorwaarde achter `while` en de update in de loop. De `print` staat boven de update, anders was de eerste hoogte op het scherm al 9 cm. De laatste `print` springt niet in, dus die komt één keer, als `hoogte < 20` niet meer `True` is.

</Puzzel>

## Er gaat iets mis

### De update vergeten

{/* niet-draaien: deze loop stopt nooit */}

```python
bladzijden = 120

while bladzijden > 0:
    print(f"Nog {bladzijden} bladzijden")
    bladzijden - 35
```

`bladzijden - 35` rekent wel iets uit, maar bewaart het nergens. `bladzijden` blijft 120 en de loop stopt nooit: het tabblad loopt vast. Schrijf `bladzijden -= 35`, of `bladzijden = bladzijden - 35`.

### De update buiten de loop

{/* niet-draaien: deze loop stopt nooit */}

```python
bladzijden = 120

while bladzijden > 0:
    print(f"Nog {bladzijden} bladzijden")
bladzijden -= 35
```

De update springt niet in en hoort dus niet bij de loop. Python komt er nooit aan toe: de loop print eindeloos `Nog 120 bladzijden` en het tabblad loopt vast. Laat de update inspringen, net als de `print`.

### De voorwaarde andersom

```python
bladzijden = 120

while bladzijden < 0:
    print(f"Nog {bladzijden} bladzijden")
    bladzijden -= 35

print("Boek uit.")
```

Uitvoer:

```
Boek uit.
```

Er komt geen enkele regel over bladzijden op het scherm. 120 is niet kleiner dan 0, dus de voorwaarde is meteen `False` en de loop draait geen ronde. Lees je voorwaarde hardop: "zolang bladzijden groter is dan 0".

## Opdracht 7.4: Virus dat verdubbelt

Een virus begint met `1` geïnfecteerd bestand en verdubbelt elke seconde. Print elke seconde het huidige aantal, totdat het boven **1 000 000** uitkomt. Print daarna na hoeveel seconden het systeem gekaapt is.

Verwachte uitvoer (de laatste regels):

```
262144
524288
Na 20 seconden is het systeem gekaapt.
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Drie stappen binnen de loop:

1. Print `infecties`.
2. Verdubbel: `infecties *= 2`.
3. Hoog `secondes` met 1 op.

Voorwaarde: `infecties <= 1_000_000`. Python negeert de liggende streepjes in een getal: `1_000_000` is hetzelfde als `1000000`, maar leest makkelijker.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
infecties = 1
secondes = 0

while infecties <= 1_000_000:
    print(infecties)
    infecties *= 2
    secondes += 1

print(f"Na {secondes} seconden is het systeem gekaapt.")
```

In de [volgende les](site:python/docs/functies/functies) ga je code **een naam geven** zodat je hem makkelijk kunt hergebruiken — dat doe je met **functies**.
