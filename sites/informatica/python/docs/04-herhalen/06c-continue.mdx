# 6c Een ronde overslaan met continue

Soms wil je in een loop één ronde overslaan. Daar is `continue` voor.

## Een rustdag in je schema

### Schrijf de loop

Je maakt een trainingsschema voor vijf dagen: elke dag trainen en daarna rekken. Eerst de loop die elke dag hetzelfde doet:

```python
for dag in range(1, 6):
    print(f"Dag {dag}: trainen")
    print("Daarna rekken")
```

Uitvoer:

```
Dag 1: trainen
Daarna rekken
Dag 2: trainen
Daarna rekken
Dag 3: trainen
Daarna rekken
Dag 4: trainen
Daarna rekken
Dag 5: trainen
Daarna rekken
```

Vijf dagen trainen en rekken, zonder rustdag.

### Herken de ronde

Dag 3 wordt een rustdag. Een `if` in de loop kijkt elke ronde of het dag 3 is. De gemarkeerde regels zijn nieuw: de `if` en de `print` die erbij hoort. Die `print` springt acht spaties in: vier voor de loop en vier voor de `if`.

```python {2-3}
for dag in range(1, 6):
    if dag == 3:
        print(f"Dag {dag}: rust")
    print(f"Dag {dag}: trainen")
    print("Daarna rekken")
```

Uitvoer:

```
Dag 1: trainen
Daarna rekken
Dag 2: trainen
Daarna rekken
Dag 3: rust
Dag 3: trainen
Daarna rekken
Dag 4: trainen
Daarna rekken
Dag 5: trainen
Daarna rekken
```

Dag 3 staat er nu twee keer: eerst rust, en daarna toch trainen en rekken. Na het `if`-blok gaat Python verder met de volgende regels van de loop.

### Sla de rest over

**`continue`** zegt: stop met déze ronde en ga meteen door met de volgende. De gemarkeerde regel is nieuw: `continue` staat onderaan in het `if`-blok, op acht spaties. Op dag 3 komt Python zo niet meer bij de twee regels eronder.

```python {4}
for dag in range(1, 6):
    if dag == 3:
        print(f"Dag {dag}: rust")
        continue
    print(f"Dag {dag}: trainen")
    print("Daarna rekken")
```

Uitvoer:

```
Dag 1: trainen
Daarna rekken
Dag 2: trainen
Daarna rekken
Dag 3: rust
Dag 4: trainen
Daarna rekken
Dag 5: trainen
Daarna rekken
```

De loop zelf draait door: dag 4 en 5 staan er nog.

### Voorspel

```python
for i in range(5):
    if i < 3:
        continue
    print(i)
```

## Waarom is dit handig?

Zonder `continue` zet je de rest van de loop in een `else`:

```python
for dag in range(1, 6):
    if dag == 3:
        print(f"Dag {dag}: rust")
    else:
        print(f"Dag {dag}: trainen")
        print("Daarna rekken")
```

Dat doet hetzelfde. Het verschil zit in de vorm: met `else` springt alles wat bij een gewone dag hoort een niveau verder in. Hoe meer code er in de loop staat, hoe fijner het is om bovenaan te zeggen "deze ronde niet" en daarna verder te schrijven zonder extra inspringen.

**Let op:** verwar `continue` niet met het verwante `break`, dat de
**hele loop** stopt in plaats van één ronde over te slaan. Dat is de
[volgende les](site:python/docs/herhalen/06d-break).

## Er gaat iets mis

### continue buiten de loop

{/* niet-compileren: bewuste syntaxfout, continue staat buiten de loop */}

```python
for i in range(3):
    print(i)
continue
```

Uitvoer:

{/* foutmelding-van: for i in range(3):\n    print(i)\ncontinue */}

```
SyntaxError: 'continue' not properly in loop
```

`continue` hoort in een loop, en die van jou springt niet ver genoeg in. Meestal hoort hij bij de `if` in de loop.

### continue buiten het if-blok

```python
for i in range(6):
    if i == 3:
        print("overslaan")
    continue
    print(i)
```

Uitvoer:

```
overslaan
```

Geen foutmelding, maar er komt geen enkel getal op het scherm. `continue` staat op vier spaties en hoort dus bij de loop, niet bij de `if`: in elke ronde slaat hij de `print` eronder over. Zet `continue` op acht spaties, in het `if`-blok.

### continue na de print

```python
for i in range(6):
    print(i)
    if i == 3:
        continue
```

Geen foutmelding, maar de 3 staat er toch: de `print` is al geweest als `continue` aan de beurt is. Zet de controle met `continue` bóven wat je wilt overslaan.

## Opdracht 6c.3: Tellen wat overblijft (uitdaging)

Loop door de getallen 0 t/m 20. Sla alles over dat kleiner is dan 5 of
groter dan 15. Print de getallen die overblijven, en print aan het eind
hoeveel het er waren.

Verwachte uitvoer (laatste regel):

```
Aantal geprint: 11
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Maak vóór de loop een teller die op 0 begint. Na de `continue`-check
print je het getal en doe je `teller = teller + 1`. De eindprint staat
buiten de loop.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teller = 0
for i in range(21):
    if i < 5 or i > 15:
        continue
    print(i)
    teller = teller + 1

print(f"Aantal geprint: {teller}")
```

De `continue` bewaakt de poort: alleen getallen van 5 t/m 15 komen bij
de `print` en de teller.
