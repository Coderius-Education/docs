# 6c Een ronde overslaan met continue

Soms wil je in een loop bepaalde rondes overslaan. Wat denk je dat dit doet?

```python
for i in range(6):
    if i == 3:
        continue
    print(i)
```

<Voorspel vraag="Welke getallen zet dit programma op het scherm?">
  <Keuze uitleg="continue stopt niet de hele loop. Na de 3 gaat hij verder.">`0`, `1` en `2`</Keuze>
  <Keuze goed uitleg="Bij i == 3 slaat continue de print over, en daarna gaat de loop door met 4.">`0`, `1`, `2`, `4` en `5`</Keuze>
  <Keuze uitleg="De print staat ná continue, dus in de ronde van de 3 komt Python er niet aan toe.">`0`, `1`, `2`, `3`, `4` en `5`</Keuze>
  <Uitleg>

  De 3 ontbreekt. **`continue`** zegt: stop met déze ronde en ga meteen door met de volgende. Wat in de loop ná `continue` staat (hier de `print`), slaat Python die ronde over, en de loop zelf draait door.

  </Uitleg>
</Voorspel>

## Waarom is dit handig?

Zonder `continue` moet je de rest van de loop in een `else` stoppen:

```python
for i in range(6):
    if i == 3:
        print("overslaan")
    else:
        print(i)
```

Bij één regel maakt dat weinig uit. Maar hoe meer code er in de loop
staat, hoe fijner het is om bovenaan te zeggen "deze ronde niet" en
daarna verder te schrijven zonder extra inspringen.

**Let op:** verwar `continue` niet met het verwante `break`, dat de
**hele loop** stopt in plaats van één ronde over te slaan. Dat is de
[volgende les](site:python/docs/herhalen/06d-break).

## Er gaat iets mis

**continue buiten de loop**

{/* niet-compileren: bewuste syntaxfout, continue staat buiten de loop */}

```python
for i in range(3):
    print(i)
continue
```

Uitvoer:

{/* foutmelding-van: for i in range(3):\n    print(i)\ncontinue */}

```
SyntaxError: 'continue' not properly in loop
```

`continue` hoort in een loop, en die van jou springt niet ver genoeg in. Meestal hoort hij bij de `if` in de loop.

**continue na de print**

```python
for i in range(6):
    print(i)
    if i == 3:
        continue
```

Geen foutmelding, maar de 3 staat er toch: de `print` is al geweest als `continue` aan de beurt is. Zet de controle met `continue` bóven wat je wilt overslaan.

## Opdracht 6c.3: Tellen wat overblijft (uitdaging)

Loop door de getallen 0 t/m 20. Sla alles over dat kleiner is dan 5 of
groter dan 15. Print de getallen die overblijven, en print aan het eind
hoeveel het er waren.

Verwachte uitvoer (laatste regel):

```
Aantal geprint: 11
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Maak vóór de loop een teller die op 0 begint. Na de `continue`-check
print je het getal en doe je `teller = teller + 1`. De eindprint staat
buiten de loop.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
teller = 0
for i in range(21):
    if i < 5 or i > 15:
        continue
    print(i)
    teller = teller + 1

print(f"Aantal geprint: {teller}")
```

De `continue` bewaakt de poort: alleen getallen van 5 t/m 15 komen bij
de `print` en de teller.
