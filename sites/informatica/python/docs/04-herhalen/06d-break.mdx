# 6d Stoppen met break

Soms is een loop eerder klaar dan je van tevoren dacht. Met `break` stap je er middenin uit.

## Sparen in de zomervakantie

### Schrijf de loop

De zomervakantie duurt zes weken en je verdient dertig euro per week met een bijbaan. Je spaart voor een koptelefoon van honderd euro. Eerst de loop die zes weken spaart en elke week het saldo laat zien:

```python
saldo = 0

for week in range(1, 7):
    saldo = saldo + 30
    print(f"Week {week}: {saldo} euro")
```

Uitvoer:

```
Week 1: 30 euro
Week 2: 60 euro
Week 3: 90 euro
Week 4: 120 euro
Week 5: 150 euro
Week 6: 180 euro
```

`saldo = saldo + 30` telt dertig op bij wat er al in `saldo` zat: Python rekent eerst de rechterkant uit en bewaart de uitkomst weer in `saldo`. Na zes weken heb je 180 euro, maar na week 4 had je al genoeg.

### Herken het moment

Een `if` in de loop kijkt elke week of het saldo de honderd euro heeft bereikt. De gemarkeerde regels zijn nieuw: de `if` en de `print` in het `if`-blok.

```python {6-7}
saldo = 0

for week in range(1, 7):
    saldo = saldo + 30
    print(f"Week {week}: {saldo} euro")
    if saldo >= 100:
        print("Genoeg gespaard.")
```

Uitvoer:

```
Week 1: 30 euro
Week 2: 60 euro
Week 3: 90 euro
Week 4: 120 euro
Genoeg gespaard.
Week 5: 150 euro
Genoeg gespaard.
Week 6: 180 euro
Genoeg gespaard.
```

Het programma ziet in week 4 dat het genoeg is, en werkt toch door tot week 6.

### Stop de loop

**`break`** stopt de loop op de plek waar hij staat. De gemarkeerde regel is nieuw: `break` staat onderaan in het `if`-blok, op acht spaties. Zo komt de melding nog op het scherm, en de weken erna niet meer.

```python {8}
saldo = 0

for week in range(1, 7):
    saldo = saldo + 30
    print(f"Week {week}: {saldo} euro")
    if saldo >= 100:
        print("Genoeg gespaard.")
        break
```

Uitvoer:

```
Week 1: 30 euro
Week 2: 60 euro
Week 3: 90 euro
Week 4: 120 euro
Genoeg gespaard.
```

De loop staat op zes weken, maar hij haalt er vier.

## Wat break stopt

```python
for getal in range(1, 6):
    if getal == 3:
        break
    print(getal)

print("Klaar")
```

<Voorspel vraag="Wat zet dit programma op het scherm?">
  <Keuze uitleg="Zo werkt continue. break slaat niet één ronde over, hij stopt de hele loop.">`1`, `2`, `4`, `5` en `Klaar`</Keuze>
  <Keuze uitleg="break stopt alleen de loop, niet het hele programma. De regel na de loop komt nog.">`1` en `2`</Keuze>
  <Keuze goed uitleg="Bij 3 stopt de loop, en Python gaat verder met de eerste regel na de loop.">`1`, `2` en `Klaar`</Keuze>
  <Uitleg>

  `break` stopt de **hele loop**, niet één ronde. De `3` komt niet meer op het scherm, `4` en `5` ook niet. `Klaar` wel, want die regel staat buiten de loop.

  </Uitleg>
</Voorspel>

## break of continue

Je kent `continue` al uit [6c](site:python/docs/herhalen/06c-continue). De twee lijken op elkaar en doen iets heel anders:

| | `continue` | `break` |
|:---:|:---:|:---:|
| **Wat stopt er** | deze ronde | de hele loop |
| **Gaat verder bij** | de volgende ronde | de eerste regel ná de loop |
| **Rest van de rondes** | komt gewoon | vervalt |

`break` gebruik je als je iets **gevonden** hebt of als er een grens bereikt is: doorzoeken heeft dan geen zin meer.

**Tip:** `break` werkt ook in een while-loop, en die komt in de [volgende les](site:python/docs/herhalen/while-loop). In het project [Raad het getal](site:python/docs/projecten/raad-het-getal/stap-5-break) stopt de speler zo het spel.

## Puzzel

Je zoekt een lokaal op de vierde verdieping en loopt de trap op, maar de regels van het programma staan door elkaar. Op elke verdieping onder de vierde print het programma dat je doorloopt. Op de vierde print het alleen `Hier moet je zijn.` en stopt de loop. Daarna klop je op de deur.

<Puzzel taal="python" code={`for verdieping in range(1, 10):
    if verdieping == 4:
        print("Hier moet je zijn.")
        break
    print(f"Verdieping {verdieping}: doorlopen")
print("Je klopt op de deur.")`}>

De `if` staat boven de `print` van het doorlopen. Zo kijkt Python op elke verdieping eerst of je er bent, en komt hij op de vierde niet meer bij die `print`. `break` staat onderaan in het `if`-blok, want een regel die daar nog onder zou staan, voert Python niet meer uit. De regel over de deur springt niet in: daar gaat het programma verder als de loop gestopt is.

</Puzzel>

## Er gaat iets mis

### break buiten de loop

{/* foutmelding-van: fout-helft */}
```
SyntaxError: 'break' outside loop
```

**Oorzaak:** je `break` staat niet in een loop. Meestal is hij te ver naar links ingesprongen en hoort hij bij de `if` binnen de loop.

**Oplossing:** zet `break` in het `if`-blok, op acht spaties.

{/* niet-compileren: toont bewust break buiten een lus */}
```python
# FOUT
for getal in range(5):
    if getal == 3:
        print("Gevonden")
break

# GOED
for getal in range(5):
    if getal == 3:
        print("Gevonden")
        break
```

### break buiten het if-blok

```python
for getal in range(1, 6):
    print(getal)
    if getal == 3:
        print("Gevonden")
    break

print("Klaar")
```

Uitvoer:

```
1
Klaar
```

Geen foutmelding, maar de loop stopt al na de eerste ronde. `break` staat op vier spaties en hoort dus bij de loop, niet bij de `if`. Zet hem op acht spaties, in het `if`-blok.

## Opdracht 6d.2: Wachtwoord raden

Je hebt drie pogingen om het getal 4 te raden. De pogingen staan vast: eerst 2, dan 4, dan 7. Print bij elke poging wat je probeert, en stop met `break` zodra het klopt. Print daarna `Binnen!`.

Verwachte uitvoer:

```
Poging: 2
Poging: 4
Binnen!
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Lijsten heb je nog niet gehad. Tel daarom met `range(1, 4)` en bepaal met `if`/`elif` welk getal bij die poging hoort.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
for poging in range(1, 4):
    if poging == 1:
        getal = 2
    elif poging == 2:
        getal = 4
    else:
        getal = 7

    print(f"Poging: {getal}")

    if getal == 4:
        print("Binnen!")
        break
```

De derde poging wordt nooit uitgevoerd: `break` stopt de loop na de tweede.

## Opdracht 6d.3: Break of continue? (uitdaging)

Print de getallen 1 tot en met 10, maar sla 5 over en stop helemaal bij 8.

Verwachte uitvoer:

```
1
2
3
4
6
7
```

<CodeExercise>{`# Schrijf hier je code`}</CodeExercise>

<details>
<summary>Klik hier voor een tip.</summary>

Je hebt allebei nodig: `continue` voor de 5, `break` voor de 8. Let op dat de 8 zelf níét geprint wordt.

</details>

<details>
<summary>Klik hier voor de oplossing.</summary>

```python
for getal in range(1, 11):
    if getal == 5:
        continue
    if getal == 8:
        break
    print(getal)
```

Bij 5 slaat hij één ronde over en gaat door met 6. Bij 8 stopt de loop, dus 8, 9 en 10 komen er niet.
