# Docentenhandleiding

Praktische informatie voor docenten die deze cursus klassikaal willen inzetten: wat de site is, welke randvoorwaarden er zijn, en hoe je de lessen indeelt.

:::tip[Tip: Pydle als dagstart]
Vanaf het moment dat je klas de for-loop heeft gehad ([les 6a](/docs/herhalen/06a-for-loop)) is [pydle.net](https://pydle.net) bruikbaar als opening van de les: elke dag één puzzel waarin je een raster van gekleurde vakjes namaakt met een dubbele for-loop en if-statements.

Projecteer de puzzel, laat leerlingen eerst op papier voorspellen welke conditie welke vakjes kleurt, bespreek de voorstellen, en run dan pas — de Predict-fase van PRIMM als routine van vijf minuten. Snelle leerlingen proberen het patroon met zo min mogelijk if-regels te bouwen. De site is Engelstalig.
:::

## Wat is dit?

Een interactieve cursus **Python** voor leerlingen die nog nooit geprogrammeerd hebben. Doelgroep: onderbouw vo en hoger, of zelfstandige beginners.

Elke les is een korte pagina met uitleg, een voorbeeld en oefeningen met oplopende moeilijkheidsgraad. Je leerlingen schrijven en draaien echte Python direct in de browser — geen installatie nodig — en lopen onderweg bewust tegen veelgemaakte fouten aan.

## Technische randvoorwaarden

| Wat | Antwoord |
|---|---|
| Operating system | Alles met een moderne browser — Windows, macOS, Linux, Chromebook |
| Browser | Chrome, Firefox, Edge of Safari (laatste versie aanbevolen) |
| Installatie | Geen — Python draait in de browser (Pyodide). Alleen voor 9e en 9f, met twee bestanden die elkaar importeren, is een editor op de computer nodig, zoals Thonny |
| Bestanden | In de browser bestaat een bestand dat je leerlingen schrijven, tot ze de pagina herladen |
| Account | Niet nodig |
| Internet | Vereist — de site is online |

## Didactische aanpak (PRIMM)

Elke les volgt hetzelfde vaste patroon — de **PRIMM-methode** — afgesloten met een fouten-sectie:

1. **Predict** — je leerling voorspelt wat de getoonde code doet, vóórdat er iets draait.
2. **Run** — je leerling draait de code en controleert die voorspelling.
3. **Investigate** — kleine, gerichte experimenten ("verander X — wat gebeurt er?").
4. **Modify** — een opdracht die voortbouwt op de bestaande code.
5. **Make** — een vrijere opdracht waarin je leerling zelf iets bouwt.
6. **Er gaat iets mis** — de fouten die je leerlingen waarschijnlijk maken, met uitleg.

Tips en antwoorden staan in `<details>`-blokken. Laat je leerlingen eerst zelf proberen voordat ze openklikken.

## Klassikaal gebruik & differentiatie

- **Plenair starten**: bespreek de Predict-vraag klassikaal, daarna werken je leerlingen zelfstandig door.
- **Snelle leerlingen** werken vooruit op eigen tempo — de lessen zijn lineair maar elk zelfstandig te doen.
- **Langzamere leerlingen** mogen de Make-opdracht overslaan zonder dat de volgende les daarop bouwt.
- **Beoordelen**: gebruik de oefeningen of een eigen project als toets.

## Leerlijn

De lessen zijn gegroepeerd in tien blokken die op elkaar voortbouwen. Begin bij [de introductie](/docs/basis/introductie); voor vrij experimenteren is er de [Playground](/playground).

| Blok | Leerdoel |
|---|---|
| Basis | `print()`, `input()` en rekenen met getallen |
| Tekst | Werken met strings: knippen, plakken, opmaken |
| Beslissen | Keuzes maken met `if`, `else` en vergelijkingen |
| Herhalen | Taken automatiseren met `for`- en `while`-loops |
| Functies | Code herbruikbaar maken met `def` |
| Modules | Functies importeren, en je eigen code in een aparte module zetten |
| Data | Lijsten, dictionaries, tuples en sets gebruiken |
| Bestanden | Tekst en JSON opslaan in een bestand, en weer inlezen |
| Klassen | Eigen objecten maken met attributen en methoden |
| Fouten afvangen | Fouten opvangen met `try` en `except`, en opwerpen met `raise` |

Naast de lessen staat een eigen route met grotere opdrachten: de
[Projecten](/docs/projecten/). In het eerste project, *Tien groene flessen*,
bouwen je leerlingen in acht stappen een aftelliedje na: van vijftig losse
`print`-regels naar één aanroep `lied(10)`. Onderweg komen variabelen,
f-strings, een aftellende `for`, `if`/`elif`, functies met parameters en
`return` samen. Het project past goed na het blok Functies, of als
herhaling van de hele basis. Elke stap noemt bovenaan de les die hij
gebruikt.

Onder *Tekenen met turtle* staat een lijn van kleine projecten. Elk
project voegt precies één ding toe: óf een turtle-commando, óf een
Python-concept. De eerste zeven gebruiken alleen losse commando's (lijnen,
een vierkant, een driehoek, kleur, een huis met een raam, een dobbelsteen en
een smiley), en passen al na les 1. Daarna komt per project één concept uit
de cursus: variabelen en rekenen, `if` en `elif`, de for-loop, de
loopvariabele en `range` met stappen, de while-loop, functies en parameters,
en lijsten. Elk project is kort genoeg voor een deel van een les, en past
direct na de les van zijn concept. Leerlingen zien bij elke opdracht een plaatje van wat
er moet komen. De speeltuin heeft een eigen turtle die in de browser tekent;
dezelfde code werkt met de echte turtle, met `turtle.done()` als laatste regel
zodat het venster buiten Thonny open blijft.
