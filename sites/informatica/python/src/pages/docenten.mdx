# Docentenhandleiding

Een cursus Python voor leerlingen die nog nooit hebben geprogrammeerd. Hoe je ermee lesgeeft, bepaal je zelf. Deze pagina laat zien op welk onderzoek de opbouw van de lessen steunt, en noemt daarna kort wat je vooraf wilt weten.

## Waar de lessen op steunen

Een les heeft vaste onderdelen. In de les zijn het de tabbladen, elk met een eigen icoon. Hieronder staat bij elk onderdeel de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

<Werkvormen />

Een voorspelvraag heeft geen eigen tabblad: hij staat in de uitleg, direct onder de code waar hij over gaat. Voorspellen, draaien, aanpassen en zelf maken is de volgorde van PRIMM.

## Wat je vooraf wilt weten

- **Geen installatie, geen account.** Python draait in een moderne browser, ook op een Chromebook. Alleen de lessen 9e en 9f, over een eigen module, vragen een editor op de computer, zoals Thonny.
- **Het oefenveld bewaart niets.** Wie de pagina herlaadt of naar een andere les gaat, is zijn code kwijt. Werk dat niet weg mag, maakt een leerling in de [Online Editor](site:ide/); daar kan hij het downloaden.
- **De lessen staan in volgorde in de lessenlijst**, vanaf [de introductie](site:python/docs/basis/introductie). Elke les gebruikt alleen wat eerder is uitgelegd.

## Naast de lessen

- [Projecten](site:python/docs/projecten): grotere opdrachten in stappen, en een lijn van korte tekenprojecten met turtle. Bij elk project staat vanaf welke les het kan.
- [Unplugged](site:python/docs/projecten/unplugged): negen hand-outs zonder computer om te printen, elk gericht op één misvatting van beginners. Op de hand-out staat wat je nodig hebt en hoe lang het duurt.
- [Leerlijnen](site:python/leerlijnen): welk concept in welke les groeit.
- [pydle.net](https://pydle.net): elke dag één puzzel met een dubbele for-loop en if-statements, te doen vanaf [les 6a](site:python/docs/herhalen/06a-for-loop). De site is Engelstalig.
