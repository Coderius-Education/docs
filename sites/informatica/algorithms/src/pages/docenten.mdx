# Docentenhandleiding

Een cursus algoritmes voor leerlingen die al wat Python kennen: van zoeken en sorteren tot grafen, speltheorie en machine learning. Hoe je ermee lesgeeft, bepaal je zelf. Deze pagina laat zien op welk onderzoek de opbouw van de lessen steunt, en noemt daarna kort wat je vooraf wilt weten.

## Waar de lessen op steunen

Een les heeft vaste onderdelen. In de les zijn het de tabbladen, elk met een eigen icoon. Hieronder staat bij elk onderdeel de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

<Werkvormen />

De zes zoek- en sorteeralgoritmes hebben dezelfde reeks lessen, in de volgorde van de lessenlijst: het concept, het algoritme bekijken, stellingen om te voorspellen, de bouwstenen met elk één klein stuk code, de complete code, aanpassen, zelf bouwen, fouten en een cheatsheet. De andere hoofdstukken volgen die reeks losser: Dijkstra, knapsack en minimax beginnen met pen en papier, Big O heeft geen code om zelf te bouwen.

## Wat je vooraf wilt weten

- **Geen installatie, geen account.** Python draait in de browser. Alleen de projecten van CS50 AI aan het eind van de route machine learning doen je leerlingen op hun eigen computer.
- **Het oefenveld en het model bewaren niets**: wat je leerlingen willen houden, kopiëren ze. Een lus die nooit stopt, laat het tabblad van de browser vastlopen; de les waarschuwt op het scherm waar je leerlingen zelf een `while` schrijven.
- **Elk algoritme staat op zichzelf.** Alleen [de route machine learning](site:algorithms/docs/machine-learning) heeft een vaste volgorde, in zes fases.
