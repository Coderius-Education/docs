# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent veelvoorkomende valkuilen bij het accumulator-
patroon en begrijpt waarom ze optreden.

## Een maximum dat er niet in staat: `maximum = 0`

Geen foutmelding, maar wel een fout antwoord op een lijst met alleen
negatieve getallen: voor `[-3, -1, -7]` geeft de functie `0`.

**Oorzaak:** geen enkele waarde is groter dan `0`, dus de `if` is nooit
waar en `maximum` blijft `0`. Maar `0` zit niet in de lijst.

**Oplossing:** gebruik `lijst[0]` als startwaarde. Dan is je startwaarde
**altijd** een echte waarde uit de lijst.

{/* niet-draaien: fragment; lijst komt uit de functie */}
```python
# FOUT
maximum = 0

# GOED
maximum = lijst[0]
```

Meer uitleg: [Bouwsteen 3 — startwaarde](site:algorithms/docs/vind-maximum/bouwen/06-initialisatie).

## Een getal dat max heet: `max` als variabelenaam

{/* foutmelding-van: max = 5\nmax([1, 2, 3]) */}
```
TypeError: 'int' object is not callable
```

**Oorzaak:** `max` is een **ingebouwde functie** in Python. Maak je er een
variabele van, dan **schaduw** je die functie: `max` is daarna een getal,
en `max([1, 2, 3])` probeert dat getal aan te roepen.

**Oplossing:** gebruik een andere naam, zoals `maximum`, `grootste` of
`max_tot_nu_toe`.

{/* niet-draaien: fragment; lijst komt uit de code eromheen */}
```python
# FOUT
max = lijst[0]

# GOED
maximum = lijst[0]
```

Meer uitleg: [Bouwsteen 1 — vergelijken en bijhouden](site:algorithms/docs/vind-maximum/bouwen/04-vergelijken).

## Geen eerste element: een lege lijst

{/* foutmelding-van: [][0] */}
```
IndexError: list index out of range
```

**Oorzaak:** op een lege lijst bestaat `lijst[0]` niet. Er **is** dan ook
geen maximum.

**Oplossing:** vang de lege lijst af voordat je `lijst[0]` leest, en geef
bijvoorbeeld `None` terug.

```python
# FOUT
def vind_maximum(lijst):
    maximum = lijst[0]

# GOED
def vind_maximum(lijst):
    if len(lijst) == 0:
        return None
    maximum = lijst[0]
```

Of je `None` teruggeeft of zelf een foutmelding geeft, is een
**ontwerpkeuze**: wie de functie aanroept, moet weten wat hij terugkrijgt.
