## Maak het af

In deze `vind_maximum` staan de bouwstenen samen, op één na. De
startwaarde en de vergelijking staan er, maar hij bekijkt alleen het
tweede getal: je krijgt de grootste van de eerste twee. `max_tot_nu_toe`
heet hier korter `maximum`.
Eén stap is nog open: bouwsteen 2, door de lijst lopen en updaten. Doe die zelf.
Gebruik daarbij niet de functie `max` van Python.

Verwachte uitvoer:

```
scores: 41
vorst: -2
```

<PyRunner initialCode={`def vind_maximum(lijst):
    maximum = lijst[0]
    waarde = lijst[1]   # nu alleen het tweede getal
    if waarde > maximum:
        maximum = waarde
    return maximum

print("scores:", vind_maximum([12, 30, 8, 41, 25]))
print("vorst:", vind_maximum([-4, -9, -2, -6]))`} />

<details>
<summary>Tip</summary>

De vergelijking moet voor elk getal van de lijst draaien, niet alleen
voor `lijst[1]`. Welke regel geeft je elke ronde een nieuwe `waarde`?
Kijk bij bouwsteen 2, door de lijst lopen en updaten, en let op wat er
dan moet inspringen.

</details>

<details>
<summary>Antwoord</summary>

```python
def vind_maximum(lijst):
    maximum = lijst[0]
    for waarde in lijst:
        if waarde > maximum:
            maximum = waarde
    return maximum

print("scores:", vind_maximum([12, 30, 8, 41, 25]))
print("vorst:", vind_maximum([-4, -9, -2, -6]))
```

De `for` staat op de plek van `waarde = lijst[1]`, en de `if` springt
in: hij draait nu voor elk getal.

</details>

## Alles samen

Zo ziet de hele functie eruit, met bij elke regel zijn bouwsteen.
`maximum` heette in de bouwstenen `max_tot_nu_toe`: het maximum tot nu
toe. In een functie die af is, is `maximum` korter en even duidelijk.

<CodeUitleg>

```python showLineNumbers
def vind_maximum(lijst):
    maximum = lijst[0]
    for waarde in lijst:
        if waarde > maximum:
            maximum = waarde
    return maximum
```

<Regel n={2}>
**Bouwsteen 3** — de startwaarde is `lijst[0]`: gegarandeerd een echte waarde uit de lijst, dus ook veilig bij louter negatieve getallen.
</Regel>

<Regel n={3}>
**Bouwsteen 2** — door de lijst lopen, elke waarde precies één keer.
</Regel>

<Regel n={4} tot={5}>
**Bouwsteen 1** — vergelijken met de kampioen tot nu toe, en bij een grotere waarde overschrijven.
</Regel>

<Regel n={6}>
Het resultaat teruggeven — ná de lus, dus pas als alles bekeken is.
</Regel>

</CodeUitleg>

<details>
<summary>Wat zie je?</summary>

Strings → werkt. Alfabetisch vergelijken: `'k' > 'b' > 'a'`, dus
"kers" > "banaan" > "appel" → output `kers`. Python kan strings
vergelijken met `<` en `>` (alfabetisch).

{/* foutmelding-van: [][0] */}

Lege lijst → `IndexError` op `lijst[0]`. Ons algoritme heeft geen
bescherming.

{/* foutmelding-van: "twee" > 1 */}

Gemengd → `TypeError: '>' not supported between instances of 'str' and
'int'`. Je kunt 1 niet met "twee" vergelijken.

</details>

## Hoeveel werk doet dit?

Voor `n` elementen doet dit algoritme `n` vergelijkingen; `lijst[0]` wordt
ook één keer met zichzelf vergeleken. Het werk groeit even hard als de
lijst: twee keer zo lang is twee keer zoveel werk.

Wil je écht minimaal werk? Sla het eerste element over met `lijst[1:]`
(zie [bouwsteen 3](site:algorithms/docs/vind-maximum/bouwen/06-initialisatie)).
Dan zijn het `n − 1` vergelijkingen. Aan hoe hard het werk groeit,
verandert die ene vergelijking niets. In het hoofdstuk
[Big O](site:algorithms/docs/big-o/01-concept) heet dat allebei `O(n)`.
