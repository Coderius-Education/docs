# Zin 5 — een voorzetselgroep

**Leerdoel:** je introduceert een voorzetselgroep en laat een
zelfstandig-naamwoordgroep zich daarmee uitbreiden.

## De zin

> **We (N) arrived (V) the (Det) day (N) before (P) Thursday (N).**

Het object is "the day before Thursday": een zelfstandig-naamwoordgroep
("the day") met daarachter een **voorzetselgroep**, "before Thursday".

## Denk na

- Een voorzetselgroep begint met een voorzetsel (`P`). Waar bestaat de
  rest uit? (Kijk naar "before **Thursday**".)
- Hoe laat je een bestaande zelfstandig-naamwoordgroep uitbreiden met
  zo'n voorzetselgroep?
- Ook hier kan een groep naar zichzelf verwijzen. Wat levert dat op voor
  ketens als "the day before Thursday in the morning ..."?
