# Het complete algoritme

**Leerdoel:** je herkent alle bouwstenen die je hebt geleerd en ziet ze
samen werken. Daarna onderzoek je het algoritme als geheel.

## Alles samen

<CodeUitleg>

```python showLineNumbers
def binair_zoek(lijst, doel):
    laag = 0
    hoog = len(lijst) - 1
    while laag <= hoog:
        midden = (laag + hoog) // 2
        if lijst[midden] == doel:
            return midden
        elif lijst[midden] < doel:
            laag = midden + 1
        else:
            hoog = midden - 1
    return -1
```

<Regel n={2} tot={3}>
**Bouwsteen 1** — de grenzen van het zoekgebied: `laag` en `hoog` wijzen naar de eerste en de laatste index die nog mee kunnen doen.
</Regel>

<Regel n={4}>
**Bouwsteen 4** — de while-lus draait zolang het zoekgebied niet leeg is. Bij `laag == hoog` is er nog precies één kandidaat, vandaar `<=`.
</Regel>

<Regel n={5}>
**Bouwsteen 2** — het midden berekenen, met `//` zodat er een hele index uitkomt.
</Regel>

<Regel n={6} tot={7}>
**Bouwsteen 3, eerste tak** — raak: de index gaat direct terug.
</Regel>

<Regel n={8} tot={9}>
Het midden is te klein, dus het doel kan alleen rechts liggen. De `+ 1` gooit het al-onderzochte midden weg — zonder die krimpt het zoekgebied niet.
</Regel>

<Regel n={10} tot={11}>
Het spiegelbeeld: te groot, dus zoek links van het midden verder.
</Regel>

<Regel n={12}>
**Bouwsteen 5** — hier kom je alleen als de lus stopt zonder match: het zoekgebied is leeg en `-1` betekent "niet gevonden".
</Regel>

</CodeUitleg>

## Voorspel

We gaan dit algoritme straks runnen met deze vier aanroepen. Wat denk
je dat er uitkomt?

{/* draaien-met: blok-erboven */}
```python
getallen = [1, 3, 5, 7, 9, 11, 13, 15]
print(binair_zoek(getallen, 7))
print(binair_zoek(getallen, 4))
print(binair_zoek([], 5))
print(binair_zoek([42], 42))
```

<details>
<summary>Antwoord</summary>

```
3
-1
-1
0
```

- `7` staat op index 3 — gevonden.
- `4` staat niet in de lijst — `return -1`.
- Bij een lege lijst draait de while-lus nul keer, want `laag=0` is al
  groter dan `hoog=-1`; het antwoord is `-1`.
- Bij `[42]` met doel `42` is het midden index 0 en is het meteen raak.

</details>

## Onderzoek

Binair zoeken gaat ervan uit dat de lijst gesorteerd is. Wat gebeurt er
als dat niet zo is? De code zoekt in `rommel`, een lijst die niet op
volgorde staat.

1. Druk op Voer uit. Klopt het antwoord voor 4? En voor 1?
2. Zoek ook 2, 3 en 5 in `rommel`. Welke vindt de functie?
3. Zet `rommel = sorted(rommel)` onder de regel met `rommel`. Wat geeft de
   functie nu voor 1?

<PyRunner initialCode={`def binair_zoek(lijst, doel):
    laag = 0
    hoog = len(lijst) - 1
    while laag <= hoog:
        midden = (laag + hoog) // 2
        if lijst[midden] == doel:
            return midden
        elif lijst[midden] < doel:
            laag = midden + 1
        else:
            hoog = midden - 1
    return -1

rommel = [5, 1, 4, 2, 3]
print(binair_zoek(rommel, 4))
print(binair_zoek(rommel, 1))`} />

<details>
<summary>Wat zie je?</summary>

```
2
-1
```

- 4 vindt de functie: het eerste midden is index 2, en daar staat
  toevallig 4. Dat is geluk.
- 1 vindt hij niet, terwijl 1 op index 1 staat. Het midden is 4, te
  groot, dus zoekt hij links verder, in `[5, 1]`. Daar is het midden 5,
  weer te groot, dus nog verder naar links, en dan is er niets meer over.
- 2, 3 en 5 vindt hij ook niet: elke keer stuurt een midden hem de
  verkeerde kant op.
- Na `sorted` is de lijst `[1, 2, 3, 4, 5]` en geeft de functie voor 1
  index 0.

Op een ongesorteerde lijst krijg je dus meestal `-1` voor een getal dat er
wél in staat, en soms toevallig het goede antwoord. Aan het antwoord zie
je niet welke van de twee.

</details>
