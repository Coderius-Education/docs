# Aanpassen — geef ook het aantal stappen terug

**Leerdoel:** je past binair zoeken aan zodat hij **twee** dingen returnt
zonder de logica te veranderen.

## Wat je aanpast

Pas `binair_zoek` aan zodat de functie twee dingen teruggeeft,
`(index, aantal_stappen)`:

- `index` zoals voorheen (de gevonden index, of `-1`).
- `aantal_stappen` is het aantal keer dat de `while`-lus draait.

Voorbeeld: `binair_zoek_met_stappen([1, 3, 5, 7, 9, 11, 13, 15], 11)` moet
`(5, 2)` returnen: index 5, in 2 stappen.

## Opdracht

De startcode geeft nog `0` als aantal stappen terug. Hij zoekt vier getallen
in de lijst 1 tot en met 100.

:::caution
Je past hier een while-lus aan. Krimpt het zoekgebied niet in elke ronde,
dan stopt de lus nooit en loopt het tabblad van de browser vast: de
speeltuin heeft geen stopknop. Kopieer je code eerst naar een kladblok.
:::

Verwachte uitvoer:

```
(0, 6)
(99, 7)
(49, 1)
(-1, 7)
```

<summary>Antwoord</summary>

```python
def binair_zoek_met_stappen(lijst, doel):
    laag = 0
    hoog = len(lijst) - 1
    stappen = 0
    while laag <= hoog:
        stappen += 1
        midden = (laag + hoog) // 2
        if lijst[midden] == doel:
            return (midden, stappen)
        elif lijst[midden] < doel:
            laag = midden + 1
        else:
            hoog = midden - 1
    return (-1, stappen)
```

Voor een lijst van 100 elementen zijn er hooguit 7 stappen, want na zes
halveringen is er nog één getal over. Maak je de lijst twee keer zo lang,
dan kost het één stap meer.
