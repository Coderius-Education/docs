# Bijstellen

Het neuron weet nu hoe fout het zat. Met die fout stelt het zijn gewichten en
zijn bias bij: een stukje omhoog als het 1 had moeten zeggen, een stukje
omlaag als het 0 had moeten zeggen. Nieuw is dat je één element van een lijst
verandert.

## Voorspel

```python
gewichten = [0, 0]
bias = 0
invoer = [1, 1]
fout = 1

for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer[i]
bias = bias + fout
print(gewichten, bias)
```

Het neuron zei 0 bij `[1, 1]`, maar het goede antwoord is 1: de fout is 1.
Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
[1, 1] 1
```

Elk gewicht krijgt er de fout keer zijn invoer bij, dus allebei 1, en de bias
krijgt de fout erbij.

</details>

## Zo werkt het

`gewichten[i] = …` is nieuw: het verandert één element van de lijst, op
positie `i`. De rest van de lijst blijft zoals hij was.

Elk gewicht krijgt er de fout keer zijn invoer bij:

- is de fout 0, dan verandert er niets;
- bij een fout van 1 gaan de gewichten van de invoeren die 1 waren omhoog,
  net als de bias;
- bij -1 gaan ze omlaag.

Een gewicht met invoer 0 verandert niet, want die invoer had niets met de
fout te maken.

<details>
<summary>Tip</summary>

Het bijstellen is zelf ook een loop, over de posities van `invoer`. Die komt

<details>
<summary>Antwoord</summary>

Dit vervangt de laatste drie regels in de editor:

{/* draaien-met: blok-erboven */}
```python
for invoer, doel in voorbeelden:
    fout = doel - neuron(invoer, gewichten, bias)
    for i in range(len(invoer)):
        gewichten[i] = gewichten[i] + fout * invoer[i]
    bias = bias + fout
    print(invoer, fout, gewichten, bias)

print(neuron([0, 1], gewichten, bias))
```

```
[0, 0] 0 [1, 1] 0
[0, 1] -1 [1, 0] -1
[1, 0] 0 [1, 0] -1
[1, 1] 1 [2, 1] 0
1
```

Na één keer alle voorbeelden is het neuron nog geen EN: bij `[0, 1]` zegt het
weer 1. Het leert niet alles in één keer. In de volgende stap laat je het
daarom vaker oefenen.

</details>

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
TypeError: unsupported operand type(s) for +: 'int' and 'list'
```

**Oorzaak:** je vergat `[i]` achter `invoer`. Dan is `fout * invoer` een
lijst, en een getal plus een lijst kan Python niet uitrekenen.

**Oplossing:** pak met `invoer[i]` de invoer die bij gewicht `i` hoort.

```python
# FOUT
gewichten = [0, 0]
invoer = [1, 1]
fout = 1
for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer

# GOED
gewichten = [0, 0]
invoer = [1, 1]
fout = 1
for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer[i]
```
