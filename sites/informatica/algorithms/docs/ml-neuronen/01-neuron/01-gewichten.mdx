# Gewichten

Ga je vanavond naar het feest? Dat hangt af van een paar dingen: gaan je
vrienden, is je huiswerk af, regent het? Het ene telt zwaarder dan het andere.
Een **neuron** in een computer beslist op dezelfde manier. Het krijgt een paar
getallen binnen, geeft elk getal een gewicht en telt alles op. Een neuraal
netwerk, zoals in een spraakassistent of een zelfrijdende auto, is gemaakt van
heel veel van zulke neuronen. In deze stap maak je de optelling.

:::info
Je gebruikt hier lijsten uit [Lijsten](site:python/docs/data/10a-lijsten-basis),
`range(len(…))` uit
[doodlopende vakjes](site:algorithms/docs/ml-zoeken/01-buren/04-doodlopende-vakjes),
en een functie met `return` uit
[Return-waarden](site:python/docs/functies/09b-return).
:::

## Voorspel

```python
invoer = [1, 0, 1]
gewichten = [3, 2, -1]

som = 0
for i in range(len(invoer)):
    som = som + invoer[i] * gewichten[i]
print(som)
```

`invoer` zegt: je vrienden gaan (1), je huiswerk is niet af (0), en het regent
(1). Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
2
```

Er komt 1 keer 3 bij voor je vrienden, 0 keer 2 voor het huiswerk, en 1 keer
-1 voor de regen. 3 + 0 - 1 is 2.

</details>

## Zo werkt het

Elke invoer heeft een eigen **gewicht**. Een groot gewicht telt zwaar, een
negatief gewicht trekt de som omlaag: als het regent, wil je minder graag.

De loop gaat met `range(len(invoer))` langs de posities 0, 1 en 2, zoals je
in het doolhof langs de nummers van de rijen liep. Nieuw is dat je zo langs
twee lijsten tegelijk loopt: op elke positie `i` pak je met `invoer[i]` de
invoer en met `gewichten[i]` het gewicht dat erbij hoort.

## Opdracht

### De opdracht

Een vierde reden: er speelt een band die je leuk vindt, en dat telt ook mee.
Je geeft het neuron een vierde invoer voor de band, met gewicht 2. Met
vrienden, zonder huiswerk, met regen en met de band komt de som dan op 4.

### Aan de slag

In de editor staat het neuron met drie invoeren.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: de som is 2.
2. Zet een 1 achteraan `invoer`, voor de band, en draai. Je krijgt een foutmelding: er is nog geen gewicht voor de band.
3. Zet het gewicht van de band, 2, achteraan `gewichten`: de som is 4. Wat is hij bij `[0, 0, 0, 1]`, alleen de band?

Verwachte uitvoer:

```
4
```

## Er gaat iets mis

{/* foutmelding-van: invoer = [1, 0, 1, 1]\ngewichten = [3, 2, -1]\nsom = 0\nfor i in range(len(invoer)):\n    som = som + invoer[i] * gewichten[i] */}
```
IndexError: list index out of range
```

**Oorzaak:** er zijn meer invoeren dan gewichten. De loop gaat langs alle
posities van `invoer`, en op de laatste positie heeft `gewichten` niets meer.

**Oplossing:** geef elke invoer een gewicht. Zet je er een invoer bij, zet dan
ook een gewicht bij.

```python
# FOUT
invoer = [1, 0, 1, 1]
gewichten = [3, 2, -1]

# GOED
invoer = [1, 0, 1, 1]
gewichten = [3, 2, -1, 2]
```
