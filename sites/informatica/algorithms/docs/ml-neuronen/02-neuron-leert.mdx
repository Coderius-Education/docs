# Een neuron dat zelf leert

In het vorige project zocht jij de gewichten van het EN-neuron. Nu laat je het
neuron ze zelf vinden. Het begint met alle gewichten op 0, en krijgt
voorbeelden met het goede antwoord erbij. Zegt het iets fouts, dan schuift het
zijn gewichten een stukje in de goede richting. Bestaan er gewichten die
kloppen, dan zegt het na een paar rondes bij elk voorbeeld het goede
antwoord. Zo'n lerend neuron heet een
**perceptron**, en het is het begin van elk neuraal netwerk.

:::info
Je gebruikt hier `neuron` uit
[één neuron met gewichten](site:algorithms/docs/ml-neuronen/01-neuron), en
voorbeelden met het goede antwoord erbij, zoals bij
[welk fruit is dit?](site:algorithms/docs/ml-afstand/01-dichtstbijzijnde-buur).
Nieuw is dat je één element van een lijst verandert, met `lijst[i] = …`.
:::

## Voorspel

```python
gewichten = [0, 0]
bias = 0
invoer = [1, 1]
doel = 1
uit = 0

fout = doel - uit
for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer[i]
bias = bias + fout

print(fout)
print(gewichten, bias)
```

Het neuron zei 0 bij `[1, 1]`, maar het goede antwoord is 1. Wat print dit
programma?

<details>
<summary>Antwoord</summary>

```
1
[1, 1] 1
```

De fout is 1 - 0 = 1. Elk gewicht krijgt er de fout keer zijn invoer bij, dus
allebei 1, en de bias krijgt de fout erbij.

</details>

## Zo werkt het

De **fout** is het goede antwoord min wat het neuron zei. Er zijn drie
mogelijkheden:

- het neuron had gelijk: de fout is 0, en er verandert niets;
- het neuron zei 0 maar het moest 1 zijn: de fout is 1, en de gewichten van de
  invoeren die 1 waren gaan omhoog, net als de bias;
- het neuron zei 1 maar het moest 0 zijn: de fout is -1, en ze gaan omlaag.

`gewichten[i] = …` verandert één element van de lijst. Een gewicht met invoer
0 verandert niet, want die invoer had niets met de fout te maken.

Eén keer alle voorbeelden langs heet een **ronde**. De code doet tien rondes,
en telt per ronde hoe vaak het neuron het fout had.

## Opdracht: appels en bananen

Een neuron kan ook met grotere getallen werken. Leer het appels en bananen uit
elkaar houden, met de maten uit fase B: de lengte en de breedte in
centimeters. Een neuron rekent alleen met getallen, dus de soort wordt een
getal: een banaan is 1, een appel 0. De maten staan nu in een lijst, net als
de invoer van het EN-neuron.

```python
fruit = [
    ([8, 8], 0), ([9, 8], 0), ([7, 7], 0), ([8, 7], 0),
    ([18, 4], 1), ([20, 4], 1), ([17, 3], 1), ([19, 4], 1),
]
```

Laat het neuron tien rondes leren, en test het daarna met twee stukken fruit
die het nooit zag:

```
[10, 7] -> 0
[15, 5] -> 1
```

<details>
<summary>Tip</summary>

Het leren in de editor werkt voor elke lijst voorbeelden, ook met grotere
getallen. Wat moet je aan de code veranderen, en wat moet je erbij zetten om
de twee nieuwe stukken fruit te testen?

</details>

<details>
<summary>Antwoord</summary>

```python
def neuron(invoer, gewichten, bias):
    som = bias
    for i in range(len(invoer)):
        som = som + invoer[i] * gewichten[i]
    if som > 0:
        return 1
    return 0

fruit = [
    ([8, 8], 0), ([9, 8], 0), ([7, 7], 0), ([8, 7], 0),
    ([18, 4], 1), ([20, 4], 1), ([17, 3], 1), ([19, 4], 1),
]
gewichten = [0, 0]
bias = 0

for ronde in range(10):
    for invoer, doel in fruit:
        fout = doel - neuron(invoer, gewichten, bias)
        for i in range(len(invoer)):
            gewichten[i] = gewichten[i] + fout * invoer[i]
        bias = bias + fout

print(gewichten, bias)   # [11, -16] -1
print("[10, 7] ->", neuron([10, 7], gewichten, bias))
print("[15, 5] ->", neuron([15, 5], gewichten, bias))
```

Het neuron leert gewichten `[11, -16]`: een lang stuk fruit telt voor banaan,
een breed stuk tegen. Bij k-NN uit fase B moest de voorspeller alle
voorbeelden onthouden. Het neuron onthoudt alleen drie getallen.

Vertrouw er nog niet te veel op. Een appel van 11 bij 7 noemt dit neuron al een
banaan: de som is 8. Met acht voorbeelden en twee testen weet je weinig. Daar
heb je [eerlijk testen](site:algorithms/docs/ml-afstand/03-eerlijk-testen) voor,
met veel meer stukken fruit.

</details>

## Bekijk de grens

Het neuron zegt banaan als de som boven 0 komt, en appel als hij dat niet
doet. Precies waar de som 0 is, ligt de grens: aan de ene kant zegt het
appel, aan de andere kant banaan. Deze runner leert het neuron op het fruit,
en tekent daarna de voorbeelden en die grens. Het tekenen staat in de
verborgen code onder de editor.

schuift de grens? Probeer ook een banaan die dicht bij de appels ligt.

daarom kan één neuron het niet.

## Bouw zelf: een functie leer

Zet het leren in een functie `leer(voorbeelden, rondes)` die de gewichten en
de bias teruggeeft. Laat hem werken voor elk aantal invoeren: twee, maar ook
drie of tien.

Leer er daarna een neuron mee dat met drie invoeren "minstens twee van de drie"
herkent: 1 als minstens twee invoeren 1 zijn. Test het op alle acht
combinaties.

<details>
<summary>Tip</summary>

Het aantal invoeren lees je af aan het eerste voorbeeld:
`len(voorbeelden[0][0])`. Met `[0] * 3` maak je een lijst van drie nullen. Een
functie kan twee dingen teruggeven als tuple: `return gewichten, bias`.

</details>

<details>
<summary>Antwoord</summary>

```python
def neuron(invoer, gewichten, bias):
    som = bias
    for i in range(len(invoer)):
        som = som + invoer[i] * gewichten[i]
    if som > 0:
        return 1
    return 0

def leer(voorbeelden, rondes):
    gewichten = [0] * len(voorbeelden[0][0])
    bias = 0
    for ronde in range(rondes):
        for invoer, doel in voorbeelden:
            fout = doel - neuron(invoer, gewichten, bias)
            for i in range(len(invoer)):
                gewichten[i] = gewichten[i] + fout * invoer[i]
            bias = bias + fout
    return gewichten, bias

voorbeelden = []
for a in [0, 1]:
    for b in [0, 1]:
        for c in [0, 1]:
            if a + b + c >= 2:
                voorbeelden.append(([a, b, c], 1))
            else:
                voorbeelden.append(([a, b, c], 0))

gewichten, bias = leer(voorbeelden, 10)
print(gewichten, bias)   # [1, 1, 1] -1
for invoer, doel in voorbeelden:
    print(invoer, neuron(invoer, gewichten, bias), "moest", doel)
```

Het neuron leert gewichten `[1, 1, 1]` met bias `-1`: bij twee of drie keer 1
komt de som boven 0. Op elke regel staat twee keer hetzelfde getal: wat het
neuron zegt, en wat het moest zijn.

</details>

## Aan de slag met Traffic

Het laatste project van de route is
[Traffic](https://cs50.harvard.edu/ai/projects/5/traffic/) van CS50 AI, en het
zwaarste. Je traint een neuraal netwerk dat verkeersborden herkent op foto's.
Reken op een paar weken, en op veel dingen die je nog niet kent.

Het idee ken je nu: neuronen met gewichten, en leren door de gewichten steeds
een stukje bij te stellen, zodat het netwerk minder fout zit. Vier dingen zijn
anders:

- Een foto is de invoer. Een foto van 30 bij 30 pixels met drie kleuren is
  2700 getallen, dus het netwerk heeft 2700 invoeren.
- Er zijn veel neuronen, in lagen achter elkaar. Daardoor kan het netwerk wel
  leren wat één neuron niet kon, zoals "precies één".
- Je schrijft het leren niet zelf. Dat doet de bibliotheek TensorFlow, met
  zijn onderdeel Keras. Jij kiest hoe het netwerk eruitziet: welke lagen, en
  hoeveel neuronen per laag. Voor foto's gebruik je lagen die naar stukjes van
  het beeld kijken, en die legt het hoorcollege uit.
- De foto's lees je zelf in. Daarvoor heb je de module `os` nodig, om de
  mappen met foto's langs te lopen, en de bibliotheek OpenCV, om een foto te
  openen en op 30 bij 30 te brengen. Allebei zijn nieuw; zoek in de opdracht
  op welke functies je nodig hebt.

Zo begin je:

1. Download de bestanden en de foto's via de
   [projectpagina](https://cs50.harvard.edu/ai/projects/5/traffic/), en lees de
   opdracht helemaal door. Bekijk ook het hoorcollege over neurale netwerken.
2. Installeer TensorFlow en de andere pakketten die het project nodig heeft,
   met `pip3 install -r requirements.txt` in een terminal, in de map van het
   project.
3. Schrijf eerst de functie die de foto's inleest, en kijk of het aantal
   foto's klopt. Bouw daarna een klein netwerk, en maak het stap voor stap
   groter. Houd bij wat je probeert en wat het oplevert: dat vraagt de
   opdracht ook.

Net als bij [eerlijk testen](site:algorithms/docs/ml-afstand/03-eerlijk-testen)
houdt het project een deel van de foto's achter als toets. Het netwerk kan een
oefenfoto onthouden, maar alleen de toets zegt of het borden herkent.

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
TypeError: unsupported operand type(s) for +: 'int' and 'list'
```

**Oorzaak:** je vergat `[i]` achter `invoer`. Dan is `fout * invoer` een
lijst, en een getal plus een lijst kan Python niet uitrekenen.

**Oplossing:** pak met `invoer[i]` de invoer die bij gewicht `i` hoort.

```python
# FOUT
gewichten = [0, 0]
invoer = [1, 1]
fout = 1
for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer

# GOED
gewichten = [0, 0]
invoer = [1, 1]
fout = 1
for i in range(len(invoer)):
    gewichten[i] = gewichten[i] + fout * invoer[i]
```
