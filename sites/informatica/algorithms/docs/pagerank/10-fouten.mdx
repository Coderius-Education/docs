# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent de drie fouten die je bij het bouwen van
PageRank het makkelijkst maakt.

## Het verschil is meteen nul

De test van [bouwsteen 4](site:algorithms/docs/pagerank/bouwen/06-itereren) faalt, en de
ranks zien eruit alsof er maar één ronde is gerekend:

{/* foutmelding-los: de fout zit in de pagerank van de leerling; src/docs-tests/pagerank.test.ts rekent deze melding na */}

```
AssertionError: {'A': 0.25, 'B': 0.1437, 'C': 0.4784, 'D': 0.0375}
```

**Oorzaak:** `nieuw = rank` maakt geen kopie, maar geeft dezelfde dict een
tweede naam. Wat je in `nieuw` zet, staat meteen ook in `rank`, dus het
verschil is altijd 0 en de lus stopt na de eerste ronde.

**Oplossing:** begin elke ronde met een lege dict. Zet ook `rank = nieuw`
pas ná het meten van het verschil: ervoor vergelijk je `nieuw` met
zichzelf, en toont de test `'C': 0.5687`.

```python
# FOUT
nieuw = rank

# GOED
nieuw = {}
```

Meer uitleg: [Bouwsteen 4](site:algorithms/docs/pagerank/bouwen/06-itereren)

## Basisdeel vergeten

De som van de ranks zakt onder de 1, en de pagina's lopen leeg.

**Oorzaak:** je rekent alleen `d · Σ ...` en laat het basisdeel
`(1 − d)/N` weg, de willekeurige sprong. Elke ronde gaat er dan een deel
van het belang verloren.

**Oplossing:** tel het basisdeel weer op.

```python
# FOUT
nieuw[p] = d * som

# GOED
nieuw[p] = (1 - d) / n + d * som
```

## Pagina zonder links

Zodra een pagina nergens naartoe linkt, telt de som niet meer op tot 1.

**Oorzaak:** een doodlopende pagina (een *dangling node*) geeft haar
belang aan niemand door, dus het verdwijnt. In het mini-web linkt elke
pagina ergens naartoe. Voeg je op
[de compleet-pagina](site:algorithms/docs/pagerank/07-compleet) een
pagina zonder links toe, dan zie je het meteen aan de som.

**Oplossing:** doe alsof een pagina zonder uitgaande links naar alle
pagina's linkt. De surfer springt dan vanaf die pagina willekeurig
verder.

```python
def uitgaande_links(web, i, paginas):
    if web[i]:
        return web[i]
    return set(paginas)
```

Zo blijft het belang behouden en telt de som weer op tot 1.
