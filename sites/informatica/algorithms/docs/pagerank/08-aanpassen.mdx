# Aanpassen — speel met de damping

**Leerdoel:** je onderzoekt wat de damping factor `d` doet en hoe een
extra link de ranks verschuift.

## Opdracht 1 — draai aan `d`

Verander `DEMPING` en kijk wat er gebeurt. Probeer `0.85`, de gewone
waarde, en daarna `0.5`, `1.0` en `0.0`.

<PyRunner rows={16} initialCode={`WEB = {
    "A": {"B", "C"},
    "B": {"C"},
    "C": {"A"},
    "D": {"C"},
}

DEMPING = 0.85   # <-- verander dit


def pagerank(web, d=0.85, epsilon=1e-9):
    n = len(web)
    rank = {}
    for p in web:
        rank[p] = 1 / n
    while True:
        nieuw = {}
        for p in web:
            som = 0.0
            for i in web:
                if p in web[i]:
                    som += rank[i] / len(web[i])
            nieuw[p] = (1 - d) / n + d * som
        verschil = 0.0
        for p in web:
            verschil = max(verschil, abs(nieuw[p] - rank[p]))
        rank = nieuw
        if verschil < epsilon:
            return rank


ranks = pagerank(WEB, DEMPING)
for p in sorted(ranks, key=lambda x: -ranks[x]):
    print(f"    {p}: {ranks[p]:.4f}")
print(f"    som: {sum(ranks.values()):.4f}")`} />

<details>
<summary>Antwoord</summary>

| `DEMPING` | A | B | C | D |
|:---:|:---:|:---:|:---:|:---:|
| 0.85 | 0.3725 | 0.1958 | 0.3941 | 0.0375 |
| 0.5 | 0.3077 | 0.2019 | 0.3654 | 0.1250 |
| 1.0 | 0.4000 | 0.2000 | 0.4000 | 0.0000 |
| 0.0 | 0.2500 | 0.2500 | 0.2500 | 0.2500 |

Hoe kleiner `d`, hoe vaker de surfer willekeurig springt, en hoe dichter
de ranks bij elkaar komen. Bij `0.5` krijgt D al ruim drie keer zoveel als
bij `0.85`.

Bij `d = 0` volgt de surfer geen enkele link meer en springt hij alleen
nog. Elke pagina krijgt dan `1/N`, dus allemaal `0.25`.

Bij `d = 1` springt hij nooit. Naar `D` linkt niemand, dus D loopt leeg
tot `0`, en al het belang blijft in de kring van A, B en C hangen. Daarom
kies je in de praktijk iets ertussenin, zoals `0.85`.

</details>

## Opdracht 2 — voeg een link toe

Laat `D` ook naar `A` linken: `"D": {"C", "A"}`. Voorspel eerst welke
rank stijgt, en draai daarna.

<details>
<summary>Antwoord</summary>

| | A | B | C | D |
|:---:|:---:|:---:|:---:|:---:|
| zonder `D → A` | 0.3725 | 0.1958 | 0.3941 | 0.0375 |
| met `D → A` | 0.3797 | 0.1989 | 0.3839 | 0.0375 |

`A` krijgt er een stem van `D` bij, dus de rank van `A` stijgt. `D`
verdeelt zijn belang nu over twee pagina's, dus de stem die naar `C` ging,
wordt kleiner. `B` stijgt ook een beetje: B krijgt de helft van wat A
uitdeelt, en A heeft nu meer. `D` zelf verandert niet, want naar D linkt
nog steeds niemand. De som blijft 1; het belang is alleen anders
verdeeld.

</details>
