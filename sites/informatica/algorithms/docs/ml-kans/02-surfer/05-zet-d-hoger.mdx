# Zet D hoger

Je surfer springt nu soms, en komt zo ook op D. Kun je D hoger krijgen door er
zelf links naartoe te maken? Zo probeerden mensen Google te foppen: duizend
nep-pagina's die naar hun eigen site linken.

## Voorspel

```python
web = {"A": ["B"], "B": ["A"]}
web["E"] = ["A"]

print(list(web))
print(web["E"])
```

Wat print dit?

<details>
<summary>Antwoord</summary>

```
['A', 'B', 'E']
['A']
```

`web["E"] = ["A"]` maakt een nieuwe pagina E in het web, met één link, naar A.

</details>

## Zo werkt het

Een nieuwe pagina zet je in het web als nieuwe sleutel, met de lijst van haar
links als waarde. Dat kan met `web["E"] = …`, of door een regel in de
dictionary erbij te typen. Een link is een stem voor de pagina waar hij naar
wijst. Of die stem veel waard is, laat de surfer zien.

## Bouw zelf: zet D hoger

Je bent de eigenaar van pagina D. Je maakt drie nieuwe pagina's, E, F en G,
die naar D linken. Hoeveel hoger komt D, en waarom niet heel veel? In de editor
staat de surfer uit de vorige stap. Begin klein, en breid de code stap voor stap uit:

1. Draai de code: D komt rond de 0,04.
2. Zet E, F en G in het web, elk met een link naar D.
3. Draai opnieuw, en vergelijk D met de andere pagina's.

<PyRunner initialCode={`import random

web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}
klikken = 10000
damping = 0.85

bezocht = {}
for p in web:
    bezocht[p] = 0

pagina = "A"
for i in range(klikken):
    if random.random() < damping:
        pagina = random.choice(web[pagina])
    else:
        pagina = random.choice(list(web))
    bezocht[pagina] = bezocht[pagina] + 1

for p in bezocht:
    print(p, bezocht[p] / klikken)

import matplotlib.pyplot as plt
plt.bar(list(bezocht), list(bezocht.values()))
plt.show()`} />

</details>

<details>
<summary>Antwoord</summary>

Zet onder `"D": ["C"],` in het web:

{/* niet-compileren: fragment; drie regels voor het web uit de opdracht */}
```python
    "E": ["D"],
    "F": ["D"],
    "G": ["D"],
```

D gaat van ongeveer 0,04 naar 0,08: verdubbeld, maar nog steeds de laagste
van de oude pagina's. De nep-pagina's krijgen zelf alleen bezoek als de
surfer er toevallig naartoe springt, elk ongeveer 0,02. Hun stem is dus weinig
waard. Een link van een pagina die zelf veel bezoek krijgt, zoals C, zou D
veel meer helpen. Dat is het idee van PageRank: een stem van een belangrijke
pagina telt zwaarder.

</details>
