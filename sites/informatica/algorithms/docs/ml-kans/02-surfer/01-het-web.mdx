# Het web

Welke pagina van het web is het belangrijkst? De oprichters van Google
stelden zich een surfer voor die eindeloos willekeurige links volgt: de pagina
waar hij het vaakst komt, is het belangrijkst. Je speelt dat na zoals de
dobbelsteen, en zet eerst het web in Python.

:::info
Je gebruikt in dit project `random.choice` uit
[Een bont bloemenveld](site:python/docs/projecten/bloemenveld/stap-6-lijst),
het tellen van
[een dobbelsteen simuleren](site:algorithms/docs/ml-kans/01-dobbelsteen/02-tellen),
en een dictionary met een lijst erin uit
[Geneste dictionaries](site:python/docs/data/11c-geneste-dictionaries).
:::

## Voorspel

```python
web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}

print(web["A"])
print(len(web["D"]))
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
['B', 'C']
1
```

`web["A"]` is de lijst links op pagina A, en pagina D heeft één link.

</details>

## Zo werkt het

Het web is een dictionary. De sleutel is een pagina, en de waarde is de lijst
pagina's waar die pagina naar linkt. `web["A"]` is dus de lijst links op
pagina A. Hetzelfde mini-web kom je straks tegen in het hoofdstuk
[PageRank](site:algorithms/docs/pagerank/01-concept#een-klein-web): A linkt naar
B en C, B en D linken naar C, en C linkt terug naar A.

## Onderzoek

1. Draai de code. Welke pagina heeft twee links?
2. Naar welke pagina linkt geen enkele andere pagina?
3. Zet een pagina E in het web, die naar A en D linkt: `"E": ["A", "D"],`.
   Linkt er nu een pagina naar D?

<PyRunner initialCode={`web = {
    "A": ["B", "C"],

}

for pagina in web:

<details>
<summary>Antwoorden</summary>

1. A, naar B en naar C.
2. D. Hij staat in geen enkele lijst.
3. Ja, E linkt naar D. Maar naar E linkt weer niemand.

</details>

## Opdracht: wie linkt naar C?

Print elke pagina die naar C linkt, en daarna hoeveel het er zijn. In de
editor staat het web, met een loop over zijn pagina's.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print elke pagina van het web.
2. Zet een `if` om de print: print een pagina alleen als `"C" in web[pagina]`. Je ziet nu A, B en D.
3. Tel de pagina's in `aantal`, en print dat na de loop.

Verwachte uitvoer:

```
A
B
D
3 pagina's linken naar C
```

<PyRunner initialCode={`web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}

for pagina in web:
    print(pagina)`} />

<details>
<summary>Tip</summary>

`web[pagina]` is een lijst. Met `in` kijk je of een element in een lijst staat,
net als bij de woorden in het spamfilter.

</details>

<details>
<summary>Antwoord</summary>

```python
web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}

aantal = 0
for pagina in web:
    if "C" in web[pagina]:
        print(pagina)
        aantal = aantal + 1

print(aantal, "pagina's linken naar C")
```

C krijgt de meeste links. Of hij daardoor ook de belangrijkste pagina is, laat
de surfer straks zien.

</details>
