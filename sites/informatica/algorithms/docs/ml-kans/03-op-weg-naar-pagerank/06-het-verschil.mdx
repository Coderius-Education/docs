# Het verschil

Je rekende zeven dagen vooruit, en na zes dagen veranderde er bijna niets meer.
Om de computer zelf te laten stoppen, moet hij eerst kunnen meten hoeveel er in
één dag veranderd is. Dat meet je met één getal: de grootste verandering van
een kans.

:::info
`abs` en `max` ken je uit
[itereren tot het stabiel is](site:algorithms/docs/pagerank/bouwen/06-itereren).
:::

## Voorspel

```python
oud = {"zon": 0.38, "wolken": 0.35, "regen": 0.27}
nieuw = {"zon": 0.349, "wolken": 0.362, "regen": 0.289}

verschil = 0
for weer in nieuw:
    verschil = max(verschil, abs(nieuw[weer] - oud[weer]))
print(round(verschil, 3))
```

Wat print dit?

<details>
<summary>Antwoord</summary>

```
0.031
```

Zon zakt 0,031, wolken stijgen 0,012 en regen 0,019. `abs` haalt het
min-teken weg, en `max` houdt de grootste verandering bij: 0,031.

</details>

## Zo werkt het

`abs(nieuw[weer] - oud[weer])` is hoeveel één kans veranderde, of hij nu
stijgt of daalt. `max(verschil, …)` houdt in `verschil` de grootste
verandering tot nu toe bij. Na de loop weet je dus hoeveel de kans veranderde
die het meest veranderde. Is dat minder dan 0,001, dan verandert geen enkele
kans nog merkbaar.

## Opdracht

Hoeveel verandert er? Reken uit hoeveel de verdeling in één dag verandert: de
grootste verandering van een kans. In de editor rekent de code de verdeling van
morgen uit, vanaf een zonnige dag. Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print de verdeling van morgen.
2. Vervang de print door `verschil = 0` en een loop `for weer in nieuw:` die de grootste verandering in `verschil` bewaart.
3. Begin op de verdeling van dag 2 uit de vorige stap: `verdeling = {"zon": 0.38, "wolken": 0.35, "regen": 0.27}`. Hoe groot is het verschil nu?

Verwachte uitvoer (vanaf een zonnige dag):

```
0.5
```

```python
verschil = 0

print(round(verschil, 3))
```

```
0.5
```

Zon verandert het meest, van 1 naar 0,5. Begin je op de verdeling van dag 2,
dan krijg je 0.031, net als in de Voorspel.
