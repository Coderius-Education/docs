# Een surfer die willekeurig klikt

Welke pagina van het web is het belangrijkst? Larry Page en Sergey Brin,
de oprichters van Google, stelden zich een surfer voor die eindeloos
doorklikt en op elke pagina een willekeurige link kiest. Waar hij het vaakst
uitkomt, die pagina is het belangrijkst. Hun idee kun je met de dobbelsteen
van het vorige project naspelen: laat een surfer duizend keer klikken, en
tel waar hij komt.

:::info
Je gebruikt hier `random.choice` uit
[Een bont bloemenveld](site:python/docs/projecten/bloemenveld/stap-6-lijst),
het tellen van
[een dobbelsteen simuleren](site:algorithms/docs/ml-kans/01-dobbelsteen), en een
dictionary met een lijst erin uit
[Geneste dictionaries](site:python/docs/data/11c-geneste-dictionaries).
:::

## Voorspel

```python
web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}

print(web["A"])
print(len(web["D"]))
```

Wat print dit programma? En wat kan `random.choice(web["A"])` opleveren?

<details>
<summary>Antwoord</summary>

```
['B', 'C']
1
```

`random.choice(web["A"])` geeft `B` of `C`: `random.choice` kiest een willekeurig element
uit de lijst links van pagina A. Draai je het vaak, dan komen ze allebei
ongeveer even vaak voor.

</details>

## Zo werkt het

Het web is een dictionary. De sleutel is een pagina, en de waarde is de lijst
pagina's waar die pagina naar linkt. `web["A"]` is dus de lijst links op
pagina A. Hetzelfde mini-web kom je straks tegen in het hoofdstuk
[PageRank](site:algorithms/docs/pagerank/01-concept#een-klein-web): A linkt naar
B en C, B en D linken naar C, en C linkt terug naar A.

De surfer begint op A. Bij elke klik kiest hij met `random.choice` een link
van de pagina waar hij is, en gaat daarheen. De dictionary `bezocht` telt
hoe vaak hij op elke pagina komt. Deel je dat door het aantal klikken, dan
weet je welk deel van de tijd hij op elke pagina doorbrengt.

## Onderzoek

1. Draai de code. Welke pagina's zijn het populairst?
2. Pagina D krijgt 0. Waarom?
3. Laat de surfer op D beginnen: `pagina = "D"`. Krijgt D nu wel bezoek?
4. Zet `"E": []` in het web, en laat C naar A én E linken:
   `"C": ["A", "E"]`. Wat gebeurt er als je de code draait?

web = {

## Opdracht: de surfer springt soms

Een echte surfer volgt niet altijd een link. Soms typt hij een nieuw adres in
en zit hij ergens anders op het web. Bij PageRank heet dat **damping**: met
kans 0,85 klikt de surfer een link, en anders springt hij naar een
willekeurige pagina van het web.

Bouw dat in. `random.random()` geeft een willekeurig kommagetal van 0 tot 1;
is het kleiner dan 0,85, dan klikt de surfer een link. `list(web)` is de lijst
van alle pagina's van het web. Met 10.000 klikken kom je bijvoorbeeld hierop
uit; de laatste cijfers zijn elke keer anders:

```
A 0.3741
B 0.1932
C 0.3951
D 0.0376
```

Teken het daarna als staafdiagram, net als bij
[de dobbelsteen](site:algorithms/docs/ml-kans/01-dobbelsteen#opdracht-twee-dobbelstenen),
met `bezocht` in plaats van `telling`.

Begin klein, en breid de code stap voor stap uit:

1. Draai de code een paar keer. Meestal zegt hij link: dat gebeurt gemiddeld 85 van de 100 keer.
2. Laat de surfer bij link een link kiezen van de pagina waar hij is, met `pagina = random.choice(web[pagina])`, en bij springen een pagina uit `list(web)`. Print `pagina` na de keuze.
3. Zet de keuze in een loop van 10.000 klikken, en tel met `bezocht` hoe vaak hij op elke pagina komt, zoals in het onderzoek.
4. Loop na de klikken met `for p in bezocht:` langs de pagina's, print per pagina `bezocht[p] / klikken`, en zet de drie regels matplotlib eronder.

In de editor staan het web, de startpagina en één keuze tussen een link volgen en springen.

<PyRunner initialCode={`import random

web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}

<details>
<summary>Tip</summary>

Verandert `pagina` niet? Zet `pagina = "A"` boven de loop, niet erin: anders
begint de surfer bij elke klik opnieuw op A.

</details>

<details>
<summary>Antwoord</summary>

```python
import random

web = {
    "A": ["B", "C"],
    "B": ["C"],
    "C": ["A"],
    "D": ["C"],
}
klikken = 10000
damping = 0.85

bezocht = {}
for p in web:
    bezocht[p] = 0

pagina = "A"
for i in range(klikken):
    if random.random() < damping:
        pagina = random.choice(web[pagina])
    else:
        pagina = random.choice(list(web))
    bezocht[pagina] = bezocht[pagina] + 1

for p in bezocht:
    print(p, bezocht[p] / klikken)

import matplotlib.pyplot as plt
plt.bar(list(bezocht), list(bezocht.values()))
plt.show()
```

D krijgt nu ook bezoek, al is het weinig: alleen als de surfer er toevallig
naartoe springt. Uitgerekend is de PageRank van dit web A 0,373, B 0,196,
C 0,394 en D 0,038. De surfer komt daar dicht bij, en hoe vaker hij klikt,
hoe dichterbij.

</details>

## Bouw zelf: zet D hoger

Je bent de eigenaar van pagina D, en je wilt hoger komen. Je maakt drie
nieuwe pagina's, E, F en G, die alle drie naar D linken. Zet ze in het web
van de opdracht en laat de surfer klikken. Hoeveel hoger komt D? En waarom
niet heel veel?

Begin klein, en breid de code stap voor stap uit:

1. Draai de code. In de editor staat de surfer met damping uit de opdracht: D komt rond de 0,04.
2. Zet E, F en G in het web, elk met een link naar D.
3. Draai opnieuw, en vergelijk D met de andere pagina's.

D gaat van ongeveer 0,04 naar 0,08: verdubbeld, maar nog steeds de laagste

## Aan de slag met PageRank

Met de surfer schat je PageRank door het na te spelen. Je kunt het ook
uitrekenen, in rondes, met een formule. Dat doe je in
[het hoofdstuk PageRank](site:algorithms/docs/pagerank/01-concept) van deze
cursus. Daar kom je de surfer bij
[Zelf bouwen](site:algorithms/docs/pagerank/09-zelf-bouwen) nog een keer tegen,
in een iets andere vorm: hij begint op een willekeurige pagina, en telt de
pagina waar hij is voordat hij klikt.

Daarna ben je klaar voor
[PageRank](https://cs50.harvard.edu/ai/projects/2/pagerank/) van CS50 AI. Daar
bouw je allebei de manieren: een surfer die klikt, en het rekenen in rondes.
Lees in de opdracht goed wat je moet doen met een pagina zonder links, want
daar loopt de surfer vast, zoals bij vraag 4.

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
IndexError: Cannot choose from an empty sequence
```

**Oorzaak:** de surfer staat op een pagina zonder links. `web[pagina]` is dan
een lege lijst, en `random.choice` kan uit een lege lijst niets kiezen.

**Oplossing:** geef elke pagina minstens één link, of laat de surfer
springen als er geen links zijn.

```python
# FOUT
import random
web = {"A": ["E"], "E": []}
pagina = random.choice(web["E"])

# GOED
import random
web = {"A": ["E"], "E": []}
if len(web["E"]) > 0:
    pagina = random.choice(web["E"])
else:
    pagina = random.choice(list(web))
```
