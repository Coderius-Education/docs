# Er gaat iets mis — vier valkuilen

**Leerdoel:** je herkent de vier valkuilen bij het bouwen van een
minimax-AI, en je weet bij elk symptoom waar je moet kijken.

## Bord muteren in `result`

Geen foutmelding, wel een onverklaarbaar verkeerd antwoord. Minimax
probeert zetten en gaat ervan uit dat het origineel niet mee verandert;
doet het dat wel, dan raakt het hele algoritme van slag.

**Oorzaak:** `nieuw = bord` maakt geen kopie: `nieuw` en `bord` zijn
hetzelfde object, dus een zet in `nieuw` staat ook in `bord`. Ook
`bord.copy()` of `list(bord)` is niet genoeg: die maken alleen de
buitenste lijst nieuw, de rijen daaronder blijven gedeeld.

**Oplossing:** maak een diepe kopie met `copy.deepcopy`.

```python
# FOUT
nieuw = bord

# GOED
nieuw = copy.deepcopy(bord)
```

## Zelfde bord in de recursie

{/* foutmelding-van: def max_value(bord):\n    return max_value(bord)\nmax_value([]) */}

Foutmelding: `RecursionError: maximum recursion depth exceeded`. De
browser hangt soms een paar seconden voordat hij komt.

**Oorzaak:** een recursieve aanroep moet een kleiner probleem krijgen.
Geef je hetzelfde bord door in plaats van het bord na de zet, dan roept
de functie zichzelf eindeloos aan op precies dezelfde positie.

**Oplossing:** geef de recursie het bord na de zet,
`result(bord, zet)`. Dat heeft één cel meer gevuld, dus na hoogstens
negen stappen is het bord vol en stopt het vanzelf.

```python
# FOUT
v = max(v, min_value(bord))

# GOED
v = max(v, min_value(result(bord, zet)))
```

## Geen base case

{/* foutmelding-los: hier blijft de melding juist uit; de reproductie staat bij de vorige fout */}

Je bent de base case vergeten in `max_value` of `min_value`. Geen
foutmelding, wel een AI die gewonnen borden niet ziet en waardes
van `inf` of `-inf` teruggeeft. Geen `RecursionError`: het bord
raakt na negen zetten vol, dus de recursie stopt wel, alleen op de
verkeerde plek.

**Oorzaak:** zonder base case speelt de functie door op een bord waar
al drie op een rij staat. Pas op een vol bord is `actions(bord)` leeg;
dan draait de lus niet, blijft `v` op `-math.inf` staan en is dát wat
er terugkomt.

**Oplossing:** check eerst of het bord terminal is, en geef dan de
utility terug. Dat is de bodem van de recursie. Idem in `min_value`, en
`minimax` zelf begint met `if terminal(bord): return None`.

```python
# FOUT
def max_value(bord):
    v = -math.inf

# GOED
def max_value(bord):
    if terminal(bord):
        return utility(bord)
    v = -math.inf
```

## Min en max omgedraaid

Geen foutmelding, wel een AI die verliest of zwak speelt.

**Oorzaak:** `max_value` roept per ongeluk `max_value` aan (zichzelf) in
plaats van `min_value`. Of je verwart wie maximaliseert (X) en wie
minimaliseert (O).

**Oplossing:** laat de beurten wisselen. Na een zet van X is O aan de
beurt, dus `max_value` roept `min_value` aan, en andersom.

```python
# FOUT
v = max(v, max_value(result(bord, zet)))

# GOED
v = max(v, min_value(result(bord, zet)))
```

Een vuistregel: in `max_value` komt het woord `min` voor, en in
`min_value` het woord `max`.
