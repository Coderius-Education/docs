# De score

Je hebt twee tellingen. Daarmee beslist het filter over een nieuw bericht.
Per woord telt het op hoe vaak dat woord in spam voorkwam, en trekt het af
hoe vaak het in gewone berichten voorkwam.

## Voorspel

```python
spam = {"klik": 2, "prijs": 1, "nu": 2}
gewoon = {"je": 3, "nu": 1}

score = 0
for woord in "klik nu".split():
    if woord in spam:
        score = score + spam[woord]
    if woord in gewoon:
        score = score - gewoon[woord]
print("score:", score)
```

Welke score krijgt het bericht `"klik nu"`?

<details>
<summary>Antwoord</summary>

```
score: 3
```

`klik` geeft +2. `nu` staat in allebei: +2 uit spam en -1 uit de gewone
berichten.

</details>

## Zo werkt het

Komt de score boven 0 uit, dan lijkt het bericht meer op spam dan op de
gewone berichten. De drempel is hier dus 0, en die kies je niet zelf: de
voorbeelden bepalen hoe hoog de score wordt.

Met de tellingen uit de vorige stap geeft het bericht
`"klik hier voor je prijs"` score 2: spam. `klik`, `hier`, `voor` en `prijs`
kwamen samen vijf keer voor in spam, en `je` kwam drie keer voor in gewone
berichten. Vijf min drie is twee.

## Opdracht

Laat het filter beslissen. In de editor telt het alleen de spam.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: score 5.
2. Trek in een tweede `if` de telling van het woord in `gewoon` van de score af. Nu is de score 2.
3. Print daaronder `spam` als de score boven 0 is, en anders `geen spam`. Probeer ook `"zie je morgen"`.

Verwachte uitvoer:

```
score: 2
spam
```

bericht = "klik hier voor je prijs"

for woord in bericht.split():
    if woord in spam:
        score = score + spam[woord]

        score = score - gewoon[woord]

if score > 0:
    print("spam")
else:
