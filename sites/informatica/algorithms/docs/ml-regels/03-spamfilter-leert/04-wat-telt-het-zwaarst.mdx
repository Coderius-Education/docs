# Wat telt het zwaarst?

Het filter beslist nu over elk bericht. Maar waarom beslist het wat het
beslist? Elk woord draagt iets bij aan de score: zijn spam-telling erbij, en
zijn gewone telling eraf.

## Voorspel

```python
spam = {"gratis": 2, "nu": 2}
gewoon = {"school": 2, "nu": 1}

score = 0
for woord in "gratis school".split():
    if woord in spam:
        score = score + spam[woord]
    if woord in gewoon:
        score = score - gewoon[woord]
print("score:", score)
```

Welke score krijgt `"gratis school"`? En is het bericht spam, als het filter
alleen bij een score boven 0 spam zegt?

<details>
<summary>Antwoord</summary>

```
score: 0
```

`gratis` geeft +2 en `school` geeft -2. Het filter beslist bij 0 op geen
spam, want de score is niet groter dan 0. Twijfelt het filter, dan laat het
het bericht dus door.

</details>

## Zo werkt het

De bijdrage van een woord is zijn spam-telling min zijn gewone telling. Een
woord dat vaak in spam stond, duwt de score omhoog, en een woord uit gewone
berichten duwt hem omlaag. Een woord dat het filter nooit zag, staat in geen
van beide tellingen en draagt niets bij.

Het filter weet dus alleen wat in zijn voorbeelden stond.

## Opdracht: wat telt het zwaarst?

### De opdracht

Laat het filter bij elk woord van het bericht printen wat dat woord aan de
score bijdraagt. Voor `"klik hier voor je prijs"` wordt dat:

```
klik 2
hier 1
voor 1
je -3
prijs 1
```

Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print de spam-telling van elk woord dat in `spam` staat. `je` mist nog.
2. Zet een tweede `if` in de loop voor `gewoon`, en print daar het woord met min de gewone telling. Nu staat `je -3` erbij.
3. Verander het bericht in `"ben je nu op school"`. `nu` staat in allebei, en je ziet hem twee keer: `nu 2` en `nu -1`.
4. Maak per woord één variabele `bijdrage`: begin op 0, tel de spam-telling erbij en de gewone telling eraf, en print na de twee `if`'s het woord met zijn bijdrage. Nu krijgt `nu` één regel: `nu 1`.

### Aan de slag

In de editor staan de tellingen uit het onderzoek al klaar, en een loop met één `if`.
