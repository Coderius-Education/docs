# Een netwerk

In Degrees van CS50 AI zoek je de kortste verbinding tussen twee acteurs, via
de films waarin ze samen speelden. Dat is breedte-eerst zoeken, maar niet in
een doolhof: in een netwerk. Je oefent hier met een eigen netwerk, de metro
van een verzonnen stad. De buren van een station zijn de stations één halte
verder, en bij elke buur hoort de lijn waarmee je er komt.

:::info
Je gebruikt hier tuples en uitpakken uit [Tuples](site:python/docs/data/tuples),
`append` uit [Lijst-methoden](site:python/docs/data/10b-lijst-methoden), een
functie met `return` uit
[Return-waarden](site:python/docs/functies/09b-return), en het zoeken uit
[breedte-eerst](site:algorithms/docs/ml-zoeken/02-kortste-weg/02-breedte-eerst).
Later in dit project komen er klassen bij, uit
[een klasse](site:algorithms/docs/ml-spellen/03-op-weg-naar-nim/01-een-klasse).
:::

## Voorspel

```python
verbindingen = [
    ("rood", "Centraal", "Markt"),
    ("blauw", "Zuid", "Markt"),
]
for lijn, a, b in verbindingen:
    if b == "Markt":
        print(a, "met", lijn)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
Centraal met rood
Zuid met blauw
```

Elke verbinding is een tuple van drie: de lijn en de twee stations die hij
verbindt. `for lijn, a, b in` pakt alle drie tegelijk uit.

</details>

## Zo werkt het

De metro heeft vier lijnen:

- rood: Centraal, Markt, Haven, Strand
- blauw: Zuid, Markt, Park, Noord
- groen: Centraal, Park, Stadion
- geel: Haven, Museum, Stadion

De lijst `verbindingen` heeft een tuple voor elk stuk tussen twee haltes. De
functie `buren` zoekt bij een station alle verbindingen waar het in staat, en
geeft een lijst paren `(lijn, station)` terug. Een metro rijdt twee kanten op,
dus `buren` kijkt naar `a` én naar `b`.

## Onderzoek

1. Draai de code. Welke buren heeft Markt? Kloppen ze met de lijnen uit Zo werkt het?
2. Vraag `buren("Zuid")`. Waarom is het er maar één?
3. Haal de tweede `if` en zijn `append` weg. Welke buren heeft Markt nu?
4. Vraag `buren("Eiland")`, een station dat niet in het netwerk staat.

## Opdracht

### De opdracht

Hoeveel haltes is elk station van Zuid? Een metronet is ook een doolhof: de
stations zijn de vakjes, en de verbindingen zeggen welke vakjes buren zijn. Je
zoekt het met breedte-eerst, net als in het doolhof, en print de afstanden.

### Aan de slag

**Pas op:** komt een station terug in de wachtrij, dan loopt het tabblad van de browser vast. Kopieer je code eerst. Begin klein:

1. Draai de code: het netwerk en `buren` staan klaar, en hij print de buren van Zuid.
2. Zet de while-loop uit het doolhof eronder, met een wachtrij `[van]` en `station = wachtrij.pop(0)`.
3. `buren` geeft paren: loop met `for lijn, buur in buren(station):`. Print ook `afstand["Strand"]`.

Verwachte uitvoer:

```
{'Zuid': 0, 'Markt': 1, 'Centraal': 2, 'Haven': 2, 'Park': 2, 'Strand': 3, 'Museum': 3, 'Noord': 3, 'Stadion': 3}
```

```python
wachtrij = [van]
while len(wachtrij) > 0:
    station = wachtrij.pop(0)
    for lijn, buur in buren(station):
        if buur not in afstand:
            afstand[buur] = afstand[station] + 1
            wachtrij.append(buur)

print(afstand)
print("Naar Strand:", afstand["Strand"], "haltes")
```


Het zoeken is hetzelfde als in het doolhof. Alleen de buren zijn anders: een
paar met een lijn, in plaats van een vakje. De lijn gebruik je hier nog niet;
dat komt bij [de weg met lijnen](site:algorithms/docs/ml-zoeken/03-op-weg-naar-degrees/04-de-weg-met-lijnen).
