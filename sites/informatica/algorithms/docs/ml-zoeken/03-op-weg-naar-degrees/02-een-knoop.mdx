# Een knoop

In het doolhof onthield je in `vorige` via welk vakje je ergens kwam. In de
metro wil je ook weten met welke lijn. CS50 stopt die twee dingen samen met
het station in één object: een knoop. Zo'n knoop maak je met een klasse.

:::info
`class` en `self` ken je uit
[een klasse](site:algorithms/docs/ml-spellen/03-op-weg-naar-nim/01-een-klasse).
Meer oefenen kan met `__init__` uit
[Je eerste klasse](site:python/docs/klassen/15a-je-eerste-klasse) in de
python-cursus. `None` uit [Return-waarden](site:python/docs/functies/09b-return)
betekent: geen waarde.
:::

## Voorspel

```python
class Knoop:
    def __init__(self, toestand, ouder, actie):
        self.toestand = toestand
        self.ouder = ouder
        self.actie = actie

start = Knoop("Zuid", None, None)
markt = Knoop("Markt", start, "blauw")
print(markt.toestand, markt.actie)
print(markt.ouder.toestand)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
Markt blauw
Zuid
```

`markt.ouder` is de knoop `start`, en daarvan is `toestand` Zuid.

</details>

## Zo werkt het

Een `Knoop` heeft drie dingen. `toestand` is waar je bent: een station.
`ouder` is de knoop waar je vandaan kwam. `actie` is wat je deed om hier te
komen: de lijn die je nam. De start heeft geen ouder en geen lijn, daarom
krijgt hij twee keer `None`.

Via `ouder` hangen de knopen aan elkaar, en loop je terug naar de start, net
als met `vorige`. Nieuw is `is not None`: `knoop.ouder is not None` is `True`
zolang de knoop een ouder heeft. Bij de start is hij `False`.

## Opdracht: terug naar de start

### De opdracht

Loop vanaf de knoop van Strand terug naar de start. Print bij elke knoop het
station en de lijn waarmee je er kwam, en print als laatste de start:

```
Strand via rood
Haven via rood
Markt via blauw
Zuid is de start
```

Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print de eerste regel, `Strand via rood`.
2. Ga één knoop terug met `knoop = knoop.ouder`, en print hetzelfde nog een keer. Nu zie je ook `Haven via rood`.
3. Zet de print en `knoop = knoop.ouder` in een loop `while knoop.ouder is not None:`, en haal de losse regels erboven weg. Nu zie je de drie stations met een lijn.
4. Print na de loop `knoop.toestand` met `"is de start"`.

### Aan de slag

:::caution
Schrijf je een while-loop die nooit `knoop = knoop.ouder` doet, dan stopt hij
nooit. De speeltuin heeft geen stopknop, dus het tabblad loopt vast: herlaad de
pagina, en je code is weg. Kopieer je code daarom eerst naar een kladblok
voordat je een nieuwe while-loop draait.
:::

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
AttributeError: 'NoneType' object has no attribute 'toestand'
```

**Oorzaak:** je liep één knoop te ver terug. De ouder van de start is `None`,
en `None` heeft geen `toestand`. Dat gebeurt als de loop doorgaat zolang
`knoop is not None`, in plaats van zolang `knoop.ouder is not None`, en je
daarna nog iets van `knoop` vraagt.

**Oplossing:** stop de loop bij de start, zolang er nog een ouder is. Weet
je niet zeker of een knoop er is, kijk dan eerst of hij niet `None` is.

```python
# FOUT
knoop = None
print(knoop.toestand)

# GOED
knoop = None
if knoop is not None:
    print(knoop.toestand)
```
