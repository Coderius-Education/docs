# Muren

`buren` geeft nu alle vakjes binnen de randen, ook als er een muur op staat.
Door een muur kan de robot niet. Daarom komt er een tweede `if` bij, die
de muren overslaat. De volgorde van de twee `if`'s doet ertoe.

## Voorspel

```python
doolhof = [
    "S.#",
    ".##",
    "..E",
]
for r, k in [(0, 1), (0, 2), (2, 2)]:
    if doolhof[r][k] != "#":
        print(r, k, "is vrij")
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
0 1 is vrij
2 2 is vrij
```

Op `(0, 2)` staat een muur, dus die print hij niet. De `E` is geen muur: de
robot mag op de uitgang staan.

</details>

## Zo werkt het

`buren` heeft nu twee `if`'s. De eerste kijkt of het vakje binnen de randen
valt, de tweede of het geen muur is. De tweede staat ín de eerste: alleen een
vakje dat bestaat, kun je in het doolhof opzoeken.

## Onderzoek

1. Draai de code. Welke buren heeft `(2, 1)`? Zoek ze op in het doolhof.
2. Waarom heeft de start `(0, 0)` maar één buur?
3. Verander de eerste `if` in `if True:`, zodat `buren` de randen niet meer
   controleert. Vraag dan `buren((0, 1))`. Wat klopt er niet?
4. Vraag daarna, nog steeds zonder controle, `buren((4, 5))`. Wat gebeurt er?

{/* draaien-met: blok-erboven */}
```python
def muren(vakje):
    rij, kolom = vakje
    teller = 0
    for r, k in [(rij - 1, kolom), (rij + 1, kolom), (rij, kolom - 1), (rij, kolom + 1)]:
        if r >= 0 and r < len(doolhof) and k >= 0 and k < len(doolhof[0]):
            if doolhof[r][k] == "#":
                teller = teller + 1
    return teller

print(muren((2, 1)))
print(muren((0, 0)))
print(muren((3, 5)))
```

```
1
1
2
```

`muren` is bijna `buren`, met `==` in plaats van `!=` en een teller in plaats
van een lijst. `(3, 5)` heeft een muur erboven en een links, en rechts de rand.

</details>

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
IndexError: list index out of range
```

{/* foutmelding-van: "S."[2] */}

**Oorzaak:** je vraagt een rij die niet bestaat. Het doolhof heeft rij 0 tot
en met 4; rij 5 ligt onder de onderrand. Dat gebeurt als je in het doolhof
kijkt voordat je de randen hebt gecontroleerd, bijvoorbeeld met de twee
`if`'s in de verkeerde volgorde. Bij een kolom die niet bestaat krijg je
`IndexError: string index out of range`, want een rij is een tekst.

**Oplossing:** kijk eerst of het vakje binnen het doolhof ligt.

```python
# FOUT
doolhof = ["S.", ".E"]
r = 2
print(doolhof[r][0])

# GOED
doolhof = ["S.", ".E"]
r = 2
if r >= 0 and r < len(doolhof):
    print(doolhof[r][0])
```

Een negatieve rij geeft geen fout, maar wel een verkeerd vakje: `doolhof[-1]`
is de onderste rij. Daarom controleert `buren` ook op `r >= 0`.
