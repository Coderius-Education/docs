# De buren van een vakje

Een robot staat in een doolhof en moet de uitgang vinden. Voordat hij een weg
kan zoeken, moet hij één ding weten: waar kan ik vanaf hier naartoe? In dit
project zet je een doolhof in Python, en schrijf je een functie die bij elk
vakje de buren geeft waar de robot naartoe kan. In het volgende project zoek
je daarmee de kortste weg.

:::info
Je gebruikt hier lijsten uit [Lijsten](site:python/docs/data/10a-lijsten-basis),
tuples en uitpakken uit [Tuples](site:python/docs/data/tuples), en een functie
met `return` uit [Return-waarden](site:python/docs/functies/09b-return). Nieuw
is dat je een tekst net als een lijst met een index leest.
:::

## Voorspel

```python
doolhof = [
    "S.#",
    ".##",
    "..E",
]

print(doolhof[0][2])
print(doolhof[2][1])
print(len(doolhof), len(doolhof[0]))
```

`S` is de start, `E` de uitgang, `#` een muur en `.` een vrij vakje. Wat
print dit programma?

<details>
<summary>Antwoord</summary>

```
#
.
3 3
```

`doolhof[0]` is de eerste rij, `"S.#"`, en daarvan is `[2]` het derde teken:
een muur. `doolhof[2][1]` is het tweede teken van de onderste rij.

</details>

## Zo werkt het

Het doolhof is een lijst van teksten, één tekst per rij. Een tekst kun je net
als een lijst met een index lezen: `"S.#"[2]` is `"#"`. Met `doolhof[rij][kolom]`
pak je dus één vakje. Rij 0 is de bovenste rij, kolom 0 de linker kolom.

Een vakje schrijf je als tuple `(rij, kolom)`. De buren van een vakje zijn de
vier vakjes erboven, eronder, links en rechts ervan. Een buur telt alleen mee
als hij binnen het doolhof ligt en geen muur is.

In de functie `buren` pakt `rij, kolom = vakje` de tuple uit in twee
variabelen, net als in een for-loop. De loop gaat langs de vier mogelijke
buren, ook als tuples. Daarna heeft `buren` twee `if`'s: de eerste kijkt of
het vakje binnen de randen valt, de tweede of het geen muur is.

## Opdracht: tel de buren

Print het doolhof opnieuw, maar zet op elk vrij vakje hoeveel buren het heeft.
Een muur blijft een `#`. Je hebt daarvoor `str` nodig: `str(3)` maakt van het
getal 3 de tekst `"3"`, want een tekst en een getal kun je niet aan elkaar
plakken. Voor het doolhof van de editor wordt het:

```
132232
#2##32
#3222#
13###1
#22222
```

<details>
<summary>Tip</summary>

Je hebt twee loops nodig: een over de rijen, en daarbinnen een over de
kolommen. Bouw per rij een tekst op, teken voor teken, en print hem als de rij
af is.

</details>

<details>
<summary>Antwoord</summary>

Dit vervangt de laatste regel van de code hierboven:

{/* draaien-met: blok-erboven */}
```python
for rij in range(len(doolhof)):
    regel = ""
    for kolom in range(len(doolhof[0])):
        if doolhof[rij][kolom] == "#":
            regel = regel + "#"
        else:
            regel = regel + str(len(buren((rij, kolom))))
    print(regel)
```

```

#2##32
#3222#
13###1
#22222
```

Geen enkel vakje heeft er vier: het doolhof heeft geen open pleintjes.

</details>

## Bouw zelf: doodlopende vakjes

Een vakje met maar één buur is doodlopend: je kunt er alleen terug. Schrijf een
functie `doodlopend()` die een lijst geeft met alle doodlopende vakjes. Voor
het doolhof van de editor is dat `[(0, 0), (3, 0), (3, 5)]`.

Teken daarna een eigen doolhof van minstens 6 bij 6, en zoek met je functie
de doodlopende vakjes. Kloppen ze met wat jij ziet?

<details>
<summary>Tip</summary>

Gebruik dezelfde twee loops als in de opdracht. Welke twee dingen moeten
waar zijn voordat je een vakje in de lijst zet?

</details>

<details>
<summary>Antwoord</summary>

{/* draaien-met: blok-erboven */}
```python
def doodlopend():
    lijst = []
    for rij in range(len(doolhof)):
        for kolom in range(len(doolhof[0])):
            if doolhof[rij][kolom] != "#" and len(buren((rij, kolom))) == 1:
                lijst.append((rij, kolom))
    return lijst

print(doodlopend())   # [(0, 0), (3, 0), (3, 5)]
```

De start telt ook mee: daar kun je maar één kant op. `(3, 5)` ligt naast de
uitgang, en `(3, 0)` ligt aan het eind van een korte gang links.

</details>

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
IndexError: list index out of range
```

{/* foutmelding-van: "S."[2] */}

**Oorzaak:** je vraagt een rij die niet bestaat. Het doolhof heeft rij 0 tot
en met 4; rij 5 ligt onder de onderrand. Bij een kolom die niet bestaat krijg
je `IndexError: string index out of range`, want een rij is een tekst. Die
krijg je ook als één rij van je eigen doolhof korter is dan de eerste:
`buren` meet de breedte aan `doolhof[0]`, en zoekt dan in de korte rij een
kolom die er niet is. Geef elke rij evenveel tekens.

**Oplossing:** kijk eerst of het vakje binnen het doolhof ligt.

```python
# FOUT
doolhof = ["S.", ".E"]
r = 2
print(doolhof[r][0])

# GOED
doolhof = ["S.", ".E"]
r = 2
if r >= 0 and r < len(doolhof):
    print(doolhof[r][0])
```

Een negatieve rij geeft geen fout, maar wel een verkeerd vakje: `doolhof[-1]`
is de onderste rij. Daarom controleert `buren` ook op `r >= 0`.
