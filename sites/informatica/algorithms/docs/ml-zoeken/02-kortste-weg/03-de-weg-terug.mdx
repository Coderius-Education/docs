# De weg terug

Je weet nu hoe ver E is, maar niet langs welke vakjes. Daarvoor onthoud je bij
elk nieuw vakje via welk vakje je er kwam. Vanaf E loop je daarna terug naar
de start, één vakje per keer.

## Voorspel

```python
vorige = {"C": "B", "B": "A"}
vakje = "C"
weg = [vakje]
while vakje != "A":
    vakje = vorige[vakje]
    weg.insert(0, vakje)
print(weg)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
['A', 'B', 'C']
```

Vanaf C zoek je op waar je vandaan kwam: B, en daarvoor A. Elk vakje komt
vooraan in `weg`, dus de weg staat aan het eind van voor naar achter.

</details>

## Zo werkt het

De dictionary `vorige` zegt bij elk vakje via welk vakje je er kwam. Je vult
hem op dezelfde plek als `afstand`: als je een nieuwe buur vindt, kwam je er
via `vakje`.

Terugvinden doe je met een tweede while-loop. Begin bij het eind, en ga steeds
één vakje terug met `vakje = vorige[vakje]`, tot je bij de start bent. Omdat
je achterstevoren loopt, zet je elk vakje met `weg.insert(0, vakje)` vooraan
in de lijst. `insert(0, …)` staat in de tabel van
[Lijst-methoden](site:python/docs/data/10b-lijst-methoden).

## Opdracht

### De opdracht

Breedte-eerst zoeken weet hoe ver de uitgang is, maar nog niet langs welke weg.
Die vind je terug: je onthoudt bij elk nieuw vakje via welk vakje je er kwam, in
een dictionary `vorige`. Daarna loop je vanaf E terug naar de start, en print je
de weg van S naar E.

### Aan de slag
