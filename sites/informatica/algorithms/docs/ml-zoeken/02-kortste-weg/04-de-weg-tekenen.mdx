# De weg tekenen

De weg is nu een lijst vakjes. Die lees je niet in één oogopslag. Daarom
teken je hem in het doolhof: een `*` op elk vrij vakje van de weg. Daarvoor
bouw je elke rij opnieuw op, teken voor teken.

## Voorspel

```python
regel = ""
for teken in "S..#":
    if teken == ".":
        regel = regel + "*"
    else:
        regel = regel + teken
print(regel)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
S**#
```

`regel` begint leeg, en bij elk teken komt er iets achteraan: een `*` in
plaats van een punt, en anders het teken zelf.

</details>

## Zo werkt het

Een tekst kun je niet veranderen, maar je kunt wel een nieuwe opbouwen. Met
`regel = regel + "*"` plak je een teken achter wat er al stond. Per rij begin
je met een lege `regel`, en loop je langs de kolommen.

Of een vakje op de weg ligt, vraag je met `(rij, kolom) in weg`: `in` werkt op
een lijst van tuples net als op een lijst van woorden. De `S` en de `E` laat
je staan, dus een `*` komt alleen op een vakje met een punt.

## Opdracht: teken de weg

### De opdracht

Een lijst met vakjes is lastig te lezen. In het doolhof zelf zie je de weg in
één oogopslag. Je print het doolhof opnieuw, met een `*` op elk vrij vakje van
de weg.

### Aan de slag

In de editor staan het doolhof en de weg uit de vorige stap.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print het doolhof, nog zonder weg.
2. Bouw elke rij op in `regel = ""`: plak met `for kolom in range(len(doolhof[0])):` elk teken `doolhof[rij][kolom]` erachter, en print `regel`.
3. Plak een `*` in plaats van het teken als `(rij, kolom)` in `weg` staat en er een punt op dat vakje staat.

Verwachte uitvoer:

```
S*....
#*##..
#*...#
.*###.
#****E
```

Dit vervangt de loop onderaan de editor:

{/* draaien-met: blok-erboven */}
```python
for rij in range(len(doolhof)):
    regel = ""
    for kolom in range(len(doolhof[0])):
        if (rij, kolom) in weg and doolhof[rij][kolom] == ".":
            regel = regel + "*"
        else:
            regel = regel + doolhof[rij][kolom]
    print(regel)
```

```
#****E
```

naar E.
