# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent de klassieke valkuilen bij selection sort.

## Het gesorteerde stuk vernield

Geen foutmelding, maar wel een stille fout: de getallen die vooraan al
goed stonden, worden door nieuwe swaps weer weggezet. Van
`[5, 2, 8, 1, 4]` maakt de code `[2, 8, 5, 4, 1]`.

**Oorzaak:** elke ronde zoek je nog in de **hele** lijst, ook in het
gesorteerde stuk vooraan. De 1 die in ronde 0 vooraan kwam, is in elke
ronde erna weer de kleinste, en wordt steeds verder naar achteren
geruild.

**Oplossing:** zoek vanaf `i`, en begin de zoektocht met `min_index = i`.
Dan blijft het gesorteerde deel met rust.

{/* niet-compileren: fragment; het lijf van de binnenste lus is weggelaten */}
```python
# FOUT
for i in range(n):
    min_index = 0
    for j in range(0, n):

# GOED
for i in range(n):
    min_index = i
    for j in range(i, n):
```

Meer uitleg: [Bouwsteen 3 — zoek vanaf een bepaalde positie](site:algorithms/docs/selection-sort/bouwen/06-vind-in-subreeks).

## Een waarde kwijt bij het ruilen

Geen foutmelding, maar na het ruilen staat hetzelfde getal twee keer in de
lijst, en een ander getal is weg.

**Oorzaak:** je overschrijft `lijst[a]` met `lijst[b]` voordat je de
oude waarde van `lijst[a]` ergens hebt bewaard. De tweede regel kopieert
dan de nieuwe waarde terug.

**Oplossing:** gebruik de tuple-swap, of eerst een tijdelijke variabele.

{/* niet-draaien: fragment; lijst, a en b komen uit de code eromheen */}
```python
# FOUT
lijst[a] = lijst[b]
lijst[b] = lijst[a]

# GOED
lijst[a], lijst[b] = lijst[b], lijst[a]
```

Meer uitleg: [Bouwsteen 2 — swappen](site:algorithms/docs/selection-sort/bouwen/05-swap).

## Eén te kort: `range(i, n - 1)`

Geen foutmelding, maar de lijst komt er bijna goed uit: van
`[5, 2, 8, 1, 4]` maakt de code `[1, 2, 5, 8, 4]`. De 4 achteraan is nooit
bekeken.

**Oorzaak:** een `- 1` hoort alleen in een lus die ook naar de buur
`lijst[j + 1]` kijkt. De binnenste lus van selection sort kijkt alleen naar
`lijst[j]`, dus `j` mag tot en met het laatste element gaan.

**Oplossing:** `for j in range(i, n)`. Het laatste element hoort bij het
ongesorteerde stuk.

{/* niet-compileren: fragment; het lijf van de lus is weggelaten */}
```python
# FOUT
for j in range(i, n - 1):

# GOED
for j in range(i, n):
```
