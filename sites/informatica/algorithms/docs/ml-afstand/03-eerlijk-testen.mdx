# Eerlijk testen

Je voorspeller werkt. Maar hoe goed is hij? Dat lijkt makkelijk te meten:
laat hem de voorbeelden voorspellen en tel hoeveel hij er goed heeft. Op deze
pagina zie je waarom dat een oneerlijke toets is, en hoe het wel moet.

:::info
Je gebruikt hier `voorspel(nieuw, voorbeelden, k)` uit
[laat de buren stemmen](site:algorithms/docs/ml-afstand/02-k-buren#opdracht-voorspel-met-k).
Die functie staat in de code hieronder al klaar: klap onder de editor de
verborgen code open om hem te lezen. Je gebruikt ook slicing uit dat
project, en `import` uit [Modules](site:python/docs/modules/09d-modules).
:::

## Voorspel

Een leerling krijgt een week van tevoren de vragen én de antwoorden van een
toets. Hij haalt een 10. Wat zegt dat cijfer over wat hij kan?

<details>
<summary>Antwoord</summary>

Bijna niets. Hij kan de antwoorden onthouden hebben zonder iets te
begrijpen. Of hij de stof kent, merk je pas bij vragen die hij nog nooit
zag. Met een voorspeller is het net zo.

</details>

## Zo wel: oefenen en toetsen

Je verdeelt de voorbeelden in twee stapels:

- de **oefenset**: hier leert de voorspeller van, dus dit zijn de voorbeelden
  waar hij de buren in zoekt;
- de **toetsset**: die houd je achter. Daarmee test je, want deze stukken
  fruit heeft de voorspeller nooit gezien.

Voordat je verdeelt, schud je de lijst met `random.shuffle`. Anders komen de
laatste zes stukken in de toetsset, en dat zijn allemaal citroenen: je toetst
dan alleen citroenen, en de voorspeller heeft er maar twee om van te leren. `random.seed(3)` zorgt dat het schudden
elke keer hetzelfde uitpakt, zodat jij dezelfde stapels krijgt als in de
antwoorden hieronder.

## Opdracht: goed per soort

Een score over alles samen kan een probleem verstoppen. Tel daarom per soort
hoeveel stukken fruit er in de toetsset zitten, en hoeveel daarvan de
voorspeller goed heeft. Met seed 3 en `k = 1` print je:

```
banaan 2 van de 2 goed
appel 2 van de 2 goed
citroen 1 van de 2 goed
```

Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print de soort van elk stuk fruit in de toetsset.
2. Tel met een dictionary `totaal` hoeveel stukken fruit van elke soort erin zitten, zoals je in het spamfilter woorden telde. Print `totaal` na de loop.
3. Zet in de loop een `if` die kijkt of `voorspel(maten, oefen, k)` gelijk is aan `soort`, en tel dat in een tweede dictionary `goed`.
4. Loop na de loop over `totaal`, en print per soort een regel zoals hierboven.

In de editor staan het fruit en het verdelen uit het onderzoek, met een loop over de toetsset.

<summary>Tip</summary>

Stopt Python bij het printen met een foutmelding over een soort? Een soort die
hij nooit goed heeft, komt dan niet in `goed`. Zet daarom in `goed` aan het begin elke soort op 0.

</details>

<details>
<summary>Antwoord</summary>

Dit vervangt de loop onderaan de code in de editor:

{/* niet-draaien: fragment; leunt op toets, oefen, k en voorspel uit de runner erboven */}
```python
totaal = {}
goed = {"appel": 0, "banaan": 0, "citroen": 0}
for maten, soort in toets:
    if soort in totaal:
        totaal[soort] = totaal[soort] + 1
    else:
        totaal[soort] = 1
    if voorspel(maten, oefen, k) == soort:
        goed[soort] = goed[soort] + 1

for soort in totaal:
    print(soort, goed[soort], "van de", totaal[soort], "goed")
```

Nu zie je dat de citroenen het moeilijkst zijn: sommige liggen even dicht bij een appel als bij een andere citroen.

</details>

## Bouw zelf: de luie voorspeller

Een webshop wil voorspellen welke bezoekers iets kopen. Van twintig
bezoekers kocht er één iets. Een luie voorspeller zegt over iedereen
`"kijkt"`, zonder ergens naar te kijken.

Schrijf code die uitrekent hoeveel procent de luie voorspeller goed heeft,
en daarna hoeveel van de kopers hij herkent. Begin zo:

```python
bezoekers = ["kijkt"] * 19 + ["koopt"]
```

`["kijkt"] * 19` is een lijst met negentien keer `"kijkt"`, en met `+` plak
je de koper erachter.

Begin klein, en breid de code stap voor stap uit:

1. Draai de code, en print `bezoekers` om te zien wat erin staat.
2. Loop over `bezoekers`. De luie voorspeller zegt bij elke bezoeker `"kijkt"`: zet dat in een variabele `voorspeld`. Tel hoe vaak `voorspeld` gelijk is aan wat de bezoeker echt deed.
3. Reken dat om naar procenten: deel door `len(bezoekers)`, en vermenigvuldig met 100.
4. Tel ook hoeveel kopers er zijn, en hoeveel daarvan de voorspeller herkent: bij hoeveel kopers `voorspeld` ook `"koopt"` is.

<PyRunner initialCode={`bezoekers = ["kijkt"] * 19 + ["koopt"]`} />

<details>
<summary>Tip</summary>

Een koper herkennen zijn twee dingen tegelijk: de bezoeker kocht echt, en de
voorspeller zei ook `"koopt"`. Dat is een `if` in een `if`, of één `if` met
`and`.

</details>

<details>
<summary>Antwoord</summary>

```python
bezoekers = ["kijkt"] * 19 + ["koopt"]

goed = 0
kopers = 0
kopers_herkend = 0
for echt in bezoekers:
    voorspeld = "kijkt"
    if voorspeld == echt:
        goed = goed + 1
    if echt == "koopt":
        kopers = kopers + 1
        if voorspeld == "koopt":
            kopers_herkend = kopers_herkend + 1

print(goed / len(bezoekers) * 100, "procent goed")   # 95.0 procent goed
print(kopers_herkend, "van de", kopers, "kopers herkend")   # 0 van de 1 kopers herkend
```

95 procent goed, en toch vindt hij geen enkele koper. Als één soort veel
vaker voorkomt dan de andere, zegt het percentage goed weinig. Kijk dan per
soort, zoals in de opdracht hierboven. Bij Shopping van CS50 moet je precies
dat doen.

</details>

## Er gaat iets mis

{/* foutmelding-van: random.shuffle([1, 2, 3]) */}
```
NameError: name 'random' is not defined. Did you forget to import 'random'?
```

**Oorzaak:** `random` is een module. Python haalt hem pas op als je erom
vraagt.

**Oplossing:** zet `import random` bovenaan je code.

```python
# FOUT
getallen = [1, 2, 3]
random.shuffle(getallen)

# GOED
import random
getallen = [1, 2, 3]
random.shuffle(getallen)
```
