# Een CSV lezen

In [Shopping](https://cs50.harvard.edu/ai/projects/4/shopping/), een project
uit CS50 AI, bouw je een voorspeller die uit duizenden bezoeken aan een
webshop leert of een bezoeker iets gaat kopen. De voorspeller is k-NN, en
beoordelen per soort deed je bij eerlijk testen. Nieuw zijn de gegevens in
een CSV-bestand en een voorspeller uit de bibliotheek scikit-learn. Dat oefen
je hier met een paar regels van een eigen webshop, te beginnen met het lezen.

:::info
Je gebruikt hier `import` uit [Modules](site:python/docs/modules/09d-modules),
`int()` en `float()` uit [Tekst naar getal](site:python/docs/basis/03b-tekst-naar-getal),
een dictionary om op te zoeken uit
[Dictionaries](site:python/docs/data/11a-dictionaries-basis), `with open`
uit [Een tekstbestand lezen](site:python/docs/bestanden/14b-tekstbestand-lezen),
en `voorspel(nieuw, voorbeelden, k)` uit
[laat de buren stemmen](site:algorithms/docs/ml-afstand/02-k-buren/03-de-winnaar#opdracht-voorspel-met-k).
:::

## Voorspel

```python
import csv

regels = [
    "maand,paginas,terugkerend,gekocht",
    "Feb,3,TRUE,FALSE",
    "Mar,12,FALSE,TRUE",
]

lezer = csv.reader(regels)
next(lezer)
for rij in lezer:
    print(rij)
```

**Vraag:** wat print dit programma?

<details>
<summary>Antwoord</summary>

```
['Feb', '3', 'TRUE', 'FALSE']
['Mar', '12', 'FALSE', 'TRUE']
```

De kopregel print hij niet: `next(lezer)` slaat die over.

</details>

## Zo werkt het

Een **CSV-bestand** is een tabel als tekst: elke regel is een rij, en de
komma's scheiden de kolommen. De eerste regel heeft de namen van de
kolommen. `csv.reader` knipt elke regel op de komma's in een lijst.

`next(lezer)` pakt de volgende rij. Doe je dat één keer vóór de loop, dan
sla je de kopregel over.

Hier lees je uit een lijst regels. Op je eigen computer lees je op dezelfde
manier uit een bestand:

{/* niet-draaien: leest een bestand van de computer van de leerling */}
```python
import csv

with open("shopping.csv") as bestand:
    lezer = csv.reader(bestand)
    next(lezer)
    for rij in lezer:
        print(rij)
```

## Opdracht: tel de kopers

Tel hoeveel bezoekers iets kochten. Dat staat in de laatste kolom,
`gekocht`.

In de editor staan vier regels van de webshop, en de code die ze leest.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print elke rij als een lijst teksten.
2. Print in de loop alleen de laatste kolom: `rij[3]`.
3. Tel met een `if` hoe vaak `rij[3]` gelijk is aan `"TRUE"`. Tel ook alle bezoekers, en print na de loop een zin zoals in de verwachte uitvoer.

Verwachte uitvoer:

```
2 van de 4 bezoekers kochten iets
```

<summary>Tip</summary>

In stap 1 zag je `'TRUE'` met aanhalingstekens. Is dat de waarde `True`, of

<details>
<summary>Antwoord</summary>

Dit vervangt alles onder de lijst `regels`:

{/* draaien-met: blok-erboven */}
```python
lezer = csv.reader(regels)
next(lezer)
kopers = 0
bezoekers = 0
for rij in lezer:
    bezoekers = bezoekers + 1
    if rij[3] == "TRUE":
        kopers = kopers + 1
print(kopers, "van de", bezoekers, "bezoekers kochten iets")
```

```
2 van de 4 bezoekers kochten iets
```

Vergelijk je met `True` zonder aanhalingstekens, dan telt hij 0 kopers:
alles wat uit een CSV komt, is tekst.

</details>
