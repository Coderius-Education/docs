# Een eigen Shopping

Je hebt alle stukken los geoefend: een CSV lezen, kenmerken en labels maken,
voorspellen, en beoordelen met gevoeligheid en specificiteit. Bij Shopping
zet je ze in functies, en de code van CS50 roept die aan. Dat doe je hier
eerst zelf, op een ander probleem: gaat het morgen regenen?

## Voorspel

```python
def tel(labels):
    enen = 0
    nullen = 0
    for label in labels:
        if label == 1:
            enen = enen + 1
        else:
            nullen = nullen + 1
    return enen, nullen
a, b = tel([1, 0, 0, 1, 0])
print(a, b)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
2 3
```

`return enen, nullen` geeft twee getallen tegelijk terug, als tuple. Met
`a, b = …` pak je ze meteen uit in twee variabelen.

</details>

## Zo werkt het

In de editor van Bouw zelf staat onderaan code die je niet verandert, zoals
CS50 je ook een deel van de code geeft. Die roept twee functies aan die jij afmaakt:

- `lees(regels)` maakt van de regels twee lijsten, `kenmerken` en `labels`,
  en geeft ze allebei terug;
- `beoordeel(labels, voorspellingen)` geeft de gevoeligheid en de
  specificiteit terug.

Het voorspellen zelf doet `voorspel_lijst`, die klaarstaat achter de knop
Klaargezette code boven de editor. Dat is wat scikit-learn bij Shopping voor je doet: de dichtstbijzijnde
buur zoeken voor elke dag in de toets. De eerste vier dagen zijn de toets, de
rest is de oefenset.

## Bouw zelf

Regent het morgen? Maak `lees` en `beoordeel` af. Begin klein, en breid de code stap voor stap uit:

1. Draai de code: `lees` print elke rij, maar geeft nog lege lijsten terug. De code onderaan blijft zo.
2. Zet in `lees` `[temperatuur, wind, bewolkt]` als getallen in `kenmerken`, en 1 of 0 voor regen in `labels`.
3. Haal de print weg, en print in `beoordeel` eerst `labels` en `voorspellingen`.
4. Reken in `beoordeel` de gevoeligheid en de specificiteit uit, en geef ze terug.

Verwachte uitvoer:

```
12 dagen
gevoeligheid: 1.0
specificiteit: 0.6666666666666666
```

<details>
<summary>Tip</summary>

Bij stap 3 zie je `[1, 0, 0, 0]` en `[1, 0, 1, 0]`. Hoeveel regendagen zitten
er in de toets, en hoeveel droge dagen noemt de voorspeller ook droog?

</details>

<details>
<summary>Antwoord</summary>

Dit vervangt alles onder de lijst `regels`:

{/* draaien-met: blok-erboven */}
```python
def lees(regels):
    kenmerken = []
    labels = []
    lezer = csv.reader(regels)
    next(lezer)
    for rij in lezer:
        temperatuur = float(rij[0])
        wind = int(rij[1])
        if rij[2] == "TRUE":
            bewolkt = 1
        else:
            bewolkt = 0
        kenmerken.append([temperatuur, wind, bewolkt])
        if rij[3] == "TRUE":
            labels.append(1)
        else:
            labels.append(0)
    return kenmerken, labels

def beoordeel(labels, voorspellingen):
    regen = 0
    herkend = 0
    droog = 0
    droog_herkend = 0
    for echt, voorspeld in zip(labels, voorspellingen):
        if echt == 1:
            regen = regen + 1
            if voorspeld == 1:
                herkend = herkend + 1
        else:
            droog = droog + 1
            if voorspeld == 0:
                droog_herkend = droog_herkend + 1
    return herkend / regen, droog_herkend / droog

kenmerken, labels = lees(regels)
print(len(kenmerken), "dagen")
toets = kenmerken[:4]
voorspellingen = voorspel_lijst(kenmerken[4:], labels[4:], toets)
echt = labels[:4]
gevoeligheid, specificiteit = beoordeel(echt, voorspellingen)
print("gevoeligheid:", gevoeligheid)
print("specificiteit:", specificiteit)
```

```
12 dagen
gevoeligheid: 1.0
specificiteit: 0.6666666666666666
```

De ene regendag herkent hij, en van de drie droge dagen noemt hij er twee
droog. Op de derde dag, `9.5,6,TRUE`, was het bewolkt en winderig zonder
regen. Met vier toetsdagen zegt dat nog weinig; bij Shopping toets je met
duizenden bezoeken.
