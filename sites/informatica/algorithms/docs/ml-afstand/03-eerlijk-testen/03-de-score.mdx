# De score

Je hebt het fruit verdeeld in een oefenset en een toetsset. Nu toets je: de
voorspeller zoekt de buren alleen in de oefenset, en je telt hoeveel stukken
uit de toetsset hij goed heeft. Dat aantal is zijn **score**.

## Voorspel

```python
uitslagen = [("appel", "appel"), ("citroen", "appel"), ("banaan", "banaan"), ("appel", "appel")]
goed = 0
for echt, voorspeld in uitslagen:
    if echt == voorspeld:
        goed = goed + 1
print(goed, "van de", len(uitslagen), "goed")
print(goed / len(uitslagen) * 100, "procent")
```

Elke uitslag is een tuple van de echte soort en wat de voorspeller zei. Wat
print dit programma?

<details>
<summary>Antwoord</summary>

```
3 van de 4 goed
75.0 procent
```

De citroen noemde hij een appel. Delen door het aantal en keer 100 geeft het
percentage.

</details>

## Zo werkt het

In de loop over de toetsset geef je `voorspel` de oefenset als voorbeelden:
`voorspel(maten, oefen, k)`. Klopt de voorspelling met de echte soort, dan
telt hij als goed. Het stuk fruit zelf zit niet in de oefenset, dus het kan
niet zijn eigen buur zijn.

## Onderzoek

1. Draai de code met `k = 1`. Hoeveel van de zes heeft hij goed?
2. Zet `k` op 3. Wordt het beter?
3. Zet `k` weer op 1, en verander de seed in 4. Wat gebeurt er met de score?
4. Zes stukken fruit is een kleine toets. Wat betekent dat voor een score
   als "5 van de 6"?

## Opdracht: welke heeft hij fout?

### De opdracht

Een score zegt hoeveel er fout gaan, maar niet welke. Print van elk stuk
fruit dat de voorspeller fout heeft de maten, de echte soort en de
voorspelling. Met seed 3 en `k = 1`:

```
(8, 6) citroen voorspeld: appel
```

Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print elk stuk fruit uit de toetsset met zijn soort.
2. Zet de voorspelling erachter: `voorspel(maten, oefen, k)`.
3. Print alleen de stukken fruit die hij fout heeft. Zet daarna `k` op 3.
