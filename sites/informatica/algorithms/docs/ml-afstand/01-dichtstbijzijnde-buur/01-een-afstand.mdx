# Een afstand

Je krijgt een stuk fruit en je weet niet wat het is. Je meet hoe lang en hoe
breed het is, in centimeters. Daarna zoek je in je lijst voorbeelden het fruit
dat er het meest op lijkt, en je zegt dat het dezelfde soort is. Dat heet
**de dichtstbijzijnde buur**, en het is een van de eenvoudigste manieren
waarop een computer leert voorspellen. In deze stap meet je eerst hoeveel twee
stukken fruit verschillen: hun afstand.

:::info
Je gebruikt hier tuples uit [Tuples](site:python/docs/data/tuples), functies
met `return` uit [Return-waarden](site:python/docs/functies/09b-return), en het
patroon "onthoud de beste tot nu toe" uit
[Vind het maximum](site:algorithms/docs/vind-maximum/01-concept).
:::

## Voorspel

```python
def afstand(a, b):
    return abs(a[0] - b[0]) + abs(a[1] - b[1])

print(afstand((8, 8), (10, 7)))
print(afstand((18, 4), (10, 7)))
```

`abs` maakt van een getal een positief getal: `abs(-2)` is `2`. Wat print
dit programma?

<details>
<summary>Antwoord</summary>

```
3
11
```

Bij `(8, 8)` en `(10, 7)`: de lengte scheelt 2, de breedte scheelt 1, samen
3. Bij `(18, 4)` en `(10, 7)`: 8 en 3, samen 11.

</details>

## Zo werkt het

Elk stuk fruit is een tuple `(lengte, breedte)`. Met `a[0]` pak je de lengte,
met `a[1]` de breedte. De functie `afstand` telt op hoeveel de lengtes en de
breedtes schelen, en geeft dat met `return` terug. Hoe kleiner de afstand,
hoe meer twee stukken fruit op elkaar lijken.

`abs` is nieuw. Zonder `abs` kan een verschil negatief zijn, en dan valt het
weg tegen een ander verschil.

## Onderzoek

1. Draai de code. Welk stuk fruit lijkt het meest op `(10, 7)`?
2. Is `afstand(appel, banaan)` hetzelfde als `afstand(banaan, appel)`?
3. Wat is de afstand van een stuk fruit tot zichzelf?
4. Haal beide keren `abs` weg, zodat er `(a[0] - b[0]) + (a[1] - b[1])`
   staat. Wat is nu de afstand van `(8, 8)` tot `(10, 6)`?

## Opdracht: hoe ver is elk voorbeeld?

Je hebt een lijst voorbeelden: tuples van een maat en een soort, zoals
`((8, 8), "appel")`. Print bij elk voorbeeld de soort en de afstand tot
`nieuw`.

In de editor staan `afstand`, zes voorbeelden en `nieuw`.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print elk voorbeeld als een tuple.
2. Pak elk voorbeeld uit met `for maten, soort in voorbeelden`, en print `soort` en `maten`.
3. Print in plaats van `maten` de afstand: `afstand(nieuw, maten)`.

Verwachte uitvoer:

```
appel 3
appel 2
appel 3
banaan 11
banaan 13
banaan 11
```

## Er gaat iets mis

{/* foutmelding-van: afstand = lambda a, b: abs(a[0] - b[0]) + abs(a[1] - b[1])\nafstand(10, (9, 8)) */}
```
TypeError: 'int' object is not subscriptable
```

**Oorzaak:** je gaf `afstand` een los getal in plaats van een tuple, zoals
`afstand(10, (9, 8))`. In de functie staat `a[0]`, maar van het getal 10 kun
je geen eerste element pakken.

**Oplossing:** geef beide maten mee als tuple, met haakjes eromheen.

{/* niet-draaien: fragment; afstand staat in de runner erboven */}
```python
# FOUT
afstand(10, (9, 8))

# GOED
afstand((10, 7), (9, 8))
```
