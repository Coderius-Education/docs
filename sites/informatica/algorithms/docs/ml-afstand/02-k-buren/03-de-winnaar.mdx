# De winnaar

De buren hebben gestemd, en de stemmen staan in een dictionary. Nu zoek je
de soort met de meeste stemmen: dat is de voorspelling. Daarna stop je alles
in één functie, `voorspel(nieuw, voorbeelden, k)`, die je in de volgende
projecten weer gebruikt.

## Voorspel

```python
stemmen = {"banaan": 1, "appel": 2}
winnaar = ""
meeste = 0
for soort in stemmen:
    if stemmen[soort] > meeste:
        meeste = stemmen[soort]
        winnaar = soort
print(winnaar)
```

## Zo werkt het

Een loop over een dictionary geeft je de sleutels: hier de soorten. Met
`stemmen[soort]` pak je het aantal stemmen. De loop onthoudt de soort met de
meeste stemmen tot nu toe, zoals je bij de dichtstbijzijnde buur de kleinste
afstand onthield.

## Onderzoek

1. Draai de code. Wie wint?
2. Maak er een gelijke stand van: `{"banaan": 1, "appel": 1}`. Wie wint er
   nu? Dit is de stand bij `k = 2`.
3. Draai de volgorde om: `{"appel": 1, "banaan": 1}`. Wie wint er nu?
4. Bij `k = 7` stemmen alle zeven voorbeelden mee: `{"banaan": 4, "appel": 3}`.
   Wie wint er, en wat betekent dat voor elk nieuw stuk fruit?

## Opdracht: voorspel met k

Maak van de code een functie `voorspel(nieuw, voorbeelden, k)` die de
winnaar teruggeeft.

In de editor staat `voorspel` met het eerste stuk: de buren zoeken. Onderaan
testen twee regels hem: met `k = 1` wint banaan, met `k = 3` appel.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: `voorspel` geeft de `k` buren terug, nog niet de winnaar.
2. Tel met een dictionary `stemmen` hoeveel buren elke soort heeft, en geef `stemmen` terug.
3. Loop over `stemmen`, onthoud met een `if` de soort met de meeste stemmen, en geef die terug.

```python
def afstand(a, b):
    return abs(a[0] - b[0]) + abs(a[1] - b[1])

def voorspel(nieuw, voorbeelden, k):
    paren = []
    for maten, soort in voorbeelden:
        paren.append((afstand(nieuw, maten), soort))
    buren = sorted(paren)[:k]
    stemmen = {}
    for d, soort in buren:
        if soort in stemmen:
            stemmen[soort] = stemmen[soort] + 1
        else:
            stemmen[soort] = 1
    winnaar = ""
    meeste = 0
    for soort in stemmen:
        if stemmen[soort] > meeste:
            meeste = stemmen[soort]
            winnaar = soort
    return winnaar

voorbeelden = [
    ((8, 8), "appel"), ((9, 8), "appel"), ((7, 7), "appel"),
    ((18, 4), "banaan"), ((20, 4), "banaan"), ((17, 3), "banaan"),
    ((10, 6), "banaan"),
]
print(voorspel((10, 7), voorbeelden, 1))   # banaan
print(voorspel((10, 7), voorbeelden, 3))   # appel
```

hij klaar in de verborgen code onder de editor.
