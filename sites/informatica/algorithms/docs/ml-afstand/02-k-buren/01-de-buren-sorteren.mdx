# De buren sorteren

Bij de dichtstbijzijnde buur bepaalde één verkeerd voorbeeld het hele
antwoord. Dat los je op door niet naar één buur te kijken, maar naar de `k`
dichtstbijzijnde, bijvoorbeeld de drie dichtstbijzijnde. Die buren stemmen,
en de soort met de meeste stemmen wint. Dat heet
**k-nearest neighbors**, of kortweg k-NN. In deze stap zoek je de `k`
dichtstbijzijnde buren: je sorteert op afstand en pakt de eerste `k`.

:::info
Je gebruikt hier je functie `afstand` uit
[welk fruit is dit?](site:algorithms/docs/ml-afstand/01-dichtstbijzijnde-buur/01-een-afstand),
`.append()` uit [Lijst-methoden](site:python/docs/data/10b-lijst-methoden),
tellen met een dictionary uit
[het spamfilter dat leert](site:algorithms/docs/ml-regels/03-spamfilter-leert/01-woorden-tellen),
en een loop over de sleutels van een dictionary uit
[Door een dictionary lopen](site:python/docs/data/11b-itereren-dictionaries).
:::

## Voorspel

```python
paren = [(3, "appel"), (1, "banaan"), (11, "banaan"), (2, "appel")]
paren = sorted(paren)
print(paren)
print(paren[:2])
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
[(1, 'banaan'), (2, 'appel'), (3, 'appel'), (11, 'banaan')]
[(1, 'banaan'), (2, 'appel')]
```

</details>

## Zo werkt het

Twee dingen zijn nieuw.

`sorted` geeft een gesorteerde kopie van een lijst terug. Een lijst tuples
sorteert hij op het eerste element van elk tuple: hier de afstand. Zijn twee
afstanden gelijk, dan kijkt hij naar het tweede element.

`paren[:2]` pakt de eerste twee elementen van de lijst. Dat heet
**slicing**: `paren[:k]` geeft je de eerste `k`. Na het sorteren zijn dat
precies de `k` dichtstbijzijnde buren.

## Onderzoek

In `paren` staan de afstanden van de voorbeelden tot `(10, 7)`, met de
vergissing uit het vorige project: de banaan op afstand 1 is in het echt een
appel.

1. Draai de code met `k = 3`. Welke drie buren krijg je?
2. Wat is het verschil tussen `sorted(paren)[:k]` en `paren[:k]`?
3. Zet `k` op 10. Er staan maar zeven paren in de lijst. Wat gebeurt er?
4. Zet `(3, "citroen")` in de lijst `paren`. Komt hij na het sorteren vóór of
   na de appels op afstand 3?

## Opdracht

Zoek de buren: maak een lijst `paren` met de afstand en de soort van elk
voorbeeld, en print de `k` dichtstbijzijnde. In de editor staan `afstand`, de
voorbeelden met de vergissing, en een loop die elke afstand uitrekent.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: hij print bij elk voorbeeld de afstand en de soort.
2. Zet in plaats van de print het tuple `(d, soort)` met `.append()` in `paren`, en print `paren` na de loop.
3. Sorteer `paren`, pak de eerste `k`, en print die buren.

Verwachte uitvoer:

```
buren: [(1, 'banaan'), (2, 'appel'), (3, 'appel')]
```

## Er gaat iets mis

{/* foutmelding-van: paren = []\nparen.append(3, "appel") */}
```
TypeError: list.append() takes exactly one argument (2 given)
```

**Oorzaak:** `append` zet één ding in een lijst. Met
`paren.append(3, "appel")` geef je er twee: een getal en een tekst.

**Oplossing:** maak er één tuple van, met een extra paar haakjes.

{/* niet-draaien: fragment; leunt op paren uit de runner */}
```python
# FOUT
paren.append(3, "appel")

# GOED
paren.append((3, "appel"))
```
