# Stemmen tellen

Je hebt de `k` dichtstbijzijnde buren gevonden. Nu stemt elke buur op zijn
eigen soort. Die stemmen tel je met een dictionary, zoals je in het
spamfilter woorden telde: de soort is de sleutel, het aantal stemmen de
waarde.

## Voorspel

```python
buren = [(1, "banaan"), (2, "appel"), (3, "appel")]
stemmen = {}
for d, soort in buren:
    if soort in stemmen:
        stemmen[soort] = stemmen[soort] + 1
    else:
        stemmen[soort] = 1
print(stemmen)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
{'banaan': 1, 'appel': 2}
```

</details>

## Zo werkt het

Elke buur is een tuple `(afstand, soort)`. Voor het tellen heb je alleen de
soort nodig; de afstand staat in `d` en doet verder niets.

Staat een soort nog niet in `stemmen`, dan krijgt hij zijn eerste stem: 1.
Staat hij er al, dan komt er 1 bij. De dictionary onthoudt de volgorde
waarin de soorten erin kwamen: hier eerst banaan, want de dichtstbijzijnde
buur is een banaan.

## Onderzoek

1. Draai de code. Hoeveel stemmen krijgt elke soort?
2. Zet `(4, "citroen")` onderaan in `buren`. Wat verandert er in `stemmen`?
3. Vervang de hele `if` en `else` door één regel:
   `stemmen[soort] = stemmen[soort] + 1`. Wat gebeurt er?

## Er gaat iets mis

{/* foutmelding-van: stemmen = {}\nstemmen["banaan"] = stemmen["banaan"] + 1 */}
```
KeyError: 'banaan'
```

**Oorzaak:** je telt 1 op bij een soort die nog niet in de dictionary staat.
`stemmen["banaan"]` bestaat pas als je hem een eerste waarde hebt gegeven.

**Oplossing:** kijk eerst met `in` of de soort er al in staat. Zo niet, zet
hem dan op 1.

{/* niet-draaien: fragment; leunt op stemmen en soort uit de runner */}
```python
# FOUT
stemmen[soort] = stemmen[soort] + 1

# GOED
if soort in stemmen:
    stemmen[soort] = stemmen[soort] + 1
else:
    stemmen[soort] = 1
```
