# Stemmen met fiches — PageRank

<Handout>

Hoe bepaalt een zoekmachine welke pagina belangrijk is? Door links als
stemmen te tellen. Jullie spelen een mini-web van vier pagina's na met
fiches, en zien op tafel welke pagina bovenaan komt.

## Wat je nodig hebt

- 48 fiches (of muntjes, blokjes, papiersnippers) per groepje van 2
  tot 4.
- Vier briefjes met de letters **A**, **B**, **C** en **D**, verspreid
  op tafel.
- Ongeveer 15 minuten.

## Het mini-web

Vier pagina's; een pijl betekent "linkt naar" (dezelfde vier als in de
les):

```
   A ──────▶ B
   ▲ ╲       │
   │   ╲     │
   │     ▼   ▼
   └────── C ◀────── D
```

- A linkt naar B en C
- B linkt naar C
- C linkt naar A
- D linkt naar C

## Zo werkt het

Elk fiche is een stukje "belang". Start: leg op elke pagina **12
fiches**.

Elke ronde, voor alle pagina's tegelijk:

1. Pak alle fiches van de pagina.
2. Verdeel ze **gelijk** over de pagina's waar hij naar linkt (A geeft
   de helft aan B en de helft aan C; de anderen geven alles aan hun ene
   link).
3. Pas als iedereen verdeeld heeft, tel je per pagina de nieuwe stapel.

Speel **vier rondes** en vul na elke ronde de stand in:

| | A | B | C | D |
|---|:---:|:---:|:---:|:---:|
| start | 12 | 12 | 12 | 12 |
| ronde 1 |  |  |  |  |
| ronde 2 |  |  |  |  |
| ronde 3 |  |  |  |  |
| ronde 4 |  |  |  |  |

## Bespreek na

- Welke pagina's staan bovenaan, en welke is helemaal leeggebloed?
  Waarom krijgt D nooit meer een fiche terug?
- D heeft evenveel uitgaande links als B. Waarom eindigt B toch hoger?
- De aantallen van A en C wiebelen per ronde. Blijft dat zo als je
  doorspeelt?
- Het echte PageRank geeft elke pagina elke ronde ook een klein vast
  basisbedrag (damping). Wat verandert daardoor voor D?

## Antwoorden

Deze pagina print als losse laatste pagina. Houd hem achter de hand, of
knip hem eraf.

| | A | B | C | D |
|---|:---:|:---:|:---:|:---:|
| start | 12 | 12 | 12 | 12 |
| ronde 1 | 12 | 6 | 30 | 0 |
| ronde 2 | 30 | 6 | 12 | 0 |
| ronde 3 | 12 | 15 | 21 | 0 |
| ronde 4 | 21 | 6 | 21 | 0 |

- A en C delen de top. Iedereen stemt direct of via een omweg op C, en C
  geeft alles weer door aan A.
- Naar D linkt niemand, dus D ontvangt niets: na één ronde is D voorgoed
  leeg. Belang moet je *krijgen*, uitdelen alleen is niet genoeg.
- B ontvangt de helft van A's fiches, en D ontvangt niets. Je uitgaande
  links zeggen niets over je eigen belang; je inkomende links alles.
- Het wiebelen dooft uit als je doorspeelt, al moet je dan fiches gaan
  halveren: A en C naderen allebei 19,2 fiches en B 9,6.
- Met damping krijgt óók D elke ronde een klein basisbedrag, dus D komt
  nooit meer op nul. Het wiebelen dooft dan ook sneller uit. Dat is
  precies de berekening die je in de les in Python bouwt.
