## De functie

Alles wat je hebt opgebouwd bij elkaar: zeven regels die elke toren
verplaatsen.

<CodeUitleg>

```python showLineNumbers
def hanoi(n, bron, doel, hulp):
    if n == 0:
        return []
    zetten = []
    zetten += hanoi(n - 1, bron, hulp, doel)
    zetten.append((bron, doel))
    zetten += hanoi(n - 1, hulp, doel, bron)
    return zetten
```

<Regel n={2} tot={3}>
Het basisgeval: nul schijven verplaatsen kost nul zetten. Zonder deze afslag blijft de recursie eeuwig doorgaan.
</Regel>

<Regel n={5}>
Stap 1 verplaatst `n - 1` schijven van bron naar de hulppaal. Let op de rolwisseling: `doel` is in deze deelstap even de parkeerplek.
</Regel>

<Regel n={6}>
Stap 2 is de grootste schijf, één losse zet als tuple `(bron, doel)`.
</Regel>

<Regel n={7}>
Stap 3 verplaatst dezelfde `n - 1` schijven van de hulppaal naar het doel; nu is `bron` de parkeerplek.
</Regel>

</CodeUitleg>

## Maak het af

Deze `hanoi` staat er op één bouwsteen na. De toren van drie schijven moet
van rechts naar links. Het basisgeval en de lijst `zetten` staan er, maar
er komt nog een lege lijst terug.
Eén stap is nog open: bouwsteen 3, de recursie. Doe die zelf.

Verwachte uitvoer:

```
van rechts naar links
van rechts naar midden
van links naar midden
van rechts naar links
van midden naar rechts
van midden naar links
van rechts naar links
7 zetten
```

```python
def hanoi(n, bron, doel, hulp):
    if n == 0:
        return []
    zetten = []
    zetten += hanoi(n - 1, bron, hulp, doel)
    zetten.append((bron, doel))
    zetten += hanoi(n - 1, hulp, doel, bron)
    return zetten


zetten = hanoi(3, "rechts", "links", "midden")
for bron, doel in zetten:
    print(f"van {bron} naar {doel}")
print(f"{len(zetten)} zetten")
```
