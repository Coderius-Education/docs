# Bouw zelf — het bereik van een lijst

**Leerdoel:** je gebruikt `max_en_min` om een **nieuwe waarde** af te
leiden: het *bereik* (`groot − klein`). Dit is een veelgebruikte
statistische maat.

## Opdracht

### De opdracht

Schrijf `bereik(lijst)` die het verschil tussen het grootste en kleinste
element returnt.

- `bereik([5, 2, 8, 1, 7, 4])` → `7` (want 8 − 1)
- `bereik([-3, -1, -7])` → `6` (want -1 − (-7))
- `bereik([42])` → `0`

### Aan de slag

De startcode roept je functie aan op vijf lijsten en print het bereik.

Verwachte uitvoer:

```
7
6
0
0
999
```

<summary>Tip</summary>

`max_en_min(lijst)` geeft een tuple terug. Hoe haal je daar `klein` en

</details>

<details>
<summary>Antwoord</summary>

```python
def bereik(lijst):
    klein, groot = max_en_min(lijst)
    return groot - klein
```

Of zonder uitpakken:

```python
def bereik(lijst):
    return max_en_min(lijst)[1] - max_en_min(lijst)[0]
```

Die laatste is slechter: hij roept `max_en_min` twee keer aan en doet dus
dubbel werk. Uitpakken is netter.

</details>

## Onderzoek

**Vraag:** wat gebeurt er als je `bereik([])` aanroept, op een lege lijst?
Zet `print(bereik([]))` onder de tests van je eigen code om het te zien.

<details>
<summary>Antwoord</summary>

{/* foutmelding-van: [][0] */}

Je krijgt een `IndexError: list index out of range` op de regel
`klein = groot = lijst[0]` binnen `max_en_min`. De functie gaat er
namelijk vanuit dat er een eerste element bestaat om mee te starten.

Dat is een afspraak over de invoer en geen bug: `max_en_min` werkt alleen
op lijsten met minstens één element. Wil je een lege lijst wél aankunnen,
dan checkt `bereik` of `max_en_min` daar eerst op, bijvoorbeeld met
`if len(lijst) == 0: return 0`.

</details>

## Uitdaging (optioneel)

### De opdracht

Schrijf `genormaliseerd(lijst)` die elk element omrekent naar een waarde
tussen 0 en 1, op basis van het bereik:

```
genormaliseerd(x) = (x - klein) / (groot - klein)
```

Voor `[1, 5, 9]` → `[0.0, 0.5, 1.0]`. Denk ook na over een lijst waarin
alle waardes gelijk zijn, zoals `[4, 4, 4]`: wat staat er dan onder de
deelstreep?

### Aan de slag

Verwachte uitvoer:

```
[0.0, 0.5, 1.0]
[0.0, 0.0, 0.0]
```

<details>
<summary>Tip</summary>

Hoeveel keer hoef je `klein` en `groot` te berekenen: één keer, of voor
elk element opnieuw? En wat geef je terug als je niet kunt delen?

</details>

<details>
<summary>Antwoord</summary>

```python
def max_en_min(lijst):
    klein = groot = lijst[0]
    for waarde in lijst:
        if waarde < klein:
            klein = waarde
        elif waarde > groot:
            groot = waarde
    return klein, groot

def genormaliseerd(lijst):
    klein, groot = max_en_min(lijst)
    bereik = groot - klein
    resultaat = []
    for x in lijst:
        if bereik == 0:
            resultaat.append(0.0)
        else:
            resultaat.append((x - klein) / bereik)
    return resultaat

print(genormaliseerd([1, 5, 9]))   # [0.0, 0.5, 1.0]
print(genormaliseerd([4, 4, 4]))   # [0.0, 0.0, 0.0]
```

{/* foutmelding-van: (4 - 4) / (4 - 4) */}

Zonder de check op `bereik == 0` crasht `[4, 4, 4]` met een
`ZeroDivisionError`.

</details>
