# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent valkuilen bij het werken met twee accumulators
tegelijk.

## Twee keer door de lijst

### Wat er misgaat: twee lussen

Geen foutmelding, maar wel het hele punt van dit algoritme gemist: elk
element wordt twee keer gelezen.

**Oorzaak:** je doet twee passes over de lijst, één voor het maximum en
één voor het minimum, in plaats van één pass met twee accumulators.

**Oplossing:** één for-lus met twee accumulators, en per element hoogstens
twee vergelijkingen.

### Eén lus in plaats van twee

Eerst de twee lussen, dan de ene lus die beide accumulators bijwerkt:

{/* niet-draaien: fragment; lijst, klein en groot komen uit de functie */}
```python
# FOUT
for waarde in lijst:
    if waarde > groot:
        groot = waarde
for waarde in lijst:
    if waarde < klein:
        klein = waarde

# GOED
for waarde in lijst:
    if waarde < klein:
        klein = waarde
    elif waarde > groot:
        groot = waarde
```

## Een start die niet in de lijst staat: `klein = 0` en `groot = 0`

Geen foutmelding, maar een fout antwoord: voor `[-3, -1, -7]` geeft de
functie `(-7, 0)`, en voor `[3, 5, 7]` geeft hij `(0, 7)`.

**Oorzaak:** zijn alle waardes negatief, dan is er geen groter dan `0`, en
blijft `groot` op `0` staan, terwijl 0 niet in de lijst staat. Bij alleen
positieve waardes gebeurt hetzelfde met `klein`.

**Oplossing:** start beide op `lijst[0]`. Dat is gegarandeerd een echte
waarde uit de lijst.

{/* niet-draaien: fragment; lijst komt uit de functie */}
```python
# FOUT
klein = 0
groot = 0

# GOED
klein = groot = lijst[0]
```

Meer uitleg: [Bouwsteen 1 — twee variabelen](site:algorithms/docs/max-en-min/bouwen/04-twee-variabelen).

## Een vergelijking te veel: `if … if …` in plaats van `if … elif …`

Geen foutmelding, wel één extra vergelijking per element. Geen ramp, maar
verspilling.

**Oorzaak:** twee aparte `if`'s checken **altijd** allebei hun conditie,
ook als de eerste al een update deed.

**Oplossing:** gebruik `elif`. Een waarde kan niet tegelijk kleiner dan
`klein` én groter dan `groot` zijn, want `klein` is nooit groter dan
`groot`.

{/* niet-compileren: fragment; het lijf van de laatste tak is weggelaten */}
```python
# FOUT
if waarde < klein:
    klein = waarde
if waarde > groot:

# GOED
if waarde < klein:
    klein = waarde
elif waarde > groot:
```
