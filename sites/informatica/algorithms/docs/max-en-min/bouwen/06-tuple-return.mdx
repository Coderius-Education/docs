**Leerdoel:** je leert hoe je **twee** waardes uit een functie returnt
met een tuple, en hoe je ze aan de andere kant weer uitpakt.

## Twee waardes returnen

Je wilt een functie die `(klein, groot)` teruggeeft, zodat de code die hem
aanroept met allebei verder kan. In Python:

```python
return klein, groot          # zonder haakjes
return (klein, groot)        # met haakjes — betekent hetzelfde
```

Beide regels geven een **tuple** met twee elementen terug.

## Voorspel

Wat denk je dat dit print?

```python
def max_en_min(lijst):
    klein = groot = lijst[0]
    for waarde in lijst:
        if waarde < klein:
            klein = waarde
        elif waarde > groot:
            groot = waarde
    return klein, groot

resultaat = max_en_min([5, 2, 8, 1, 7, 4])
print(resultaat)
print(type(resultaat))
```

<details>
<summary>Antwoord</summary>

```
(1, 8)
<class 'tuple'>
```

De functie geeft een tuple terug — Python zet de twee waardes automatisch
in een tuple, ook al schreef je `return klein, groot` zonder haakjes.

</details>

## Tuple uitpakken

{/* foutmelding-van: a, b = (1, 2, 3) */}

Met `k, g = max_en_min(…)` pak je de tuple uit: `k` krijgt het eerste
element, `g` het tweede. Links staan net zoveel namen als er elementen in
de tuple zitten; anders krijg je een `ValueError`.

<PyRunner initialCode={`def max_en_min(lijst):
    klein = groot = lijst[0]
    for waarde in lijst:
        if waarde < klein:
            klein = waarde
        elif waarde > groot:
            groot = waarde
    return klein, groot

k, g = max_en_min([5, 2, 8, 1, 7, 4])
print(f"kleinste: {k}")
print(f"grootste: {g}")
print(f"bereik:   {g - k}")

r = max_en_min([5, 2, 8])
print(r[0], r[1])`} />

Pak je de tuple niet uit, dan haal je de elementen eruit met een index:
`r[0]` is `klein`, `r[1]` is `groot`. Uitpakken is duidelijker: de namen
zeggen wat je hebt.
