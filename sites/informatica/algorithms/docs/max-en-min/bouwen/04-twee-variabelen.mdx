**Leerdoel:** je kunt twee accumulators in één keer initialiseren, beide
op `lijst[0]`.

## Voorspel

Je wilt twee variabelen, `klein` en `groot`, die allebei starten op een
veilige waarde: een waarde die zeker in de lijst staat. Wat denk je dat dit
print?

```python
lijst = [5, 2, 8, 1, 7, 4]
klein = lijst[0]
groot = lijst[0]
print(klein, groot)
```

<details>
<summary>Antwoord</summary>

```
5 5
```

Beide variabelen krijgen dezelfde waarde — het eerste element van de
lijst. Dat is op dit moment nog niet *het echte* min en max — we hebben
namelijk de rest van de lijst nog niet bekeken. Het is een veilige
beginschatting, want die waarde staat zeker in de lijst.

</details>

## Korter opschrijven

Python laat je op één regel meerdere namen dezelfde waarde geven:

```python
klein = groot = lijst[0]
```

Beide variabelen krijgen dezelfde waarde. Korter — maar betekent precies
hetzelfde.

<PyRunner initialCode={`lijst = [5, 2, 8, 1, 7, 4]
klein = groot = lijst[0]
print(klein, groot)`} />

## Waarom niet 999?

Soms zie je code als:

```python
klein = 999     # hoog beginnen — wordt vanzelf vervangen door kleinere
groot = -999    # laag beginnen — wordt vanzelf vervangen door grotere
```

Dat werkt alleen als je weet dat alle waardes tussen `-999` en `999`
liggen. Bij `[1000, 2000, 3000]` krijg je dan `groot = -999` als
antwoord — fout.

`lijst[0]` is dus veiliger.

## Experimenteer

De code zet `klein` en `groot` op `lijst[0]` voor vier lijsten. Voorspel
eerst de startwaardes, en zet er daarna een eigen lijst bij.

<PyRunner initialCode={`lijsten = [
    [5, 2, 8, 1, 7, 4],
    [-3, -1, -7],
    [42],
    [100, 100, 100],
]
for lijst in lijsten:
    klein = groot = lijst[0]
    print(f"lijst={lijst} → start: klein={klein}, groot={groot}")`} />

Je hebt nu startwaardes, maar de variabelen veranderen nog niet: de rest
van de lijst doet nog niet mee. In de volgende stap voeg je de
**updates** toe.
