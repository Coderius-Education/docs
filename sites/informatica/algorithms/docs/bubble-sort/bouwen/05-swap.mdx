# Bouwsteen 2 — twee buren ruilen

<Voorkennis

/>

**Leerdoel:** je kunt twee opeenvolgende elementen ruilen wanneer ze fout
staan.

## Ruilen in één regel

Staat een paar fout (`lijst[i] > lijst[i+1]`), dan wissel je de twee
elementen om. Net als bij [selection sort](site:algorithms/docs/selection-sort/bouwen/05-swap) gebruiken
we de Pythonische *tuple-swap*:

```python
lijst[i], lijst[i + 1] = lijst[i + 1], lijst[i]
```

Python evalueert eerst de rechterkant tot een tuple
`(lijst[i+1], lijst[i])` en kent die dan toe aan de linkerkant. Geen
informatieverlies.

## Voorspel

Wat denk je dat dit print?

```python
lijst = [3, 1, 4, 1, 5]
i = 0

if lijst[i] > lijst[i + 1]:
    lijst[i], lijst[i + 1] = lijst[i + 1], lijst[i]

print(lijst)
```

<details>
<summary>Antwoord</summary>

```
[1, 3, 4, 1, 5]
```

De 3 en de 1 op posities 0 en 1 zijn geruild.

</details>

## Experimenteer

De code ruilt voor elke `i` van 0 tot en met 3, net als in bouwsteen 1.
Verander daarna de lijst in `[5, 4, 3, 2, 1]`: waar staat de 5 na afloop?

<PyRunner initialCode={`lijst = [3, 1, 4, 1, 5]
print("start:", lijst)

for i in [0, 1, 2, 3]:
    if lijst[i] > lijst[i + 1]:
        lijst[i], lijst[i + 1] = lijst[i + 1], lijst[i]
        print(f"i={i}: swap → {lijst}")
    else:
        print(f"i={i}: laat → {lijst}")

print("eind:", lijst)`} />

<details>
<summary>Wat zie je?</summary>

```
start: [3, 1, 4, 1, 5]
i=0: swap → [1, 3, 4, 1, 5]
i=1: laat → [1, 3, 4, 1, 5]
i=2: swap → [1, 3, 1, 4, 5]
i=3: laat → [1, 3, 1, 4, 5]
eind: [1, 3, 1, 4, 5]
```

Dit is precies één pass van bubble sort over de lijst. De 5 zit nu
achteraan op zijn juiste plek. Bij `[5, 4, 3, 2, 1]` schuift de 5 in vier
swaps helemaal naar achteren: `[4, 3, 2, 1, 5]`.

</details>

De lijst is na één pass nog niet gesorteerd: er moeten meer passes komen.
En `[0, 1, 2, 3]` uitschrijven werkt alleen voor een lijst van vijf. In de
volgende stap wordt dat een `range` die voor elke lengte klopt.
