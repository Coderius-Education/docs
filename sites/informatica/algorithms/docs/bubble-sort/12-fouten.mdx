# Er gaat iets mis — vier fouten

**Leerdoel:** je herkent de klassieke valkuilen van bubble sort.

## Voorbij het eind: `range(len(lijst))` zonder `- 1`

{/* foutmelding-van: lijst = [3, 2, 1]\nfor i in range(len(lijst)):\n    if lijst[i] > lijst[i + 1]:\n        pass */}
```
IndexError: list index out of range
```

{/* foutmelding-van: [3, 2, 1][3] */}

**Oorzaak:** bij de laatste ronde is `i = n - 1`, dus `lijst[i + 1]` is
`lijst[n]`, en die bestaat niet. Vandaar de `IndexError`.

**Oplossing:** gebruik `range(n - 1)`. Vergelijk je `lijst[i]` met
`lijst[i + 1]`, dan is `n - 2` de laatste geldige `i`, en daar stopt
`range(n - 1)` precies.

{/* niet-compileren: fragment; het lijf van de if is weggelaten */}
```python
# FOUT
for i in range(n):
    if lijst[i] > lijst[i + 1]:

# GOED
for i in range(n - 1):
    if lijst[i] > lijst[i + 1]:
```

## Toekennen in een if: `=` in plaats van `==`

{/* foutmelding-van: if lijst[0] = lijst[1]:\n    pass */}
```
SyntaxError: cannot assign to subscript here. Maybe you meant '==' instead of '='?
```

**Oorzaak:** `=` is **toekennen**, niet vergelijken. In een `if` heb je een
vergelijking nodig: `==`, `<`, `>`. Python ziet dat je aan `lijst[i]`
probeert toe te kennen en stelt de oplossing zelf al voor.

**Oplossing:** gebruik een vergelijking. Bij bubble sort is dat niet `==`
maar `>`, want je wilt weten of het paar fout staat.

{/* niet-compileren: toont bewust de = in plaats van == */}
```python
# FOUT
if lijst[i] = lijst[i + 1]:

# GOED
if lijst[i] > lijst[i + 1]:
```

Meer uitleg: [Bouwsteen 1 — vergelijk twee buren](site:algorithms/docs/bubble-sort/bouwen/04-vergelijk-buren).

## Een waarde kwijt bij het ruilen

Geen foutmelding, maar na het ruilen staat hetzelfde getal twee keer in de
lijst: van `[3, 1]` maakt de code `[1, 1]`. De 3 is weg.

**Oorzaak:** je ruilt in twee regels. Na de eerste regel staat in
`lijst[i]` al de waarde van `lijst[i + 1]`, en de oude waarde is
overschreven. De tweede regel kopieert die nieuwe waarde gewoon terug.

**Oplossing:** ruil in één regel, met de tuple-swap. Python rekent dan
eerst de hele rechterkant uit, voordat er iets wordt overschreven.

{/* niet-draaien: fragment; lijst en i komen uit de lus */}
```python
# FOUT
lijst[i] = lijst[i + 1]
lijst[i + 1] = lijst[i]

# GOED
lijst[i], lijst[i + 1] = lijst[i + 1], lijst[i]
```

Meer uitleg: [Bouwsteen 2 — twee buren ruilen](site:algorithms/docs/bubble-sort/bouwen/05-swap).

## Een vlag die blijft staan: `geswapt` vóór de lus

Geen foutmelding, maar de vroege uitstap doet niets meer: ook op een
lijst die al na twee rondes klaar is, doet bubble sort alle rondes.

**Oorzaak:** `geswapt` krijgt **één keer** de waarde `False`, vóór de
buitenste lus. Na de eerste swap blijft hij `True` voor alle rondes erna,
dus `if not geswapt` is nooit meer waar.

**Oplossing:** zet `geswapt = False` **binnen** de buitenste lus, aan het
begin van elke pass. Dan kijkt elke pass opnieuw of er iets wisselt.

{/* niet-compileren: fragment; de binnenste lus is weggelaten */}
```python
# FOUT
geswapt = False
for ronde in range(n - 1):
    for i in range(n - 1 - ronde):

# GOED
for ronde in range(n - 1):
    geswapt = False
    for i in range(n - 1 - ronde):
```
