# Nim die van zichzelf leert

In het vorige project kreeg `slim` de truc van Nim mee, als functie. Nu
krijgt de computer geen truc. Hij speelt tweeduizend keer tegen
zichzelf, en onthoudt na elk spel welke zetten de winnaar deed en welke de
verliezer. Zetten van de winnaar krijgen een punt erbij, zetten van de
verliezer een punt eraf. Zo leert hij, zonder dat iemand het hem vertelt,
welke zet bij elke stapel de beste is. Dit heet **reinforcement learning**:
leren van beloning en straf.

:::info
Je gebruikt hier het spel en de while-loop uit
[Nim met een vaste strategie](site:algorithms/docs/ml-spellen/01-nim-strategie),
tuples uit [Tuples](site:python/docs/data/tuples), en tellen met een dictionary
uit [een spamfilter dat leert](site:algorithms/docs/ml-regels/03-spamfilter-leert).
:::

## Voorspel

```python
score = {(10, 1): 4, (10, 2): -1, (10, 3): -3}

print(score[(10, 2)])

beste = 1
for pak in [1, 2, 3]:
    if score[(10, pak)] > score[(10, beste)]:
        beste = pak
print(beste)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

```
-1
1
```

`score[(10, 2)]` is de score van de zet "pak 2 als er 10 liggen". De loop
zoekt de zet met de hoogste score, en dat is pak 1, met 4.

</details>

## Zo werkt het

Nieuw is dat de sleutel van een dictionary een tuple is. Bij het spamfilter
was de sleutel één woord; hier is hij `(stapel, pak)`: hoeveel er liggen, en
hoeveel de speler pakt. `score[(10, 1)]` is dus de score van de zet "pak 1 als
er 10 liggen". De waarde zegt hoe goed die zet tot nu toe uitpakte.

Een lijst kan geen sleutel zijn. Een lijst kun je later nog veranderen, en dan
zou de dictionary zijn sleutel niet meer terugvinden. Een tuple kan niet meer
veranderen, en mag dus wel.

Het spelen staat al klaar, in de verborgen code onder de editor:

- `speel_tegen_jezelf(score, ontdekken)` speelt één spel, met twee spelers
  `"a"` en `"b"` die allebei dezelfde `score` gebruiken. Hij geeft de zetten
  van elke speler terug, en wie er verloor.
- Bij elke beurt kiest `kies` meestal de zet met de hoogste score. Maar bij
  kans `ontdekken` kiest hij een willekeurige zet, om ook iets nieuws te
  proberen.
- `beste_zet(score, stapel)` geeft de zet met de hoogste score.

Het leren zie je in de editor. Na elk spel krijgt elke zet van de winnaar een
punt erbij, en elke zet van de verliezer een punt eraf. Een zet die de
computer nog nooit deed, zet hij eerst op 0.

## Opdracht: speel tegen de geleerde strategie

Laat de geleerde strategie 100 keer spelen tegen `willekeurig` uit het vorige

In de editor staan het leren uit het onderzoek en `willekeurig`.

```python
def speel(stapel):
    beurt = "geleerd"
    while stapel > 0:
        if beurt == "geleerd":
            stapel = stapel - beste_zet(score, stapel)

```

Hij wint ze alle 100, net als `slim`. Bij 10 lucifers pakt hij 1, en daarna
laat hij steeds een viervoud plus 1 over.

## Bouw zelf: hoeveel spellen heeft hij nodig?

Tweeduizend spellen is veel. Zoek uit hoeveel spellen de computer nodig heeft
om alles goed te leren. Probeer 1, 2, 5, 10, 20 en 50 spellen, en tel bij elk
aantal bij hoeveel stapels hij iets anders kiest dan `slim`. Kijk alleen naar
de stapels waar je kunt winnen: 2, 3, 4, 6, 7, 8 en 10. Gebruik bij elk aantal
opnieuw `random.seed(1)` en een lege `score`.

In de editor staat `slim`, met één spel tegen zichzelf om mee te beginnen.

<PyRunner verborgen="nim-leren" initialCode={`import random

def slim(stapel):
    pak = (stapel - 1) % 4
    if pak == 0:
        pak = 1
    return pak

random.seed(1)
score = {}
zetten, verliezer = speel_tegen_jezelf(score, 0.2)
print(zetten, verliezer)`} />

<details>
<summary>Tip</summary>

Maak van het leren uit de opdracht een functie `leer(spellen)` die een nieuwe
`score` teruggeeft. Dan kun je hem in een loop aanroepen met elk aantal
spellen.

</details>

<details>
<summary>Antwoord</summary>

{/* draaien-met: blok-erboven */}
```python
import random

def leer(spellen):
    random.seed(1)
    score = {}
    for spel in range(spellen):
        zetten, verliezer = speel_tegen_jezelf(score, 0.2)
        for speler in zetten:
            for zet in zetten[speler]:
                if zet not in score:
                    score[zet] = 0
                if speler == verliezer:
                    score[zet] = score[zet] - 1
                else:
                    score[zet] = score[zet] + 1
    return score

def slim(stapel):
    pak = (stapel - 1) % 4
    if pak == 0:
        pak = 1
    return pak

for spellen in [1, 2, 5, 10, 20, 50]:
    score = leer(spellen)
    fout = 0
    for stapel in [2, 3, 4, 6, 7, 8, 10]:
        if beste_zet(score, stapel) != slim(stapel):
            fout = fout + 1
    print(spellen, "spellen:", fout, "fout")
```

```
1 spellen: 2 fout
2 spellen: 2 fout
5 spellen: 1 fout
10 spellen: 0 fout
20 spellen: 0 fout
50 spellen: 0 fout
```

Met deze seed heeft hij er na 1 en 2 spellen nog twee fout, na 5 nog één, en
vanaf 10 spellen geen enkele meer. Dat gaat zo snel omdat Nim met 10
lucifers een klein spel is: er zijn maar 27 zetten om te onthouden. Bij
schaken zijn er meer standen dan er zandkorrels op aarde zijn, en past zo'n
tabel nergens.

</details>

## Aan de slag met Nim

Nu ben je klaar voor [Nim](https://cs50.harvard.edu/ai/projects/4/nim/) van
CS50 AI. Het idee is wat je hier deed: een tabel met een waarde voor elke
stand en elke zet, meestal de beste zet spelen en soms een willekeurige, en
na elk spel de waarden bijwerken. Vier dingen zijn anders:

- Er zijn vier stapels in plaats van één, en je mag van één stapel zoveel
  pakken als je wilt. Een zet is dus welke stapel en hoeveel.
- Een stand is een lijst van vier getallen. Als sleutel moet het een tuple
  zijn: met `tuple(stand)` maak je er een van. Vergeet je dat, dan krijg je
  de fout hieronder.
- Een waarde gaat niet met hele punten omhoog of omlaag. Hij schuift telkens
  een stukje op, met een formule uit het college, die ook kijkt naar de
  beste zet daarna.
- Het spel en het spelen staan al klaar. Jij schrijft de functies die de
  tabel lezen, bijwerken en een zet kiezen.

Lees de opdracht helemaal door voordat je begint, en kijk in de code die je
krijgt hoe een stand en een zet eruitzien.

Een computer kan een spel ook zonder te leren goed spelen: door alle zetten
vooruit door te rekenen. Dat doet minimax, en daarmee win je bij
Tic-Tac-Toe van CS50.

## Er gaat iets mis

{/* foutmelding-van: fout-helft */}
```
TypeError: unhashable type: 'list'
```

**Oorzaak:** je gebruikt een lijst als sleutel van de dictionary. Een sleutel
mag niet kunnen veranderen, en een lijst kan dat wel.

**Oplossing:** gebruik een tuple, met ronde haakjes.

```python
# FOUT
score = {}
score[[10, 1]] = 0

# GOED
score = {}
score[(10, 1)] = 0
```
