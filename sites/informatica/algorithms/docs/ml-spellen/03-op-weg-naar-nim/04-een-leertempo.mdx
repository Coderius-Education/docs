# Een leertempo

Een blinde muis vindt de kaas in de helft van de wandelingen. Nu gaat hij
onthouden wat elke stap opleverde. Bij Nim kreeg een zet een hele punt erbij
of eraf, en liep de score op tot 971: een getal dat vooral zegt hoe vaak een
zet gespeeld is. Nieuw is een **leertempo**: de waarde van een stap schuift
telkens een stukje op naar de beloning, en blijft zo tussen -1 en 1.

## Voorspel

```python
tempo = 0.5
schatting = 0
for keer in range(3):
    schatting = schatting + tempo * (1 - schatting)
    print(schatting)
```

Wat print dit programma? Komt `schatting` ooit boven 1?

<details>
<summary>Antwoord</summary>

```
0.5
0.75
0.875
```

Nee. Elke keer gaat de helft van wat er tot 1 over is erbij. Hij komt steeds
dichter bij 1, maar er nooit boven.

</details>

## Zo werkt het

De regel is:

```
nieuwe waarde = oude waarde + tempo * (beloning - oude waarde)
```

`beloning - oude waarde` is hoever de schatting ernaast zat. Het tempo zegt
welk deel daarvan de muis in één keer bijstelt. Bij 0.5 is dat de helft. Bij
CS50 heet het tempo `alpha`.

## Onderzoek

1. Draai de code. Wat doet de schatting na de beloning -1?
2. Zet `tempo` op 0.25. Gaat de schatting nu sneller of langzamer naar 1?
3. Zet `tempo` op 1. Wat onthoudt de schatting dan nog van eerdere
   beloningen?

## Opdracht: de muis onthoudt

### De opdracht

Een muis die alleen de laatste beloning onthoudt, vergeet alles wat hij
eerder leerde. Je geeft de muis een methode `bijwerken(vakje, actie, beloning)`
die de waarde van een stap met het leertempo een stukje naar de beloning
schuift. Dan laat je hem leren van 1000 blinde wandelingen, en print je zijn
tabel.

### Aan de slag

In de editor staat een muis met een `bijwerken` die de beloning overschrijft.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: `bijwerken` zet nu de beloning van één wandeling in de tabel.
2. Laat `bijwerken` de oude waarde, `self.waarde(vakje, actie)`, met `self.tempo` naar de beloning schuiven, zoals `schatting + tempo * (1 - schatting)` naar 1 schoof.
3. Leer van 1000 wandelingen in plaats van één.
4. Print voor elk vakje van 1 tot en met 3 de waarde van links en van rechts.

Verwachte uitvoer:

```
1 -1.0 -0.25
2 -0.25 -0.25
3 -0.25 1.0
```

{/* draaien-met: blok-erboven */}
```python
import random

class Muis:
    def __init__(self):
        self.q = {}
        self.tempo = 0.5

    def waarde(self, vakje, actie):
        if (vakje, actie) in self.q:
            return self.q[(vakje, actie)]
        return 0

    def bijwerken(self, vakje, actie, beloning):
        oud = self.waarde(vakje, actie)
        self.q[(vakje, actie)] = oud + self.tempo * (beloning - oud)

random.seed(1)
piep = Muis()
for keer in range(1000):
    for vakje, actie, nieuw, beloning in willekeurige_wandeling():
        piep.bijwerken(vakje, actie, beloning)
for vakje in [1, 2, 3]:
    print(vakje, piep.waarde(vakje, "links"), piep.waarde(vakje, "rechts"))
```

```
1 -1.0 -0.25
2 -0.25 -0.25
3 -0.25 1.0
```

In vakje 1 weet de muis nu dat links de val is, en in vakje 3 dat rechts de
kaas is. Maar in vakje 2, waar hij begint, zijn links en rechts allebei
-0.25. Hij leert alleen wat één stap direct oplevert, en vanuit vakje 2 is
dat nooit de kaas.

</details>
