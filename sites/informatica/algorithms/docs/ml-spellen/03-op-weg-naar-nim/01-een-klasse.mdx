# Een klasse

De tabel en de functies van Nim die leert zitten bij CS50 AI samen in een
**klasse**. Die oefen je met een muis die de kaas zoekt.

:::info
Je gebruikt hier `class`, `__init__` en `self` uit
[Je eerste klasse](site:python/docs/klassen/15a-je-eerste-klasse), attributen
uit [Attributen veranderen](site:python/docs/klassen/15c-attributen-veranderen),
methoden uit [Je eerste methode](site:python/docs/klassen/15d-je-eerste-methode)
en [Methoden met return](site:python/docs/klassen/15f-methoden-met-return),
`random.random()` uit
[de surfer springt soms](site:algorithms/docs/ml-kans/02-surfer/04-de-surfer-springt-soms),
en een tuple als sleutel uit
[een score per zet](site:algorithms/docs/ml-spellen/02-nim-leert/01-een-score-per-zet).
:::

## Voorspel

```python
class Muis:
    def __init__(self, vakje):
        self.vakje = vakje

piep = Muis(2)
snuf = Muis(0)
piep.vakje = piep.vakje + 1
print(piep.vakje, snuf.vakje)
```

Wat print dit programma?

<details>
<summary>Antwoord</summary>

`3 0`. `piep` en `snuf` hebben elk een eigen `vakje`. Zet je `piep` een vakje
verder, dan blijft `snuf` staan.

</details>

## Zo werkt het

Klassen zijn nieuw in de route. De python-cursus legt ze uit in
[Je eerste klasse](site:python/docs/klassen/15a-je-eerste-klasse); dit zijn de
regels die je hier nodig hebt:

- `class Muis:` maakt een klasse. De naam begint met een hoofdletter.
- `__init__` zegt wat er gebeurt als je een nieuwe muis maakt, met
  `Muis(2)`. De twee lage streepjes voor en na `init` horen erbij.
- `self` is de muis die op dat moment gemaakt wordt. `self.vakje = vakje`
  bewaart het vakje in die muis.
- `piep` is een **object**: één muis, gemaakt volgens de klasse. Met
  `piep.vakje` lees je zijn vakje, en met `piep.vakje = 3` zet je het.

Een attribuut kan ook een dictionary zijn. Bij CS50 heeft de speler een tabel
`self.q`, met een waarde voor elke stand en elke zet, net als `score` bij Nim.
De muis krijgt er ook een. Elke muis heeft dan zijn eigen tabel.

2. Zet onderaan `snuf.vakje` op 3, en print beide muizen opnieuw. Verandert

3. Haal in `__init__` de `self.` weg vóór `q = {}`. Wat gebeurt er nu?

## Opdracht

### De opdracht

Elke muis die je met `Muis(…)` maakt, heeft zijn eigen attributen. Dat laat
je zien met twee muizen. Je geeft de muis een naam en een teller voor zijn
stappen, laat `piep` twee stappen naar rechts zetten, en maakt een tweede muis
`snuf` in vakje 1. Zijn teller blijft op 0 staan.

### Aan de slag

In de editor staat een klasse `Muis` met alleen een vakje.
Begin klein, en breid de code stap voor stap uit:

1. Draai de code: je ziet in welk vakje de muis `piep` zit.
2. Geef `__init__` een parameter `naam` en een attribuut `stappen` dat op 0 begint. Print ze allebei.
3. Zet `piep` twee keer een vakje naar rechts en tel de stappen. Maak dan `snuf` in vakje 1.

Verwachte uitvoer:

```
Piep zit in vakje 4 na 2 stappen
Snuf zit in vakje 1 na 0 stappen
```

<PyRunner initialCode={`class Muis:
    def __init__(self, vakje):
        self.vakje = vakje

piep = Muis(2)
print("piep zit in vakje", piep.vakje)`} />

<details>
<summary>Tip</summary>

De volgorde telt: `Muis("Piep", 2)` vult de parameters na `self` van links
naar rechts in. Staat in `__init__` eerst `naam` en dan `vakje`, dan wordt
`"Piep"` de naam.

</details>

<details>
<summary>Antwoord</summary>

```python
class Muis:
    def __init__(self, naam, vakje):
        self.naam = naam
        self.vakje = vakje
        self.stappen = 0

piep = Muis("Piep", 2)
piep.vakje = piep.vakje + 1
piep.stappen = piep.stappen + 1
piep.vakje = piep.vakje + 1
piep.stappen = piep.stappen + 1
snuf = Muis("Snuf", 1)
print(piep.naam, "zit in vakje", piep.vakje, "na", piep.stappen, "stappen")
print(snuf.naam, "zit in vakje", snuf.vakje, "na", snuf.stappen, "stappen")
```

```
Piep zit in vakje 4 na 2 stappen
Snuf zit in vakje 1 na 0 stappen
```

`stappen` is geen parameter: elke nieuwe muis begint op 0. Twee keer
dezelfde twee regels voor een stap is wel veel. In de volgende stap maak je
daar een methode van.

</details>

## Er gaat iets mis

{/* foutmelding-van: class Muis:\n    def __init__(self, vakje):\n        self.vakje = vakje\n        q = {}\npiep = Muis(2)\npiep.q[(2, "rechts")] = 0.5 */}
```
AttributeError: 'Muis' object has no attribute 'q'
```

**Oorzaak:** in `__init__` staat `q = {}` zonder `self.`. Dan is `q` een
variabele die alleen in `__init__` bestaat, en krijgt de muis zelf geen tabel.

**Oplossing:** zet `self.` voor elk attribuut dat de muis moet onthouden.

{/* niet-compileren: fragment; alleen de regels van __init__ die veranderen */}
```python
# FOUT
    def __init__(self, vakje):
        self.vakje = vakje
        q = {}

# GOED
    def __init__(self, vakje):
        self.vakje = vakje
        self.q = {}
```
