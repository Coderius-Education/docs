# De beste toekomst

In vakje 2 weet de muis nog niets: elke stap kost daar -0.25 en levert
direct niets op. Toch is rechts beter, want vanuit vakje 3 is de kaas één
stap. Nieuw is dat de waarde van een stap ook meeneemt wat de muis daarna nog
kan halen: de beste waarde van het vakje waar hij uitkomt.

## Voorspel

```python
q = {(3, "links"): -0.25, (3, "rechts"): 1.0}
beste = q[(3, "links")]
for actie in ["links", "rechts"]:
    if q[(3, actie)] > beste:
        beste = q[(3, actie)]
print(beste)
print(-0.25 + beste)
```

Rechts vanuit vakje 2 kost -0.25, en dan sta je in vakje 3. Wat print dit
programma?

<details>
<summary>Antwoord</summary>

```
1.0
0.75
```

De beste stap in vakje 3 levert 1.0 op. Rechts vanuit vakje 2 is dus -0.25
nu, plus 1.0 straks: 0.75.

</details>

## Zo werkt het

De regel krijgt er een stuk bij:

```
nieuwe waarde = oude waarde + tempo * (beloning + toekomst - oude waarde)
```

`toekomst` is de hoogste waarde in het nieuwe vakje: het beste wat de muis
daarna nog kan doen. Is de wandeling voorbij, bij de val of de kaas, dan staat
dat vakje niet in de tabel, en is de toekomst 0. Dit is de regel uit het
college van CS50. Hij heet *Q-learning*, en daarom heet de tabel `q`.

In de editor rekent `leer` de oude waarde en de toekomst uit, en geeft ze aan
`bijwerken`. Zo staat het ook bij CS50.

```python
import random

class Muis:
    def __init__(self):
        self.q = {}
        self.tempo = 0.5

    def waarde(self, vakje, actie):
        if (vakje, actie) in self.q:
            return self.q[(vakje, actie)]
        return 0

    def bijwerken(self, vakje, actie, oud, beloning, toekomst):
        self.q[(vakje, actie)] = oud + self.tempo * (beloning + toekomst - oud)

    def beste_toekomst(self, vakje):
        beste = self.waarde(vakje, acties[0])
        for actie in acties:
            if self.waarde(vakje, actie) > beste:
                beste = self.waarde(vakje, actie)
        return beste

    def leer(self, vakje, actie, nieuw, beloning):
        oud = self.waarde(vakje, actie)
        toekomst = self.beste_toekomst(nieuw)
        self.bijwerken(vakje, actie, oud, beloning, toekomst)

random.seed(1)
piep = Muis()
for keer in range(1000):
    for vakje, actie, nieuw, beloning in willekeurige_wandeling():
        piep.leer(vakje, actie, nieuw, beloning)
for vakje in [1, 2, 3]:
    print(vakje, piep.waarde(vakje, "links"), piep.waarde(vakje, "rechts"))
```

```
2 0.25 0.75
3 0.5 1.0
```

Nu weet de muis in elk vakje welke kant beter is: rechts, en hoe dichter bij
de kaas, hoe hoger de waarde. Ook links in vakje 2 is positief: vanuit
vakje 1 kan hij nog terug naar de kaas, al kost dat twee stappen extra.
