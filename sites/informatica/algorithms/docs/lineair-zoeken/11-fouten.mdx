# Er gaat iets mis — top-3 fouten

**Leerdoel:** je herkent veelvoorkomende foutmeldingen en begrijpt **waarom**
ze optreden. Een fout is geen tegenslag — het is informatie.

## Te vroeg klaar: `return -1` op de verkeerde inspringing

Geen foutmelding, maar wel een logische fout: de functie geeft `-1` terug
voor een doel dat wél in de lijst staat.

**Oorzaak:** `return -1` staat binnen de `for`-lus. Is het eerste element
niet het doel, dan voert Python al in de eerste ronde `return -1` uit, en
de rest van de lijst komt hij nooit tegen.

**Oplossing:** laat `return -1` even ver inspringen als `for`, niet als
`if`. In Python is inspringing geen versiering: ze bepaalt bij welk blok
een regel hoort.

{/* niet-compileren: fragment uit de functie, met zijn inspringing */}
```python
# FOUT
    for i, waarde in enumerate(lijst):
        ...
        return -1

# GOED
    for i, waarde in enumerate(lijst):
        ...
    return -1
```

## Toekennen in een if: `=` in plaats van `==`

{/* foutmelding-van: if waarde = doel:\n    pass */}
```
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

**Oorzaak:** `=` is **toekenning** (`x = 5` zet de waarde 5 in x);
`==` vergelijkt: `if x == 5` vraagt of x gelijk is aan 5. In een
`if` heb je een vergelijking nodig.

**Oplossing:** gebruik `==` in vergelijkingen. Eén `=` is toekennen, twee
`==` is vergelijken.

{/* niet-compileren: toont bewust de = in plaats van == */}
```python
# FOUT
if waarde = doel:

# GOED
if waarde == doel:
```

Meer uitleg: [Bouwsteen 2 — vergelijken met het doel](site:algorithms/docs/lineair-zoeken/bouwen/05-vergelijken).

## Het laatste element per ongeluk: `-1` als index

Geen foutmelding, maar wel een stille fout: je zoekt iets dat er niet is,
en het programma print toch een antwoord. Met `lijst = [10, 20, 30]` print
de FOUT-versie hieronder `gevonden: 30`.

**Oorzaak:** `zoek` geeft `-1` terug bij "niet gevonden", en `lijst[-1]`
is in Python gewoon geldig: het laatste element. Gebruik je het resultaat
meteen als index, dan krijg je een echte waarde voor iets dat niet in de
lijst staat.

**Oplossing:** controleer eerst op `-1` voordat je de index gebruikt.

{/* niet-draaien: fragment; zoek en lijst staan op de compleet-pagina */}
```python
# FOUT
print("gevonden:", lijst[zoek(lijst, 99)])

# GOED
index = zoek(lijst, 99)
if index == -1:
    print("niet gevonden")
else:
    print("gevonden:", lijst[index])
```
