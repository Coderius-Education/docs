# Het complete algoritme

**Leerdoel:** je maakt de functie af met een bouwsteen die je al kent,
ziet alle bouwstenen samen werken en onderzoekt het algoritme als geheel.

## Maak het af

Je hebt de vier bouwstenen los gebouwd. In deze `zoek` staan ze samen,
op één na: hij loopt door een lijst namen en geeft een index terug, maar
vergelijkt nog niet met het doel. Bij elke naam komt er nu `0` uit.
Eén stap is nog open: bouwsteen 2, vergelijken met het doel. Doe die zelf.

Verwachte uitvoer:

```
Yara: 2
Sam: 1
Lotte: -1
```

<PyRunner initialCode={`def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        # hier komt bouwsteen 2: vergelijken met het doel
        return i
    return -1

namen = ["Noor", "Sam", "Yara", "Daan", "Sam"]
print("Yara:", zoek(namen, "Yara"))
print("Sam:", zoek(namen, "Sam"))
print("Lotte:", zoek(namen, "Lotte"))`} />

<details>
<summary>Tip</summary>

Draai de code eerst. `return i` draait nu al in de eerste ronde, wat het
doel ook is. Wanneer mag hij pas draaien? Kijk bij bouwsteen 2,
vergelijken met het doel, en let daarna op de inspringing van `return i`.

</details>

<details>
<summary>Antwoord</summary>

```python
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1

namen = ["Noor", "Sam", "Yara", "Daan", "Sam"]
print("Yara:", zoek(namen, "Yara"))
print("Sam:", zoek(namen, "Sam"))
print("Lotte:", zoek(namen, "Lotte"))
```

`return i` staat nu in het `if`-blok: hij draait alleen bij een match.

</details>

## Alles samen

Zo ziet de hele functie eruit, met bij elke regel zijn bouwsteen:

<CodeUitleg>

```python showLineNumbers
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1
```

<Regel n={2}>
**Bouwsteen 1** — door de lijst lopen. `enumerate` geeft je elke ronde de index én de waarde tegelijk.
</Regel>

<Regel n={3}>
**Bouwsteen 2** — vergelijken met het doel.
</Regel>

<Regel n={4}>
**Bouwsteen 3** — de index teruggeven bij een match. `return` stopt meteen de functie én de lus: verder zoeken is niet meer nodig.
</Regel>

<Regel n={5}>
**Bouwsteen 4** — deze regel wordt alleen bereikt als de lus afloopt zonder match. Let op de inspringing: hij staat buiten de `for`, op functie-niveau.
</Regel>

</CodeUitleg>

## Onderzoek

De code zoekt drie keer. Voorspel eerst wat elke regel print, en druk dan
op Voer uit:

1. Een 7 in een lijst met vier zevens. Welke index krijg je?
2. Het woord `"peer"` in een lijst met woorden. Werkt dat?
3. `"Peer"`, met een hoofdletter, in dezelfde lijst. Wat krijg je nu?

<PyRunner initialCode={`def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1

print(zoek([7, 7, 7, 7], 7))
print(zoek(["appel", "peer", "kers"], "peer"))
print(zoek(["appel", "peer", "kers"], "Peer"))`} />

<details>
<summary>Wat zie je?</summary>

```
0
1
-1
```

- Staat een waarde meerdere keren in de lijst, dan krijg je de eerste.
- Strings werken precies hetzelfde: `==` vergelijkt ook strings.
- Maar `"Peer"` is niet gelijk aan `"peer"`: `==` let op hoofdletters,
  dus de functie geeft `-1`.

Lineair zoeken is *type-onafhankelijk*: het werkt op alles waar `==`
betekenis heeft.

</details>
