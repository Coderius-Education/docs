# Het complete algoritme

**Leerdoel:** je herkent alle bouwstenen die je hebt geleerd en ziet ze
samen werken. Daarna onderzoek je het algoritme als geheel.

## Alles samen

Hier is het hele algoritme, in 5 regels:

<CodeUitleg>

```python showLineNumbers
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1
```

<Regel n={2}>
**Bouwsteen 1** — door de lijst lopen. `enumerate` geeft je elke ronde de index én de waarde tegelijk.
</Regel>

<Regel n={3}>
**Bouwsteen 2** — vergelijken met het doel.
</Regel>

<Regel n={4}>
**Bouwsteen 3** — de index teruggeven bij een match. `return` stopt meteen de functie én de lus: verder zoeken is niet meer nodig.
</Regel>

<Regel n={5}>
**Bouwsteen 4** — deze regel wordt alleen bereikt als de lus afloopt zonder match. Let op de inspringing: hij staat buiten de `for`, op functie-niveau.
</Regel>

</CodeUitleg>

## Onderzoek

De code zoekt drie keer. Voorspel eerst wat elke regel print, en druk dan
op Voer uit:

1. Een 7 in een lijst met vier zevens. Welke index krijg je?
2. Het woord `"peer"` in een lijst met woorden. Werkt dat?
3. `"Peer"`, met een hoofdletter, in dezelfde lijst. Wat krijg je nu?

<PyRunner initialCode={`def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1

print(zoek([7, 7, 7, 7], 7))
print(zoek(["appel", "peer", "kers"], "peer"))
print(zoek(["appel", "peer", "kers"], "Peer"))`} />

<details>
<summary>Wat zie je?</summary>

```
0
1
-1
```

- Staat een waarde meerdere keren in de lijst, dan krijg je de eerste.
- Strings werken precies hetzelfde: `==` vergelijkt ook strings.
- Maar `"Peer"` is niet gelijk aan `"peer"`: `==` let op hoofdletters,
  dus de functie geeft `-1`.

Lineair zoeken is *type-onafhankelijk*: het werkt op alles waar `==`
betekenis heeft.

</details>
