# Bouwsteen 4 — het "niet gevonden"-geval

**Leerdoel:** je voegt het laatste stukje toe: `-1` teruggeven als het
doel niet in de lijst zit.

## Waar moet `return -1` staan?

Bij een doel dat niet bestaat, gaf `zoek` in de vorige stap `None` terug.
Liever `-1`: een duidelijk signaal voor "niet gevonden". Waar zet je die
`return -1`? Dit is een valstrik waar veel mensen intrappen. Hier staat hij op een
plek die er logisch uitziet. Wat denk je dat dit print?

```python
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
        return -1

print(zoek([3, 1, 4, 1, 5], 4))   # zou 2 moeten zijn
print(zoek([3, 1, 4, 1, 5], 9))   # zou -1 moeten zijn
```

<details>
<summary>Antwoord</summary>

```
-1
-1
```

Allebei `-1`, terwijl er bij doel 4 een `2` had moeten staan.

Dat komt doordat `return -1` binnen de `for`-lus staat. In de eerste ronde
is `3 == 4` niet waar, dus voert Python `return -1` uit en stopt de
functie na één ronde. De rest van de lijst komt hij nooit tegen.

</details>

<details>
<summary>Tip</summary>

In Python bepaalt de inspringing bij welk blok een regel hoort. Moet
`return -1` in elke ronde van de lus draaien, of pas als de lus klaar is?
Hoe ver moet hij dan inspringen?

</details>

<details>
<summary>Antwoord</summary>

```python
def zoek(lijst, doel):
    for i, waarde in enumerate(lijst):
        if waarde == doel:
            return i
    return -1   # buiten de for, dezelfde inspringing als 'for'

print(zoek([3, 1, 4, 1, 5], 4))   # 2
print(zoek([3, 1, 4, 1, 5], 9))   # -1
```

`return -1` staat nu buiten de `for`-lus, op functie-niveau. Python komt
er pas als de hele lus is afgelopen zonder match.

</details>
