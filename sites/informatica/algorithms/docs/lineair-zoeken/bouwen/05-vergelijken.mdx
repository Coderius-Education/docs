# Bouwsteen 2 — vergelijken met het doel

<Voorkennis
  items={[

/>

**Leerdoel:** je voegt een `if`-vergelijking toe binnen je lus, zodat je
*alleen iets doet* als het element gelijk is aan wat je zoekt.

## Voorspel

Tijdens het doorlopen wil je weten of het huidige element gelijk is aan
het doel. Zo ja, dan meld je iets; zo nee, dan loop je door. Wat denk je
dat dit print? Let goed op de inspringing.

```python
lijst = [3, 1, 4, 1, 5]
doel = 4
for waarde in lijst:
    if waarde == doel:
        print("gevonden")
```

<details>
<summary>Antwoord</summary>

```
gevonden
```

Eén keer `gevonden` — namelijk wanneer `waarde` gelijk is aan 4. Voor de
andere elementen (3, 1, 1, 5) is de `if` onwaar en wordt er niets geprint.

</details>

## Run

**Let op** het verschil tussen `=` en `==`:

- `=` is **toekenning**: `x = 5` betekent *"zet 5 in x"*.
- `==` is **vergelijking**: `if x == 5` betekent *"klopt het dat x gelijk
  is aan 5?"*.

{/* foutmelding-van: if x = 5:\n    pass */}

In een `if` moet je `==` gebruiken, anders krijg je een `SyntaxError`.

## Experimenteer

- Verander `doel` in `1`. Wat print het nu?
- Verander `doel` in `9`. Wat print het?

<PyRunner initialCode={`lijst = [3, 1, 4, 1, 5]
doel = 4
for waarde in lijst:

<details>
<summary>Wat zie je?</summary>

- Met `doel = 1` staat er twee keer `gevonden`, want de 1 komt twee keer voor.
- `doel = 9` → **niets** (9 staat niet in de lijst). Het programma loopt
  netjes af zonder fout, maar zonder output.

</details>

De code *meldt* nu dat hij iets vindt, maar geeft nog niets terug, en zegt
ook niet **waar** in de lijst het staat (de index).
