# Stap 1: een projectmap aanmaken

Alles van dit project komt in één map te staan: je code, en straks ook de afgesloten omgeving met de packages die je installeert. Die map maak je eerst, vóór je iets anders doet.

1. Open de Verkenner en ga naar de plek waar je je projecten bewaart, bijvoorbeeld je map Documenten
2. Klik met de rechtermuisknop in het lege deel van het venster en kies **Nieuw** → **Map**
3. Geef de map een naam zonder spaties, bijvoorbeeld `python-project`
4. Dubbelklik op de map om hem te openen

## Wat je nu ziet

Je staat ín de nieuwe map en die is leeg. Bovenin het venster toont de adresbalk het pad ernaartoe, bijvoorbeeld `Documenten > python-project`.

<details>
<summary>Op een Mac of Linux</summary>

Dezelfde stap in Finder (**Archief** → **Nieuwe map**) of in je bestandsbeheerder. De rest van deze tutorial werkt ook daar; per stap staat onderaan wat er anders gaat.

</details>
