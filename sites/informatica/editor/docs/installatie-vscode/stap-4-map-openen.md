# Stap 4: een map openen

Om te beginnen met coderen heb je een projectmap nodig. VS Code werkt met mappen, niet met losse bestanden: alles wat bij één project hoort staat in één map.

1. Klik op **File** → **Open Folder...**
2. Kies een map op je computer, of maak er in dat venster een nieuwe aan met de knop **Nieuwe map** (**New Folder**)
3. Bevestig met de knop onderaan het venster: **Select Folder** op Windows, **Open** op een Mac

De eerste keer dat je een map opent, verschijnt een venster met **"Do you trust the authors of the files in this folder?"** Dit is een map die je zelf gemaakt hebt, dus klik op **Yes, I trust the authors**. Kies je **No**, dan zet VS Code zichzelf in een beperkte modus en werken de terminal en extensies straks niet goed.

## Wat je nu ziet

In de Explorer links staat de naam van je map in hoofdletters bovenaan, met daaronder de bestanden die erin zitten. Bij een nieuwe map is dat nog niets.
