# Stap 1: download VS Code

1. Ga naar de officiële website: [https://code.visualstudio.com](https://code.visualstudio.com)
2. Klik bovenaan op de grote knop **Download for Windows** (op een Mac staat er **Download for Mac**, op Linux **Download for Linux**). De website kiest zelf je besturingssysteem.
3. Zie je twee versies, kies dan **Stable**. **Insiders** is een testversie die dagelijks verandert.

Je krijgt op Windows een `.exe`-bestand, op een Mac een `.zip`-bestand. Zie je een keuzemenu met meer varianten, neem dan de **User Installer** (Windows) of **Universal** (Mac).
