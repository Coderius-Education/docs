# Stap 3: rondkijken op je repo-pagina

Je repository is nog leeg. Daarom toont GitHub geen bestanden, maar een blok **Quick setup**:

- **De URL van je repository**, met **HTTPS** ervoor gekozen. Die heb je straks nodig om je map te koppelen in [Code online zetten met push](site:editor/git/push).
- **Terminal-commando's** die je *zou* kunnen typen. Die hoef je niet over te nemen: je doet het straks via VS Code.

Bovenaan de pagina staat ook het tabblad **Settings** op GitHub: daar verander je bijvoorbeeld de naam van de repository, of verwijder je hem. Zodra je iets gepusht hebt, verschijnen op deze pagina je bestanden en je commits.
