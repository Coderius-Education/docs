# Stap 4: zien wat git ziet

Zodra je geïnitialiseerd hebt, verschijnt er onder **Source Control** een lijst met **Changes**. Dit is precies wat `git status` je in de simulator liet zien:

- **Changes** = je werkmap (in de simulator: de linker kolom)
- **Staged Changes** = de staging-zone (in de simulator: de middelste kolom)

## Wat je nu ziet

Naast `hello.txt` staat een **U** — dat staat voor **Untracked**, dezelfde "niet-gevolgd" die je in de simulator zag. Achter de kop **Changes** staat een **1**: het aantal bestanden dat aandacht vraagt.

Klik op `hello.txt`. VS Code opent een vergelijking: links leeg, rechts je regel met een groene streep ervoor. Alles is nieuw, want git kende dit bestand nog niet.
