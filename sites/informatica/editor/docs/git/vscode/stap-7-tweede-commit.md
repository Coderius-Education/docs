# Stap 7: een tweede commit

Pas `hello.txt` aan: voeg een tweede regel toe, bijvoorbeeld `Dit is regel twee.` en sla op.

Kijk weer naar **Source Control**. Naast `hello.txt` staat nu een **M** — **Modified** (gewijzigd). Stage hem (`+`), typ een nieuwe commitboodschap (`tweede regel toegevoegd`) en commit.

## Wat je nu ziet

Het Source Control-paneel is weer leeg. Het verschil met de eerste keer: er stond **M** in plaats van **U**, want git kende dit bestand al. Klik op `hello.txt` vóórdat je stagede, en VS Code laat naast elkaar zien wat er veranderd is — links de oude versie, rechts de nieuwe.
