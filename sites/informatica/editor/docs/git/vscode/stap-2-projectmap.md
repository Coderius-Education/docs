# Stap 2: een projectmap openen

Git werkt altijd op één map. Die maak je eerst.

1. Maak ergens op je computer een nieuwe map en noem hem `git-oefenen`. Zet hem op een plek die je terugvindt: je Documenten-map bijvoorbeeld, niet je Downloads.
2. Open die map in VS Code via **File** → **Open Folder...** en kies `git-oefenen`.
3. De eerste keer dat je een map opent, vraagt VS Code **"Do you trust the authors of the files in this folder?"** Het is je eigen map, dus klik op **Yes, I trust the authors**. Kies je "No", dan zet VS Code zichzelf in een beperkte modus en werkt de Source Control-knop straks niet.

## Maak een bestand

1. Klik met de rechtermuisknop in het linker paneel (**Explorer**) en kies **New File...**
2. Noem het bestand `hello.txt` en druk op Enter
3. Typ erin: `Hallo wereld.`
4. Sla op met **Ctrl+S** (macOS: **Cmd+S**)

Maak het bestand in VS Code, niet in Verkenner of Finder. Dan weet je zeker dat het in de goede map staat.

## Wat je nu ziet

In het Explorer-paneel links staat `hello.txt` onder de kop **GIT-OEFENEN**. Op het tabblad van `hello.txt` in VS Code staat geen bolletje naast de naam: dat bolletje betekent "niet opgeslagen".
