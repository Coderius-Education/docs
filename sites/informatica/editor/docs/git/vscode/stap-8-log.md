# Stap 8: controleer met `git log`

Open de terminal in VS Code via **Terminal** → **New Terminal** en typ:

```bash
git log
```

Je ziet beide commits, nieuwste eerst. Dit is hetzelfde commando als in de simulator, alleen draait het nu op je echte computer met echte bestanden.

Past de uitvoer niet in de terminal, dan toont git hem in een venstertje waar je met de pijltjes doorheen scrolt. Je herkent het aan een `:` of `(END)` op de onderste regel. Druk dan op **q** (*quit*) om het te sluiten. Staat de prompt er meteen weer, dan hoef je niets te doen.

## Wat je nu ziet

Twee blokken, met bovenaan je laatste commit. Bij elke commit staan op de regel `Author:` de naam en het e-mailadres die je in [stap 1](site:editor/git/vscode/stap-1-config) instelde. Achter de bovenste staat `(HEAD -> main)`: dat is waar je nu bent.
