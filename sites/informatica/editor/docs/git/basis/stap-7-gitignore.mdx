# Stap 7: bestanden negeren met `.gitignore`

Soms wil je dat git bepaalde bestanden **negeert** — bijvoorbeeld tijdelijke bestanden of wachtwoorden. Daarvoor maak je een speciaal bestand: `.gitignore`. Elke regel in `.gitignore` is een bestandsnaam die git moet overslaan. Een `.gitignore` die het bestand `geheim.txt` negeert, heeft één regel:

```
geheim.txt
```

## Probeer het zelf

1. Klik op **"+ nieuw bestand"**, maak een bestand `geheim.txt` en typ `git status`: git ziet het als niet-gevolgd. Typ nog geen `git add`.
2. Maak op dezelfde manier een bestand `.gitignore`, met één regel: `geheim.txt`.
3. Typ opnieuw `git status`: `geheim.txt` is weg uit de lijst en in de werkmap doorgestreept.

**Let op:** `.gitignore` werkt alleen voor een bestand dat git nog niet volgt.
