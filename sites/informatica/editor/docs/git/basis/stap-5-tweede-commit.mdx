# Stap 5: een tweede commit

Een project heeft veel commits. Bij elke verandering herhaal je drie stappen: aanpassen → `git add` → `git commit`.

In de simulator hieronder staat de eerste commit er al. Voeg met de knoppen onder de zones een tweede bestand toe, of pas `hello.txt` aan, en maak nog een commit.

<GitSimulator scenarioId="stap-5-tweede-commit" />

<details>
<summary>Klik hier voor een tip.</summary>

De eerste commit staat er al. Klik op **"+ nieuw bestand"** of **"bewerk hello.txt"** om iets te veranderen, en doe daarna `git add ...` en `git commit -m "..."`.
