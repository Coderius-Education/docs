# Stap 6: de geschiedenis bekijken met `git log`

Met `git log` zie je alle commits, nieuwste eerst. Elke commit heeft een uniek **id** en je commitboodschap. In de simulator staan de twee commits uit stap 5 er al.

```bash
git log
```

Wil je één regel per commit, typ dan `git log --oneline`.
