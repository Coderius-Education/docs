# Docentenhandleiding

Een cursus voor leerlingen die voor het eerst met een code-editor werken: ze installeren VS Code, maken er een website en een Python-project in, en leren de basis van Git en GitHub. Hoe je ermee lesgeeft, bepaal je zelf.

## Waar de lessen op steunen

Bijna elke pagina is één stap, die je leerling meteen uitvoert: in VS Code, op GitHub of in de git-simulator. Bij elk onderdeel staat de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

De stappen zijn klein en hebben een [succesmoment](site:didactiek/bronnen/kleine-stappen). Werkt je leerling op zijn eigen computer met Python of git, dan zegt Wat je nu ziet waaraan hij ziet dat het gelukt is. In de simulator doet het doel boven de oefening dat.

## Wat je vooraf wilt weten

- **Installeren**: VS Code, Git en Python 3.14 komen op de computer van de leerling (Windows, macOS of Linux), met de extensies Live Server en Python. Op een beheerde schoolcomputer moet installeren mogen. Python komt uit de Microsoft Store, en waar die dicht staat van python.org. Alleen Git basis draait in de browser.
- **Waar werk blijft**: de simulator van Git basis bewaart niets. Al het andere staat op de computer van de leerling en, na [Code online zetten met push](site:editor/git/push), op GitHub. Daarvoor heeft elke leerling een account met een bevestigd e-mailadres.
- **Volgorde**: eerst [Installatie VS Code](site:editor/installatie-vscode). Daarna staan [Website in VS Code](site:editor/web), [Python in VS Code](site:editor/python) en [Git & GitHub](site:editor/git) los van elkaar. Binnen Git & GitHub ligt de volgorde vast.

## Beoordelen

De cursus heeft geen eindopdracht en geen nakijker. Wat je leerling deed, zie je in zijn repository op GitHub: de commits en de pull request die is gemerged. De branch ruimt de cursus zelf weer op. Koos je leerling voor Private, dan zie jij de repository niet.
