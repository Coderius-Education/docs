# Docentenhandleiding

Een cursus voor leerlingen die voor het eerst met een code-editor werken: ze installeren VS Code, maken er een website en een Python-project in, en leren de basis van Git en GitHub. Hoe je ermee lesgeeft, bepaal je zelf. Deze pagina laat zien op welk onderzoek de opbouw steunt, en noemt daarna kort wat je vooraf wilt weten.

## Waar de lessen op steunen

Dit is een cursus om mee te doen: elke pagina is één stap, die je leerling meteen uitvoert in zijn eigen editor. Een stap past op één scherm, of heeft een paar tabbladen met elk een eigen icoon. Hieronder staat bij elk onderdeel de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

<Werkvormen />

Elke stap eindigt met Wat je nu ziet: waaraan je leerling ziet dat het gelukt is, voordat hij doorgaat. Dat zijn [kleine stappen met een succesmoment](site:didactiek/bronnen/kleine-stappen). Git oefent hij eerst in een simulator in de browser, die dezelfde uitvoer geeft als echte git.

## Wat je vooraf wilt weten

- **VS Code en Git komen op de computer van de leerling**, op Windows, macOS of Linux. De installatie staat in de cursus; op een beheerde schoolcomputer moet installeren mogen.
- **Voor het deel over GitHub heeft elke leerling een account**, met een bevestigd e-mailadres. Dat bevestigen kan blijven hangen: daarom komt GitHub in de volgorde vóór Git in VS Code.
- **Vier sporen, los te gebruiken**: [Installatie VS Code](site:editor/installatie-vscode), [Website in VS Code](site:editor/web), [Python in VS Code](site:editor/python) en [Git & GitHub](site:editor/git). Binnen Git & GitHub liggen de tutorials in volgorde vast.

## Beoordelen

- De cursus heeft geen eindopdracht. Wat je leerling kan, zie je aan zijn repository op GitHub: de commits, de branches en een pull request die is gemerged.
