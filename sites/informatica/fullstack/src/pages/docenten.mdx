# Docentenhandleiding

Een cursus fullstack-ontwikkeling met FastAPI: je leerlingen bouwen een gastenboek met een server in Python, beveiligen het en zetten het online. Hoe je ermee lesgeeft, bepaal je zelf. Deze pagina laat zien op welk onderzoek de opbouw van de lessen steunt, en noemt daarna kort wat je vooraf wilt weten.

## Waar de lessen op steunen

Een les heeft vaste onderdelen. In de les zijn het de tabbladen, elk met een eigen icoon. Hieronder staat bij elk onderdeel de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

<Werkvormen />

Een voorspelvraag en een controlevraag zijn meerkeuzevragen die meteen zeggen of het antwoord klopt, met bij elk fout antwoord waarom niet. In Veiligheid en Online zetten eindigt elke stap met een blok Gelukt als je dit ziet, waaraan de leerling zijn eigen uitvoer toetst.

## Wat je vooraf wilt weten

- **Python en een editor op de computer.** Je leerlingen werken in VS Code met Python 3; [Installatie](site:fullstack/docs/FastAPI/eerste-server/installatie) zegt wat er moet staan. De site vraagt geen account.
- **Het werk staat op de computer van de leerling**, niet op de site. Wie het wil bewaren of delen, zet het in [git](site:editor/git).
- **Drie routes, in deze volgorde.** [FastAPI](site:fullstack/docs/FastAPI) bouwt het gastenboek en vraagt Python, HTML, CSS en JavaScript (zie het [cursusoverzicht](site:fullstack/cursussen)). [Veiligheid](site:fullstack/docs/veiligheid) bouwt daarop verder. [Online zetten](site:fullstack/docs/online) vraagt de [Linux-cursus](site:linux/docs), en voor het laatste deel een server met een domeinnaam: zie [Eén server voor de klas](site:fullstack/docs/voor-de-docent/schoolserver).

## Naast de lessen

- [Unplugged](site:fullstack/docs/unplugged): negen hand-outs zonder computer om te printen, elk gericht op één misvatting. De les waar een hand-out bij hoort, wijst ernaar met de tip Eerst op papier.
- [Hoe een verzoek werkt](site:fullstack/docs/FastAPI/afronden/hoe-een-verzoek-werkt): de vijf diagrammen van browser tot database bij elkaar.

## Beoordelen

- [Leerdoelen](site:fullstack/leerdoelen): per niveau de concepten waarop je beoordeelt, met de les erbij, en hoe je er een cijfer van maakt. Niveau 1 en 2 gaan over het FastAPI-project, niveau 3 over Veiligheid en Online zetten.
- [Project checken](site:fullstack/project-checken): je leerling uploadt zijn project en ziet welke onderdelen erin zitten en waar zijn bestanden niet op elkaar aansluiten. Jij gebruikt [Project checken voor docenten](site:fullstack/project-checken-docent); wat in geen bestand staat, zoals de installatie of de server, vink je daar zelf aan.
