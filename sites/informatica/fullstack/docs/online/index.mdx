# Online zetten: zo werkt deze route

Je gastenboek draait op je eigen laptop, met `fastapi dev`. Alleen jij kunt erbij, en als je laptop dichtgaat, is hij weg. In deze route zet je hem op een server op internet, waar een klasgenoot hem vanaf zijn telefoon kan openen. Op een veilige manier: met een eigen gebruiker, alleen de deuren open die nodig zijn, en HTTPS.

## Wat je al moet kunnen

- **De FastAPI-route**, minstens de basis. Je hebt een project in git, met een `.gitignore` die je databases en `.venv` buiten git houdt (uit [Wat er in je map staat](site:fullstack/docs/veiligheid/zichtbaar/gitignore)).
- **De route Veiligheid.** Een site op internet krijgt binnen een paar minuten bezoek van programma's die naar zwakke plekken zoeken. Wachtwoorden in gewone tekst, of een handleiding op `/docs` die iedereen alles laat proberen: los dat op voordat je online gaat.
- **Linux.** Deze route legt geen Linux uit. Alles over de terminal, rechten, `sudo apt`, `nano`, diensten en `ssh` staat in de [Linux-cursus](site:linux/docs). Elke les zegt welke Linux-les je nodig hebt.

## Waar je werkt

Je doet alles eerst op je eigen computer, in Ubuntu in WSL ([WSL installeren](site:linux/docs/wsl/installeren)). Daar kan niets stuk en kost het niets. Pas als het daar werkt, huur je een echte server en doe je hetzelfde nog een keer, plus de stappen die alleen op internet nodig zijn.

| Deel | Waar | Wat je doet |
|:---|:---|:---|
| Oefenen in WSL | je eigen computer | je project in Linux, `fastapi run`, een eigen gebruiker, een dienst, een voordeur |
| Op een echte server | een server op internet | inloggen, de deuren dicht, HTTPS met je eigen domein, een nieuwe versie uitrollen |

Voor het tweede deel heb je een server nodig. Vraag je docent of de school er een heeft. Anders huur je er een voor een paar euro per maand bij een hostingbedrijf; dat mag alleen met toestemming van een ouder of verzorger, en zeg hem op als je klaar bent.
