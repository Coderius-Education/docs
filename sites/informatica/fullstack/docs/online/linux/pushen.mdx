# Online zetten: een wijziging vanuit Ubuntu

<Voorkennis items={[{site: 'editor', to: '/git/basis/stap-4-commit', label: 'Een commit maken'}, {site: 'editor', to: '/git/push/stap-2-wijziging', label: 'Een wijziging pushen'}]} />

Je site draait in Ubuntu. Het laatste stuk van deze reeks: een wijziging van hier naar GitHub brengen, zoals je dat straks steeds doet.

## Iets veranderen

Verander iets kleins wat je ziet: de titel in je README, of een tekst in een template. Sla op, en kijk wat git ziet:

```bash
git status
```

Je bestand staat bij `Changes not staged for commit`. Je databases staan er niet bij: die staan in `.gitignore`. `.venv` ook niet.

## Commit en push

```bash
git add README.md
git commit -m "Titel aangepast in Ubuntu"
git push
```

De eerste keer met ssh kan git vragen of je de vingerafdruk van GitHub vertrouwt; typ `yes`.

<Gelukt>

Op GitHub staat je commit bovenaan, met je naam uit [les 7](site:fullstack/docs/online/linux/git) en je bericht `Titel aangepast in Ubuntu`. `git status` zegt in Ubuntu `nothing to commit, working tree clean`.

</Gelukt>

## Er gaat iets mis

### Author identity unknown

```text
Author identity unknown

*** Please tell me who you are.
```

**Oorzaak:** git in Ubuntu weet nog niet wie je bent.

**Oplossing:** doe de twee regels met `git config --global` uit [les 7](site:fullstack/docs/online/linux/git), en commit opnieuw.

### Username for 'https://github.com'

**Oorzaak:** je kloonde met het https-adres, en daarover laat GitHub je niet met een wachtwoord pushen.

**Oplossing:** zet het adres om naar ssh zoals in [les 9](site:fullstack/docs/online/linux/klonen), en push opnieuw.

### Updates were rejected

```text
 ! [rejected]        main -> main (fetch first)
```

**Oorzaak:** op GitHub staat een commit die jouw Ubuntu nog niet heeft, bijvoorbeeld omdat je nog op Windows pushte.

**Oplossing:** haal hem eerst op met `git pull`, en push dan opnieuw.
