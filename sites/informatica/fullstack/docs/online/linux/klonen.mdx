# Online zetten: je project in Ubuntu

<Voorkennis items={[{site: 'editor', to: '/git/pull-clone/stap-3-clone', label: 'Een project klonen'}, {site: 'linux', to: '/docs/terminal/mappen', label: 'Door mappen lopen met cd'}, {site: 'linux', to: '/docs/wsl/windows-en-linux', label: 'Je project in je Linux-thuismap, en code . vanuit Ubuntu'}]} />

Je project staat op GitHub. Nu haal je het naar Ubuntu, zoals de server het straks ook ophaalt: met alleen wat in je repository staat.

## Klonen

Je hebt het ssh-adres van je repository nodig. Je vindt het op GitHub onder de groene knop **Code**, bij **SSH**. Zet je eigen adres op de plek van dat van `sam`:

```bash
cd ~
git clone git@github.com:sam/gastenboek.git
cd gastenboek
```

`cd ~` brengt je naar je Linux-thuismap. Daar hoort je project, en niet onder `/mnt/c`: in Linux zelf is het sneller, en straks ziet Docker het goed.

## Openen in VS Code

```bash
code .
```

De eerste keer installeert VS Code een stukje in Ubuntu; dat duurt even.

<Gelukt>

VS Code opent je project, en linksonder staat **WSL: Ubuntu-24.04**. In de verkenner staan `main.py`, `requirements.txt`, `README.md`, `templates` en `static`. Alles wat je nu verandert, verandert in Ubuntu.

</Gelukt>

## Er gaat iets mis

### Username for 'https://github.com'

Bij `git clone` of later bij `git push` vraagt git om een gebruikersnaam en een wachtwoord, en daarna staat er `Support for password authentication was removed`.

**Oorzaak:** je kloonde met het https-adres. Daarover laat GitHub je in de terminal niet met een wachtwoord inloggen.

**Oplossing:** zet het adres om naar ssh, en probeer het opnieuw:

```bash
git remote set-url origin git@github.com:sam/gastenboek.git
```

### destination path 'gastenboek' already exists

```text
fatal: destination path 'gastenboek' already exists and is not an empty directory.
```

**Oorzaak:** er staat al een map `gastenboek` in je thuismap, van een eerdere poging.

**Oplossing:** werk in die map verder met `cd gastenboek`, of gooi hem weg met `rm -r gastenboek` als er niets in staat wat je nog nodig hebt, en kloon opnieuw.

### Command 'code' not found

**Oorzaak:** VS Code op Windows weet nog niet dat hij met WSL moet samenwerken.

**Oplossing:** volg [Command 'code' not found](site:linux/docs/wsl/windows-en-linux#command-code-not-found) in de Linux-cursus.
