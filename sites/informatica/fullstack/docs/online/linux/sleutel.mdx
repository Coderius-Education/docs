# Online zetten: je sleutel op GitHub

<Voorkennis items={[{site: 'linux', to: '/docs/wsl/ssh', label: 'Een sleutelpaar maken met ssh-keygen'}, {site: 'linux', to: '/docs/wsl/github', label: 'Je ssh-sleutel op GitHub'}]} />

Deed je [les 7.3 van de Linux-cursus](site:linux/docs/wsl/github) al, dan is dit je controle. Straks haal je je project op en push je vanuit Ubuntu. GitHub laat je in de terminal niet inloggen met een wachtwoord. Je gebruikt een ssh-sleutel, en die staat na deze stap op GitHub.

## De sleutel op GitHub

Heb je in de Linux-cursus een sleutelpaar gemaakt, dan staat het in `~/.ssh`. Zo niet, maak er dan eerst een zoals in [Inloggen op een andere computer](site:linux/docs/wsl/ssh).

Zet de publieke sleutel op GitHub zoals in [Je sleutel op GitHub](site:linux/docs/wsl/github): de regel uit `~/.ssh/id_ed25519.pub`, onder je profielfoto, **Settings**, **SSH and GPG keys**, **New SSH key**. Nooit `id_ed25519` zelf, zonder `.pub`: dat is je privésleutel.

## Kent GitHub je?

```bash
ssh -T git@github.com
```

De eerste keer vraagt ssh of je de vingerafdruk van GitHub vertrouwt; typ `yes`. Iedereen logt in als `git`, ook jij. GitHub herkent je aan je sleutel.

<Gelukt>

GitHub groet je met je eigen GitHub-naam:

```text
Hi sam! You've successfully authenticated, but GitHub does not provide shell access.
```

Dat laatste is goed: je wilde alleen weten of de sleutel werkt.

</Gelukt>

  `git@github.com` is het adres, niet je naam. Welk account je bent, haalt GitHub uit de sleutel die je laptop laat zien. Daarom staat er in de groet je GitHub-naam, en weet je na `ssh -T` dat de sleutel bij het goede account hoort.

  </Uitleg>

## Er gaat iets mis

### `Permission denied (publickey)`

```text
git@github.com: Permission denied (publickey).
```

**Oorzaak:** GitHub kent je sleutel niet. Je zette de publieke sleutel niet op GitHub, of een andere dan die in `~/.ssh/id_ed25519.pub`.

**Oplossing:** vergelijk `cat ~/.ssh/id_ed25519.pub` met de sleutel onder **SSH and GPG keys** op GitHub, en probeer `ssh -T git@github.com` opnieuw.

### Connection timed out

```text
ssh: connect to host github.com port 22: Connection timed out
```

**Oorzaak:** het netwerk, bijvoorbeeld dat van school, laat poort 22 niet door.

**Oplossing:** laat ssh poort 443 gebruiken, met de regels uit [Je sleutel op GitHub](site:linux/docs/wsl/github) van de Linux-cursus.
