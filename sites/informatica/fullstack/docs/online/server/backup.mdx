# Online zetten: een back-up

<Voorkennis items={[{site: 'linux', to: '/docs/wsl/scp', label: 'Bestanden kopiëren met scp'}]} />

Het volume is het enige op je server dat je niet opnieuw kunt maken: je code staat op GitHub, maar de berichten en accounts van je bezoekers staan alleen in `gastenboek_data`. Hetzelfde geldt voor de instellingen van de server, `.env` en de map `~/traefik`. Een kapotte schijf, een `docker compose down -v` of een opgezegde server, en ze zijn weg. Maak er daarom een kopie van, op een andere computer.

## Een kopie maken

Stop je site even, zodat er tijdens het kopiëren niets verandert, en kopieer de map `data` uit de container:

```bash
mkdir ~/backup
cd ~/gastenboek
docker compose stop
docker compose cp gastenboek:/app/data ~/backup/data
docker compose start
```

`docker compose cp` kopieert tussen een container en de server, ook als de container gestopt is. `gastenboek:` is de naam van de service uit `compose.yaml`. Zet de instellingen van de server erbij:

```bash
cp ~/gastenboek/.env ~/backup/
cp -r ~/traefik ~/backup/
```

Haal de kopie daarna in WSL naar je laptop met `scp`:

```bash
scp -r sam@gastenboek.voorbeeld.nl:backup ~/backup-gastenboek
```

Ging ssh tot nu toe met het IP-adres, dan vraagt hij bij de domeinnaam nog één keer of je de vingerafdruk vertrouwt; het is dezelfde server. Gooi de kopie op de server daarna weg met `rm -r ~/backup`. In `gebruikers.db` staan de wachtwoorden van je bezoekers, als hash; bewaar de back-up dus net zo zorgvuldig als de server zelf.

<Gelukt>

In WSL toont `ls -A ~/backup-gastenboek` drie dingen: de map `data` met je databases, het bestand `.env` en de map `traefik`.

</Gelukt>

## Er gaat iets mis

### Permission denied bij rm -r ~/backup

**Oorzaak:** je maakte de back-up met `sudo docker compose cp`. Dan is de kopie van `root`.

**Oplossing:** gooi hem weg met `sudo rm -r ~/backup`, en laat `sudo` voortaan weg voor `docker`.

## Opdrachten

### Opdracht 1: Run - Een back-up op je laptop

Maak een back-up van je server, en haal hem naar je laptop. Wat staat er in `~/backup-gastenboek`?

<details>
<summary>Antwoord</summary>

De map `data` met je databases (`gebruikers.db`, en de andere die je site gebruikt), het bestand `.env`, en de map `traefik` met de `compose.yaml` van de voordeur. Met die drie, en je repository op GitHub, kun je op een nieuwe server alles terugzetten.

</details>
