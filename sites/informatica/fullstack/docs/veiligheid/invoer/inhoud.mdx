# Invoer controleren: de inhoud controleren

`max_length` uit [les 2](./grenzen) bewaakt de lengte, en een leeg veld weigert
FastAPI al, zoals je in [les 3](./fouten-lezen) zag. Maar een naam van drie
spaties is niet leeg en niet te lang. Maak een script `spaties.py` dat zo'n
naam stuurt:

```python
import httpx

antwoord = httpx.post("http://127.0.0.1:8000/bericht", data={"naam": "   ", "bericht": "hoi"})
print(antwoord.status_code, antwoord.json())
```

Uitvoer:

```
200 {'lengte': 3}
```

Draai `lees_database.py` uit [les 1](./maxlength). Onderaan staat het nieuwe
bericht:

```
[   ] 3 tekens
```

Tussen de blokhaken staan drie spaties: in je gastenboek staat nu een bericht
zonder zichtbare naam. Zo'n regel over de
inhoud controleer je zelf.

## `strip()`

`strip()` haalt de spaties aan het begin en het eind van een tekst weg:

```python
print(repr("   ".strip()))
print(repr(" Sara ".strip()))
```

Uitvoer:

```
''
'Sara'
```

`repr` laat de aanhalingstekens zien, zodat je de spaties ziet. Blijft er na
`strip()` niets over, dan bestond de naam alleen uit spaties.

## De controle in het endpoint

<CodeUitleg>

```python showLineNumbers
@app.post("/bericht")
async def bericht_plaatsen(
    naam: str = Form(..., max_length=30),
    bericht: str = Form(..., max_length=280),
):
    if not naam.strip():
        raise HTTPException(status_code=400, detail="Vul een naam in")
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

<Regel n={6}>
Een lege tekst telt in een `if` als niet waar, dus `not naam.strip()` is waar als er niets overblijft.
</Regel>

<Regel n={7}>
`raise HTTPException` stopt de functie en stuurt een foutmelding, zoals de 404 in [Een 404 sturen: als het item niet bestaat](/docs/FastAPI/berichten-tonen/niet-gevonden). Voeg `HTTPException` toe aan de import uit `fastapi`.
</Regel>

</CodeUitleg>

Draai `spaties.py` opnieuw:

```
400 {'detail': 'Vul een naam in'}
```

Het is een **400** en geen 422. Een 422 komt van FastAPI zelf, als een veld niet
past bij wat er in `Form` staat. Een 400 stuur meestal jij, voor een regel die
je zelf bedacht. De uitzondering zag je in [les 1](./maxlength): bij een veld
boven een megabyte stuurt Starlette zelf een 400.

`lees_database.py` laat geen nieuwe regel met `[   ]` zien: het bericht kwam
niet in de database.

## Er gaat iets mis

De server geeft `400`, maar `lees_database.py` laat toch een nieuwe regel met
`[   ]` zien.

**Oorzaak:** de controle staat ná het opslaan:

{/* niet-compileren: een stuk uit de functie bericht_plaatsen */}

```python
# FOUT
with SqliteDict("gastenboek.db") as db:
    db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
    db.commit()
if not naam.strip():
    raise HTTPException(status_code=400, detail="Vul een naam in")

# GOED
if not naam.strip():
    raise HTTPException(status_code=400, detail="Vul een naam in")
with SqliteDict("gastenboek.db") as db:
    db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
    db.commit()
```

**Oplossing:** controleer eerst, en sla pas op als alles klopt.

## Opdrachten

### Opdracht 1: Predict - Spaties eromheen

Je stuurt de naam `" Sara "`, met een spatie ervoor en erachter.

**Vraag:** geeft de server `200` of `400`? En wat komt er in de database?

<details>
<summary>Antwoord</summary>

`200`: na `strip()` blijft `Sara` over, dus de controle laat hem door. Maar
`lees_database.py` laat `[ Sara ] 3 tekens` zien, met de spaties, want de
controle verandert `naam` niet. Wil je ze kwijt, zet dan `naam = naam.strip()`
bovenaan de functie.

</details>

### Opdracht 2: Modify - Ook het bericht

Zorg dat een bericht van alleen spaties ook een `400` geeft, met de melding
`Schrijf een bericht`.

<details>
<summary>Tip</summary>

Dezelfde twee regels als voor de naam, met `bericht` in plaats van `naam`.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.post("/bericht")
async def bericht_plaatsen(
    naam: str = Form(..., max_length=30),
    bericht: str = Form(..., max_length=280),
):
    if not naam.strip():
        raise HTTPException(status_code=400, detail="Vul een naam in")
    if not bericht.strip():
        raise HTTPException(status_code=400, detail="Schrijf een bericht")
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

Een bericht van drie spaties geeft nu `400 {'detail': 'Schrijf een bericht'}`.

</details>

<details>
<summary>Zo ziet je `main.py` er nu uit</summary>

```python
import time

from fastapi import FastAPI, Form, HTTPException
from fastapi.staticfiles import StaticFiles
from sqlitedict import SqliteDict

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.post("/bericht")
async def bericht_plaatsen(
    naam: str = Form(..., max_length=30),
    bericht: str = Form(..., max_length=280),
):
    if not naam.strip():
        raise HTTPException(status_code=400, detail="Vul een naam in")
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

De lengte bewaakt FastAPI, de inhoud jij.

</details>
