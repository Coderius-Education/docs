# Invoer controleren: maxlength is geen controle

In een formulier kun je met `maxlength` een grens zetten op een veld. De
browser laat je dan niet verder typen. Maar die grens is een hulp voor wie zich
vergist, geen controle. Hier zie je met een script waarom, en hoe ver het gaat.
Deed je de uitbreiding JavaScript al, dan ken je het idee uit
[Server of browser?](/docs/FastAPI/in-de-browser/server-of-browser); deze les kun je ook
zonder die uitbreiding volgen.

:::note[Waar je werkt]
Maak voor deze reeks een nieuwe map `veiligheid-invoer`, naast je eigen
project, en open die in VS Code. De server, de scripts en de database van deze reeks komen daarin. Zo blijft je eigen gastenboek heel. Aan
het eind van de reeks pas je het geleerde toe op je eigen project.

Maak in die map een virtual environment en installeer de packages; hoe dat gaat staat bij [Een map per reeks](/docs/veiligheid/gereedschap#een-map-per-reeks).
:::

## Een gastenboek met een formulier

Het formulier staat als los bestand in `static/formulier.html`, met een grens
op beide velden:

```html
<!doctype html>
<html>
<body>
    <form method="post" action="/bericht">
        <input type="text" name="naam" maxlength="30" required>
        <input type="text" name="bericht" maxlength="280" required>
        <button type="submit">Verstuur</button>
    </form>
</body>
</html>
```

De server slaat op wat binnenkomt, en geeft terug hoe lang het bericht was:

<CodeUitleg>

```python showLineNumbers
import time

from fastapi import FastAPI, Form
from fastapi.staticfiles import StaticFiles
from sqlitedict import SqliteDict

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.post("/bericht")
async def bericht_plaatsen(naam: str = Form(...), bericht: str = Form(...)):
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

<Regel n={8}>
De map `static` met het formulier, zoals in [CSS in een eigen bestand (static files)](/docs/FastAPI/html/static_files).
</Regel>

<Regel n={15}>
De lengte van het bericht, zodat je in de test ziet wat er binnenkwam.
</Regel>

</CodeUitleg>

## Doe het na, op je eigen server

:::danger[Alleen je eigen server]
Stuur zulke verzoeken **uitsluitend** naar je eigen server op `127.0.0.1`. Een
server van een ander volstoppen met grote of veel verzoeken is een aanval, en
strafbaar.
:::

Start je server en open `http://127.0.0.1:8000/static/formulier.html`. Typ een
lang bericht: na 280 tekens gaat er niets meer bij, want `maxlength` houdt je
tegen.

Nu een scriptje `groot.py` dat níét via het formulier gaat, maar rechtstreeks
naar het endpoint:

<CodeUitleg>

```python showLineNumbers
import httpx

adres = "http://127.0.0.1:8000/bericht"

bericht = "a" * 1_000_000
antwoord = httpx.post(adres, data={"naam": "Sara", "bericht": bericht})
print(antwoord.json())
```

<Regel n={5}>
Een bericht van een miljoen keer de letter `a`. In het formulier kreeg je dit er nooit in. `1_000_000` is hetzelfde getal als `1000000`; het liggende streepje maakt het leesbaar.
</Regel>

<Regel n={6}>
Hetzelfde verzoek dat de browser zou sturen, maar zonder de grens uit de HTML.
</Regel>

</CodeUitleg>

Uitvoer:

```
{'lengte': 1000000}
```

## Kijk in je database

De server zegt dat hij een miljoen tekens kreeg. Of ze ook echt in je database
staan, zie je met een tweede scriptje, `lees_database.py`. Het print van elk
bericht de naam en hoeveel tekens het bericht heeft; het bericht zelf zou je
terminal vullen.

<CodeUitleg>

```python showLineNumbers
from sqlitedict import SqliteDict

with SqliteDict("gastenboek.db") as db:
    for gegevens in db.values():
        print(f"[{gegevens['naam']}] {len(gegevens['bericht'])} tekens")
```

<Regel n={4}>
`db.values()` geeft alle berichten, zoals in [Alles tonen: een for-lus in je template](/docs/FastAPI/gastenboek/lijst_tonen).
</Regel>

<Regel n={5}>
De naam staat tussen blokhaken, zodat je ook ziet of er spaties in staan. Dat komt in [les 4](./inhoud) van pas.
</Regel>

</CodeUitleg>

Uitvoer:

```
[Sara] 1000000 tekens
```

Alle miljoen tekens staan in je database. `maxlength` zat in de HTML, en die
HTML draaide in de browser die je nu hebt overgeslagen. Het endpoint zag alleen
het verzoek, en dat had geen grens.

Eén bericht van een miljoen tekens is al vervelend, en een script dat dat
duizend keer doet, vult je schijf.

## Eén ruwe grens

Helemaal zonder grens is je server niet. Maak van het bericht in `groot.py`
tien miljoen tekens, `10_000_000`, en zet er onderaan een regel
`print(antwoord.status_code)` bij:

```
{'detail': 'Field exceeded maximum size of 1024KB.'}
400
```

Starlette, het deel van FastAPI dat formulieren leest, weigert zelf een veld
dat groter is dan een megabyte, ongeveer een miljoen tekens. Het bericht van
precies een miljoen kwam er nog net door. Die grens beschermt je tegen het
ergste, maar een bericht in een gastenboek hoort geen megabyte te zijn. De
echte grens zet je zelf, in [les 2](./grenzen).

## Er gaat iets mis

`groot.py` geeft een `422` terug in plaats van de lengte.

**Oorzaak:** je stuurt geen `naam` of `bericht` mee, of de namen in `data`
komen niet overeen met de `Form`-parameters. FastAPI mist dan een verplicht
veld.

**Oplossing:** stuur beide velden mee, met precies de namen `naam` en `bericht`,
net als het formulier.

`lees_database.py` print niets, terwijl `groot.py` wel `{'lengte': 1000000}`
gaf.

**Oorzaak:** het script draait in een andere map dan je server.
`SqliteDict("gastenboek.db")` zoekt het bestand in de map waarin je het script
start. Bestaat het daar niet, dan maakt hij stil een nieuwe, lege database aan.

**Oplossing:** zet `lees_database.py` in dezelfde map als `main.py`, en draai
het vanuit de terminal in die map.

Wat er in zo'n `422` staat, lees je in [les 3](./fouten-lezen). Alle
statuscodes van deze route staan op [de startpagina](/docs/veiligheid#statuscodes).

## Opdrachten

### Opdracht 1: Predict - 300 tekens

In het formulier kom je niet verder dan 280 tekens. Je stuurt met een script een
bericht van 300 tekens.

**Vraag:** wat antwoordt de server?

<details>
<summary>Antwoord</summary>

`{'lengte': 300}`. De server kent de grens van 280 niet: die staat alleen in
de HTML.

</details>

### Opdracht 2: Investigate - Vijf keer

Draai `groot.py` vijf keer achter elkaar, en daarna `lees_database.py`. Hoeveel
tekens staan er nu in je database?

<details>
<summary>Tip</summary>

Tel ook het bericht mee dat er al stond.

</details>

<details>
<summary>Antwoord</summary>

Zes regels `[Sara] 1000000 tekens`: het bericht van daarnet en de vijf nieuwe.
Samen zes miljoen tekens, en het bestand `gastenboek.db` is ongeveer zes
megabyte. Elke keer dat het script draait, groeit het. Een script dat niet
stopt, maakt je schijf vol.

</details>

<details>
<summary>Zo ziet je `main.py` er nu uit</summary>

```python
import time

from fastapi import FastAPI, Form
from fastapi.staticfiles import StaticFiles
from sqlitedict import SqliteDict

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.post("/bericht")
async def bericht_plaatsen(naam: str = Form(...), bericht: str = Form(...)):
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

Naast `main.py` staat `static/formulier.html`. In de volgende lessen verandert
alleen de functie `bericht_plaatsen`.

</details>
