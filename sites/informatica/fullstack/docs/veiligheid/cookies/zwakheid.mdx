# Cookies afschermen: scripts lezen cookies

Het sessie-id uit [Onthouden op de server: sessies](/docs/FastAPI/sessies) is de sleutel tot een
sessie: wie het heeft, is voor je server ingelogd als die bezoeker, zonder
wachtwoord. Daarom is het een lang,
willekeurig getal dat niemand raadt. Maar raden hoeft niet als een script het
kan lezen, en standaard kan dat.

:::note[Waar je werkt]
Maak voor deze reeks een nieuwe map `veiligheid-cookies`, naast je eigen
project, en open die in VS Code. De server, de scripts en de databases van deze reeks komen daarin. Zo blijft je eigen gastenboek heel. Aan
het eind van de reeks pas je het geleerde toe op je eigen project.

Maak in die map een virtual environment en installeer de packages; hoe dat gaat staat bij [Een map per reeks](/docs/veiligheid/gereedschap#een-map-per-reeks).
:::

## Een formulier bij de server

Neem de server uit Wie mag wat, in de stand van
[les 4: elk endpoint apart](../toegang/elk-endpoint), met Alles wissen erin. Zet
er formulieren bij, als los bestand `static/formulier.html`: een om te
registreren, een om in te loggen en een voor een bericht.

```html
<!doctype html>
<html>
<body>
    <form method="post" action="/registreer">
        <input type="text" name="naam" placeholder="Je naam" required>
        <input type="password" name="wachtwoord" placeholder="Wachtwoord" required>
        <button type="submit">Registreer</button>
    </form>
    <form method="post" action="/inloggen">
        <input type="text" name="naam" placeholder="Je naam" required>
        <input type="password" name="wachtwoord" placeholder="Wachtwoord" required>
        <button type="submit">Inloggen</button>
    </form>
    <form method="post" action="/bericht">
        <input type="text" name="bericht" placeholder="Je bericht" required>
        <button type="submit">Verstuur</button>
    </form>
</body>
</html>
```

In `main.py` komen er twee regels bij, zodat de server de map `static` laat
zien:

```python
from fastapi.staticfiles import StaticFiles

app.mount("/static", StaticFiles(directory="static"), name="static")
```

Zet de import bovenaan bij de andere, en `app.mount` direct onder
`app = FastAPI()`.

<details>
<summary>Zo ziet je `main.py` er nu uit</summary>

Heb je de server uit Wie mag wat niet meer, of wil je zeker weten dat je
dezelfde hebt: dit is het hele `main.py`, met de twee nieuwe regels erin.

```python
import secrets
import time

from fastapi import Cookie, FastAPI, Form, HTTPException
from fastapi.responses import JSONResponse
from fastapi.staticfiles import StaticFiles
from sqlitedict import SqliteDict

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.post("/registreer")
async def registreer(naam: str = Form(...), wachtwoord: str = Form(...)):
    with SqliteDict("gebruikers.db") as gebruikers:
        if naam in gebruikers:
            raise HTTPException(status_code=400, detail="Deze naam is al bezet")
        gebruikers[naam] = wachtwoord
        gebruikers.commit()
    return {"bericht": f"Welkom, {naam}"}

@app.post("/inloggen")
async def inloggen(naam: str = Form(...), wachtwoord: str = Form(...)):
    with SqliteDict("gebruikers.db") as gebruikers:
        opgeslagen = gebruikers.get(naam)
    if opgeslagen != wachtwoord:
        raise HTTPException(status_code=401, detail="Naam of wachtwoord klopt niet")

    sessie_id = secrets.token_hex(16)
    with SqliteDict("sessies.db") as sessies:
        sessies[sessie_id] = {"naam": naam}
        sessies.commit()

    antwoord = JSONResponse({"bericht": f"Ingelogd als {naam}"})
    antwoord.set_cookie(key="sessie_id", value=sessie_id, max_age=60 * 60 * 24 * 30)
    return antwoord

@app.post("/bericht")
async def bericht_plaatsen(bericht: str = Form(...), sessie_id: str = Cookie(default="")):
    with SqliteDict("sessies.db") as sessies:
        mijn = sessies.get(sessie_id, {})
    if not mijn:
        raise HTTPException(status_code=401, detail="Log eerst in")

    sleutel = f"bericht_{time.time_ns()}"
    with SqliteDict("gastenboek.db") as db:
        db[sleutel] = {"naam": mijn["naam"], "bericht": bericht}
        db.commit()
    return {"sleutel": sleutel}

@app.get("/berichten")
async def berichten():
    with SqliteDict("gastenboek.db") as db:
        return dict(db)

@app.delete("/bericht/{sleutel}")
async def bericht_verwijderen(sleutel: str, sessie_id: str = Cookie(default="")):
    with SqliteDict("sessies.db") as sessies:
        mijn = sessies.get(sessie_id, {})

    with SqliteDict("gastenboek.db") as db:
        bericht = db.get(sleutel)
        if bericht is None or bericht["naam"] != mijn.get("naam"):
            raise HTTPException(status_code=403, detail="Dit is niet jouw bericht")
        del db[sleutel]
        db.commit()
    return {"bericht": "Verwijderd"}

@app.delete("/berichten")
async def alles_wissen(sessie_id: str = Cookie(default="")):
    with SqliteDict("sessies.db") as sessies:
        mijn = sessies.get(sessie_id, {})
    with SqliteDict("gastenboek.db") as db:
        van_mij = []
        for sleutel, bericht in db.items():
            if bericht["naam"] == mijn.get("naam"):
                van_mij.append(sleutel)
        for sleutel in van_mij:
            del db[sleutel]
        db.commit()
    return {"bericht": "Jouw berichten zijn gewist"}
```

</details>

## Bekijk je eigen cookie

:::danger[Alleen je eigen server]
Kijk alleen naar de cookies van je eigen server op `127.0.0.1`, in je eigen
browser. Het sessie-id van een ander gebruiken om als die persoon binnen te
komen, is strafbaar.
:::

1. Open `http://127.0.0.1:8000/static/formulier.html`, maak een account met het
   eerste formulier, ga terug en log in met het tweede. Je ziet
   `{"bericht":"Ingelogd als …"}` als JSON.
2. Ga terug naar het formulier en open de ontwikkelaarstools. Kijk in het
   tabblad **App** (Firefox: Opslag) onder Cookies bij `http://127.0.0.1:8000`.
   Daar staat `sessie_id`, met in de kolom **HttpOnly** niets:

<DevtoolsPaneel tab="App">

| Naam | Waarde | HttpOnly | SameSite |
|---|---|:---:|---|
| `sessie_id` | `bb4b18ca1efc4877c990fdadd8a6f593` |  | Lax |

</DevtoolsPaneel>

3. Typ in de **Console** `document.cookie`. De Console antwoordt met je
   sessie-id; bij jou is het getal anders:

<DevtoolsPaneel tab="Console">
  <ConsoleRegels
    regels={[
      { tekst: 'document.cookie', soort: 'invoer' },
      { tekst: "'sessie_id=bb4b18ca1efc4877c990fdadd8a6f593'", soort: 'antwoord' },
    ]}
  />
</DevtoolsPaneel>

`document.cookie` is niet alleen voor jou in de Console. Elk script dat op deze
pagina draait, kan het ook, en daar zit de zwakheid. Staat er ergens een gat
zoals in [HTML van een bezoeker](../xss/zwakheid), dan draait er misschien een
script van een ander op je pagina, en dat leest je sessie-id net zo makkelijk.

## Er gaat iets mis

`document.cookie` geeft `''`, een lege tekst, terwijl je wel bent ingelogd.

**Oorzaak:** je hebt de pagina geopend via `localhost:8000` in plaats van
`127.0.0.1:8000`, of andersom. Het is dezelfde server, maar voor de browser zijn
het twee verschillende sites, elk met eigen cookies.

**Oplossing:** gebruik overal hetzelfde adres. Log in en open de Console op
`127.0.0.1:8000`.

## Opdrachten

### Opdracht 1: Investigate - Wat stuurt de server mee?

Open het tabblad **Netwerk**, log nog een keer in, en klik op het verzoek
`inloggen`. Zoek bij Headers, onder **Reactieheaders**, de regel `set-cookie`. Welke instellingen
zie je achter het sessie-id staan?

<details>
<summary>Tip</summary>

De instellingen staan achter de waarde, gescheiden door puntkomma's.

</details>

<details>
<summary>Antwoord</summary>

Iets als:

```
sessie_id=bb4b18ca1efc4877c990fdadd8a6f593; Max-Age=2592000; Path=/; SameSite=lax
```

`Max-Age` is de 30 dagen uit `max_age` in
seconden, `Path=/` betekent: voor de hele site. `SameSite=lax` zet FastAPI er
vanzelf bij; wat dat doet, staat in [les 3: `samesite`](./samesite). `HttpOnly`
staat er niet bij, en daarom mag een script de cookie lezen.

</details>

### Opdracht 2: Predict - Een ander tabblad

Je opent in hetzelfde browservenster een tweede tabblad met
`http://127.0.0.1:8000/berichten`, en typt daar in de Console
`document.cookie`.

**Vraag:** zie je daar ook je sessie-id?

<details>
<summary>Antwoord</summary>

Ja. Een cookie hoort bij de site, niet bij één pagina of tabblad. Met `Path=/`
geldt hij voor elke pagina op `127.0.0.1:8000`, en een script op elk van die
pagina's kan hem lezen.

</details>

Door naar [les 2: `httponly`](./httponly).
