Voor een foto op je pagina heb je twee dingen nodig: het bestand in je `static`-map en één HTML-tag.

## Afbeelding klaarzetten

Zoek een afbeelding op internet, klik er met de rechtermuisknop op en kies **Afbeelding opslaan als…** (Save image as…). Sla hem op in de map `static` van je project, onder de naam `kat.jpg`:

```
je-project/
├── main.py
└── static/
    ├── css/
    │   └── style.css
    ├── pages/
    │   ├── home.html
    │   ├── about.html
    │   └── foto.html
    └── kat.jpg          ← jouw afbeelding
```

## De img tag

In je HTML gebruik je de `<img>` tag:

```html
<img src="/static/kat.jpg" alt="Een kat">
```

- `src` is het pad naar de afbeelding, via de `static`-map.
- In `alt` staat de tekst die de browser laat zien als de afbeelding niet laadt.

## Compleet voorbeeld

Maak `static/pages/foto.html`:

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Mijn Foto</title>
        <link rel="stylesheet" href="/static/css/style.css">
    </head>
    <body>
        <h1>Kijk naar deze foto!</h1>
        <img src="/static/kat.jpg" alt="Een kat">
    </body>
</html>
```

En in `main.py`:

```python
@app.get("/foto")
async def foto():
    return FileResponse("static/pages/foto.html")
```

## Testen

Ga naar [http://127.0.0.1:8000/foto](http://127.0.0.1:8000/foto). Je ziet je afbeelding.

:::danger[Gaat er iets mis?]
Afbeelding laadt niet? Controleer of:
1. De afbeelding echt in de `static`-map staat
2. De bestandsnaam precies klopt, ook de hoofdletters en de extensie. Windows verbergt de extensie vaak: dan heet je bestand `kat.jpg.jpg` of `kat.webp` terwijl je `kat.jpg` ziet. In de Verkenner van VS Code zie je de echte naam.
3. `app.mount("/static", ...)` in je code staat

Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

<summary>Zo ziet je `main.py` er nu uit</summary>

Dit is je hele `main.py` na deze les, zonder wat je in de opdrachten maakte.

```python
from fastapi import FastAPI
from fastapi.responses import FileResponse, HTMLResponse
from fastapi.staticfiles import StaticFiles

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.get("/")
async def home():
    return FileResponse("static/pages/home.html")

@app.get("/info")
async def info():
    return {"naam": "Jouw Naam", "leeftijd": 16}

@app.get("/pagina", response_class=HTMLResponse)
async def pagina():
    return """
    <!DOCTYPE html>
    <html>
        <head>
            <title>Mijn Pagina</title>
        </head>
        <body>
            <h1>Hallo!</h1>
            <p>Dit is mijn eerste HTML pagina.</p>
        </body>
    </html>
    """

@app.get("/styled", response_class=HTMLResponse)
async def styled():
    return """
    <!DOCTYPE html>
    <html>
        <head>
            <title>Met CSS</title>
            <style>
                h1 { color: blue; }
                p { color: gray; }
            </style>
        </head>
        <body>
            <h1>Gestylede pagina</h1>
            <p>Deze tekst is grijs.</p>
        </body>
    </html>
    """

@app.get("/about")
async def about():
    return FileResponse("static/pages/about.html")

DIEREN = {
    "kat": "Een kat spint als hij tevreden is.",
    "hond": "Een hond kwispelt als hij blij is.",
    "vis": "Een vis ademt met kieuwen.",
}

@app.get("/dier/{naam}", response_class=HTMLResponse)
async def dier(naam: str):
    tekst = DIEREN.get(naam, "Dit dier staat nog niet op de site.")
    return f"""
    <!DOCTYPE html>
    <html>
        <body>
            <h1>Over dieren</h1>
            <p>{tekst}</p>
            <a href="/">Terug naar Home</a>
        </body>
    </html>
    """

@app.get("/zoek")
async def zoek(term: str):
    return {"je_zocht": term}

@app.get("/foto")
async def foto():
    return FileResponse("static/pages/foto.html")
```

## Opdrachten

### Opdracht 1: Predict - Wat zie je?

```html
<img src="/static/logo.png" alt="Logo">
```

**Vraag:** Wat zie je als `logo.png` niet bestaat in de static folder?

<details>
<summary>Tip</summary>

De browser kan de afbeelding niet laden. Waarvoor is het `alt` attribuut bedoeld?

</details>

<details>
<summary>Antwoord</summary>

Je ziet de alt-tekst "Logo" en het icoon van een kapotte afbeelding. De pagina laadt wel, de afbeelding niet.

</details>

### Opdracht 2: Run

Ga naar `http://127.0.0.1:8000/static/kat.jpg`. Zie je alleen de afbeelding, zonder pagina eromheen? Dan geeft `app.mount` het bestand goed door. Ga daarna naar `/foto`: staat hij nu op je pagina, onder de kop?

### Opdracht 3: Investigate - Zonder alt

Wat zie je als je het `alt` attribuut weglaat en het bestand niet bestaat? Probeer het uit.

```html
<img src="/static/bestaat_niet.jpg">
```

<details>
<summary>Antwoord</summary>

Je ziet alleen het icoon van een kapotte afbeelding, zonder tekst. Met `alt` lees je tenminste nog wat er had moeten staan, dus zet hem er altijd bij.

</details>

Zet een afbeelding in je `static`-map en maak een pagina die hem laat zien.

<details>

### Opdracht 5: Make - Fotogalerij

Maak een pagina met drie afbeeldingen onder elkaar. Geef elke afbeelding een titel met een `<h3>` tag erboven.

<details>
<summary>Tip</summary>

Zet drie afbeeldingen in je `static`-map. Gebruik voor elke foto een `<h3>` gevolgd door een `<img>` tag.

</details>

<details>
<summary>Antwoord</summary>

`static/pages/galerij.html`:
```html
<!DOCTYPE html>
<html>
    <body>
        <h1>Mijn Fotogalerij</h1>

        <h3>Foto 1</h3>
        <img src="/static/foto1.jpg" alt="Eerste foto">

        <h3>Foto 2</h3>
        <img src="/static/foto2.jpg" alt="Tweede foto">

        <h3>Foto 3</h3>
        <img src="/static/foto3.jpg" alt="Derde foto">
    </body>
</html>
```

```python
@app.get("/galerij")
async def galerij():
    return FileResponse("static/pages/galerij.html")
```
