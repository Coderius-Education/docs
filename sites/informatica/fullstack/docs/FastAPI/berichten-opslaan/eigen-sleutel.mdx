# Elk bericht bewaren: een eigen sleutel

In [Een formulier opslaan](/docs/FastAPI/berichten-opslaan/naam-opslaan) overschreef elke naam de vorige, want ze gingen allemaal onder de sleutel `laatste_naam`. Voor een gastenboek wil je elk bericht bewaren. Dan heeft elk bericht een eigen sleutel nodig.

## Een nieuwe sleutel per bericht

`time.time_ns()` geeft het aantal nanoseconden sinds 1970: bij elk bericht een ander getal, dus een nieuwe sleutel. Dit gastenboek bouw je in de volgende lessen verder uit, dus maak het echt.

### Formulier (`static/pages/gastenboek_form.html`)

```html
<!DOCTYPE html>
<html>
    <body>
        <h1>Gastenboek</h1>
        <form method="post" action="/gastenboek">
            <input type="text" name="naam" placeholder="Je naam" required>
            <input type="text" name="bericht" placeholder="Je bericht" required>
            <button type="submit">Verstuur</button>
        </form>
    </body>
</html>
```

### Endpoints (`main.py`, onder de endpoints van de naam)

Zet `import time` bovenaan je `main.py`, bij de andere imports.

<CodeUitleg>

```python showLineNumbers
@app.get("/gastenboek")
async def gastenboek_form():
    return FileResponse("static/pages/gastenboek_form.html")

@app.post("/gastenboek")
async def gastenboek_opslaan(naam: str = Form(...), bericht: str = Form(...)):
    with SqliteDict("gastenboek.db") as db:
        sleutel = f"bericht_{time.time_ns()}"
        db[sleutel] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"bericht": "Bedankt voor je bericht"}

@app.get("/berichten")
async def berichten():
    with SqliteDict("gastenboek.db") as db:
        alle_berichten = list(db.values())
    return {"berichten": alle_berichten}
```

<Regel n={8}>
Zo krijgt elk bericht een nieuwe sleutel, zoals `bericht_1767225600123456789`, en overschrijven twee berichten elkaar niet meer.
</Regel>

<Regel n={9}>
De waarde is een dictionary met beide velden, zoals in [Een dictionary als waarde](/docs/FastAPI/sqlitedict/dictionary).
</Regel>

<Regel n={16}>
`db.values()` geeft alle waarden, zonder sleutels, maar haalt ze pas op als iets erdoorheen loopt. `list()` doet dat meteen, binnen het `with`-blok. Zonder `list()` loopt FastAPI er pas doorheen als hij de JSON maakt, en dan is de database al dicht: je krijgt `AttributeError: 'NoneType' object has no attribute 'select'`.
</Regel>

</CodeUitleg>

:::caution
Gebruik `time.time_ns()` (nanoseconden) en niet `int(time.time())` (hele seconden). Twee berichten die binnen dezelfde seconde binnenkomen, krijgen anders dezelfde sleutel, en dan overschrijft het tweede het eerste.
:::

## Het gastenboek testen

1. Ga naar `http://127.0.0.1:8000/gastenboek` en verstuur twee berichten.
2. Ga naar `http://127.0.0.1:8000/berichten`. Je ziet ze allebei, als JSON.
3. Stop de server, start hem opnieuw en kijk nog een keer: ze staan er nog.

:::danger[Gaat er iets mis?]
Blijft je data niet bewaard? Kijk dan of je `db.commit()` niet bent vergeten. Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

## Opdrachten

### Opdracht 1: Predict - Hoeveel berichten?

Iemand haalt `time.time_ns()` weg en schrijft `sleutel = "bericht"`. Daarna verstuurt iemand drie berichten. Wat laat `/berichten` zien?

<details>
<summary>Tip</summary>

Hoeveel verschillende sleutels zijn er dan?

</details>

<details>
<summary>Antwoord</summary>

Eén bericht: het laatste. Alle drie gaan onder de sleutel `bericht`, dus elk nieuw bericht overschrijft het vorige.

</details>

### Opdracht 2: Run

Maak het gastenboek uit deze les. Test of de berichten bewaard blijven door de server te stoppen en opnieuw te starten.

### Opdracht 3: Investigate - Wat staat er echt in?

Laat `/berichten` ook de sleutels zien: vervang `list(db.values())` door `list(db.items())`. Wat verandert er in de JSON?

<details>
<summary>Antwoord</summary>

Elk bericht wordt een paar: eerst de sleutel, dan de dictionary, zoals `["bericht_1767225600123456789", {"naam": "Sam", "bericht": "Hoi"}]`. Aan de getallen zie je in welke volgorde de berichten binnenkwamen. De sleutel heb je later nodig om één bericht aan te wijzen.

</details>

### Opdracht 4: Make - Hoeveel berichten

Maak een endpoint `/aantal` dat teruggeeft hoeveel berichten er in het gastenboek staan: `{"aantal":3}`.

<details>
<summary>Tip</summary>

`len(db)` geeft het aantal sleutels in de database, net als bij een dictionary.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.get("/aantal")
async def aantal():
    with SqliteDict("gastenboek.db") as db:
        hoeveel = len(db)
    return {"aantal": hoeveel}
```

</details>

Na het versturen sta je nu op een pagina met alleen `{"bericht":"Bedankt voor je bericht"}`. In [Doorsturen na opslaan (redirect)](/docs/FastAPI/berichten-opslaan/redirect) kom je daarna vanzelf bij de berichten uit.
