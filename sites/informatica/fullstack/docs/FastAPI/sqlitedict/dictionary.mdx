# Een dictionary als waarde

Onder elke sleutel stond tot nu toe één ding: een naam, een getal. Een bericht in een gastenboek heeft meer: wie het schreef en wat er staat. Die zet je samen onder één sleutel, als dictionary. Zo blijft bij elkaar wat bij elkaar hoort.

## Een dictionary opslaan

Vervang de inhoud van `proef_db.py` door:

<CodeUitleg>

```python showLineNumbers
from sqlitedict import SqliteDict

with SqliteDict("mijn_data.db") as db:
    db["sara"] = {"klas": "4B", "vakken": ["informatica", "wiskunde"]}
    db.commit()

with SqliteDict("mijn_data.db") as db:
    sara = db["sara"]
    print(sara["klas"])
    print(sara["vakken"])
```

<Regel n={4}>
De waarde onder `"sara"` is een dictionary, met daarin zelfs een lijst. SqliteDict bewaart hem zoals hij is.
</Regel>

<Regel n={8}>
Bij het uitlezen krijg je hem terug als dictionary.
</Regel>

<Regel n={9} tot={10}>
Een veld haal je eruit zoals bij elke dictionary.
</Regel>

</CodeUitleg>

Uitvoer:

```
4B
['informatica', 'wiskunde']
```

Het kan ook in één keer: `db["sara"]["klas"]` haalt eerst de dictionary van Sara uit de database en daarna het veld `klas` uit die dictionary.

Draai ook `bekijk_db.py`. Daar staat Sara op één regel, naast de sleutels die je al had:

```
sara = {'klas': '4B', 'vakken': ['informatica', 'wiskunde']}
```

## Er gaat iets mis

### KeyError met de naam van een veld

```
KeyError: 'naam'
```

**Oorzaak:** de sleutel bestaat wel, maar het veld in de dictionary niet. `db["sara"]["naam"]` vraagt om een veld `naam`, en de dictionary van Sara heeft alleen `klas` en `vakken`.

**Oplossing:** kijk met `bekijk_db.py` welke velden er echt in staan. Ontbreekt een veld soms, gebruik dan `get` op de dictionary: `sara.get("naam", "onbekend")`.

### TypeError: string indices must be integers

```
TypeError: string indices must be integers, not 'str'
```

**Oorzaak:** onder de sleutel staat tekst, geen dictionary. `db["naam"]["klas"]` haalt eerst `"Jan"` op, en vraagt daarna aan die tekst om een veld `klas`. Een stuk tekst heeft geen velden.

**Oplossing:** kijk met `bekijk_db.py` wat er onder de sleutel staat. Alleen waar `{…}` achter de `=` staat, kun je een veld opvragen.

Test jezelf met dit script:

```python
from sqlitedict import SqliteDict

with SqliteDict("mijn_data.db") as db:
    db["ali"] = {"klas": "4A"}
    db["ali"] = {"vakken": ["biologie"]}
    db.commit()
```

## Opdrachten

### Opdracht 1: Predict - Wat telt len?

```python
from sqlitedict import SqliteDict

with SqliteDict("klas.db") as db:
    db["sara"] = {"klas": "4B", "vakken": ["informatica", "wiskunde"]}
    db["ali"] = {"klas": "4A", "vakken": ["biologie"]}
    db.commit()

with SqliteDict("klas.db") as db:
    print(len(db))
    print(db["ali"]["klas"])
    print(len(db["sara"]["vakken"]))
```

<Voorspel vraag="Welke drie regels print dit, van boven naar beneden?">
  <Keuze uitleg="len(db) telt de sleutels van de database, niet de velden in de dictionaries.">`4` · `4A` · `2`</Keuze>
  <Keuze uitleg="De laatste regel gaat over Sara, niet over Ali. Hoeveel vakken staan er in haar lijst?">`2` · `4A` · `1`</Keuze>
  <Keuze uitleg='Met db["ali"] krijg je de hele dictionary, maar daarachter vraag je nog één veld op.'>`2` · `{'klas': '4A', 'vakken': ['biologie']}` · `2`</Keuze>
  <Keuze goed uitleg="Twee sleutels in de database, het veld klas van Ali, en twee vakken in de lijst van Sara.">`2` · `4A` · `2`</Keuze>
  <Uitleg>

  `len` telt wat er direct in zit. Bij de database zijn dat de sleutels `sara` en `ali`; bij een lijst de dingen in die lijst.

### Opdracht 3: Investigate - Welke KeyError?

Verander in `proef_db.py` de regel `print(sara["klas"])` in `print(sara["Klas"])` en draai het. Zet hem terug, verander daarna `sara = db["sara"]` in `sara = db["Sara"]` en draai het weer. Beide keren krijg je een `KeyError`. Kijk naar de regels erboven: waaraan zie je of de database of de dictionary de sleutel niet vond?

<details>
<summary>Tip</summary>

Een foutmelding noemt elk bestand waar Python doorheen ging, van boven naar onder.

</details>

<details>
<summary>Antwoord</summary>

Bij `KeyError: 'Klas'` noemt de foutmelding alleen je eigen `proef_db.py`: de dictionary van Sara heeft geen veld `Klas`. Bij `KeyError: 'Sara'` staat er onder je eigen regel nog een regel uit `sqlitedict.py`, met `raise KeyError(key)`: SqliteDict zocht in de database en vond geen sleutel `Sara`. Zet beide regels daarna weer terug.

</details>

### Opdracht 4: Make - Huisdieren

Maak `huisdieren_opslaan.py` dat twee huisdieren opslaat in `huisdieren.db`. De naam is de sleutel, en de waarde een dictionary met de soort en de leeftijd. Maak daarna `huisdieren_lezen.py` dat per dier één regel print, zoals `Max is een hond van 3 jaar`.

<details>
<summary>Tip</summary>

Voor het lezen loop je met `db.items()` door de database. Elke waarde is een dictionary, dus daaruit haal je de soort en de leeftijd.

</details>

<details>
<summary>Antwoord</summary>

`huisdieren_opslaan.py`:

```python
from sqlitedict import SqliteDict

with SqliteDict("huisdieren.db") as db:
    db["Max"] = {"soort": "hond", "leeftijd": 3}
    db["Pluis"] = {"soort": "kat", "leeftijd": 7}
    db.commit()
```

`huisdieren_lezen.py`:

```python
from sqlitedict import SqliteDict

with SqliteDict("huisdieren.db") as db:
    for naam, dier in db.items():
        print(f"{naam} is een {dier['soort']} van {dier['leeftijd']} jaar")
```

Uitvoer:

```
Max is een hond van 3 jaar
Pluis is een kat van 7 jaar
```

</details>
