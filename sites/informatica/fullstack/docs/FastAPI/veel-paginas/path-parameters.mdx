# Eén route voor veel pagina's: path-parameters

Je gastenboek heeft voor elke pagina een eigen route: `/gastenboek` voor het formulier, `/berichten` voor de lijst. Straks krijgt ook elk bericht een eigen pagina, en dat zijn er zoveel als er berichten zijn. Daarvoor heb je één route nodig die veel pagina's maakt. Je oefent dat eerst met iets kleins: een site over dieren, met een pagina per dier.

### Een route per dier

Met een route per dier zou het zo beginnen:

<Bestand pad="main.py" />

{/* niet-compileren: drie losse routes als voorbeeld van het probleem, niet om over te nemen */}
```python
@app.get("/kat")
async def kat(request: Request):
    return templates.TemplateResponse(request, "dier.html", {"tekst": "Een kat spint als hij tevreden is."})

@app.get("/hond")
async def hond(request: Request):
    return templates.TemplateResponse(request, "dier.html", {"tekst": "Een hond kwispelt als hij blij is."})

@app.get("/vis")
async def vis(request: Request):
    return templates.TemplateResponse(request, "dier.html", {"tekst": "Een vis ademt met kieuwen."})
```

Deze drie hoef je niet over te nemen. Ze laten zien waar het knelt: drie functies die bijna hetzelfde doen. Alleen het stuk achter de `/` en de zin verschillen. Bij vijftig dieren schrijf je vijftig functies.

## Eén route met een plekhouder

Zet dit endpoint onder je andere endpoints:

<Bestand pad="main.py" />

```python
@app.get("/dier/{naam}")
async def dier(naam: str):
    return {"je_vroeg_om": naam}
```

Ga naar [http://127.0.0.1:8000/dier/kat](http://127.0.0.1:8000/dier/kat). Je krijgt `{"je_vroeg_om":"kat"}`. Op `/dier/olifant` krijg je `{"je_vroeg_om":"olifant"}`.

`{naam}` tussen accolades is een plekhouder in het pad: een **path-parameter**. Wat er in de URL op die plek staat, komt binnen als de parameter met dezelfde naam, net zoals een formulierveld binnenkomt bij de parameter met `Form(...)`. Eén route vangt zo elk adres dat begint met `/dier/`.

## De tekst opzoeken

Wat per dier verschilt, zet je in een dictionary, met de naam uit de URL als sleutel. De pagina zelf is een template. Maak in de map `templates` het bestand `dier.html`:

<Bestand pad="templates/dier.html" />

```html
<!DOCTYPE html>
<html>
    <body>
        <h1>Over dieren</h1>
        <p>{{ tekst }}</p>
        <a href="/">Terug naar Home</a>
    </body>
</html>
```

### Het endpoint met de dictionary

Vervang je endpoint door deze versie, met de dictionary erboven:

<Bestand pad="main.py" />

<CodeUitleg>

{/* route-dubbel: vervangt de eerste versie van GET /dier/{naam} hierboven */}
```python showLineNumbers
DIEREN = {
    "kat": "Een kat spint als hij tevreden is.",
    "hond": "Een hond kwispelt als hij blij is.",
    "vis": "Een vis ademt met kieuwen.",
}

@app.get("/dier/{naam}")
async def dier(request: Request, naam: str):
    tekst = DIEREN.get(naam, "Dit dier staat nog niet op de site.")
    return templates.TemplateResponse(
        request,
        "dier.html",
        {"tekst": tekst}
    )
```

<Regel n={1} tot={5}>
De dictionary `DIEREN` staat buiten de functie, vlak boven het endpoint. Een dier erbij is één regel erbij.
</Regel>

<Regel n={8}>
`request` heeft de template nodig, net als bij je andere templates. De volgorde maakt niet uit: FastAPI koppelt op naam.
</Regel>

<Regel n={9}>
`DIEREN.get(naam, …)` geeft de zin bij `naam`, zoals `get` bij de database in [Bestaat de sleutel? in en get](site:fullstack/docs/FastAPI/sqlitedict/zoeken#korter-met-get). Staat `naam` niet in de dictionary, dan krijg je de tekst na de komma.
</Regel>

<Regel n={10} tot={14}>
Eén template voor alle dieren: alleen `{{ tekst }}` verschilt per verzoek.
</Regel>

</CodeUitleg>

Zet in de pagina de zin uit je eigen dictionary. Wat in de URL staat, typt de bezoeker, en dat kan ook HTML zijn. Een template zet het met `{{ }}` veilig als tekst neer; waarom dat nodig is, zie je later in de route Veiligheid, bij [HTML van een bezoeker: tekst uit de URL](site:fullstack/docs/veiligheid/xss/url).

## Testen

1. Ga naar `/dier/kat`, `/dier/hond` en `/dier/vis`. Elk dier krijgt zijn eigen zin, uit één functie en één template.
2. Ga naar `/dier/olifant`. Je ziet "Dit dier staat nog niet op de site."
3. Ga naar `/dier/Kat`, met een hoofdletter. Ook dat dier kent je site niet: een sleutel telt elke letter mee.

Hoe je zelf een 404 stuurt voor iets dat er niet is, leer je later, in [Een 404 sturen: als het item niet bestaat](site:fullstack/docs/FastAPI/berichten-tonen/niet-gevonden). Daarmee kun je ook `/dier/olifant` een nette 404 geven.

## Er gaat iets mis

Schrijf je `DIEREN[naam]` in plaats van `DIEREN.get(naam, …)`, dan werkt `/dier/kat` wel. Maar `/dier/olifant` geeft `Internal Server Error`, met de statuscode 500, en in je terminal staat:

```
KeyError: 'olifant'
```

Het is dezelfde fout als bij `db[...]` met een sleutel die er niet is, in [Bestaat de sleutel? in en get](site:fullstack/docs/FastAPI/sqlitedict/zoeken). `get` geeft bij een onbekende sleutel de tekst na de komma, en je server blijft heel.

from fastapi.staticfiles import StaticFiles

app = FastAPI()

async def home():

        </head>
        <body>
            <h1>Hallo!</h1>
            <p>Dit is mijn eerste HTML pagina.</p>
        </body>
    </html>
    """

@app.get("/styled", response_class=HTMLResponse)
async def styled():
    return """
    <!DOCTYPE html>
    <html>

            <style>
                h1 { color: blue; }
                p { color: gray; }
            </style>
        </head>
        <body>
            <h1>Gestylede pagina</h1>
            <p>Deze tekst is grijs.</p>
        </body>
    </html>
    """

@app.get("/about")

@app.get("/foto")
async def foto():

@app.get("/dobbelsteen")

    return templates.TemplateResponse(

@app.get("/naam")
async def toon_formulier():

async def ontvang_naam(naam: str = Form(...)):
    print(f"Naam ontvangen: {naam}")
    return {"bericht": f"Hallo {naam}!"}

@app.get("/groet")
async def groet_form():
    return FileResponse("static/pages/groet_form.html")

@app.post("/groet")
async def groet_verwerk(request: Request, naam: str = Form(...)):
    return templates.TemplateResponse(
        request,
        "groet_resultaat.html",

@app.get("/opslaan")
async def naam_formulier():
    return FileResponse("static/pages/naam_opslaan.html")

@app.post("/opslaan")
async def naam_opslaan(naam: str = Form(...)):
    with SqliteDict("namen.db") as db:
        db["laatste_naam"] = naam
        db.commit()

    return {"bericht": f"'{naam}' opgeslagen!"}

@app.get("/toon_naam")
async def toon_naam():
    with SqliteDict("namen.db") as db:
        naam = db.get("laatste_naam", "Nog niets opgeslagen")
    return {"naam": naam}

@app.get("/gastenboek")
async def gastenboek_form():
    return FileResponse("static/pages/gastenboek_form.html")

@app.post("/gastenboek")
async def gastenboek_opslaan(naam: str = Form(...), bericht: str = Form(...)):
    with SqliteDict("gastenboek.db") as db:
        sleutel = f"bericht_{time.time_ns()}"
        db[sleutel] = {"naam": naam, "bericht": bericht}
        db.commit()
    return RedirectResponse(url="/berichten", status_code=303)

@app.get("/berichten")
async def berichten():
    with SqliteDict("gastenboek.db") as db:
        alle_berichten = list(db.values())
    return {"berichten": alle_berichten}

### Opdracht 2: Run

Maak de dictionary `DIEREN` en het endpoint `/dier/{naam}`. Zet er een vierde dier bij, zonder een nieuwe functie. Krijgt het op `/dier/<jouw dier>` meteen een eigen pagina?

### Opdracht 3: Investigate - Andere naam

Verander de parameter in je functie van `naam` naar `dier_naam`, maar laat `{naam}` in het pad staan:

<Bestand pad="main.py" />

{/* niet-compileren: losse handler-signature, toont juist de mismatch */}
```python
@app.get("/dier/{naam}")
async def dier(request: Request, dier_naam: str):
```

Verander `DIEREN.get(naam, …)` ook in `DIEREN.get(dier_naam, …)`. Wat zie je op `/dier/kat`?

<details>
<summary>Antwoord</summary>

Je browser toont een weigering met `"loc":["query","dier_naam"]` en `"msg":"Field required"`, en in je terminal staat de statuscode 422.

FastAPI koppelt op naam, niet op volgorde. Het ziet `{naam}` in het pad en zoekt een parameter die zo heet; die is er niet. Tegelijk vraagt je functie om `dier_naam`, en dat staat nergens in het pad. Daarom vraagt FastAPI erom na een vraagteken in de URL: `/dier/kat?dier_naam=hond` toont de zin over de hond. Dat is niet wat je bedoelde. Zet beide namen weer gelijk.

</details>

### Opdracht 4: Investigate - Zonder naam

Wat krijg je op `/dier`, zonder `/` en zonder naam erachter? En op `/dier/kat/hond`?

<details>
<summary>Antwoord</summary>

Allebei `{"detail":"Not Found"}`, een 404. De route `/dier/{naam}` past alleen op een adres met precies één stuk na `/dier/`. Bij `/dier` ontbreekt dat stuk, en bij `/dier/kat/hond` zijn het er twee. Geen enkel endpoint past, dus FastAPI stuurt zelf een 404.

</details>

### Opdracht 6: Make - Een titel per dier

Geef elk dier een eigen kop in plaats van "Over dieren": `De kat`, `De hond`, `De vis`. Zet de kop en de zin samen onder de naam van het dier in `DIEREN`, en laat `dier.html` allebei tonen.

<details>
<summary>Tip</summary>

Maak van elke waarde in `DIEREN` een dictionary met twee sleutels, zoals in [Een dictionary als waarde](site:fullstack/docs/FastAPI/sqlitedict/dictionary). Ook de tekst na de komma bij `get` wordt dan een dictionary. In de template haal je een sleutel op met een punt: `{{ info.titel }}`.

</details>

<details>
<summary>Antwoord</summary>

<Bestand pad="main.py" />

{/* route-dubbel: vervangt GET /dier/{naam} hierboven, in een opdracht */}
```python
DIEREN = {
    "kat": {"titel": "De kat", "tekst": "Een kat spint als hij tevreden is."},
    "hond": {"titel": "De hond", "tekst": "Een hond kwispelt als hij blij is."},
    "vis": {"titel": "De vis", "tekst": "Een vis ademt met kieuwen."},
}

@app.get("/dier/{naam}")
async def dier(request: Request, naam: str):
    info = DIEREN.get(naam, {"titel": "Onbekend dier", "tekst": "Dit dier staat nog niet op de site."})
    return templates.TemplateResponse(
        request,
        "dier.html",
        {"info": info}
    )
```

<Bestand pad="templates/dier.html" />

```html
<!DOCTYPE html>
<html>
    <body>
        <h1>{{ info.titel }}</h1>
        <p>{{ info.tekst }}</p>
        <a href="/">Terug naar Home</a>
    </body>
</html>
```

De template krijgt nu één naam, `info`, met twee sleutels erin. Een dier erbij is nog steeds één regel in `DIEREN`.
