# Unplugged

In een webproject werken browser, server en database samen, en dat zie je
niet gebeuren. Op papier wel. Elke hand-out hieronder print je, speel je met
een paar klasgenoten na, en kijk je na met het antwoordblad.

| Hand-out | Je oefent | Na de les |
|---|---|---|
| [Het verzoek-rollenspel](site:fullstack/docs/unplugged/verzoek-rollenspel) | één klik is vaak meer dan één verzoek | [Doorsturen na opslaan (redirect)](site:fullstack/docs/FastAPI/berichten-opslaan/redirect) |
| [Welke route antwoordt?](site:fullstack/docs/unplugged/welke-route) | welke functie bij een verzoek hoort, en wanneer het `404`, `405` of `422` wordt | [Een waarde na een vraagteken](site:fullstack/docs/FastAPI/veel-paginas/query-parameters) |
| [Welke taal, waar?](site:fullstack/docs/unplugged/welke-taal-waar) | wat op de server draait en wat in de browser | [Templates met Jinja2](site:fullstack/docs/FastAPI/formulieren/templates) |
| [Volg de naam](site:fullstack/docs/unplugged/volg-de-naam) | dezelfde naam in formulier, functie, dictionary en template | [Een formulier beantwoorden met een template](site:fullstack/docs/FastAPI/formulieren/post_met_templates) |
| [Template invullen](site:fullstack/docs/unplugged/template-invullen) | wat Jinja van `{{ }}`, `{% for %}` en `{% if %}` maakt | [Nog niets? if en else in je template](site:fullstack/docs/FastAPI/berichten-tonen/leeg) |
| [Een postbode zonder geheugen](site:fullstack/docs/unplugged/postbode) | waarom een server een cookie en een sessie nodig heeft | [Cookie of sessie?](site:fullstack/docs/FastAPI/onthouden/cookie-of-sessie) |
| [Vertrouw de bezoeker niet](site:fullstack/docs/unplugged/vertrouw-de-bezoeker) | welke controle op de server hoort | [Wie mag wat: een knop is geen slot](site:fullstack/docs/veiligheid/toegang/zwakheid) |
