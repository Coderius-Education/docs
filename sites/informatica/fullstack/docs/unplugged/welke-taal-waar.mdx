# Welke taal, waar?

<Handout>

In een webproject staan vier talen door elkaar: Python, HTML met Jinja, CSS
en JavaScript. Ze draaien niet op dezelfde plek. Een deel draait op de
server, een deel in de browser van de bezoeker, en Jinja zit ertussenin. Wie
weet waar een regel draait, weet ook wat hij wel en niet kan.

## Wat je nodig hebt

- Per tweetal een geprinte hand-out, een schaar en een pen.
- De stroken staan op het knipblad, de laatste pagina. Print die enkelzijdig
  of los, anders knip je door wat er op de achterkant staat.
- Ongeveer 20 minuten.

## Bespreek na

**Sorteren.**

| Strook | Waar |
|---|---|
| 1 `@app.get("/berichten")` | server |
| 2 `with SqliteDict("gastenboek.db") as db:` | server |
| 3 `{% for sleutel, bericht in berichten %}` | de server vult het in |
| 4 `<li>{{ bericht.naam }}</li>` | de server vult het in |
| 5 `<form method="post" action="/gastenboek">` | browser |
| 6 `h1 { color: darkblue; }` | browser |
| 7 `teller.textContent = 80 - veld.value.length;` | browser |
| 8 `return RedirectResponse(url="/berichten", status_code=303)` | server |
| 9 `<link rel="stylesheet" href="/static/css/style.css">` | browser |
| 10 `veld.addEventListener("input", tel);` | browser |
| 11 `{% if berichten %}` | de server vult het in |
| 12 `naam: str = Form(...)` | server |

**Wat ziet de bezoeker?** 5, 6, 7, 9 en 10: HTML, CSS en JavaScript gaan
zoals ze zijn naar de browser. Van strook 4 ziet hij alleen het resultaat,
bijvoorbeeld `<li>Sam</li>`. Jinja-regels als 3 en 11 komen er nooit aan, en
Python ook niet.

Zo vult de server strook 3, 4 en 11 in, en dit is alles wat de browser krijgt:

```python
from jinja2 import Template

template = Template("{% if berichten %}{% for sleutel, bericht in berichten %}<li>{{ bericht.naam }}</li>{% endfor %}{% endif %}")
print(template.render(berichten=[("bericht_1", {"naam": "Sam"})]))   # <li>Sam</li>
```

**Waar hoort het?** 1 browser (JavaScript), 2 server, 3 server, 4 browser
(CSS), 5 server (Jinja vult de lijst in).

**Bespreek na.** Vraag 1: de `{{ }}` is van Jinja, en Jinja draait op de
server. De browser krijgt de `<li>` pas als de naam al is ingevuld. Vraag 2:
nee. De database staat op de computer van de server, en de browser krijgt
alleen wat de server stuurt. Vraag 3: `maxlength` staat in de browser, en
alles in de browser kan de bezoeker veranderen of overslaan. Een controle die
moet gelden, hoort op de server.
