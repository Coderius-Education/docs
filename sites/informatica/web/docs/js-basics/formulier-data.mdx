In [Formulieren](site:web/docs/html-css/formulieren) bouwde je een formulier, maar typen leverde nog niets op. Met JavaScript lees je de ingevulde tekst uit via de eigenschap **`.value`**.

### Lees het veld

Voor een feest vraagt een formulier hoeveel gasten er komen, in een `<input type="number" id="gasten">`. Een klik op de knop roept de functie `telStoelen` aan:

```js
function telStoelen() {
  const gasten = document.getElementById('gasten').value;
  document.getElementById('uitvoer').textContent = gasten;
}
```

`gasten` bevat wat de gebruiker typte. Typ je 6 en klik je op de knop, dan staat er `6` op de pagina. Maar je zit er zelf ook bij: er zijn zeven stoelen nodig.

### Tel erbij op

Wie het feest geeft, zit zelf ook aan tafel. De gemarkeerde regel is veranderd: de functie telt 1 bij het aantal gasten op, voor die ene stoel extra.

```js {3}
function telStoelen() {
  const gasten = document.getElementById('gasten').value;
  document.getElementById('uitvoer').textContent = gasten + 1;
}
```

Bij 6 gasten staat er `61` op de pagina, geen 7. `.value` is altijd een **string**, ook bij een `<input type="number">`, en `+` plakt een string en een getal aan elkaar.

### Zet om met Number

Rekenen met invoer gaat via `Number()`, zoals bij `prompt()`. De gemarkeerde regel is veranderd: `Number()` staat om de hele uitdrukking die het veld uitleest.

```js {2}
function telStoelen() {
  const gasten = Number(document.getElementById('gasten').value);
  document.getElementById('uitvoer').textContent = gasten + 1;
}
```

Bij 6 gasten staat er nu `7` op de pagina.

## Voor welke velden werkt dit?

| Element | Wat `.value` teruggeeft |
|---|---|
| `<input type="text">` | De getypte tekst |
| `<input type="number">` | De getypte tekst (nog steeds een string) |
| `<textarea>` | De inhoud van het tekstvak |
| `<select>` | De `value` van de gekozen `<option>` |

## Predict

Dit is de functie uit de startcode van het oefenveld; hij draait als je op de knop klikt. Beantwoord de vraag **voordat** je de code draait.

```js
function begroet() {
  const naam = document.getElementById('naam').value;
  const leeftijd = Number(document.getElementById('leeftijd').value);

  const bericht = 'Hoi ' + naam + '. Over 10 jaar ben je ' + (leeftijd + 10) + ' jaar.';
  document.getElementById('uitvoer').textContent = bericht;
}
```

## Er gaat iets mis

**Number-veld vergeten te converteren**

```js
const a = document.getElementById('getal1').value;  // string
const b = document.getElementById('getal2').value;  // string
console.log(a + b);  // '5' + '3' wordt '53', niet 8
```

`.value` is **altijd een string**, ook bij `<input type="number">`. Zonder `Number(...)` plakt `+` de waarden aan elkaar in plaats van op te tellen — dezelfde val als bij `prompt()`. Wikkel `Number()` om elke numerieke invoer:

```js
const a = Number(document.getElementById('getal1').value);
const b = Number(document.getElementById('getal2').value);
console.log(a + b);  // 8
```
