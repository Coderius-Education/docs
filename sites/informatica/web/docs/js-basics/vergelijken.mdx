Een vergelijking is een vraag met twee mogelijke antwoorden: `true` of `false`.

### Stel de vraag

In een achtbaan mag je alleen als je minstens 140 centimeter lang bent. De vergelijking `lengte >= 140` stelt die vraag: `>=` betekent groter dan of gelijk aan.

```js
const lengte = 150;
console.log(lengte >= 140);
```

De console logt `true`: 150 is lang genoeg. Het antwoord staat alleen in de console. Verderop in je code kun je er niets mee.

### Bewaar het antwoord

Het antwoord op een vergelijking is een **boolean**, en je kunt hem opslaan als elke andere waarde. De gemarkeerde regels zijn nieuw of veranderd: het antwoord gaat eerst naar de variabele `langGenoeg`, en de console logt die variabele.

```js {2-3}
const lengte = 150;
const langGenoeg = lengte >= 140;
console.log(langGenoeg);
```

De console logt nog steeds `true`. De achtbaan heeft een tweede regel: je moet ook 12 jaar of ouder zijn. Daar kijkt de code niet naar.

### Stel twee vragen

Met **`&&`** (en) combineer je twee vergelijkingen: het geheel is alleen `true` als beide kanten waar zijn. De gemarkeerde regels zijn nieuw of veranderd: een leeftijd, en de variabele `magErin`, die ook naar die leeftijd kijkt.

```js {2,4-5}
const lengte = 150;
const leeftijd = 11;
const langGenoeg = lengte >= 140;
const magErin = langGenoeg && leeftijd >= 12;
console.log(magErin);
```

De console logt `false`: lang genoeg, maar te jong. Met **`||`** (of) is één kant al genoeg: `langGenoeg || leeftijd >= 12` is hier `true`. Met **`!`** (niet) draai je een boolean om: `!magErin` is `true`.

## Vergelijkingsoperatoren

| Operator | Wat het doet | Voorbeeld |
|---|---|---|
| `===` | Gelijk aan | `5 === 5` is `true` |
| `!==` | Niet gelijk aan | `'a' !== 'b'` is `true` |
| `>` | Groter dan | `5 > 3` is `true` |
| `<` | Kleiner dan | `5 < 3` is `false` |
| `>=` | Groter of gelijk | `5 >= 5` is `true` |
| `<=` | Kleiner of gelijk | `5 <= 3` is `false` |

Het type telt mee: `5 === '5'` is `false`, want een number en een string zijn niet gelijk.

## Predict

Dit is de functie uit de startcode van het oefenveld; hij draait als je op de knop klikt. Beantwoord de vraag **voordat** je de code draait.

```js
function check() {
  const leeftijd = Number(prompt('Hoe oud ben je?'));
  const meerderjarig = leeftijd >= 18;
  document.getElementById('uitvoer').textContent = 'Meerderjarig: ' + meerderjarig;
  console.log('leeftijd is', leeftijd, 'en meerderjarig is', meerderjarig);
}
```

## Er gaat iets mis

**`==` lijkt te werken, maar verrast**

```js
console.log('5' == 5);    // true - huh?
console.log('5' === 5);   // false
```

Naast `===` bestaat ook `==`. Die zet de waarden eerst stiekem om naar hetzelfde type, waardoor een string ineens "gelijk" is aan een number. Dat lijkt handig, maar het verstopt precies de fouten die je met `typeof` en `Number()` net hebt leren zien. Gebruik altijd **`===`** (en `!==`): die vergelijkt waarde én type, zonder verrassingen.
