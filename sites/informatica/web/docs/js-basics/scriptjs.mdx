In de vorige les stond je JavaScript in een `<script>`-tag onderaan de body. Bij grotere projecten wil je HTML en JavaScript in aparte bestanden houden: overzichtelijker en makkelijker te hergebruiken.

### Koppel het bestand

De wekker uit [De script-tag](site:web/docs/js-basics/script-tag), zonder de oranje kleur: een alinea en een knop. De JavaScript komt in een eigen bestand, `script.js`, en de HTML koppelt dat bestand in de `<head>` met het `defer`-attribuut:

```html
<head>
  <script src="script.js" defer></script>
</head>
<body>
  <p id="wekker">Je slaapt nog.</p>
  <button onclick="wekMij()">Wek mij</button>
</body>
```

`defer` betekent: laad het script, maar voer het pas uit als de volledige HTML geladen is. Hetzelfde effect als de `<script>`-tag onderaan de body, maar netter in de `<head>`. Het bestand script.js is nog leeg: een klik op de knop geeft in de console een melding die eindigt op `wekMij is not defined`.

### Schrijf de functie

De functie `wekMij` komt in script.js. In dat bestand staat alleen JavaScript, zonder `<script>`-tags eromheen:

```js
function wekMij() {
  document.getElementById('wekker').textContent = 'Goedemorgen.';
}
```

Na een klik staat er `Goedemorgen.` op de pagina. In het oefenveld van deze les staat de JavaScript ook in **script.js**, naast index.html en style.css. De console blijft leeg: daar zette tot nu toe alleen de browser iets in, als er een fout was.

### Log een bericht

Met **`console.log()`** zet je zelf een bericht in de **console**: een paneel dat bezoekers niet zien, maar jij als programmeur wel. De gemarkeerde regel is nieuw: de functie meldt in de console dat hij draait.

```js {3}
function wekMij() {
  document.getElementById('wekker').textContent = 'Goedemorgen.';
  console.log('De wekker ging af.');
}
```

Na een klik staat `De wekker ging af.` in de console. In het oefenveld staat de console onder het voorbeeld; in een gewone browser open je hem met **F12** → tabblad "Console". Met `console.log` spoor je fouten op (**debuggen**): een bericht op een paar plekken in je code laat zien welke regels draaien. Welke tekst er nu in de alinea staat, zegt dit bericht niet.

### Log een waarde

Na de tekst kan `console.log` met een komma een **waarde** krijgen, en die zet hij erachter. De gemarkeerde regels zijn nieuw: ze loggen de tekst die nu in de alinea staat.

```js {4-5}
function wekMij() {
  document.getElementById('wekker').textContent = 'Goedemorgen.';
  console.log('De wekker ging af.');
  console.log('In de alinea:',
    document.getElementById('wekker').textContent);
}
```

Na een klik staat er onder `De wekker ging af.` een tweede regel: `In de alinea: Goedemorgen.` Zo zie je niet alleen dat een regel draait, maar ook met welke waarde.

## Er gaat iets mis

**`defer` vergeten**

```html
<!-- Zonder defer: script draait vóórdat de HTML geladen is -->
<head>
  <script src="script.js"></script>
</head>
```

Zonder `defer` voert de browser `script.js` uit zodra hij de tag tegenkomt — de `<body>` bestaat dan nog niet. Code die dan al een element opzoekt, krijgt `null` terug, met een foutmelding in de console. Gebruik altijd `defer` als je een extern script in de `<head>` koppelt.

In het oefenveld zie je deze fout niet: het zet script.js altijd onderaan de body, ook zonder `defer`. In een eigen bestand op je computer krijg je hem wel.
