Tot nu toe deed je code altijd hetzelfde. Vaak wil je een andere actie afhankelijk van een waarde: als de batterij bijna leeg is, toon dan een waarschuwing. Dat schrijf je met een `if`-statement.

### Schrijf de if

Een telefoon waarschuwt als de batterij onder de 20 procent komt:

```js
const batterij = 15;

if (batterij < 20) {
  console.log('Zoek een oplader.');
}
```

Tussen de haakjes staat een **voorwaarde**: een expressie die `true` of `false` oplevert, zoals in [Vergelijken](site:web/docs/js-basics/vergelijken). Is de voorwaarde `true`, dan voert JavaScript de regels tussen `{ ... }` uit: de console logt `Zoek een oplader.` Anders slaat hij het blok over. Bij een batterij van 80 blijft de console leeg, en zie je niet of de code wel draaide.

### Voeg else toe

Met `else` geef je het alternatief voor wanneer de voorwaarde **niet** waar is. De gemarkeerde regels zijn nieuw of veranderd: de batterij staat op 80, en het `else`-blok heeft een eigen bericht.

```js {1,5-6}
const batterij = 80;

if (batterij < 20) {
  console.log('Zoek een oplader.');
} else {
  console.log('Genoeg stroom.');
}
```

De console logt `Genoeg stroom.` Eén van de twee blokken draait, nooit allebei. Een batterij van 25 krijgt hetzelfde bericht als een van 80, terwijl hij bijna leeg is.

### Voeg een tak toe

Voor meer dan twee gevallen zet je er een `else if`-tak tussen, met een eigen voorwaarde. De gemarkeerde regels zijn nieuw of veranderd: de batterij staat op 25, en er is een tak voor alles onder de 50.

```js {1,5-6}
const batterij = 25;

if (batterij < 20) {
  console.log('Zoek een oplader.');
} else if (batterij < 50) {
  console.log('Laad straks op.');
} else {
  console.log('Genoeg stroom.');
}
```

De console logt `Laad straks op.` JavaScript probeert de voorwaarden van boven naar beneden en stopt bij de eerste die `true` is. Elke tak heeft een eigen `console.log`: moet het bericht naar de pagina, dan verander je drie regels.

### Bewaar de uitkomst

`let advies;` maakt een variabele aan zonder waarde; één van de takken vult hem. De gemarkeerde regels zijn nieuw of veranderd: elke tak bewaart zijn tekst in `advies`, en de laatste regel logt hem.

```js {2,5,7,9,11}
const batterij = 25;
let advies;

if (batterij < 20) {
  advies = 'Zoek een oplader.';
} else if (batterij < 50) {
  advies = 'Laad straks op.';
} else {
  advies = 'Genoeg stroom.';
}
console.log(advies);
```

De console logt nog steeds `Laad straks op.` Het bericht naar de pagina sturen kost nu één regel.

## Predict

Dit is een deel van de startcode van het oefenveld. `score` is het getal dat je in de prompt typt. Beantwoord de vraag **voordat** je de code draait.

```js
if (score >= 90) {
  cijfer = 'A';
} else if (score >= 70) {
  cijfer = 'B';
} else if (score >= 50) {
  cijfer = 'C';
} else {
  cijfer = 'Onvoldoende';
}

document.getElementById('uitvoer').textContent = 'Score: ' + score + ' → ' + cijfer;
```

<summary>Je vult 75 in. Wat komt er op de pagina te staan?</summary>

`Score: 75 → B`. `75 >= 90` is `false`, dus JavaScript gaat door naar de volgende tak. `75 >= 70` is `true`: daar stopt hij, en de takken eronder komen niet meer aan de beurt.

</details>

## Er gaat iets mis

**Toekenning (`=`) in plaats van vergelijking (`===`)**

```js
if (score = 10) {   // Fout: één =-teken
  // ...
}
```

Eén `=`-teken **kent toe** in plaats van **vergelijkt**. Deze regel zet `score` op `10` en geeft die `10` terug — en dat telt in JavaScript als `true`. Het `if`-blok draait dus altijd, wat de oorspronkelijke waarde ook was.

Schrijf voor een vergelijking altijd `===` (drie tekens). Het oefenveld waarschuwt hier niet voor: de code draait zonder foutmelding. Let er dus zelf op.
