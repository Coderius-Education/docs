Tot nu toe schreef je code direct in `onclick`. Dat werkt voor één regel, maar in [Opdracht 2 van Inline stijl](site:web/docs/js-basics/inline-stijl) zag je al hoe onleesbaar het wordt zodra er meer bij komt. De oplossing is een **functie**: een blok code met een naam.

### Begin in onclick

Een wekker verandert de tekst van een alinea en kleurt hem oranje: twee regels code. In een `onclick` staan ze samen in één attribuut, en dat leest lastig:

```html
<button onclick="document.getElementById('wekker').textContent =
  'Goedemorgen.'; document.getElementById('wekker').style.color =
  'orange';">Wek mij</button>
```

### Schrijf de functie

In een functie staan de twee regels van de wekker onder elkaar, met één naam erboven:

```js
function wekMij() {
  document.getElementById('wekker').textContent = 'Goedemorgen.';
  document.getElementById('wekker').style.color = 'orange';
}
```

1. `function`: het sleutelwoord dat zegt dat hier een functie begint.
2. `wekMij`: de **naam**, die kies je zelf. Geen spaties; gebruik camelCase voor meer woorden (`maakKleurRood`).
3. `()`: twee ronde haakjes. Die horen bij elke functie; ze blijven in deze cursus leeg.
4. `{ ... }`: accolades met daartussen de regels code die bij de functie horen.

De functie hoort nog bij geen pagina: er is geen alinea om te veranderen en geen knop om op te klikken.

### Zet hem in `<script>`

De functie `wekMij` komt in een `<script>`-tag, **onderaan** de `<body>`: zo bestaan alle HTML-elementen al op het moment dat de code laadt. Erboven staan de alinea en de knop:

```html
<body>
  <p id="wekker">Je slaapt nog.</p>
  <button>Wek mij</button>

  <script>
    function wekMij() {
      document.getElementById('wekker').textContent = 'Goedemorgen.';
      document.getElementById('wekker').style.color = 'orange';
    }
  </script>
</body>
```

Een klik op de knop doet niets, en de console blijft leeg. De code tussen de accolades draait niet vanzelf: de functie bestaat, maar niemand voert hem uit.

### Roep hem aan

De code tussen de accolades draait pas als je de functie **aanroept**: zijn naam met `()` erachter. De gemarkeerde regel is veranderd: de knop roept `wekMij()` aan in zijn `onclick`.

```html {3}
<body>
  <p id="wekker">Je slaapt nog.</p>
  <button onclick="wekMij()">Wek mij</button>

  <script>
    function wekMij() {
      document.getElementById('wekker').textContent = 'Goedemorgen.';
      document.getElementById('wekker').style.color = 'orange';
    }
  </script>
</body>
```

Na een klik staat er `Goedemorgen.` in oranje letters. De haakjes horen erbij: `wekMij` zonder haakjes noemt alleen de naam van de functie, `wekMij()` voert hem uit.

## Er gaat iets mis

### `<script>`-tag staat vóór de HTML-elementen

```html
<head>
  <script>
    function verander() {
      document.getElementById('bericht').textContent = 'Hoi';
    }
    verander();   // Fout: dit draait meteen, de <p> bestaat nog niet
  </script>
</head>
<body>
  <p id="bericht">Tekst</p>
</body>
```

```
JavaScript fout: Uncaught TypeError: Cannot set properties of null (setting 'textContent')
```

De aanroep `verander();` draait zodra de browser de `<script>`-tag in de `<head>` leest. De `<body>` is er dan nog niet, dus `getElementById` geeft `null`. Zet de `<script>`-tag daarom **onderaan** de `<body>`.

### Functienaam verschilt tussen `onclick` en `<script>`

```html
<button onclick="veranderTekst()">Klik</button>

<script>
  function verander() {
    document.getElementById('bericht').textContent = 'Hoi';
  }
</script>
```

```
JavaScript fout: Uncaught ReferenceError: veranderTekst is not defined
```

De knop roept `veranderTekst` aan, maar de functie heet `verander`. "Is not defined" betekent: deze naam ken ik niet. Kijk bij deze melding of de naam in de `onclick` letter voor letter gelijk is aan de naam achter `function`, hoofdletters meegeteld.
