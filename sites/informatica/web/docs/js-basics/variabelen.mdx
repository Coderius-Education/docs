Een variabele is een plek in het geheugen met een naam. Hij onthoudt een waarde, en die waarde kun je later veranderen.

### Maak de variabele

Een variabele houdt bij hoeveel euro er in je spaarpot zit. Je maakt hem aan met `let`:

```js
let spaarpot = 0;
console.log('In de pot:', spaarpot);
```

`let` maakt een nieuwe variabele aan, `spaarpot` is de naam (kies zelf; kleine letters, geen spaties) en `= 0` is de beginwaarde. De console logt `In de pot: 0`: na de komma zet `console.log` een tweede waarde achter de tekst. De pot is leeg, en er komt nog niets bij.

### Verander de waarde

De waarde van een variabele kun je veranderen. De gemarkeerde regel is nieuw: er gaat 2 euro in de pot.

```js {2}
let spaarpot = 0;
spaarpot = spaarpot + 2;
console.log('In de pot:', spaarpot);
```

JavaScript rekent eerst de rechterkant uit, `0 + 2`, en bewaart de uitkomst weer in `spaarpot`. De console logt `In de pot: 2`. Dat gebeurt één keer, bij het laden van de pagina: nog een keer sparen kan niet.

### Spaar met een knop

Een knop met `onclick="spaar()"` roept een functie aan, en die spaart bij elke klik opnieuw. De gemarkeerde regels zijn nieuw of veranderd: de functie `spaar`, met de twee regels erin. `let spaarpot = 0;` blijft erboven staan, **buiten** de functie: binnen de functie zou elke klik weer bij 0 beginnen.

```js {3-6}
let spaarpot = 0;

function spaar() {
  spaarpot = spaarpot + 2;
  console.log('In de pot:', spaarpot);
}
```

Bij de eerste klik logt de console `In de pot: 2`, bij de tweede `In de pot: 4`. De variabele blijft bestaan tussen de klikken door en onthoudt zijn waarde: daar zijn variabelen voor. Op de pagina zelf is nog niets te zien.

### Toon de waarde

Op de pagina staat een `<p id="pot">` voor het bedrag. De gemarkeerde regel is nieuw: na elke klik zet de functie de waarde van `spaarpot` in die alinea.

```js {5}
let spaarpot = 0;

function spaar() {
  spaarpot = spaarpot + 2;
  document.getElementById('pot').textContent = spaarpot;
  console.log('In de pot:', spaarpot);
}
```

Het bedrag op de pagina loopt nu gelijk met de console.

## `let` of `const`?

Naast `let` bestaat `const`. Het verschil:

- `let`: de waarde **kan veranderen** (zoals een teller die optelt)
- `const`: de waarde **blijft constant**; na het toekennen mag hij niet meer veranderen

```js
const startwaarde = 0;    // verandert nooit
let teller = startwaarde; // mag wel veranderen
teller = teller + 1;
```

**Vuistregel**: gebruik standaard `const`. Pas als de waarde echt moet kunnen veranderen, gebruik je `let`.

## Er gaat iets mis

**Variabele binnen de functie declareren**

```js
function telOp() {
  let teller = 0;       // Fout: elke klik begint opnieuw bij 0
  teller = teller + 1;
}
```

Staat `let teller = 0` binnen de functie, dan maakt elke klik een verse variabele aan die weer bij 0 begint — de teller komt nooit verder dan 1. Zet variabelen die je wilt onthouden **buiten** de functie.
