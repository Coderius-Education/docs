# Code - Broncode

## De challenge

> **[Open deze challenge op ctf.hackchallenges.nl](https://ctf.hackchallenges.nl/)** - zoek naar *"Broncode"* onder Code.

De flag is verborgen in de broncode van de pagina. Zoek goed.

- **Moeilijkheid:** Makkelijk
- **Onderwerp:** HTML-broncode

**Wat je oefent**

- De broncode van een webpagina bekijken
- Zoeken in een lange lap code
- Het verschil zien tussen wat een pagina toont en wat er in de code staat

Probeer het eerst zelf. Loop je vast, dan staan er op het tabblad Hints drie hints: open ze een voor een.

## Hints

<details>
<summary>Hint 1</summary>

Elke webpagina heeft broncode die je kunt bekijken. Klik met de rechtermuisknop op de pagina en zoek de optie om de bron te bekijken.

</details>

<details>
<summary>Hint 2</summary>

Gebruik **Ctrl+F** om te zoeken in de broncode. Zoek naar termen als "flag" of "CTF".

</details>

<details>
<summary>Hint 3</summary>

De flag kan op een plek staan die je normaal niet ziet:
- HTML-commentaar
- Verborgen elementen
- Data-attributen
- JavaScript-variabelen

</details>
