# Code - Obfuscated

## De challenge

> **[Open deze challenge op ctf.hackchallenges.nl](https://ctf.hackchallenges.nl/)** - zoek naar *"Obfuscated"* onder Code.

De code is moeilijk te lezen omdat deze is **geobfusceerd** (onleesbaar gemaakt). Hoe kom je er toch achter wat hij doet?

- **Moeilijkheid:** Gemiddeld
- **Onderwerp:** Code obfuscation

**Wat je oefent**

- Uitzoeken wat code doet zonder hem regel voor regel te lezen
- Zien waarvoor obfuscation wordt gebruikt

Probeer het eerst zelf. Loop je vast, dan staan er op het tabblad Hints drie hints: open ze een voor een.

## Hints

<details>
<summary>Hint 1</summary>

Obfuscation maakt code opzettelijk onleesbaar, maar de code doet nog hetzelfde. Je hoeft hem niet te begrijpen om hem uit te voeren.

</details>

<details>
<summary>Hint 2</summary>

Kopieer de code en voer hem uit in de juiste omgeving. Is het JavaScript, plak hem dan in de **browserconsole** (F12 > Console).

</details>

<details>
<summary>Hint 3</summary>

Geeft uitvoeren de flag niet meteen, maak de code dan weer leesbaar (**deobfusceren**) met een online tool, zoals:
- [deobfuscate.io](https://deobfuscate.io/)
- [beautifier.io](https://beautifier.io/)

</details>
