# Forensics - Voor altijd

## De challenge

> **[Open deze challenge op ctf.hackchallenges.nl](https://ctf.hackchallenges.nl/)** - zoek naar *"Voor altijd"* onder Forensics.

Sommige informatie op het internet verdwijnt nooit helemaal. Zelfs als een website offline gaat, kan de inhoud ergens bewaard zijn gebleven.

- **Moeilijkheid:** Makkelijk
- **Onderwerp:** Oude versies van websites

**Wat je oefent**

- Zoeken naar informatie die van een website is verdwenen
- Oude versies van een website terugvinden en bekijken

Probeer het eerst zelf. Loop je vast, dan staan er op het tabblad Hints drie hints: open ze een voor een.

## Hints

<details>
<summary>Hint 1</summary>

Er bestaan diensten die oude versies van websites bewaren, ook als die offline zijn gegaan. Zoek naar een internet-archiefdienst.

</details>

<details>
<summary>Hint 2</summary>

De bekendste archiefdienst is de **Wayback Machine**, op [web.archive.org](https://web.archive.org). Voer daar de URL uit de challenge in.

</details>

<details>
<summary>Hint 3</summary>

Bekijk de verschillende **snapshots** (tijdstippen) die beschikbaar zijn. De flag kan verborgen zijn in een oudere versie van de pagina.

</details>
