# De meesterproef

De meesterproef is project waarin je geheel zelf mag kiezen.

We raden aan dat je dit project kiest richting het einde van het vak Informatica.

Bij de meesterproef kies je tussen:
- een **leerdoel** en een **maakdoel**.
- een **begeleid project** of **op avontuur**

## Leerdoel
Bij een leerdoel ligt de focus leren, waarbij je mogelijk iets maakt om hierbij te helpen.

## Maakdoel
Bij een maakdoel ligt de focus op het maken, waarbij je uiteraard ook zaken leert.

## Begeleid project
Een begeleid project is een project waarbij de docent je kan helpen met debuggen, vermoedelijk met materiaal uit de informatica-cursussen van Coderius.

## Op avontuur
Als je op avontuur gaat, dan is je docent meer iemand die meedenkt dan dat de docent je echt altijd inhoudelijk kan helpen.
