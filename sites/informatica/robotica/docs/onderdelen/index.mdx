# Onderdelen

Hier zoek je een onderdeel op: wat het doet, hoe je het aansluit en een script
dat je kunt kopiëren. Elk onderdeel staat op één pagina. Bouw je de
[Lego-auto](site:robotica/lego_auto/frame), dan kom je de meeste onderdelen daar
vanzelf tegen; hier vind je ze terug, en ook de onderdelen die de Lego-auto
niet gebruikt.
