# Wat is de bedoeling?

In dit hoofdstuk laat je je robot een **zwarte lijn volgen**. Alles wat je tot nu toe geleerd hebt (IR-sensoren, motoren, while-loops) komt hier samen.

## Wanneer heb je deze stap gehaald?

- Je robot volgt een zwarte lijn op een witte ondergrond.
- Wil je verder: met vier sensoren neemt hij ook een scherpe bocht ([Deel 9](site:robotica/lego_auto/lijnvolgen/vier-sensoren)).

Wil je meer uitdaging? Kijk dan eens naar de [Redden Basis-competitie](site:robotica/docs/robocup/start).
