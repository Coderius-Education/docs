# Docentenhandleiding

Een cursus robotica: je leerlingen bouwen een robot en sturen zijn sensoren en motoren aan, in MicroPython op een Arduino Nano RP2040 Connect of met blokken op de Golfbot. Hoe je ermee lesgeeft, bepaal je zelf. Deze pagina laat zien op welk onderzoek de opbouw van de lessen steunt, en noemt daarna kort wat je vooraf wilt weten.

## Waar de lessen op steunen

Een les heeft vaste onderdelen. In de les zijn het de tabbladen, elk met een eigen icoon. Hieronder staat bij elk onderdeel de literatuur waarop het steunt; een link opent de uitleg bij [vakdidactiek](site:didactiek/).

<Werkvormen />

Een les van de Lego-auto bouwt één script in kleine stappen op, en na elke stap test de leerling op de robot. Een voorspelvraag staat direct bij de code of het blokprogramma waar hij over gaat.

## Wat je vooraf wilt weten

- **Je hebt hardware nodig.** Per onderdeel staat onder Materiaal wat er op tafel ligt. Voor MicroPython is er de [Editor](site:robotica/editor) in Chrome of Edge, zonder installatie; [Installatie](site:robotica/docs/onderdelen/installatie) zegt wat er op het bord en de laptop moet staan.
- **De code staat op het bord, niet op de site.** Wat een leerling in de Editor typt, blijft in de browser van dat apparaat; `main.py` op het bord is wat de robot uitvoert.
- **Er zijn vier ingangen.** De [Lego-auto](site:robotica/lego_auto/frame) en de [Golfbot](site:robotica/golfbot/intro) zijn leerlijnen in volgorde. [Onderdelen](site:robotica/docs/onderdelen) is naslag per sensor en actuator, en [RoboCup Junior](site:robotica/docs/robocup/start) bouwt daarop verder.

## Beoordelen

- [Leerdoelen](site:robotica/leerdoelen): per niveau de concepten waarop je beoordeelt, met de les erbij, en hoe je er een cijfer van maakt.
- [Robot checken](site:robotica/robot-checken): je leerling levert zijn `main.py` en foto's van de robot in. Jij opent dezelfde pagina met `-docent` erachter; het wachtwoord is `coderius-docent`.
