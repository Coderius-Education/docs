# Invoer controleren: de oplossing

De grens hoort op de server, waar de bezoeker er niet bij kan. FastAPI kan hem
zelf bewaken: je geeft in `Form` een minimum en een maximum mee, en een verzoek
dat er niet aan voldoet komt niet eens in je functie.

## `max_length` in `Form`

<CodeUitleg>

```python showLineNumbers
@app.post("/bericht")
async def bericht_plaatsen(
    naam: str = Form(..., min_length=1, max_length=30),
    bericht: str = Form(..., min_length=1, max_length=280),
):
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

<Regel n={3} tot={4}>
`min_length` en `max_length` zetten de grens op de server. Dezelfde getallen als de `maxlength` in de HTML, maar nu telt hij echt.
</Regel>

</CodeUitleg>

## Doe de test opnieuw

Draai `groot.py` uit [stap 1](./zwakheid) met het bericht van een miljoen
tekens:

```
{'detail': [{'type': 'string_too_long', 'loc': ['body', 'bericht'], 'msg': 'String should have at most 280 characters', ...}]}
```

Je krijgt een **422**, en het bericht komt niet in de database. FastAPI ziet dat
`bericht` te lang is, weigert het verzoek, en jouw code draait niet eens. De
`maxlength` in de HTML laat je staan: die helpt nog steeds wie zich in de
browser vergist.

## Wat FastAPI niet voor je doet

`max_length` bewaakt de lengte. Een naam van alleen spaties, uit
[opdracht 1](./zwakheid), komt er nog steeds door: dat is drie tekens lang, dus
lang genoeg. Zulke controles blijven van jou:

```python
if not naam.strip():
    raise HTTPException(status_code=400, detail="Vul een naam in")
```

`naam.strip()` haalt de spaties aan het begin en eind weg; blijft er niets over,
dan was de naam leeg. De regel `raise HTTPException` ken je uit
[Jouw project](/docs/FastAPI/jouw-project): hij stopt de functie met een
foutmelding.

## Opdrachten

### Opdracht 1: Run - Te lang en te kort

Zet `min_length` en `max_length` in je endpoint. Stuur met `httpx` een bericht
van 300 tekens, en daarna een leeg bericht. Welke statuscode krijg je?

<details>
<summary>Tip</summary>

Een leeg bericht is `""`. Dat is korter dan `min_length=1`.

</details>

<details>
<summary>Antwoord</summary>

Allebei een `422`. Het bericht van 300 tekens is langer dan `max_length=280`,
en het lege bericht is korter dan `min_length=1`. In beide gevallen weigert
FastAPI voordat je code draait, en komt er niets in de database.

</details>

### Opdracht 2: Modify - Een naam van spaties weren

Voeg de controle op `naam.strip()` toe. Stuur daarna een naam van drie spaties
met `httpx` en kijk wat er gebeurt.

<details>
<summary>Tip</summary>

Zet de controle aan het begin van de functie, vóór het `with`-blok.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.post("/bericht")
async def bericht_plaatsen(
    naam: str = Form(..., min_length=1, max_length=30),
    bericht: str = Form(..., min_length=1, max_length=280),
):
    if not naam.strip():
        raise HTTPException(status_code=400, detail="Vul een naam in")
    with SqliteDict("gastenboek.db") as db:
        db[f"bericht_{time.time_ns()}"] = {"naam": naam, "bericht": bericht}
        db.commit()
    return {"lengte": len(bericht)}
```

De naam van spaties geeft nu een `400` met "Vul een naam in". `max_length`
bewaakt de lengte, en deze controle bewaakt de inhoud.

</details>
