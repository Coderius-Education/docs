# Installatie

Tijd voor een back-end. Voordat je de eerste server start, loop je deze vijf checks van boven naar beneden door. Elke check zegt hoe je ziet dat het goed is. Klopt het niet, klap dan de hulp eronder open.

## Check 1: VS Code

Start Visual Studio Code. Je ziet het welkomstscherm of het project waar je het laatst aan werkte.

<details>
<summary>Heb je dit nog niet? Klik hier.</summary>

Visual Studio Code is de editor waarin je in deze cursus werkt. Download hem gratis en installeer hem met de standaardinstellingen. Laat op Windows het vakje **Add to PATH** aangevinkt staan; zonder dat vakje mist je het commando uit check 4. De stappen met schermafbeeldingen staan in de editor-cursus: <SiteLink site="editor" to="/installatie-vscode/">VS Code installeren</SiteLink>.

</details>

## Check 2: een projectmap met een terminal erin

In die map komt alles van deze cursus te staan. Open PowerShell vanuit die map: klik met de rechtermuisknop in het lege deel van het Verkenner-venster en kies **Openen in Terminal**. Het prompt eindigt op het pad van je map:

```
PS C:\Users\jij\Documenten\fullstack-project>
```

<details>
<summary>Heb je dit nog niet? Klik hier.</summary>

1. Maak in de Verkenner een nieuwe map, bijvoorbeeld `fullstack-project`, en open hem
2. Klik met de rechtermuisknop in het lege deel van het venster en kies **Openen in Terminal**

Op Windows 10 heet die keuze **PowerShell-venster hier openen** en verschijnt hij pas als je Shift ingedrukt houdt bij het rechtsklikken. Staat hij er helemaal niet, klik dan in de adresbalk bovenin, typ `powershell` over het pad heen en druk op Enter.

Het maakt uit vanuit welke map je de terminal opent: alles wat je typt gebeurt in díé map, en daar komen straks je virtual environment en je code te staan. Meer hierover: <SiteLink site="editor" to="/python/stap-1-projectmap">Een projectmap aanmaken</SiteLink>.

</details>

## Check 3: Python

Typ in PowerShell:

```bash
python --version
```

Het antwoord begint met `Python 3`.

<details>
<summary>Heb je dit nog niet? Klik hier.</summary>

Typ in PowerShell `python` zonder meer. Windows opent de Microsoft Store op de pagina van Python; klik daar op **Ophalen**.

Sluit daarna het PowerShell-venster en open een nieuw venster vanuit je projectmap. Een venster dat al open stond kent het nieuwe commando niet, en dan blijft de Store terugkomen. De volledige uitleg, inclusief wat je doet als de Store geblokkeerd is: <SiteLink site="editor" to="/python/stap-3-installeren">Python installeren</SiteLink>.

Op een Mac opent `python` geen Store. Installeer Python van [python.org](https://www.python.org/downloads/); het commando heet daar `python3`, dus je controleert met `python3 --version`.

</details>

## Check 4: een virtual environment

Je project staat open in VS Code, met een map `.venv` in de Explorer links. Open een terminal via **Terminal** → **New Terminal**; vóór de prompt staat `(.venv)`:

![De terminal in VS Code met (.venv) voor de prompt](@site/static/vs_code/venv.png)

**Let op:** dit is de check die het vaakst misgaat. Zonder `(.venv)` installeer je FastAPI straks op de verkeerde plek en zegt Python later dat het `fastapi` niet kent.

<details>
<summary>Heb je dit nog niet? Klik hier.</summary>

Een virtual environment is een afgesloten omgeving voor dit project. Packages die je hier installeert, komen niet in de weg van andere projecten.

1. Maak de omgeving aan in PowerShell, in je projectmap:

```bash
python -m venv .venv
```

2. Open je project in VS Code vanuit datzelfde venster:

```bash
code .
```

3. Installeer in VS Code de Python-extensie van **Microsoft**: klik in de linkerbalk op het blokjes-icoon (Extensions), zoek `Python` en klik op **Install**
4. Open een terminal via **Terminal** → **New Terminal**

VS Code zet je virtual environment in zijn eigen terminal automatisch aan, dus daar verschijnt `(.venv)` vanzelf. Staat het er niet, sluit die terminal dan met het prullenbak-icoon en open een nieuwe. De volledige uitleg: <SiteLink site="editor" to="/python/stap-4-venv">Een virtual environment aanmaken</SiteLink>.

</details>

## Check 5: FastAPI

Typ in de terminal van VS Code (met `(.venv)` ervoor):

```bash
fastapi --version
```

Je ziet een versienummer, bijvoorbeeld `FastAPI CLI version 0.0.8`.

<details>
<summary>Heb je dit nog niet? Klik hier.</summary>

FastAPI is een package: een stuk Python van iemand anders, dat je met `pip` in je virtual environment zet. Typ in de terminal van VS Code:

```bash
python -m pip install "fastapi[standard]"
```

De aanhalingstekens horen erbij: zonder die tekens leest PowerShell de blokhaken zelf. Het installeren duurt even; daarna geeft `fastapi --version` een versienummer. Meer over pip: <SiteLink site="editor" to="/python/stap-7-pip">Packages installeren met pip</SiteLink>.

Doe dit niet in het losse PowerShell-venster waarin je de omgeving aanmaakte: daar staat de virtual environment niet aan en belandt FastAPI buiten je project. Zegt de terminal `No module named pip` of `No module named fastapi`, kijk dan of `(.venv)` voor de prompt staat en ga anders terug naar check 4.

</details>

Alle vijf checks goed? Dan ben je klaar voor [je eerste endpoint](/docs/FastAPI/eerste_endpoint).
