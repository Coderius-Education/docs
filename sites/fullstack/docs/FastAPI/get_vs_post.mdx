Tot nu toe gebruikte je alleen GET. Er is nog een tweede soort verzoek, POST, en in deze les zie je het verschil.

## GET = Data ophalen

Alles wat je tot nu toe hebt gedaan is GET. De browser vraagt data op van de server, zoals bij je endpoint voor `/`:

{/* route-dubbel: voorbeeld van een endpoint dat de leerling al heeft */}
```python
@app.get("/")
async def home():
    return FileResponse("static/pages/home.html")
```

Data kan meegestuurd worden in de URL:
```
http://127.0.0.1:8000/zoek?term=python
```

<CodeUitleg>

```python showLineNumbers
@app.get("/zoek")
async def zoek(term: str):
    return {"je_zocht": term}
```

<Regel n={2}>
Een parameter met een type, `term: str`, haalt FastAPI uit de URL: het stuk na het vraagteken, `?term=python`. De naam van de parameter moet gelijk zijn aan de naam in de URL.
</Regel>

</CodeUitleg>

Zet dit endpoint onder je andere endpoints en ga naar [http://127.0.0.1:8000/zoek?term=python](http://127.0.0.1:8000/zoek?term=python). Je ziet `{"je_zocht":"python"}`.

Laat je `?term=python` weg, dan weigert FastAPI het verzoek. Je ziet:

```json
{"detail":[{"type":"missing","loc":["query","term"],"msg":"Field required","input":null}]}
```

`"loc":["query","term"]` zegt waar het mis ging: in de query, het stuk na het vraagteken, ontbreekt `term`. Wil je dat de parameter mag ontbreken, geef hem dan een standaardwaarde: met `term: str = ""` krijgt `term` een lege tekst als er niets in de URL staat.

## POST = Data versturen

POST gebruik je als een gebruiker data naar de server stuurt, bijvoorbeeld via een formulier. Zet `Form` bij je imports en dit endpoint onder je andere endpoints. Het formulier dat hem gebruikt, maak je in de volgende les.

<CodeUitleg>

```python showLineNumbers
from fastapi import Form

@app.post("/verstuur")
async def verstuur(naam: str = Form(...)):
    return {"ontvangen": naam}
```

<Regel n={3}>
`@app.post` in plaats van `@app.get`: dit endpoint reageert alleen op een POST. Een browser die de URL opvraagt met een GET krijgt een 405.
</Regel>

<Regel n={4}>
`Form(...)` zegt dat `naam` uit een verstuurd formulier komt, niet uit de URL. De data zit in de body van het verzoek en is niet zichtbaar in de adresbalk. In het tabblad Netwerk zie je hem wel: klik op het verzoek en kies **Payload**, dan staat hij onder **Formuliergegevens** (Form Data).
</Regel>

</CodeUitleg>

## Wanneer gebruik je wat?

| | GET | POST |
|---|---|---|
| **Doel** | Data ophalen | Data versturen |
| **Data in** | URL | Request body |
| **Voorbeeld** | Pagina laden, zoeken | Formulier versturen, inloggen |

**Vuistregel:** GET = "Geef me iets" / POST = "Hier is iets"

:::danger[Gaat er iets mis?]
Krijg je een **405 Method Not Allowed**? Dan stuur je waarschijnlijk een POST naar een GET endpoint of andersom. Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

<details>
<summary>Zo ziet je `main.py` er nu uit</summary>

Dit is je hele `main.py` na deze les, zonder wat je in de opdrachten maakte.

```python
import random

from fastapi import FastAPI, Form, Request
from fastapi.responses import FileResponse, HTMLResponse
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")
templates = Jinja2Templates(directory="templates")

@app.get("/")
async def home():
    return FileResponse("static/pages/home.html")

@app.get("/info")
async def info():
    return {"naam": "Jouw Naam", "leeftijd": 16}

@app.get("/pagina", response_class=HTMLResponse)
async def pagina():
    return """
    <!DOCTYPE html>
    <html>
        <head>
            <title>Mijn Pagina</title>
        </head>
        <body>
            <h1>Hallo!</h1>
            <p>Dit is mijn eerste HTML pagina.</p>
        </body>
    </html>
    """

@app.get("/styled", response_class=HTMLResponse)
async def styled():
    return """
    <!DOCTYPE html>
    <html>
        <head>
            <title>Met CSS</title>
            <style>
                h1 { color: blue; }
                p { color: gray; }
            </style>
        </head>
        <body>
            <h1>Gestylede pagina</h1>
            <p>Deze tekst is grijs.</p>
        </body>
    </html>
    """

@app.get("/about")
async def about():
    return FileResponse("static/pages/about.html")

@app.get("/foto")
async def foto():
    return FileResponse("static/pages/foto.html")

@app.get("/dobbelsteen")
async def dobbelsteen(request: Request):
    worp = random.randint(1, 6)
    return templates.TemplateResponse(
        request,
        "dobbelsteen.html",
        {"worp": worp}
    )

@app.get("/zoek")
async def zoek(term: str):
    return {"je_zocht": term}

@app.post("/verstuur")
async def verstuur(naam: str = Form(...)):
    return {"ontvangen": naam}
```

## Opdrachten

### Opdracht 1: Predict - GET of POST?

Wat gebruik je voor:
1. Een pagina met zoekresultaten
2. Een inlogformulier versturen
3. Een foto tonen

<details>
<summary>Tip</summary>

Denk aan de vuistregel: GET = "Geef me iets" (data ophalen), POST = "Hier is iets" (data versturen).

</details>

<details>
<summary>Antwoord</summary>

1. **GET**: je haalt zoekresultaten op
2. **POST**: je stuurt je naam en wachtwoord naar de server
3. **GET**: je haalt een bestand op

</details>

### Opdracht 2: Run - GET met parameter

Maak dit endpoint en test het met verschillende namen in de URL, en ook een keer zonder:

```python
@app.get("/hallo")
async def hallo(naam: str = "Bezoeker"):
    return {"bericht": f"Hallo {naam}!"}
```

Test: `http://127.0.0.1:8000/hallo?naam=Jan` en `http://127.0.0.1:8000/hallo`. Zonder naam in de URL krijgt `naam` de standaardwaarde `"Bezoeker"`.

### Opdracht 3: Investigate - POST via browser

Wat gebeurt er als je `http://127.0.0.1:8000/verstuur` rechtstreeks in je browser typt?

<details>
<summary>Tip</summary>

Als je een URL in je browser typt, stuurt de browser altijd een GET request. Wat is het endpoint type van `/verstuur`?

</details>

<details>
<summary>Antwoord</summary>

Je browser toont `{"detail":"Method Not Allowed"}`, en in Netwerk en je terminal staat de statuscode **405**. De browser stuurt een GET, maar `/verstuur` is een POST endpoint (`@app.post`). POST endpoints kun je alleen bereiken via formulieren of tools, niet door de URL in te typen.

</details>

### Opdracht 4: Make - Rekensom

Maak een endpoint `/rekensom` met twee getallen in de URL, dat hun som teruggeeft: `/rekensom?a=3&b=4` geeft `{"som":7}`.

<details>
<summary>Tip</summary>

Twee parameters in de URL scheid je met `&`. Geef ze het type `int`, dan rekent Python met getallen en niet met tekst.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.get("/rekensom")
async def rekensom(a: int, b: int):
    return {"som": a + b}
```

Test met `http://127.0.0.1:8000/rekensom?a=3&b=4`. Met `?a=3&b=vier` krijg je weer een weigering, nu met `"loc":["query","b"]`: `vier` is geen getal.

</details>
