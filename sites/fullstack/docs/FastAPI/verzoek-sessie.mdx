# Wat er gebeurt bij een sessie

De diagrammen van [één klik](/docs/FastAPI/verzoek-get) en [één formulier](/docs/FastAPI/verzoek-post) gaan uit van een verzoek dat op zichzelf staat. Dat is ook wat er gebeurt: je server weet niet dat je er net ook al was. Een sessie is het rondje dat dat gat dicht.

<VerzoekCyclus variant="sessie" />

Stap 3 is het hele verschil met een gewone cookie. De server leest niet wat de browser stuurde, maar zoekt het op in zijn eigen database, en alleen het id reist mee in de cookie. Waarom je dat zo wilt, staat in [Cookie of sessie?](/docs/FastAPI/cookie-of-sessie).
