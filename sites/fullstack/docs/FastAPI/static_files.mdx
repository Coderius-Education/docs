# CSS in een eigen bestand (static files)

<Voorkennis
  items={[
    {site: 'web', to: '/docs/html-css/tekst-opmaken-css', label: 'CSS in een apart bestand koppelen'},
  ]}
/>

In [HTML tonen](/docs/FastAPI/html_tonen) zette je CSS in een `<style>`-tag. Met meer pagina's wil je één CSS-bestand dat ze allemaal delen. Zo'n bestand stuurt de server ongewijzigd door, zonder dat er een functie van jou aan te pas komt: een **static file**.

## Mappenstructuur

Maak in je map `static` naast `pages` een map `css`:

```
je-project/
├── main.py
└── static/
    ├── css/
    │   └── style.css
    └── pages/
        └── home.html
```

## Static files configureren

Pas je `main.py` aan:

<CodeUitleg>

```python showLineNumbers
from fastapi import FastAPI
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.get("/")
async def home():
    return FileResponse("static/pages/home.html")
```

<Regel n={3}>
`StaticFiles` is het stuk van FastAPI dat bestanden ongewijzigd doorgeeft.
</Regel>

<Regel n={6}>
`app.mount` hangt de map `static` aan de URL `/static`. Alles in die map is daarmee bereikbaar in de browser: `static/css/style.css` staat op `/static/css/style.css`. De `name` is verplicht en mag zo blijven staan.
</Regel>

</CodeUitleg>

## CSS in een eigen bestand

Maak `static/css/style.css`:

```css
h1 {
    color: blue;
}

p {
    color: gray;
}
```

## CSS koppelen aan je pagina

Zet in `static/pages/home.html` een `<link>` in de `<head>`:

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Home</title>
        <link rel="stylesheet" href="/static/css/style.css">
    </head>
    <body>
        <h1>Welkom</h1>
        <p>De CSS komt uit een eigen bestand.</p>
    </body>
</html>
```

De `<link>` laadt de CSS via de URL die `app.mount` net heeft aangemaakt. De browser vraagt dat bestand zelf op, als tweede verzoek na de pagina. Dezelfde regel kun je op elke pagina zetten; dan delen ze één stylesheet.

:::note
Omdat `pages` ook in `static` staat, is `home.html` nu ook bereikbaar op `/static/pages/home.html`. Dat kan geen kwaad, maar link in je pagina's altijd naar het endpoint, zoals `/`, en niet naar het bestand.
:::

## Testen

Ga naar [http://127.0.0.1:8000](http://127.0.0.1:8000). De kop is blauw en de tekst grijs: de CSS uit het eigen bestand werkt.

:::danger[Gaat er iets mis?]
CSS werkt niet? Check of `app.mount("/static", ...)` in je code staat en of het pad in `<link>` klopt. Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

## Als je wijziging niet doorkomt

Pas je `style.css` aan en blijft de kop blauw? Dan kijk je waarschijnlijk naar een oude kopie. De browser bewaart van sommige antwoorden een kopie, de **cache**. Vraagt hij hetzelfde adres nog eens, dan pakt hij soms die kopie in plaats van de server te vragen. Bij de JSON van je endpoints gebeurt dat zelden, bij bestanden zoals je CSS wel.

In het tabblad Netwerk uit [Kijken wat de browser doet](/docs/FastAPI/devtools-netwerk) zie je het aan de kolom Grootte: daar staat dan **(schijfcache)** of **(disk cache)** in plaats van een aantal bytes. Twee manieren om het te voorkomen:

- Bovenin het tabblad Netwerk staat het vinkje **Cache uitzetten** (Disable cache). Zet het aan; het werkt zolang de ontwikkelaarstools open staan.
- Klik met de rechtermuisknop op de herlaadknop van je browser en kies **Cache wissen en geforceerd opnieuw laden**. Die keuze bestaat alleen als de ontwikkelaarstools open staan. Sneller is **Ctrl+Shift+R**.

## Opdrachten

### Opdracht 1: Predict - Wat gebeurt er?

Je hebt twee pagina's, `home.html` en `about.html`, en in allebei staat dezelfde regel:

```html
<link rel="stylesheet" href="/static/css/style.css">
```

**Vraag:** wat gebeurt er met `about.html` als je de kleur in `style.css` aanpast?

<details>
<summary>Tip</summary>

Beide pagina's laden hetzelfde bestand. Wat betekent dat als je dat ene bestand aanpast?

</details>

<details>
<summary>Antwoord</summary>

`about.html` verandert ook. Beide pagina's laden hetzelfde CSS-bestand, dus als je dat bestand aanpast, veranderen alle pagina's die het gebruiken.

</details>

### Opdracht 2: Run

Maak `static/css/style.css` en de `<link>` in `home.html` uit het voorbeeld. Start de server en controleer of de styling werkt. Pas daarna de kleur aan en kijk in Netwerk of de nieuwe CSS binnenkomt.

### Opdracht 3: Investigate - Ander pad

Wat gebeurt er als je `app.mount("/static", ...)` verandert in `app.mount("/bestanden", ...)`? Laadt de CSS dan nog?

<details>
<summary>Antwoord</summary>

Nee. De `<link>` verwijst naar `/static/css/style.css`, maar dat adres bestaat niet meer. In Netwerk zie je bij `style.css` een 404. Je zou de link moeten aanpassen naar `/bestanden/css/style.css`.

</details>

### Opdracht 4: Make - Eigen CSS

Geef je `style.css` minstens drie eigen regels, bijvoorbeeld een achtergrondkleur, een lettergrootte en een kleur voor je kop.

<details>
<summary>Tip</summary>

Je hoeft niets aan `main.py` of `home.html` te veranderen: alleen `style.css` verandert. Zie je niets, denk dan aan de cache.

</details>

<details>
<summary>Antwoord</summary>

`static/css/style.css`:
```css
h1 { color: darkblue; }
p { font-size: 18px; }
body { background-color: lightyellow; }
```

</details>

### Opdracht 5: Make - Twee stijlen

Maak een tweede pagina `about.html` met een eigen CSS-bestand `about.css`, zodat `/` en `/about` er verschillend uitzien.

<details>
<summary>Tip</summary>

Maak `static/css/about.css` en zet in `about.html` een `<link>` naar `/static/css/about.css`. Voor de pagina zelf heb je een endpoint `/about` nodig, net als in [HTML in bestanden](/docs/FastAPI/html_bestanden).

</details>

<details>
<summary>Antwoord</summary>

`static/css/about.css`:
```css
h1 { color: green; }
body { background-color: lightblue; }
```

`static/pages/about.html`:
```html
<!DOCTYPE html>
<html>
    <head>
        <link rel="stylesheet" href="/static/css/about.css">
    </head>
    <body>
        <h1>Over mij</h1>
    </body>
</html>
```

```python
@app.get("/about")
async def about():
    return FileResponse("static/pages/about.html")
```

</details>
