Een endpoint is een URL waarop je server reageert. Hieronder maak je je eerste FastAPI endpoint.

## main.py aanmaken

Maak een bestand `main.py` in je project:

<CodeUitleg>

```python showLineNumbers
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"bericht": "Hallo wereld!"}
```

<Regel n={3}>
`FastAPI()` maakt een nieuwe app. Alles wat je server kan, hang je aan deze `app`.
</Regel>

<Regel n={5}>
De decorator `@app.get("/")` koppelt de functie eronder aan de URL `/`. Vraagt een browser die URL op, dan draait FastAPI deze functie.
</Regel>

<Regel n={6}>
De functie heet `root`, maar de naam doet er niet toe; de URL in de regel erboven bepaalt wanneer hij draait. Het `async` hoort bij FastAPI en mag je overnemen.
</Regel>

<Regel n={7}>
Wat de functie teruggeeft, krijgt de browser. Een dictionary zet FastAPI zelf om in JSON.
</Regel>

</CodeUitleg>

## Server starten

Start je server in de terminal:

```bash
fastapi dev main.py
```

Ga naar [http://127.0.0.1:8000](http://127.0.0.1:8000) in je browser. Je ziet:

```json
{"bericht": "Hallo wereld!"}
```

Misschien staat het er bij jou zonder spaties: `{"bericht":"Hallo wereld!"}`. Dat is dezelfde JSON; spaties tussen de onderdelen tellen niet mee. Dat geldt voor alle JSON in deze cursus.

:::note[Laat de server draaien]
Je hoeft de server niet opnieuw te starten als je `main.py` aanpast. Sla op met **Ctrl+S**, en `fastapi dev` ziet de wijziging en start zichzelf opnieuw. In de terminal verschijnt dan `WatchFiles detected changes in 'main.py'. Reloading...`, en even later `Application startup complete.` Daarna herlaad je de pagina in je browser.

Stoppen doe je met **Ctrl+C** in de terminal. Typ je `fastapi dev main.py` terwijl de server nog draait, dan krijg je `Address already in use`.
:::

:::tip[Wijzigingen niet zichtbaar?]
Kijk eerst of je hebt opgeslagen: een stip in plaats van het kruisje op het tabblad van `main.py` in VS Code betekent dat er nog iets niet is opgeslagen. Kijk daarna in de terminal. Staat daar een foutmelding, dan kon de server niet opnieuw starten, en blijft je pagina laden zonder dat er iets verschijnt. Los de fout op, sla op, en herlaad.
:::

## Meerdere endpoints

Een tweede endpoint zet je er op dezelfde manier onder:

```python
@app.get("/info")
async def info():
    return {"naam": "Jouw Naam", "leeftijd": 16}
```

Ga naar [http://127.0.0.1:8000/info](http://127.0.0.1:8000/info) om dit te testen.

:::danger[Gaat er iets mis?]
Start je server niet, met `NameError: name 'app' is not defined`? Dan staat je endpoint bóven de regel `app = FastAPI()`. Python leest van boven naar beneden. Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

<details>
<summary>Zo ziet je `main.py` er nu uit</summary>

Dit is je hele `main.py` na deze les, zonder wat je in de opdrachten maakte.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"bericht": "Hallo wereld!"}

@app.get("/info")
async def info():
    return {"naam": "Jouw Naam", "leeftijd": 16}
```

</details>

## Opdrachten

### Opdracht 1: Predict - Wat zie je?

```python
@app.get("/school")
async def school():
    return {"school": "Mijn school", "vak": "Informatica"}
```

**Vraag:** Wat zie je als je naar `/school` gaat?

<details>
<summary>Tip</summary>

De functie returnt een Python dictionary. Wat doet FastAPI standaard met een dictionary?

</details>

<details>
<summary>Antwoord</summary>

```json
{"school": "Mijn school", "vak": "Informatica"}
```

FastAPI zet de dictionary automatisch om naar JSON.

</details>

### Opdracht 2: Run

Voeg het `/school` endpoint toe aan je `main.py`, sla op en ga naar `http://127.0.0.1:8000/school`. Zie je hetzelfde als in het antwoord hierboven?

### Opdracht 3: Investigate - Dubbele URL

Wat gebeurt er als je twee endpoints met dezelfde URL maakt?

```python
@app.get("/test")
async def test1():
    return {"bericht": "Eerste"}

@app.get("/test")
async def test2():
    return {"bericht": "Tweede"}
```

Probeer het uit. Welke van de twee zie je?

<details>
<summary>Antwoord</summary>

Je ziet `{"bericht": "Eerste"}`. FastAPI gebruikt het eerste endpoint dat matcht en slaat het tweede over.

</details>

### Opdracht 4: Make - Eigen endpoint

Maak een endpoint `/hobby` dat jouw favoriete hobby teruggeeft als JSON.

<details>
<summary>Tip</summary>

Je hebt een `@app.get("/hobby")` nodig met een functie die een dictionary returnt, bijvoorbeeld `{"hobby": "voetbal"}`.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.get("/hobby")
async def hobby():
    return {"hobby": "voetbal"}
```

</details>

### Opdracht 5: Make - Meerdere endpoints

Maak drie endpoints: `/eten`, `/muziek`, en `/game` die elk jouw favorieten teruggeven.

<details>
<summary>Tip</summary>

Maak voor elk endpoint een aparte functie met `@app.get(...)`. Geef elke functie een eigen naam, dan houd je ze uit elkaar.

</details>

<details>
<summary>Antwoord</summary>

```python
@app.get("/eten")
async def eten():
    return {"eten": "pizza"}

@app.get("/muziek")
async def muziek():
    return {"muziek": "pop"}

@app.get("/game")
async def game():
    return {"game": "Minecraft"}
```

</details>
