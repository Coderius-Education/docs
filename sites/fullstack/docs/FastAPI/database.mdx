## Data opslaan

Maak `test_db.py`:

<CodeUitleg>

```python showLineNumbers
from sqlitedict import SqliteDict

with SqliteDict("mijn_data.db") as db:
    db["naam"] = "Jan"
    db["leeftijd"] = 16
    db.commit()

print("Data opgeslagen!")
```

<Regel n={3}>
`with` opent de database uit het bestand `mijn_data.db` en sluit hem vanzelf weer na het ingesprongen blok. Bestaat het bestand nog niet, dan maakt SqliteDict het aan.
</Regel>

<Regel n={4} tot={5}>
Binnen het blok gedraagt `db` zich als een dictionary: een sleutel, een waarde.
</Regel>

<Regel n={6}>
`db.commit()` schrijft de wijzigingen echt naar het bestand. Zonder deze regel is de wijziging weg zodra het `with`-blok sluit, ook als je programma daarna nog doorloopt.
</Regel>

</CodeUitleg>

Draai `python test_db.py`. Daarna staat er een bestand `mijn_data.db` naast je programma.

## Data uitlezen

```python
from sqlitedict import SqliteDict

with SqliteDict("mijn_data.db") as db:
    print(db["naam"])      # Jan
    print(db["leeftijd"])  # 16
```

De data is er nog, zelfs na herstarten.

## Overzicht commando's

```python
with SqliteDict("data.db") as db:
    db["sleutel"] = "waarde"            # Opslaan
    waarde = db["sleutel"]              # Uitlezen
    del db["sleutel"]                   # Verwijderen
    db.commit()                         # Wijzigingen opslaan, niet vergeten

    for sleutel, waarde in db.items():  # Alles bekijken
        print(sleutel, waarde)

    if "sleutel" in db:                 # Checken of iets bestaat
        print("Bestaat")
```

<details>
<summary>Waarom is db.commit() nodig?</summary>

Een database slaat wijzigingen niet meteen op in het bestand. Met `db.commit()` zeg je: "Sla nu alles echt op." Als je dit vergeet, verdwijnen je wijzigingen zodra de database sluit, aan het eind van het `with`-blok. Vergelijk het met een Word-document: je moet op "Opslaan" klikken, anders ben je je werk kwijt.

</details>

:::danger[Gaat er iets mis?]
Is je data weg zodra je hem opnieuw opvraagt? Dan ben je waarschijnlijk `db.commit()` vergeten. Meer oplossingen staan op [Er gaat iets mis](/docs/troubleshooting).
:::

## Opdrachten

### Opdracht 1: Predict - Wat gebeurt er?

```python
from sqlitedict import SqliteDict

with SqliteDict("test.db") as db:
    db["score"] = 100
    db.commit()

with SqliteDict("test.db") as db:
    print(db["score"])
```

**Vraag:** Wat print dit?

<details>
<summary>Tip</summary>

`commit()` schrijft de data naar het bestand. Daarna opent het programma dat bestand opnieuw. Staat de data er dan nog?

</details>

<details>
<summary>Antwoord</summary>

`100`. De data staat in het bestand, want `db.commit()` heeft hem daar weggeschreven.

</details>

### Opdracht 2: Make - Eerste database

Maak een programma dat een contact met naam en telefoonnummer opslaat en weer uitleest. Werkt het?

<details>
<summary>Tip</summary>

Sla twee waarden op onder verschillende sleutels, bijvoorbeeld `db["naam"] = "Jan"` en `db["telefoon"] = "0612345678"`. Vergeet `db.commit()` niet.

</details>

<details>
<summary>Antwoord</summary>

```python
from sqlitedict import SqliteDict

with SqliteDict("contacten.db") as db:
    db["naam"] = "Jan"
    db["telefoon"] = "0612345678"
    db.commit()

with SqliteDict("contacten.db") as db:
    print(f"Naam: {db['naam']}")
    print(f"Telefoon: {db['telefoon']}")
```

</details>

### Opdracht 3: Investigate - Commit vergeten

Wat gebeurt er als je `db.commit()` vergeet? Probeer het uit.

<details>
<summary>Antwoord</summary>

De data komt niet in het bestand. Zodra het `with`-blok sluit, is de wijziging weg: open je de database daarna opnieuw, ook in hetzelfde programma, dan staat hij er niet meer in.

</details>

### Opdracht 4: Make - Favorieten opslaan

Maak een programma dat drie favorieten opslaat (eten, muziek, game) en ze daarna weer uitleest.

<details>
<summary>Tip</summary>

Gebruik drie sleutels: `db["eten"]`, `db["muziek"]`, `db["game"]`. Sla alles op met één `db.commit()` aan het eind.

</details>

<details>
<summary>Antwoord</summary>

```python
from sqlitedict import SqliteDict

with SqliteDict("favorieten.db") as db:
    db["eten"] = "pizza"
    db["muziek"] = "pop"
    db["game"] = "Minecraft"
    db.commit()

with SqliteDict("favorieten.db") as db:
    for sleutel, waarde in db.items():
        print(f"{sleutel}: {waarde}")
```

</details>
